## 三、跨章转职节奏（核心校准）

### 3.1 转职里程碑全局排布

| 阶段 | 门槛 | 达成时机 | 定位 |
|---|---|---|---|
| **一转** | 袈裟≥3 且 法杖≥3 | **章1达成** | 小里程碑 · 质变期 |
| **二转初** | 袈裟≥4 且 法杖≥4 | **章2达成** | 硬件小锚点 · 填补章2成长感 |
| **二转满** | 袈裟≥6 且 法杖≥6 | **章3达成** | 大目标 · 跨两条章累积 |
| **终转** | 6珠6石 + **复合条件**（法宝+六道+第80难剧情） | **章4固定，不可提前** | 善=旃檀功德佛 / 依道异名 / 逆=真·逆道 |

**校准原则**：
- **一转提前到章1（V51）为改进**——玩家第一章即有转职成就感，成长闭环闭合。
- **二转必须保持跨章累积**（6珠6石），作为长线钩子，**不能靠商店无脑堆满**。
- **二转分步 + 终转复合（V2）**：不新增 9 珠 9 石（坏六度语义、收集负担重），保持「六」体系，将 6 珠 6 石拆成 **3→4→6 三步梯度**；终转为复合触发（详见 §3.3）。

### 3.2 一转硬件（章1，V51 定稿）

- 定风珠（难13 黄风怪阻）+ 避水珠（难15 流沙难渡）+ **辟火珠（商店概率刷出，第3店兜底）**。
- 法杖三石：禅定（难8）/ 持戒（难12）/ 忍辱（难16），收徒必得。
- 双 3 齐 → 一转，质变期启动。

### 3.3 终转复合条件（V2 定稿）

**终转变「复合触发」而非纯堆数量**——硬件只是「资格」，法宝/六道/剧情才是「成佛」的仪式构成，避免玩家陷入「为凑数而苦工」：

```
终转 = 6珠6石（硬件达标·资格）
     + 特定法宝（如来金钵 / 通关文牒 等，对应取经终局）
     + 六道条件（善 → 旃檀功德佛 / 恶·逆 → 真·逆道 / 依道异名）
     + 第80难取经剧情（固定触发点，不可提前）
```

原则：与隐藏专职的复合触发逻辑（每章 §六）相呼应；demo 内仅作预告展示。

## 四、商店兜底机制：只给一转

**V51 的「第3店必刷」是章1专属**，不可复制到每章（否则二转过早达成）。

| 章 | 商店宝珠策略 |
|---|---|
| ① | **商店兜底**（保一转）：第1店30% / 第2店60% / 第3店必刷 |
| ②③ | 该章宝珠走**关键劫难固定获取**，商店出率压至15%，不设兜底 |
| ④ | 宝珠聚焦第80难终转，不再需要商店兜底 |

**结论**：商店随机+兜底只服务于「一转」这一关键节点，二转靠劫难自然推进，避免转职节奏被商店稀释。

## 五、时长口径：分清单章与完整周目

| 口径 | 时长 | 说明 |
|---|---|---|
| **单章（demo=章1）** | 60-90 分钟 | V51 定稿，动画占比≤20% |
| **完整周目** | 4 × 60-90 ≈ **4-6 小时** | 四章线性打通 |
| **二周目逆道** | 额外 +4-6 小时 | 逆道专属岔路 + 逆经 |

**节奏要求**：
- demo 若只做章1，60-90 分钟合理。
- 完整游戏"一局"是 4-6 小时长线单局，**单章必须支持分支路线独立重玩**（事件池 / 逆道），否则四章线性一次后重玩性不足。

## 六、隐藏专职的六道供给（每章一个主打道）

用户早期要求"每一章都能有专职"。唐僧每章一个隐藏职，但**触发依赖某道≥3**：

| 唐僧隐藏职 | 章 | 六道门槛 |
|---|---|---|
| 谤佛金蝉 | ① | 逆≥3（二周目） |
| 弃经者 | ② | 逆≥3 |
| 判官金蝉 | ③ | 隐≥3 |
| 金蝉了缘 | ④ | 缘≥3 |

**综合校验**：
- ③判官金蝉需「隐≥3」、④金蝉了缘需「缘≥3」——**事件池必须保证该章所需道有充足选项**。
- 章1评估显示：恶/夺仅3次、缘7次，供给不均。跨章同理，**每章需显式设计"该章主打道"的事件池偏向**，不能靠全局随机。

**设计原则**：每章事件池按"该章隐藏职所需道"做偏向加权，确保"每章有专职"不因选项不足而落空。

---

## 七、贪狼套跨章：章1只成3件（关键校准）

**V51 原定"章1贪狼4散件成型"。跨章校验发现冲突**：章1若做满4件，后续章贪狼散件成"锦上添花"，跨章累积无意义。

**校准**：
- **章1**：贪狼**3件共鸣**（共鸣最小档），第4件留到章2。
- **跨章**：第4件 + 后续章贪狼散件 + 六道属性 → 触发贪狼系隐藏转职。
- **目的**：让贪狼套的"收集成型"与"跨章转纵深"都有意义，避免"章1做满、跨章空转"。

> 这是"章1局部最优 vs 四章全局"最典型的冲突，需在章1设计文档 §3.1.2 中同步修正。

## 十、市场验证修正（V1 · 参照第一章市场评估）

> 依据《第一章 Demo 评估报告》市场前景结论（6.5/10：方向有潜力，高度依赖落地品质与内容厚度）。以下把市场风险映射为四章框架的具体设计修正。

### 10.1 定位确认：叙事型 roguelike，非纯数值 deckbuilder

| 市场风险 | 对四章框架的修正 |
|---|---|
| **品类竞争激烈**（杀戮尖塔/月圆之夜/小丑牌等，玩家爽感阈值高） | 不与头部纯数值拼深度，主打"暗黑西游再演绎 + 六道行为因果"；**每章一个 boss 机制记忆点**（章1 三化三尸已立），作为差异卖点 |
| **内容体量偏小**（单主角+25节点） | 单章紧凑，但**四章 + 多周目 + 逆道**总量须撑起买断定价（完整周目4-6h + 二周目+4-6h）；每章内容量不得再压缩 |
| **美术/演出未定 = 首要变量** | 将"暗黑西游视觉 + 叙事演出"提为**立项级支柱**，非后置；每章明确美术主题/风格基调（见10.3） |
| **暗黑题材尺度** | 明确叙事尺度边界：**求真/破道之善 vs 纯黑化**——逆道是"超越原著的至善"，非无脑黑化，避免口碑反噬（呼应 W3） |
| **单机买断冷启动** | **demo 先行策略**：章1 作为可独立验证的 demo 首发，验证市场反应再铺四章 |

### 10.2 情感差异化：六道叙事贯穿全四章

- **六道 = 行为人格**，每章一个"行为主题"作为叙事与市场卖点的双钩子：

| 章 | 行为主题 | 市场卖点 |
|---|---|---|
| ① | 渡/善/恶 的初辨 | 建立"你的每个选择都改变结局"承诺 |
| ② | 逆道暗线揭开 | 制造"二周目才能看清真相"的传播话题 |
| ③ | 隐/判官 因果权柄 | 深化"种因得果"的哲学纵深 |
| ④ | 缘/终局 命运收束 | 终转而归，情感升华 |

- **记忆点沉淀为社区传播**：章1 渡道系数削弱 boss、三化三尸、"念经克尸"终结，均为可安利的"名场面"，每章保留 1-2 个。

### 10.3 美术/演出立项级支柱（市场首要变量）

- **美术主风格已定稿（V1）**：**「暗墨 · 佛光」**——暗黑水墨为底 + 敦煌重彩高光。尘世泼墨枯笔冷色、佛性/逆道觉醒骤转鎏金朱砂。完整视觉规范见《逆道西行_美术风格设计.md》。
- **每章视觉基调**（暗黑水墨 + 差异化色调）：

| 章 | 视觉基调 |
|---|---|
| ① | 长安红尘 → 白骨荒原（暖→冷） |
| ② | 群魔乱世，暗金/煞气 |
| ③ | 因果轮回，青冥/幽冥 |
| ④ | 灵山金辉，庄严/超脱 |

- **演出优先级**：星级过场（序章/收徒/终局/章末）> 战斗演出 > 场景转场。市场评估已给"动画占比≤20%、单局60-90分钟"红线，演出贵精不贵多。

### 10.4 demo 先行验证策略

- **章1 = 垂直切片 demo**：验证「暗黑西游叙事 + 六道因果 + 转职闭环」三件事是否成立。
- **验证指标**：① 一转达成率（应接近100%，防断点）；② 多周目重开率（逆道钩子）；③ 章1通关后"想继续看章2"的意愿（叙事留存）。
- **若通过**：以章1为基准，逐章迭代铺开；若未通过，优先修叙事呈现与美术，而非加数值层。

### 10.5 市场前景修正后评级

- 加入四章整体框架 + demo 先行 + 美术立项后，**市场前景由 6.5 → 7.0/10**：叙事差异化与 demo 验证策略可对冲品类竞争与冷启动风险，但**美术落地仍是最大待验证变量**。
