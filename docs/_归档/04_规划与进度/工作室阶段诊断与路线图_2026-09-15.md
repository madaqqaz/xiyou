## 二、里程碑路线图（full 评审强度）


### 里程碑 M0 · 收口 P5 内容缺口（设计↔代码一致性）
- **目标**：把审计评分为 5/10 的「设计↔代码一致性」拉到闭环，消除三处根因级漂移。
- **负责成员**：`design-strategist`（决策）+ `engineering-lead`（落地）。
- **入口门控**：`node scripts/_run_all_gates.js` 全绿。
- **出口门控（PASS 条件）**：
  1. 结局三源统一为单一判定链（当前 `determineEnding` 10 → `computeEnding` 7 → `data_endings_cg` 6 → `data_endings_index` 20 已索引桥接，须确认无分叉回退）；
  2. 心魔双源决策落地（GDD 经文驱动 vs 代码六道驱动，已出 `docs/xinmo-single-source-decision_2026-09-14.md`，推荐 A 归档并桥接）；
  3. 哪吒/杨戬区域偏移修正（当前 +1，设计应为 1/3/6/9/12/15）。
- **已知风险**：内容评分「深度 4/10」是本轮重点，改数据须同步 `docs/逆道西行_开发文档.md`（AGENTS.md §五）。

### 里程碑 M1 · 正式 P6 打磨 pass
- **目标**：首次正式打磨，覆盖 Playtest / 性能 / 资产 / 音频四线。
- **负责成员**：`quality-lead`（≥3 轮 Playtest + 回归）、`engineering-lead`（性能剖析）、`art-director`（资产审计）、`audio-director`（音频打磨）。
- **入口门控**：M0 PASS + 门禁全绿。
- **出口门控（PASS 条件）**：
  1. Playtest ≥3 轮、关键屏（起始/地图/战斗/叙事/结算/商店）无阻断；
  2. 移动端性能剖析达标（图片压缩、DOM 操作精简，尤其微信内置浏览器）；
  3. 资产审计清掉 **AI 生成水印**（`portraits/npcs/` 存量带水印，含已接入 `npc_shaseng_liushahe`/`npc_jiangliuer`；`img/ui/dao_*.jpg` 亦带）；
  4. 音频回退链（`js/sound.js` 已修）全场景无静音死角。
- **已知风险**：打磨可能暴露新阻断，回灌 M0 或 M2。

### 里程碑 M2 · P7 发布准备门控（Release-Readiness）
- **目标**：清掉上架阻断项，产出发布清单 + 补丁说明，拿到 QA 签字。
- **负责成员**：`release-ops-lead`（发布清单/构建/本地化/回滚）+ `quality-lead`（最终 QA 门控）+ `design-strategist`（合规文案）。
- **入口门控**：M1 PASS。
- **出口门控（PASS 条件）**：见第四节阻断项全部 CONCERNS→PASS。
- **已知风险**：三端同步上线硬约束（AGENTS.md §七·五），任一端阻断 = 整体阻断。

### 里程碑 M3 · 三端上线
- **负责成员**：`release-ops-lead`。
- **出口门控**：三端（浏览器 H5 / 微信小游戏 / TapTap 买断）构建可安装、隐私合规、回滚预案就绪。

- 门禁 `node scripts/_run_all_gates.js`：基准 **31/31 / worst=0**；任何里程碑改动后须保持全绿。
