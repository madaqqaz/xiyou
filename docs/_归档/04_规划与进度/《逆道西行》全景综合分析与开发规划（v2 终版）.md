# 一、游戏全新介绍（产品定义）

## 1.1 一句话定位

> 《逆道西行》是一款**黑暗西游题材的单局 Roguelike 构筑游戏**：你不是去取经的，你是去**拆经的**——取经是献祭，真经是锁，灵山是笼。
>
> **v2 补充定位（双形态）**：完整局 = 17 地区 · 81 难 · 8–12 小时的 TapTap 买断主体验；短局 = 单地区 · 4–5 难 · **数分钟一局**的小游戏主体验。同一套构筑系统、同一张世界地图、两个时长档位——**短局不是「砍内容」，而是「换目标」：完整局的目标是功成西行，短局的目标是在有限地区里把 Build 打到最强。**

## 1.5 差异化卖点（相对竞品的护城河）

1. **叙事解构的深度**：81 难全部重写暗面，且「渡/逆」双经文线真正改变结局——这在肉鸽品类里是**罕见的叙事权重**。
2. **六道作为构筑主轴**：战/渡/缘/夺/隐/逆 六道既是数值轴（`SEAL_DAO_BREAKPOINTS` 3/6/9/12 层阶段加成）又是叙事轴（音频共振、地区配额），**机制与叙事同源**；v2 起**词汇已归一**（佛经侧改名「六藏」，六道一词一义）。
3. **双形态时长**（新增护城河）：数分钟短局与 8–12 小时完整局共享构筑深度——竞品里《无限轮回》只有短、《杀戮尖塔》只有长，**两者兼得且同源的产品在赛道内暂无**。
4. **零依赖 file:// 直跑**：三端一致性极高，无构建即无构建失败——这在长期维护上是**真实优势**。
5. **自适应音频引擎自研**：17 区域音景 + 25 Boss 动机变体 + 四轴 RTPC + **M15 长曲式四声部**，零外部音频资产（避开 `file://` fetch 墙），**在同类小游戏里几乎没有对手**。

## 2.3 探针口径声明（避免重复踩坑）

按 `NDX.<大写常量>` 名匹配会漏掉**小写命名空间**系统（`Daily`/`Cultivation`/`Exploration`/`LoopEnhance`/`SaveSystem`/`DaoSystem`/`audio`），❌ **不等于系统缺失**。历史误报两次教训（09-08 误报 60 件法宝全死，实为 6 件；09-09 误判 H6 路径与 H7 前提）已沉淀为**前提三查**方法论：

> **提案落地前必须先跑「前提三查」**：
> ① 目标函数**有没有人调用**（防对着孤儿函数造轮子）；
> ② 该功能**是不是已经存在**（防重复实现）；

## 4.1 核心循环（地区/难度/轮回/短局）

### 实现事实
- `data_region_config.js` 唯一真源：17 地区、`TOTAL_TRIALS=81`、`MAX_COL=4`、每层 3-4 节点。
- 四档难度（data_config.js V8.40）+ `scaleRunMods` 逆道/渡道即时调压 0.55~1.6。
- 死亡 → `buildDeathReview` 归因复盘；轮回 = 劫印传承（引渡匣，法宝不传承）+ 轮回赐福。
- 地图为杀戮尖塔式网状分叉：`_genBranchCols` 每层 3-4 节点、1-2 条出边、列差≤1、孤岛修复；末层 Boss 单列汇聚。
- **存档勘误（v2 重要更正）**：09-05 基线曾记「仅整局存档」——实际 `autoSave()`（`game_meta.js:264`）自 **V8.35** 起在每个节点结算后（`game_core_2.js:839`）与每场战斗胜利后（`game_combat_2.js:153`）落盘 `NDX.storage.KEYS.RUN`，`restoreRun()`/`hasRunSave()` 支撑「继续西行」断点续玩。**节点级 autosave 早已存在**，S3 规划据此撤销该项（前提三查命中）。

### 设计分析
- 优点：真源单一、调压有 clamp、死亡有归因、轮回传承有明确「什么带得走」的边界（V8.60 起法宝不传承，防止滚雪球）。
- 结构性短板：地图拓扑过窄——每层最多 4 节点 4 列，**商店全局限主线 2 处**，rest 每区仅 0.5-1 个。尖塔的 SL 策略空间建立在「路线规划有真实取舍」上，本作分叉少+关键节点稀缺，路线选择的策略价值有限，多数局走同构路线。
- **短局对循环的改造（v2 新增）**：短局不是「砍内容」而是「换目标」——完整局目标是功成西行（叙事驱动），短局目标是把 Build 打到最强（构筑驱动）。两者共享世界地图与构筑系统，meta 层（`RunMode.clears` → `LoopEnhance`/`Exploration`）使短局失败也有积累，形成独立小闭环。

### 竞品对比
- 《杀戮尖塔》Ascension 1–20 是「同一局变难」，本作短局是「同一世界变短」——后者更接近《Hades》的「每次逃亡都是一局」结构，与 roguelite 单局制天然契合。
- 《无限轮回》3–5 分钟单局 + 避难所经营兜底；本作短局 + meta 记录（地区通关次数/战绩卡分享）是对同一问题的不同解法。

### 改进措施
1. 节点池扩大商品/休整密度（mob 40% → 35%，shop/rest +5%），或把商店改造成「可重刷的坊市节点」（花劫灰重置货架一次），给金币第二条消费出口。
2. 末段地区（15-17）允许 5 列分叉，制造「绕路拿资源 vs 直奔 Boss」的尖塔式决策。
3. **短局断点续玩宣传位**：标题屏「继续西行」按钮已有，需在短局模式下同步可用并在结算屏提示（当前 `autoSave` 全局通用，短局继承无额外工作，仅缺 UI 提示）。

## 4.2 战斗系统 🔄（B+ 落地后重述）

### 实现事实（含公式）
- **聚合顺序**：`playerBaseAt(diff)` → 装备平铺（hit 封顶 1）→ 佛经 → 随从 → 劫印（按当前值乘算 + 道心 `sealDaoMod`/本命道 `HOME_DAO_MULT` 双乘）→ 转职乘算 → 套装共鸣乘区 → 封顶：hp≤baseHp×4、dr≤0.85、mdef≤0.85、eva≤0.6。
- **战力公式**：`atk + matk×0.8 + maxHp×0.12 + dr×1500 + mdef×1500 + eva×800 + cri×700 + criMult×120 + 命痕数×60`。
- **伤害**：普攻 `atk×(1+atkB)×克制×(1-effMDr)`，怪物 dr 默认 0.20；终乘 `GLOBAL_DMG_MUL=0.5`；暴击默认 ×1.6。
- **动态校准双轨（v2 权威口径）**：
  - 血量侧（方案 A，V8.58 已有）：`m.hp = _targetRounds × _baseDpr × _growthMul`，`_growthMul = _atkGrowth^(-0.35)` —— atk 300→3000 回合 2.65→1.38（−48%），**攻击向成长单调可感**。
  - 威胁侧（方案 B+，**v2 已落地**，`data_config.js`）：`scale = clamp(raw^γ, 0.5, 1.5)`，γ=0.45 可热调（`NDX.BALANCE.threatGamma`）—— 净承伤 ∝ `threatCur^(1-γ)`，**死区消除**。
- **气势**：命中+1 封顶 5；层级阈值 [0,1,3,5]，爆发倍率 [0, 0.6, 1.0, 1.5]×双攻和，克制命中再 ×1.5；受击 >15%maxHp 掉 1 势。
- **识破**：仅 telegraph 回合可触发；格挡+反制双攻×0.8（克制 ×1.5）+奖 2 势。QTE 窗口：小怪 2000ms / Boss 2500ms。
- **Combo**：每 3 次必暴；3/6/9 连击升档 ×1.5/1.8/2.2；搓招奥义 `[atk,atk,chant]` ×2.5。
- **战斗分片**：`combat_calc/combo/debuff/effect/intervention/narrative/skills` 七分片已拆，`combat.js` 仍 86KB 未拆完。

### 结论 2：题材踩中风口，微恐分寸对标《无限轮回》

#### 8.2.1 S2-5 短局调参核验小结（2026-09-10）

用 headless 探针 `_audit_s2_shortcalib.js` 对 17 地区 × 3 战斗类型（共 51 组）跑真实 `buildMatchFight` 势均采样，结论如下：

- **代码层完成率保证成立**：所有组 `pressure` 恒钳 `[0.25,0.90]`、`scale` 恒钳 `[0.5,1.5]`，必死局占比≈0（设计上首局「有解」）。探针 5/0 全绿。
- **真问题——高地区短局逼近红线**：`pressure` 随地区单调上升（地区 1 ≈0.54 → 地区 16/17 ≈0.84–0.88）。短局 `startAct:'random'` 若抽到 16/17，裸装新手承伤余量极薄，是「首局完成率 ≥85%」的真实风险点。
- **Boss scale 恒钳 0.50 下界**：boss 原始 `atk/matk` 相对承伤预算偏高，被校准压到最低 0.5；而 mob/elite 在 1.2–1.4。建议复核 boss 基础属性是否过激进。

**调参旋钮（若真机发现首局完成率不足，按序尝试，均不改动全程难度）**：
1. 短局 `startAct` 随机范围收窄至 `[1,10]`（避开高压尾区）；
2. 短局专属 `pressureFactor` 下调至 `0.45–0.50`（normal 为 0.56），给裸装更多承伤余量；
3. `NDX.BALANCE.threatGamma` 维持 `0.45`（B+ 幂律已平滑防御收益，勿回退）。

> 注：本核验为「设计保证」级，非真人胜率；单局 4–6 分钟、断点续玩≥99% 仍须真机验收（后者由全程 `autoSave` 机制保证，S3 已验证）。
