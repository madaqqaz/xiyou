### A.3 【阻断级发现】三键气泡教学战在真实首局被绕过

**现象**：全新开局点首节点「江流儿劫」，直接进入六道抉择（`kind=trial, teach=sixdao`），**从未出现 `kind=tutorial-intro` 的「⚔ 迎战接引使者」教学战**，因此攻击/诵经/绝招逐回合气泡（`p.teach==='tutorial'` 分支，`ui_panel_1.js` 三键高亮逻辑）永远不会在新玩家首局触发。

**根因（已定位到行）**：
- 首节点「江流儿劫」是**复合节点**，进入时走 `NDX.Game.prototype._compoundTrial`（`js/game/game_event_1.js:252`），而非 `game_core_2.js` 的 `case 'trial'` 分支。
- 该函数 `game_event_1.js:282` 注释明确写道："V8.5x 新手指引重构：难1战后六道教学（**复合节点内同样移除接引使者教学战**）"。
- 因此唯一会设置 `kind:'tutorial-intro'` 的门控 `game_core_2.js:467`（`assigned===1 && !s._tutorialFought`）对首局复合节点**不可达**——这是 V8.5x 的**有意移除**，不是笔误。
- 探针佐证：开局后 `s._tutorialFought===undefined`、`taught={}`，进节点后 `kind=trial/teach=sixdao`、无 `tutorial-fight` 按钮、`sixdaoSelect` 未由教学块设置（走 `trials81.js:19` 数据自带）。

**处理结论（按宪法 §十五停止并上报，不擅自复活）**：
- 任务预期"三键气泡在正确时机弹出"，与当前代码"有意移除教学战"存在设计冲突。
- 复活需改核心流程（在 `_compoundTrial` 内重新挂 `tutorial-intro` / `tutorialResume` 恢复链），触及核心战斗入口，且会推翻 V8.5x 重构决策。
- **本轮不改**，列为待用户决策项：是接受"无逐回合三键气泡、仅靠实战主键高亮引导"，还是在复合节点内恢复接引使者教学战。
