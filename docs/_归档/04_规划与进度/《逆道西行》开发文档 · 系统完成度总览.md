# 《逆道西行》开发文档 · 系统完成度总览

> 生成日期：2026-09-07（P0–P2 十项整改全部收口后）
> 数据口径：运行时快照 + 36 个无头门禁实证，非设计稿推断。**代码为真源**——本文与设计文档冲突时以代码为准。

---

## 一、项目概况

| 项 | 内容 |
|---|---|
| 品类 | 暗黑西游题材回合制 Roguelike 构筑（RPG 内核 + 动作化演出层 + 肉鸽随机性） |
| 技术栈 | 纯前端原生 JS/CSS，零构建零依赖；全局单例 `NDX`；`index.html` 按序加载 + `?v=NN` 缓存戳 |
| 运行环境 | 浏览器直开 `index.html`；Node 仅用于无头门禁（模拟 window/localStorage 引导全量逻辑层） |
| 核心架构 | 体/愿双伤害体系 · 命运/劫印多轴构筑 · 渡逆双经文线 · 法宝克制 · 二周目轮回 |

## 二、工程结构（2026-09-05 拆分后）

```
index.html          # 加载序：data_* → combat → audio → game.js → game/*(23 shard) → ui.js → ui/*(16 shard) → main.js
js/data_*.js        # 数据层：英雄/敌人/装备/经文/事件/结局/立绘
js/combat.js        # 战斗结算引擎（含 GLOBAL_DMG_MUL、PDEBUFF、_BOSS_DEBUFF_MAP、cfx 连招）
js/game/*.js        # 23 shard，167 个 Game.prototype 方法（流程/战斗/成长/论道/遥测接入）
js/ui/*.js          # 16 shard，147 个 ui 方法（面板/浮层/FX/论道 UI）
js/audio/           # 三层音频：引擎 + 配置 + 桥接
js/main.js          # 回合演出编排（_emitBattleFx）、输入派发、Canvas 战斗桥接
css/style.css       # ~15k 行暗墨国画风格
scripts/            # 36 个无头门禁 + 工具（密度审计/乱码还原/遥测分析）
```
