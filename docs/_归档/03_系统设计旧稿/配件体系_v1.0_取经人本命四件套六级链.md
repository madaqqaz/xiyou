## 〇、口径确认（须拍板）

用户原话：「唐僧的袈裟为初始套装不动，黑熊精的袈裟设定为其他角色夺取，可做特殊武器，飞龙宝杖同理，可以做法杖，同唐僧的法杖僧袍一同升级。设定为将黑熊精的袈裟融入唐僧的袈裟，袈裟加属性，飞龙宝杖融入唐僧法杖加属性。如果可以甚至可以为唐僧设定出一套四件带六配件的三级物品，并作为一套终极套装。」

## 一、设计目标

1. **四件套对齐**：取经人四件（法杖/僧袍/僧冠/僧履）各成一条 **6 级链**，与现有法杖、僧袍同构。
2. **配件可融合**：外来之宝（黑熊精袈裟、飞龙宝杖）可**主动融入**本命件，属性永久叠加——形成「夺来 → 融入」的成长闭环。
3. **三级收口**：每件以 `setTier 3`（第二章 ch4 级）为终极档，四件齐 + 六配件齐 → 激活**取经人终极套装**隐藏职。
4. **跨英雄复用**：非唐僧线时，同一件外物转为 weapon 槽「特殊武器/法杖」形态，不浪费素材。

## 四·五、获取线：24 个落点全走【渡】（2026-09-18 拍板）

### 4.5.1 口径（已定）

用户原话：「你再补充两件装备，需要 24 个选项进行补充，原来的设计是全部走缘，导致缘数量不足……
是不是把这 24 个配件全部改为渡路线赠送。即走渡是西游正统路线，即官方推荐玩法。」

| 项 | 决定 |
|---|---|
| 24 个装备落点的道归属 | **全部挂【渡】** |
| 缘路线 | 保留少量「人物相赠」类装备点（现有 2 处不动），其余腾出容量改投随从/羁绊 |
| 六宝石 | **六颗各自是独立法宝**，可单独使用；与僧袍升级不冲突（集珠升袍 ≠ 珠被消耗独占） |
| 数值 | 本轮不动，只定获取线与道归属 |

### 4.5.2 为什么走渡成立（四条依据）

**① 代码原设计就已经这么写了。** `js/data_equip_core.js:27` 的 `NDX.SET_DAO` 明确：

```javascript
NDX.SET_DAO = { 破军:'战', 悟空:'战', 黑风:'战', 狮驼:'夺', 沙僧:'夺',
                取经人:'渡', 玄武:'渡', 凌云:'渡', 八戒:'缘', 贪狼:'缘',
                龙马:'隐', 影遁:'隐', 逆命:'逆', ... };
```

注释写明这是「套装 / 劫印 / 隐藏职 / 宠物 共用「战渡缘夺隐逆」一套语言」。
**`取经人` 本来就标着 `渡`** —— 走缘才是偏离。

**② 语义。** 渡 = 求告神佛、归位超度 → **上级赐予**。取经人四件套的来源本就是「观音所赠」「唐王所赐」。
赐予即渡的语义域；缘的语义是「人情羁绊」，产出应是随从/关系，不是装备。

**③ 容量。** `NDX.TRIAL_LIB` 81 难 312 选项实测：

| 道 | 覆盖难数 | 占比 |
|---|---|---|
| **渡** | **80** | 98.8% |
| 逆 | 73 | 90% |
| 战 | 59 | 73% |
| 夺 | 35 | 43% |
| 隐 | 33 | 41% |
| **缘** | **32** | **40%** |

24 点挂缘 = 占缘 75%；挂渡 = 占渡 30%。

**④ 缘的实证问题：走缘根本走不通。** 32 个缘选项中 **14 个是纯 `ti.hp` 填充**（hp 47→147 随章递增、零剧情），
仅 3 处有实义（`ally` 难8 许悟空自由 / `rel` 难16·19 / `equipPick` 难5·难63）。
缘的格子本就在用血量撑场面 —— **装备装不进缘是语义错位，不是容量不足**。

### 4.5.3 坐标：六级链对应「四程制」，不是九章制

`data_equip_core.js:16-17` 定义装备侧的 `chapter`：**初程 难1-20 / 中程 难21-40 / 乱程 难41-60 / 终程 难61-81**。
故六级链的天然落位是：

| 级 | 落程 |
|---|---|
| 凡 | 序章（初始馈赠） |
| 胚 | 初程 |
| 成品 | 初程 |
| 第 4 级 | 中程 |
| 第 5 级 | 乱程 |
| 第 6 级（终极） | 终程 |

四件 × 六级 = **24 个落点**；分布 初程 12（含 4 个初始馈赠）/ 中程 4 / 乱程 4 / 终程 4。

## 五、`fuse` 吞噬接口设计

### 5.1 数据结构

```javascript
// 新增：融合表（本命件 ← 可融入物）
NDX.FUSE_RECIPES = {
  // target 本命件 id : { srcId: { 属性增量, flag } }
```

### 5.2 接口签名

```javascript
// 吞融入：src 从背包移除，属性永久并入 target（可叠层）
// 返回 { ok, target, added } 或 { ok:false, reason }
NDX.fuseEquip = function (s, targetId, srcId) {
  const t = (s.equips || []).find((e) => e.id === targetId);
  if (!t) return { ok: false, reason: 'target-not-held' };
  const recipe = (NDX.FUSE_RECIPES || {})[targetId] || {};
  const add = recipe[srcId];
  if (!add) return { ok: false, reason: 'not-fusable' };
  const idx = (s.equips || []).findIndex((e) => e.id === srcId);
  if (idx < 0) return { ok: false, reason: 'src-not-held' };
  s.equips.splice(idx, 1);                        // 吞噬源物
  t.fuse = t.fuse || {};
  t.fuse[srcId] = Object.assign({}, add);         // 记账（可叠层，同 id 不重复）
  return { ok: true, target: t, added: add };
};

// 查询某件可融入什么（供 UI 列表）
NDX.fuseOptionsFor = function (s, targetId) { /* ... */ };
```

### 5.3 结算接入

`attr_calc.js` 装备汇总处，遍历 `eq.fuse` 累加增量（与 `stackable` 同层）：

```javascript
// 伪码：装备属性汇总时
if (eq.fuse) {
  Object.keys(eq.fuse).forEach((k) => {
    const f = eq.fuse[k];
    if (f.hp)   ti.maxHp += f.hp;
    if (f.dr)   ti.dr += f.dr;
    if (f.matk) yuan.matk += f.matk;
    if (f.mdef) yuan.mdef += f.mdef;
    if (f.eva)  ti.eva += f.eva;
  });
}
```

### 5.4 UI 入口

- 位置建议：**歇脚点 / 坊市** 的「铸器」页新增「融合」页签（与合成并列）。
- 列表逻辑：列出背包中「可作为融合源」的物 → 选中 → 选目标本命件 → 确认。
- 提示文案复用现有 `setProgressHint` 风格：`【锦襕袈裟】可融入：黑熊精袈裟（血+60 减伤+4%）`。

### 5.5 与 `TREASURE_EVO` 的分工（避免双机制打架）

| 机制 | 触发 | 形态 | 用在哪 |
|---|---|---|---|
| `TREASURE_EVO` | 被动（持宝 + 道数达标） | 同件变身 | 至宝（金刚琢/芭蕉扇等） |
| **`fuse`（新）** | 主动（玩家点选） | 属性并入他件，源物消失 | 本命件（黑熊精袈裟→袍、飞龙宝杖→杖、六宝石→四件） |

> **分界原则**：**至宝进化走 evo（被动），本命件融合走 fuse（主动）**。同一件物不得同时挂两套。

## 六、剧情挂钩（原著依据）

### 6.1 黑熊精的袈裟 → 融入唐僧僧袍 ✓ 完全成立

- **原著**：第 16–17 回，观音院金池长老欲烧死唐僧夺锦襕袈裟 → 悟空借辟火罩 → 火烧观音院 → **黑熊精趁火偷走锦襕袈裟** → 观音收黑熊精为守山大神，袈裟归唐僧。
- **判断**：**黑熊精偷的就是唐僧的锦襕袈裟**。所以"融入唐僧袈裟"不是拼凑，是**物归原主**——比现在代码里 `tre_nishang`（锦襕袈裟·夺）的至宝 evo 处理更贴原著。
- **建议**：`tre_nishang` 保持至宝身份（其他角色/夺道可用），额外开一条 fuse 通道，**唐僧线可把它融回本命袍**。

### 6.2 飞龙宝杖 → 融入唐僧法杖 ⚠ 有归属冲突（见 D4）

| 来源 | 说法 |
|---|---|
| v1.0 特殊装备文档 §5.6 | **灵吉菩萨**的法宝，第 11–13 难·黄风岭夺路线，可收黄风怪 |
| 代码 `equipment_part1.js:380` | 「**龙宫镇海之杖**」，`dao:'缘'`，`chapter:4`，被动「驯龙压下（减速）」 |

→ 两处归属不一致，须拍板（D4）。

### 6.3 其他角色夺取可做特殊武器

- **机制**：`tre_nishang` / `feilong_zhang` 保留 `slot:'treasure'` 身份；新增跨英雄分支——非唐僧角色持有时，以 `weapon` 槽「特殊形态」出现（补 `atk`/`matk`）。
- **实现建议**：不改原条目 `slot`（会破坏法宝体系），改为**新增平行条目** `tre_nishang_blade`（slot:'weapon'）+ 在授予处按 `s.hero` 分流。
