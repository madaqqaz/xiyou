# 逆道西行 · 地区配额制与两界山落地设计

> 版本：V1.0（2026-08-27）
> 状态：设计蓝图（待实现）
> 定位：解决"低分支节点树"的两大缺陷 —— ①拓扑路径丧失（肉鸽选择性不足）②六道空转（选夺想多刷怪却实现不了）
> 配套文档：`逆道西行_主线节点树设计.md`（低分支版，本设计为其替代/升级）

---

## 第一部分：设计总纲

### 一、核心问题回顾

| 原问题 | 具体表现 |
|--------|---------|
| 拓扑路径丧失 | 每难固定"启→拦→抉→守→劫"5节拍，玩家只能单线推进，没有杀戮尖塔式路线选择 |
| 六道空转 | 六道只是抉择倾向，选了"夺"想多刷精英多拿装备，但固定节拍只给1场拦路+1场守关 |
| 无长线目标 | 玩家缺乏"为了凑够条件"而主动规划路线的策略动机 |

### 二、设计总纲

**核心一句话**：以**地区为总量单位**，玩家在地区内自由选路推进小劫难，满足**六道配额**（任选一道主攻+替代路径）后解锁地区最终Boss；劫印直接给（劫难融合节点提高品质），战斗只掉装备，经文成为渡/逆两道的专属成长曲线。

**三条原则**：
1. **六道 = 偏好加权，不是路线锁定**——玩家可以全选渡，然后照样打小怪精英（战斗给装备）
2. **配额 = 最低门槛 + 替代路径**——主攻道决定"最少做什么"，替代路径防卡死
3. **劫难融合 = 2-3小劫难合成1大节点**——减少节点数、提高劫印品质、直接给不用碎片

## 第二部分：地区配额制架构

### 一、结构总览

```
【地区入口】→ 小劫难群（3-5个，融合节点）→ 中间节点（缩短）→ 【地区Boss】（配额满足后刷新）
```

- **第一章（大唐境内）**：保持线性教学，不引入配额制
- **第二章起（两界山）**：引入地区配额制，玩家开始自由选路
- **17地区**：每地区一个配额池，满足后解锁该地区最终Boss

### 二、地区节点构成（以两界山为例）

两界山 = act 2，难5-9，5层。实际道选项分布（代码实查 `trials81.js`）：

| 难 | 名称 | 类型 | 道选项 |
|----|------|------|--------|
| 5 | 出城逢虎 | 战斗 | 战（双人杀虎）/ 渡（放虎归山）/ 缘（伯钦赠刀） |
| 6 | 落坑折从 | 事件 | 逆（不信老者）/ 渡（收尸立碑）/ 缘（受指引） |
| 7 | 双叉岭上 | 战斗 | 战（斩残魂）/ 渡（听名字）/ 隐（绕行） |
| 8 | 两界山头 | 剧情 | 渡（立约同行）/ 逆（保命条件）/ 缘（许自由） |
| 9 | 两界山·鹰愁涧 | 战斗 | 战（降龙）/ 渡（点化）/ 缘（放归） |

**融合为3-4个大节点 + 中间节点 + Boss**：

```
【两界山入口】
   ↓
【融合节点1 = 难5+6】出城逢虎·落坑折从
   （战斗 → 抉择，完成给 蓝劫3选1）
   ↓
【融合节点2 = 难7】双叉岭上
   （战斗，完成给 蓝劫3选1）
   ↓
【融合节点3 = 难8】两界山头收悟空
   （剧情+抉择，完成给 金劫3选1）
   ↓
【中间节点】土地庙（休息）/ 商店（可选，缩短）
   ↓
【地区Boss = 难9】鹰愁涧白龙（配额满足后解锁，给 金劫+金装）
```

### 三、地区Boss配额锁

- **未满足配额**：Boss节点锁定（显示"配额未满"），玩家继续在小劫难群/中间节点探索
- **满足配额**：Boss节点解锁刷新，可进入战斗
- **超额奖励**：超过最低门槛越多，Boss掉落品质越高（+1档/每50%超额）

## 第三部分：六道配额设计

### 一、核心逻辑：偏好加权，非路线锁定

**玩家进入地区时选择一道作为"主攻道"（也可不选=自由混合）**，该道影响：
1. **劫印池加权**：主攻道劫印出现率×2，其他道正常
2. **最低配额门槛**：主攻道决定"最少做什么"才能解锁Boss
3. **但玩家仍可自由做其他事**：选渡也可以打所有战斗，只是门槛偏向事件

**经文成为渡/逆的专属成长曲线**（代码已支持）：
- 渡道：渡经（16部全本）→ 诵经·禅光（法伤持续增益）→ 血多法伤路线
- 逆道：逆经（9部全本）→ 戾骨献祭（重创+清势）→ 高攻暴击反伤路线

### 二、两界山六道配额表（替代路径）

**以两界山地区规模（3-4融合节点）设计**，满足**任一**即解锁Boss：

| 道 | 主路径 | 替代路径 | 两界山可行性 |
|----|--------|----------|-------------|
| **战** | 战斗≥2场 | 无 | ✅ 融合节点1/2/4都是战斗 |
| **渡** | 抉择选渡≥3次 | **诵经次数≥3次 或 渡经全本≥1部** | ✅ 5难全覆盖渡选项 |
| **缘** | 抉择选缘≥2次 + 消费≥1次 | 休息≥2次 | ✅ 4难有缘选项 |
| **夺** | 战斗≥2场 + 装备≥2件 | 精英≥1场 | ⚠️ 无夺选项，靠战斗+装备替代 |
| **隐** | 抉择选隐≥1次 + 战斗≥1场 | 闪避累计≥5次 | ✅ 难7有隐选项 |
| **逆** | 抉择选逆≥1次 + 战斗≥1场 | **心魔≥5 或 逆经碎片≥3** | ✅ 难6/8有逆选项 |

### 三、配额计数规则（融合后按节点计）

| 节点类型 | 战 | 夺 | 渡 | 缘 | 隐 | 逆 |
|----------|----|----|----|----|----|----|
| 战斗节点 | +1 | +1(若精英) | 0 | 0 | 战斗中闪避 | 0 |
| 事件/抉择节点 | 0 | 0 | +1 | 0 | 0 | 抉择选逆+1 |
| 剧情节点 | 0 | 0 | +1 | 0 | 0 | 0 |
| 休息/商店 | 0 | 0 | 0 | +1消费/休息 | 0 | 0 |
| 诵经（战斗内） | 0 | 0 | +1 | 0 | 0 | 0 |
| 心魔增长 | 0 | 0 | 0 | 0 | 0 | +1 |

### 四、跨地区配额递增

| 地区档位 | 覆盖地区 | 战 | 夺 | 渡 | 缘 | 隐 | 逆 |
|----------|----------|----|----|----|----|----|----|
| 初级 | 2-5章 | 战斗≥2 | 装备≥2 | 渡≥3 | 消费≥1 | 隐≥1 | 逆≥1 |
| 中级 | 6-11章 | 战斗≥3 | 装备≥3 | 渡≥4 | 消费≥2 | 隐≥2 | 逆≥2 |
| 高级 | 12-17章 | 战斗≥4 | 装备≥4 | 渡≥5 | 消费≥3 | 隐≥3 | 逆≥3 |

> 注：数值随地区内实际节点数动态校准，原则是"该道主攻玩家正常打能超额完成，其他道玩家换主攻也能达成"。

## 第四部分：劫印机制（直接给，融合提高品质）

### 一、劫印获取新规则

| 获取渠道 | 旧规则 | 新规则 |
|----------|--------|--------|
| 小怪战 | 白劫3选1 | **不再给劫印，只掉装备** |
| 精英 | 蓝劫3选1 | **不再给劫印，只掉装备** |
| 小劫难（融合节点） | - | **完成给劫印3选1**（品质按融合规模：单难融合=白/蓝，双难融合=蓝/金） |
| 地区Boss | 金劫3选1 | **给金劫3选1 + 金装** |
| 劫难融合大节点 | - | 直接给高品质劫印（如难8两界山头收悟空=金劫） |

### 二、为什么直接给不用碎片

- **81难实际有劫难融合**：2-3个小劫难融合成1个大节点，节点数减少
- **融合后劫印品质提高**：单难=白/蓝，融合=蓝/金，大节点=金
- **碎片合成增加操作负担**：每次获取都要点多次，破坏"打完即得"的爽感
- **劫印是路线加强**：直接给才能让玩家感受到"我的选择带来了什么"

### 三、劫印池加权（主攻道影响）

```
进入地区选择主攻道后：
  主攻道劫印出现率 ×2
  其他道劫印正常
  （如选渡 → 渡道劫印（法伤/血/防）出现率×2，配合渡经走血多法伤路线）
```

### 一、装备体系支撑（代码实查 `equipment.js`）

| 维度 | 现状 | 支撑性 |
|------|------|--------|
| 装备总数 | 356个id | ✅ 充足 |
| 部位 | 兵刃/甲胄/头冠/战靴/法宝/宠物 | ✅ 6部位 |
| 品质 | 白/蓝/金/红 | ✅ 完整 |
| 套装 | 破军/玄武/贪狼/唐僧/悟空/八戒/龙马/沙僧/黑风/狮驼/凌云/御兽 | ✅ 12套装 |
| 获取 | 战斗掉落/商店/Boss/合成 | ✅ 多渠道 |

**战斗作为主要装备渠道完全可行**：普通战斗掉白装、精英掉蓝装、Boss掉金/红装。

### 二、道途装备倾向

| 道途 | 装备倾向 | 对应部位/套装 |
|------|----------|--------------|
| 渡 | 法伤/气血/御念 | 法宝、僧袍（唐僧套/沙僧套） |
| 战 | 物攻/暴击 | 兵刃、甲胄（破军/悟空套/黑风套） |
| 缘 | 减伤/法防 | 甲胄、头冠（玄武套/狮驼套） |
| 夺 | 气血/吸血 | 甲胄、法宝（八戒套） |
| 隐 | 闪避/身法 | 头冠、战靴（龙马套） |
| 逆 | 反伤/气血 | 任意部位 |

### 三、经文系统（代码实查 `data.js`/`combat.js`）

**渡道经文（16部全本）**：
- 获取：渡道抉择 / 篝火 / 劫难掉落 → 碎片 → 全本
- 诵经加成：每部 +1.5% 诵经（大悲咒/阿弥陀 5%）
- 诵经主动技：禅光加持（法伤持续增益，CD 2）
- 全本被动：16部不同加成（血/法伤/减伤/暴击等）

**逆道经文（9部全本）**：
- 获取：选逆道 / 心魔事件 → 碎片 → 3段合成
- 诵经加成：每部 +10%（逆天录额外+50%）
- 诵经主动技：戾骨献祭（重创+清势，CD 6）
- 全本被动：攻/血/暴/防（齐天残卷/逆天录等）

**渡/逆配额联动**：渡道配额替代路径"诵经次数≥3"直接读 `sutraChantBonus(s,'ferry')`；逆道配额替代路径"逆经碎片≥3"读 `s.niSutraFrags` 计数。

## 第六部分：中间节点缩短策略

| 节点类型 | 旧时长 | 新时长 | 缩短方式 |
|----------|--------|--------|----------|
| 普通战斗 | 2-3分钟 | 1-1.5分钟 | 减少回合数、加快动画、可跳过剧情 |
| 精英战斗 | 4-5分钟 | 2-3分钟 | 单阶段、减少机制复杂度 |
| 事件 | 1-2分钟 | 30秒-1分钟 | 精简文本、直接2选项 |
| 商店 | 1-2分钟 | 30秒 | 固定3件+1随机 |
| 休息 | 1分钟 | 20秒 | 一键回血+强化选项 |

配合**战斗速度调节**（1x/2x/3x）：1x完整演出、2x动画加速、3x极速刷局。

## 第八部分：实施步骤

1. 新增 `REGION_QUOTA` 数据表（17地区×六道，先填两界山）
2. 把两界山5难（5-9）融合为3-4个大节点 + 中间节点 + Boss

5. 劫印获取迁移：小劫难结算给劫印（融合节点品质提高）
6. Boss刷新逻辑：配额满足后解锁难9鹰愁涧白龙
7. 验证：战/渡/夺/缘/隐/逆各玩一遍，确认配额可达成、不卡死

1. 为17地区配置融合节点+中间节点分布
2. 按地区难度分档配额（初级/中级/高级）
3. 实现超额奖励结算
4. 实现劫印池加权（主攻道×2）

### P2：体验优化

## 第九部分：验收标准

| 验收项 | 标准 |
|--------|------|
| 配额可达成 | 六道各玩一遍，主路径或替代路径均能解锁Boss |
| 配额不卡死 | 选任何道+正常build，都能在地区内满足配额 |
| 六道有区分 | 战道玩家战斗多、渡道玩家事件多、夺道玩家精英多……行为可区分 |
| 劫印品质提升 | 融合节点给蓝/金，直接给不用碎片 |
| 装备供给正常 | 战斗只给装备后，玩家装备成长曲线平滑（不卡装备） |
| 第一章不受影响 | 第一章仍线性教学，无配额制 |
| 性能 | 融合节点+配额追踪不卡顿 |
