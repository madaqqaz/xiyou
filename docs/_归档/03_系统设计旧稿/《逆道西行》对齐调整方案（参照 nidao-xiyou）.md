## 二、目标架构（五层单向依赖）

> 注：此架构为参考项目的**设计参考**。按用户范围澄清，demo **不重写为五层 ESM**，
> 保持现有 `NDX` 命名空间 + `<script>` 顺序加载结构；仅借鉴其**数据组织与设计语义**。

```
L0 data          src/data/          纯数据：章/难/节点、词缀、Boss、事件、劫印、灯油参数
L1 core          src/core/          GameState 单一真源、事件总线、可种子 RNG、storage 适配
L2 systems       src/systems/       游戏规则与数值：战斗状态机、劫印库、道心、六道命数、灯油结算
L3 progression   src/progression/   地图结构与门控：章→难→节点解析、岔路包、选项门控
L4 flow          src/flow/          一局/一周目生命周期 + 对 ui 的命令面（commands/run/settlement/meta）
L5 ui/audio      src/ui/ + audio/   渲染/特效/音效：只读 state + 订阅 events + 调 flow/commands
```

依赖方向（单向朝下）：`data → core → systems → progression → flow → ui/audio`。
禁止：ui import systems 写函数；任何层 import ui/audio/style；全局变量；裸 `Math.random()`。

## 四、执行原则（参照参考项目宪法）

1. **逻辑/渲染分离**：ui 只读 state、订阅 events、调 flow/commands；禁止在 ui 层计算数值。
2. **数据模块零环境依赖**：data 禁止引用 window/document/localStorage/console，Node 可裸 import。
3. **CSS 按域拆分 + design token**：色值/字号/间距只定义在 tokens.css。
4. **3 秒可决策**：选项代价/收益图标+颜色+数字前置，不读字也能选。
5. **数据驱动**：新内容只加 data/ 配置，不改引擎代码。
6. **可种子 RNG**：所有随机经 rng 实例，禁止裸 Math.random()。
7. **改码必改档**：修改代码/接口/schema 后同步文档。
