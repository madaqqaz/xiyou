### 1.3 三条硬约束（本版更新）

| 约束 | 内容 |
|---|---|
| **C1** | **六珠 / 六舍利 的名称、座位、克制矩阵、宝库/市场兜底一律不动**；本版**只改「获取道」与「落点难号」** |

### 1.4 为什么全走渡（三条依据）

1. **代码原设计本就写着** `NDX.SET_DAO = { …, 取经人:'渡', … }`（`js/data_equip_core.js:27`）—— 走缘才是偏离。
2. **黄风岭的 `元吉`/`灵吉` 线本就是渡**：定风珠三来源中「宝库三选一」与「黄风岭集市 100%」**不动**，故**破黄风怪的风系禁忌不被破坏**（定风珠仍在难 1-4 得，早于 Boss 难 13）。
3. **渡是六道里唯一不稀缺的道**（81 难中 80 难含渡选项，98.8%），承接 24 个配件绰绰有余；缘（32 难）则本就靠纯 `ti.hp` 血量填充硬撑。

### 3.1 这一版的三个关键判断

**① 舍利③ 前移 = 你点的那个位置。** 原案第 3 颗在难 50-51（第六章），导致**杖一阶比六道一转门槛晚约 4 章**（详见 v3.0 §3.2）。新锚点 **难 27 红孩真火** 是天然佛门事件——**红孩儿被观音收为「善财童子」**，是全书最标准的「佛门皈依」之一，「善财舍利」既贴事件又贴语义。

**② 雷音古舍利移出体系，是修一处重复占用。** v3.0 里新设的 **僧冠④「弥勒宝相」** 与 **法杖⑤「雷音古舍利」** 都挂在**难 53-54 小雷音寺·黄眉童儿**——同一事件被两件装备各占一次。本版把小雷音**归僧冠线独占**，法杖第 ⑤ 位改由「金光佛舍利」顶上，第 ⑥ 位改锚狮驼岭。

**③ ⑥ 从灭法国改到狮驼岭，是为了让二转不撞三转。** 灭法古舍利原挂**难 70（Ch8）**，而三转（四件二阶）也落在 Ch8——**二转与三转会挤在同一个章**。改锚 **难 58 狮驼岭（如来收大鹏）** 后，杖二阶提前到 **Ch7**，二转（Ch7）与三转（Ch8）自然错开。灭法古舍利降为「隐藏第 7 舍利」，留作后续扩展（不占 6 数）。

| **F1** | **满四件套 → 触发特殊属性** | 同套 `兵/甲/冠/靴` 四槽齐备（不论是否融合）→ 激活该套**专属特殊属性（共鸣）**。此即「四件套的真正价值」：不是四件属性简单相加，而是**多一条特殊属性**。 |
| **F2** | **初始四件套不可融合** | 五套**英雄本命套**（取经人 / 悟空 / 八戒 / 沙僧 / 龙马）为「本命装」，**只能靠配件升级**（六珠+六舍利+六赐+六纤 / 四英雄本命 6），**不得进入土地庙融合**。 |
| **F3** | **其他四件套可在土地庙融合** | 战利品套（黑风 / 狮驼 / 涅槃 / 降魔 / 封神 / 轮回 / 贪狼 / 破军 / 玄武 / 影遁 / 逆命 / 饕餮 / 明镜，共 **13 套**）满四件后，可在**土地庙**执行「融合」：<br>① 保留 **50%** 原属性<br>② **保留该套特殊属性**<br>③ 转为**被动加成**、**包裹中生效**（不占装备格）<br>④ **释放 4 个装备槽** |

### 7.2 为什么这么设计（三条 rationale）

1. **解决「四件套绑架四槽」**。现有 13 套四件套一旦穿齐就锁死武器/甲/冠/靴，玩家没有搭配自由。融合后**四槽全空**，玩家可自由混搭散件与其它套装件——**这是「装备自由度」的唯一解**。
2. **复用现成机制，零新底座**。`NDX.SET_JOBS`（`js/equipment_part2.js:776`）已经是「四件套 → 熔铸组件 → 包裹中生效 → `attr_calc` 7.5 结算」的完整链路；`NDX.upgradeEquip`（`js/data_equipment.js:189`，土地庙淬炼 ×1.6）已是土地庙的装备交互入口。**融合 = 把 SET_JOBS 从「隐藏职解锁」扩成「50% 属性 + 特殊属性」的通用产物**。
3. **初始套不可融合，保住英雄身份**。五套本命装是英雄辨识度的载体（悟空金箍棒/八戒钉耙/沙僧宝杖/白马龙蹄），必须**始终占槽**才能看见；其成长交给**配件**（一条 24 格的长期收集线），与「融合」这条自由线区分开。

### 7.3 数值口径（待 playtest）

| 项 | 口径 |
|---|---|
| **融合后属性** | 原四件属性之和 × **50%**，折算为一件 `slot:'component'` 的 `bonus.ti`（走 `SET_JOBS` 通道） |
| **特殊属性** | 该套的共鸣效果原样保留（如 `破军 → 弑神（攻+105 血+480 减伤+9% 暴击+6%）` 这一类） |
| **生效方式** | **被动**、**包裹中生效**、**不占装备格**（与现有 `component` 完全一致） |
| **可否重复** | 同一套**只可融合一次**（避免反复刷套利） |
| **初始套** | **禁止融合**（F2），且**不给**融合入口（UI 不显示） |
