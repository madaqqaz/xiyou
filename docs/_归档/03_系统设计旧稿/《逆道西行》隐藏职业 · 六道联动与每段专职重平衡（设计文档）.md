# 《逆道西行》隐藏职业 · 六道联动与每段专职重平衡（设计文档）

> 版本：V41.2 · 复核基准：demo 现有 `HIDDEN_JOBS` / `HIDDEN_TRIAL_REQ` / `evalHiddenCond`
> 目的：让隐藏职业与「劫难选项六道」（战/渡/逆/隐/夺/缘）强联动，并做到**每一段（地区）都覆盖多数英雄**的专职局面。

> 地区 1-17 = 大唐境内/两界山/黄风岭/流沙河/五庄观/火云洞/车迟国/通天河/女儿国/真假猴王/火焰山/祭赛国/狮驼岭/比丘国/天竺·玉兔/灵山/凌云渡。

**三大问题**：
1. **六道失衡**：专职条件几乎全押「逆/渡」，战/隐/夺 三道完全空白，"选项六道"有一半与专职脱钩。
2. **段失衡**：前段满员但中后段（地区11-13）空白、中段缺3，中后期无专职期待。
3. **命数数值脱钩**：除「善≥」外，几乎不要求「某道命数累计值≥N」，倾向选择与解锁联系弱。

---

## 二、设计目标

1. **六道全覆盖**：战/渡/逆/隐/夺/缘 六道，每道至少有一个可解锁的隐藏专职。
2. **每段覆盖多数英雄**：每一段至少有 3~5 名英雄拥有该段可触发的专职。
3. **六道命数门槛**：新增「某道命数累计值≥N」约束，让玩家的道途倾向决定专职方向。
4. **保留已验证专职**：现有 13 个专职的触发点不破坏，仅补缺口、补六道。

## 四、六道命数累计门槛（`evalHiddenCond` 扩展）

现有 `evalHiddenCond` 已支持 `渡≥5` 语法（data.js:1868），但各专职条件未使用。**新增统一语法**：`{道}≥{N}` 表示该道命数累计值需达阈值。

修改建议（`data.js` NDX.evalHiddenCond）：

```javascript
// 1) 命运累计数值门槛（已存在，确认覆盖六道全键）
let m = c.match(/^(逆|渡|缘|战|夺|隐)≥(\d+)/);
if (m) {
  const dao = m[1]; const need = +m[2];
  const cur = (s.fate && s.fate[dao]) || 0;
  if (cur < need) return fail('fate', { dao, need, cur });
}
```

> 该语法已覆盖六道，只需在新增专职的 `cond` 中填入如 `战≥3` / `隐≥3` 即可生效，无需改函数。

### 六道命数累计来源校验

六道累计值来自 `s.fate[道]`（每选一次对应道累积分）。需确认各段劫难选项确实**覆盖全部六道**，否则会出现"某道无法累计到阈值"。当前选项 `fate` 字段已含 战/隐/夺/渡/逆+特殊（data.js 1187-1282），战/隐/夺 在前段（地区1-5）已出现。**落地时需做一次全库选项六道覆盖审计**（见 §六）。

## 五、必经劫难约束扩展（`HIDDEN_TRIAL_REQ`）

新增专职需挂入对应英雄的必经劫难，保证触发节点必现且需实际经过：

```javascript
// 当前 data.js 实际值（V8.23）：
NDX.HIDDEN_TRIAL_REQ = {
  bajie:      [1, 2, 13, 18, 26, 31, 39, 46, 66, 69],   // 九次特定劫难（天蓬身份线）
  wukong:     [1, 16, 22, 29, 39, 42, 62, 81],          // 补 42/62（后段暗线）
  tangseng:   [1, 27, 53, 73, 81],                      // 补 53/73（后段暗线）
  xiaobailong:[6, 59, 61],                              // 补 61（后段暗线）
  shaseng:    [14, 46, 63, 81],                         // 补 46（中后段暗线）
  all:        [29, 39],
};
```

> **新增专职落地时**：斗战明王(9)/白衣渡客(36)/判官金蝉(43)/卷帘夺宴(47)/夺宝龙子(61)/金蝉了缘(65) 需将对应难号补入各英雄必经列表（悟空补 9/36，唐僧补 43/65，沙僧补 47，小白龙补 61）。

> **⚠ 死锁修复（V41.1）**：原实现以 `flags.hiddenJobReady[hero]`（须历经"全部"必经劫难）作为门槛 1，而各专职的**自身难号**也在其英雄的必经列表里——导致「难43判官金蝉须先过难43及后续难65/73/81 才能触发」，全专职一绕不过、逻辑死锁。
>
> **修复方案「位置感知」门槛**：`hiddenTrialsMet(hero, trialsPassed, curDiff)` 新增可选 `curDiff`（当前难号）。传入后只要求 **`必经劫难 ≤ 当前难号`** 的子集已过，且**当前难本身视为已达成**。即难43判官金蝉只校验难1/27 已历，不再被难65/73/81 前置卡死，同时保留「逃课过多则无法触发」的反逃课约束。
> - 门槛 1 判定由 `game.js` `applyTrialOpt` 改为 `NDX.hiddenTrialsMet(s.hero, s.trialsPassed, s.diff)`（不再依赖 `hiddenJobReady` 标志位；标志位仅保留作【隐藏资格】日志）。
> - 各专职触发时点：所在难号到达且六道/持有/必经前置满足即可觉醒。
