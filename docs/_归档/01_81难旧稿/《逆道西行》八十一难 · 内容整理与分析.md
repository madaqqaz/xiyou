## 一、结论先行

1. **骨架完整、无空缺**：81 难 100% 有专属叙事条目（`TRIAL_LIB` 81/81），17 地区全覆盖，5 英雄专属文本全覆盖——不存在"占位/缺条目"级缺口。
2. **真正的问题不是"有没有"，而是"厚不厚、选不选择得动"**：叙事均值仅 **69 字**，40 难 < 50 字；六道供给严重不均（渡 84% vs 夺 36%）；选项数均值 **3.1**，4 个难只有 2 选项。
3. **发现系统性内容错位（首要问题）**：`HERO_TRIALS`（5 英雄 × 81 层）仍按 2026-09-01 地理重排**前**的旧难号索引——难 14–17（主线已是流沙河段）全 5 英雄都在讲"高老庄/收八戒"；难 41–44（真假猴王段）英雄文本是火焰山/祭赛国内容；难 70 与难 67 文本重复。玩家在英雄专属线会读到与当前劫难无关的剧情。详见 §七。
4. **两份调整提案（第一批/第二批）基本未落回代码**，与现状存在可枚举的差异清单（§八）。

## 四、类型分布与语义问题

- 全局：**fight 39 / event 36 / story 4 / boss 2**。
- `type='boss'` 仅 77、81 两条；其余 15 个地区 Boss（4/9/18/22/27/31/36/40/45/49/54/58/63/72）在 `TRIAL_LIB` 里标为 `fight`。
- **问题（P2）**：`type` 字段语义不统一——UI 与统计无法据此区分"地区 Boss 战"与普通战斗。建议在 `TRIAL_LIB` 显式补 `boss:true` 标记（不改 type，避免影响既有分支），或统一改为 boss 并同步消费方。

- 只有**难 1**提供完整六道直选（`sixdaoSelect:true`）；其��� 80 难为 2–4 选项（均值 3.1），40/54/63/73 只有 2 选项。
- **与既有分析的呼应**：《六道抉择单选项症结分析》指出"选第二条道没意义"的根因是奖励塌缩 + 单主道攻式。本审计补充了上游证据——**缘/夺/隐 在 60%+ 的难里根本不给选项**，玩家连"选第二条道"的机会都没有，频次的先天不均让多套路构筑在数据源头即不可达。
- **建议（P1）**：按"每难至少 3 道、地区内六道覆盖均衡"设下限；优先在缘/夺供给缺口最大的 act5/9/11/13 补选项。

## 七、善恶极性与英雄专属层

- 选项总数 **257**：显式善 100 / 显式恶 89 / **未声明 68（26%）**。未声明者走 fate 兜底（渡/缘→善、逆/夺→恶、战/隐→中性）。
- 终态极性规则要求"战/隐按剧情后果逐选项签署"，目前 26% 未签署 → 提案文档要求的逐项签署尚未铺满。
- **英雄专属层**：`HERO_TRIALS` 覆盖 5 英雄 × 81 层（tangseng 80）。但抽查 `wukong`：**仅层 1 提供 `options` 覆盖**，其余全为 `name` + `dark` 文本替换 → 英雄差异体现在"叙事视角"，**不体现在分支/奖励**。与 §六 叠加后，"换英雄重玩"的收益几乎全是读新文本。
### 7.3 ⚠️ 系统性错位：HERO_TRIALS 仍用旧难号索引

`trials81.js` 头部注释记载：**2026-09-01 原著地理重排**，难号按 17 地区重新编号、原 57–80 返程段移入 `RETURN_TRIALS`。但 `hero_trials.js` 的层号**未同步重排**，导致英雄专属文本与当前主线的劫难语义错位。抽查证据（脚本 `scripts/_audit_herotrial_align.js` → `_herotrial_align_out.txt`）：

| 难号区间 | 主线（新编号） | 英雄专属文本实际内容 | 错位程度 |
|---|---|---|---|
| 14–17 | 流沙河段（沙僧初遇 / 四圣试禅心 / 流沙九颅 / 河神问渡） | **全 5 英雄**均讲"高老庄闻妖 / 云栈洞戏猪 / 八戒归降 / 高老送别" | 🔴 严重 |
| 28–34 | 车迟国 → 通天河 | 英雄文本滞后约 3 难（28 讲"黑水擒龙"，31 才讲"高台求雨"，32 讲"隔板猜物"） | 🔴 严重 |
| 41–44 | 真假猴王段 | 英雄文本是**火焰山/芭蕉扇/祭赛国/碧波潭**内容（41"火焰山前"、42"三调芭蕉"、43"祭赛国前"、44"碧波潭探"） | 🔴 严重 |
| 59 | 比丘白鹿 | 英雄文本"祭赛金光"（上一段内容） | 🟡 中 |
| 68–72 | 天竺·玉兔段 | 68"天竺国前"、70"铜台府案"（与 67 重复）、71"灵山前望"、72"凌云渡前" | 🟡 中 |
| 79–80 | 晒经石 / 接引佛 | 79"通天河遇"、80"真经晒干"（二者互换） | 🟡 中 |

**排除"英雄视角并行"的可能**：若是"同一难不同英雄讲各自视角"，5 个英雄的文本应彼此不同且各自呼应当前劫难；但 14–17 段 5 英雄**高度雷同地讲同一段收八戒剧情**，且八戒本身是可玩英雄（`HEROES: wukong/tangseng/bajie/xiaobailong/shaseng`），主线并不存在"收八戒"节点——这是旧编号残留，不是视角设计。

**修复路径（建议 P1）**：
1. 以 `TRIAL_LIB` 新编号为唯一索引，逐条把 `HERO_TRIALS[hero][层]` 重挂到语义对应的新层号；
2. 重排后缺失的英雄文本（如真假猴王段）需新写；
3. 加一条门禁：断言每层的英雄文本主题词与 `TRIAL_LIB[层].name` 至少共享一个语义关键词（或维护一张 `旧层→新层` 映射表做一次性迁移 + 校验）。
