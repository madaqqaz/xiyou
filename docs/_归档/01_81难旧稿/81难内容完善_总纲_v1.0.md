## 二、九大完善维度 → 设计规则（核心）

用户提出的 9 个方向，逐条转成**可执行的规则与验收项**。

### 维度 1 · 设计合理性 / 唐僧行为逻辑 / 佛法背景

**现状**：多数六道分配合理，但存在**规则自相矛盾**——如"隐=善+10"违反《劫难系统基本原则》§2.6（隐应最恶劣）；"战在观音院=恶+10"与代码 `alignGood:3~4` 符号相反；单/复合劫善恶系数混用。

**设计规则**：
1. **善恶值统一算法**：`善恶 = 基础值 × 复合系数`。基础值固定档位：战/夺=恶（+5/+10），隐=恶（+8→**须改为恶**，不得为善），渡/缘=善（+8/+10），逆=恶（+8）。单劫难系数 ×1。**复合系数取值规则（用户定调 2026-09-18）**：第一、二章所有劫难善恶**不加系数**（系数=1，无论单/复合劫）；第三至九章复合劫难系数 = 该劫难包含的**难数**（如女儿国2难→×2、六耳2难→×2），单劫难系数=1。
2. **六道优先级**（依《基本原则》）：隐（最恶、优先级最高）> 夺 > 战/逆 > 渡 > 缘。
3. **唐僧行为逻辑自检**（每难过一遍）：
   - 该选项是否符合"取经人"身份？（不是玩家想爽，是玄奘会怎么选）
   - 佛法背景是否成立？（杀生/夺宝必落"恶"，符合因果）
   - 逆选项是否始终绑定"须先炼成一世正果"门槛？

**验收**：每章输出一张「六道 × 善恶值」表，符号与档位全绿。

### 维度 2 · 原著契合 / 黑暗内容 / 选择度 / 不同背景线

**现状**：黑暗改写已有强点（沙僧九世骷髅=灵山"分期账单"、白骨精=被写死的角色、狮驼岭满城食人做包子、善财童子"没人问过他愿不愿意"）；但**分支深度不均**——第八/九章多为"选择只降后续难度"，缺乏独立背景线。

**设计规则**：
1. **单劫难复杂度下限（对标《不一样西游》）**：≥3 阶段 × ≥3 抉择 × ≥5 六道结局。
2. **"选择产生不同背景"硬指标**：每章 ≥2 处"**改写后续文本**"的分支（非仅数值降难），例：①第1-4难是否杀刘洪 → 第9难白龙对白变化；②四圣是否点化 → 五庄观前置解锁。
3. **黑暗母题统一**：全书统一 3 条暗线——"天庭/灵山才是真妖"（被写死的棋子）、"取经非到灵山而为放下执"、"每一难的妖都是另一个被牺牲的人"。
4. **原著契合**：每难标注"原著第 N 难"对照；改写处标注"黑暗点"。

**验收**：每章输出「原著对照 + 黑暗点 + 背景分支树」。

### 维度 3 · 耦合与钩子体系（内部 / 前后 / 跨章）

**现状**：耦合不少（避水珠/照妖镜/芭蕉扇跨章、四圣→五庄观前置、红孩儿态度→女儿国），但**两版难号错位导致钩子源引用混乱**；跨章钩子几乎全是法宝。

**设计规则**：
1. **钩子登记表**（每章必填）：

| 钩子名 | 类型 | 埋点（章/难/选项） | 兑现（章/难） | 若错过 |
|---|---|---|---|---|
| 定风珠 | 法宝 | 第一章 1-4 缘 | 第一章 14 黄风怪 | 宝库/市场兜底 |

2. **三类耦合分层**：
   - **章内单元耦合**：单元 A 的选择改写单元 B（如双叉岭夺虎皮裙 → 黄风岭虎先锋升 Lv.2）。
   - **相邻章耦合**：上一章 Boss 态度/随从影响下一章（如红孩儿救/败 → 铁扇态度）。
   - **跨章长线**：法宝升级链（芭蕉扇→阴阳 / 净瓶→观音→三才）、角色伏线（残魂、白晶晶、隐藏 81 难）。
3. **每个钩子必须有"埋—收—兜底"三件套**，不得只埋不收（当前第九卷"老鼋/隐藏81难"即断线）。

**验收**：每章一张钩子登记表，全书汇总成「跨章钩子总表」，校验无孤儿钩子。

| 装备 | 级别 | 材料 | 落点（章/难/路线） |

| 虎皮裙 | Lv.1 | 寅将军虎皮 | 第一章 5-7 夺 |
| | Lv.2 | 虎先锋皮 | 第一章 13 夺（需 Lv.1） |

| | Lv.3 | 幌金绳 | 第三章 24-25 平顶山 夺 |

2. **战路线专属价值（采纳用户方案并强化）**：
   - 战路线 Boss **有概率掉落额外特殊装备/材料**；

### 维度 7 · 兜底机制 → 节点拥堵 + 隐路线战力崩塌（用户重点）

**现状**：隐路线不战斗 → **无装备、无宠物随从、无法宝**，战力远低于他道；所有错过的法宝/装备集中涌入市场+宝库 → 节点拥堵。

**设计规则**：
1. **各道战力供给表**（让每道有独特收益，避免隐=零产出）：

| 道 | 核心收益 | 战力补偿 |
|---|---|---|
| 战 | 装备/特殊装备材料/越战越强 | 物理成长 |
| 渡 | 经文（法伤）/佛经缘法 | 法术成长 |
| 隐 | 闪避/减伤/**潜行绕过 Boss 获该 Boss 部分奖励**、捷径宝箱 | **补足：绕过不空手** |
| 夺 | 法宝/装备（强取） | 爆发成长 |
| 缘 | 随从/羁绊/宝物 | 辅助成长 |
| 逆 | 逆道经文/逆随从/上限 | 高风险高收益 |

2. **市场/宝库分流**：按"当前主修道"刷不同池，避免全塞同一处；**兜底节点分散化**（每章市场各自兜底本章法宝，不集中）。
3. **隐路线专用补偿**：潜行成功 → 获得"未战斗省下的气血/寿命"折算奖励 + 该 Boss 掉落池的**概率抽取**（如隐藏宝箱）。

**验收**：六道单章产出对照表，隐路线产出 ≥ 战路线的 70%。

### 维度 8 · 随从系统（借鉴《不一样西游》四徒弟）

**现状**：代码已有随从（FOLLOWERS 12、cap 3）与宠物（petSlotCap 2）双轨；文档中随从有人形/妖形、羁绊**仅当前劫难**、**无升级链**。用户新计划：**可收多个随从，只能上场 4 个**。

**设计规则**：
1. **核心四随从 = 主角团**：悟空（8）/ 八戒（12）/ 沙僧（第二章）/ 白龙马（9）为**固定核心位**（对应"四徒弟"），有完整升级链与剧情。
2. **可招募额外随从**：各劫难收的妖/神（寅将军、黄风怪、黑熊精、龙三太子…）为**候补位**，上场上限 4（核心+候补自由组队）。
3. **随从升级链**：随从可升级（材料来自劫难），人形/妖形作**形态切换（觉醒/转职）**——人形=高成长/技能，妖形=高爆发。
4. **羁绊升级为"关系值"**：跨劫难持久（不再"仅本劫难"）；满值触发合体技/专属剧情。
5. **随从定位**：主力参战单位，受六道影响（逆道随从仅在逆路线可得）。

**验收**：随从总表（含升级链/形态/羁绊关系值/招募节点）。

### 维度 9 · 宠物系统（借鉴《冒险日记》，与随从区分）

**现状**：宠物已有（petSlotCap 2、12 进化、7 羁绊、4 协同），但与随从**边界模糊**。

**设计规则 · 随从 vs 宠物 分界**：

| 维度 | 随从 | 宠物 |
|---|---|---|
| 本质 | 人形/神怪·有身份剧情 | 妖形/小家伙·捕捉孵化 |
| 获取 | 劫难选择（缘/逆） | 捕捉/孵化/劫难赠 |
| 成长 | 升级链 + 形态切换 | **进化链**（12 进化） |
| 战斗 | 主力参战 | 辅助/增益/协同（4 协同） |
| 羁绊 | 关系值（跨章） | 羁绊（7 条）+ 图鉴 |
| 栏位 | 上场 4 | 独立栏位 2 |
