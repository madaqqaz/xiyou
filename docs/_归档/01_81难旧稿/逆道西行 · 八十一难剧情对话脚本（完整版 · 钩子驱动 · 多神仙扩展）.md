# 第一章 · act1（难 1-18）：出长安，过两界，入西境

## 难 1 · 金蝉遭贬 【story · 观音链·一】

> **开场独白**：灵山莲台上，如来合掌，声音像隔着一层水："金蝉子，你十世修行的功德，朕替你记着。这一世，你去替朕取一卷经。"你低头，看见自己的手掌——掌心刻着一个字："走"。你忽然明白，取经不是选择，是宿命。而你，最不喜欢宿命。

**观音·承佛之命**（独白内景）：你闭眼，听见一个女声——不是佛的，是观音的，隔着万里水汽传来："取经人，你若承这卷经，我便在沿途替你留一盏灯。灯亮着，路便没断。"你睁开眼，莲台下跪着一行金身罗汉，他们不看你，看如来。你忽然觉得，这卷经，是如来替自己取的，不是替众生。

**选项**

- **【渡】承佛之命**："经，我取。但路，我自己走。" → `fate:'渡'` `alignGood:10` `favorGain:{观音:10}` `mark:'观音·初逢'`。观音好感 +10（链起点）。**对话**：观音（水月声中）："善。灯已点亮，你回头便看得见。" → 解锁后续观音门控。
- **【战】叩问如来**："凭什么我去？" → `fate:'战'` `alignEvil:5` `ti:{atk:8}`。如来不答，只合掌。你被金光推出灵山，摔在长安城外。**对话**：如来（远去）："凭你是金蝉子。凭你没得选。" → 前期逆道倾向开启。
- **【隐】默然接旨**：不语，接过经卷。 → `fate:'隐'` `alignGood:5` `yuan:{matk:6}`。**对话**：你翻开经卷第一页——空白。住持说："真经从来就是空的。"你合上经，上路。

## 难 2 · 长安送行 【event】

> **开场**：长安城朱雀大街，百姓夹道。一个老僧拦住你，递来一只破钵："取经人，这是前九任取经人留下的钵。他们都没回来，钵却回来了。"钵底刻着九个人的名字，最后一个名字被血浸透，只看清一个"悟"字。

> **开场**：两界山下，一块巨石裂开——不是石猴，是悟空。他被压了五百年，出来时骨头都是碎的。他看你一眼，没跪，先笑了："又一个取经人。前九个都让我等，我没等到。"他伸手，掌心一道金箍印——是如来烙的。

## 难 81 · 灵山·无字真经 【boss · 三链终局汇聚】

> **开场**：灵山顶上，如来坐在莲台，身后是金光万道。他看你，像看了五百年："取经人，你走到了。经，在那里。"他指了指莲台旁——三卷经，都是无字的。你忽然明白，这一路走来，所有神仙的灯、所有妖的骨、所有前人的碑，都指向同一个真相：**经是空的，路是真的。**

- **【取经·渡】收空白真经**：`fate:'渡'` `good:40` `healFull:true` `mark:'结局·取经'`。**对话**：你把三卷空白经收进怀里。如来（合掌）："善。取经人，你取到了。"你走出灵山，身后金光万道——但你心里清楚，经是空的，是你一路走来的善，填满了它。→ **金蝉正果结局**。若 `观音好感≥30` + `mark_观音·终` 存在：额外触发"观音引渡"真结局分支（如来合掌时，观音从莲台侧走出，替你证道）。

- **【双开·缘】两卷都收**：`fate:'缘'` `good:20` `evil:20` `yuan:{matk:25}` `mark:'结局·双开'`。**对话**：你把三卷经拆开——一卷带走，一卷留下，一卷撕了。如来（沉默）："取经人，你是第一个不全取的。"你走出灵山，身后金光半明半灭——你既取了经，也逆了道。→ **坐化西行 / 一魄转世结局**（取决于累计善恶）。

> **终局钩子结算**：本难为五链汇聚点。系统依次检查 `mark`：观音·终 / 二郎·五 / 龙王·四 / 哪吒·三 / 老君·终。每满足一条，对应神仙在终局演出中出场并赠送对话/奖励。五链全满时触发**"五圣证道"隐藏终极演出**（所有神仙同台，为你一人证道）。

# 附录 D · 与现有代码衔接说明
