## 三、接入点

| 优先级 | 位置 | 说明 |
|---|---|---|
| **P0** | `dao-overview` 面板的 `.dao-card` | 首难择道后的六道介绍面板，当前纯文字；加 56px 圆徽章即可 |
| P1 | 战斗内「道途加成」提示 | 每次抉择为某道充值时强化反馈（需先确认是否已有该 UI） |
| P2 | 六道转盘 `sixdao_roulette.jpg` | 仅当有六道随机事件/转盘玩法时启用 |

## 四、落地步骤（P0）

1. 复制 6 张到 `img/icons/dao/`（与 `img/icons/` 现有分组一致），或沿用 `img/ui/dao_*` 原位；
2. `js/ui/ui_panel_2.js` `.dao-card` 模板：在 `.opt-main` 前插入
   `<img class="dao-badge" src="img/icons/dao/渡.webp" alt="渡道">`（路径建议用**道名**而非 `dao_du`，与 `img/icons/sutras/du_*` 的命名习惯冲突需先定）；
3. `css/style.css` 加 `.dao-badge { width:56px;height:56px;border-radius:50%;flex:0 0 56px; }`
   并给 `.dao-overview-card` 改 `flex-direction: row`（徽章在左、内容在右）；
4. `index.html` 递增 `ui_panel_2.js` 与 `style.css` 的 `?v=NN`（**缓存版本号纪律**）；
5. 跑 `node scripts/_run_all_gates.js` 确认全绿。

## 五、风险

1. **水印**：6 张 `dao_*.jpg` **全部带右下角「AI生成」水印**。在 56px 圆徽章下源图水印被缩到约 6×2px、肉眼不可辨 —— **徽章用途可接受**；但**不可**放大用于六道转盘/立绘等大尺寸位。若要放大使用，须先去水印。
2. **风格落差**：`dao_*` 是**精绘水墨**，而现役 `.dao-card` 是纯 CSS 极简卡面。加徽章会打破当前"全文字面板"的一致性 —— 这正是收益（视觉锚点），但需一次看全 6 张的效果（已出视觉稿）。
3. **`dao_e` 的语义**：把「恶（赤瞳）」指派为「隐」是一次**再解释**。若美术有异议，需新绘一张「隐」（潜入/影/蒙面）。
4. 接入后 `img/ui/` 从"100% 死目录"变为"部分在用"，后续归档 B 批时需按文件白名单操作，不能整目录处理。
