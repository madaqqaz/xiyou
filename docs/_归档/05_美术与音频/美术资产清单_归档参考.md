| Spine骨骼配置模板_通用动作库.json | Spine JSON | 通用骨骼配置模板，包含22个核心骨骼节点+5个辅助挂载点+24个通用动画时间轴框架+9个事件 |

**配置文件内容（v2.0）**：
- **22个核心骨骼节点**：root → hip → spine1 → spine2 → neck → head，左右肩/臂/手/髋/腿/足完整层级
- **5个辅助挂载点**：weapon_right/left（武器）、back_item（背部道具）、head_item（头部道具）、waist_item（腰部道具）
- **23个插槽配置**：按渲染顺序从脚到头排列
- **9个事件**：footstep、attack_start/hit、cast_start/hit、item_use、damage、death、victory
- **24个通用动画时间轴（全部填充基础关键帧）**：idle/cast/hit/death/walk/attack/guard/use_item/jump/dodge/victory/stun/run/sleep/poison/burn/freeze/paralyze/skill/transform/buff/summon/interact/pickup，每个动画均包含主要骨骼的旋转/位移关键帧和对应事件

**使用方法**：
1. 用Spine 4.1+打开此JSON文件
2. 导入角色立绘切片到images目录
3. 在对应插槽中替换附件为角色切片
4. 基于已有关键帧框架调整每个动画的骨骼运动
5. 导出为.skel或.json格式供游戏引擎使用

3. 点击左侧"人形骨架"预设，或手动创建22个骨骼
4. 将每张部位图拖到画布，对齐到对应骨骼位置
5. 设置图片与骨骼的父子绑定关系
6. 在时间轴上参考24张动画关键帧，逐帧摆骨骼姿态制作动画
7. 导出JSON骨骼动画数据

## 技术规格

| 项目 | 规格 |
|------|------|
| 图片格式 | PNG |
| 分辨率 | 1773 × 2364 像素（约3:4竖版） |
| 背景 | 纯白（#FFFFFF），方便抠图 |
| 风格 | 国风二次元半写实 |
| 生成模型 | Seedream 5.0 Pro |
| 骨骼软件 | Spine 4.1+ |
| 配置文件格式 | Spine JSON |
