## 〇、使用说明

- 本文档每条 `【ID】` 对应一张需生成的立绘资产 = 一条独立可复制的提示词（**一图标一提示词**）。
- `@主体名` 表示该立绘复用某张**已生成的同主体基础图**作参考——先生成带 ★ 的基础主体图，后续变体在提示词开头加 `@主体名`，即梦会引用已保存的主体图，保证角色一致性。
- 建议顺序：先做 P0 基础主体（标 ★），再用 `@主体` 生成变体；P1 / P2 / P3 按优先级依次推进。
- 尺寸：英雄 / NPC 4:7 竖版半身；灵兽 站姿构图；Boss / 三大白骨精 / 终局 4:7 大半身或全身。

## 十二、即梦操作速查

1. 打开即梦 → 图片生成 → 选择「图片 5.0 Pro」模型。
2. 设置 图片 4:7（竖版）、2K 分辨率。
3. 先复制带 ★ 的 P0 基础主体提示词 → 上传参考图或直接生成 → 满意后保存为主体素材。
4. 生成变体时，在提示词开头加 `@主体名`，平台会引用你保存的主体图。
5. 无 `@` 的提示词直接粘贴即可（NPC / 独立 Boss 等）。
6. 负面提示词（全局设置一次即可）：`no modern elements, no cartoon, no anime, no 3D render, no extra limbs, no watermark.`
