② 行为契约（用户原话 → 实现）

  • 自动 自动攻击仅含普通攻击 + 诵经攻击；绝招只有手动点击才触发 → aiAutoSkill 永不返回 ult，aiAutoTreasure 已删。
  • comb链 连续基础攻击 3 次触发 1 次暴击；自动攻击也能触发暴击提示 → 基础攻击链双端生效，自动出 crit 音效 + 战斗日志；手动受 2s 窗口约束、自动不受。
  • 法宝 其他法宝也类似 → 法宝纯手动，自动不代祭；自动模式下法宝按钮仍可手动点击（金色脉冲环提示）。
  • 不影响操作 自动只是取消玩家对基础攻击的点击，绝招/爆发/法宝/风格攻击仍可由玩家随时手动触发（覆盖自动），按钮不锁。
