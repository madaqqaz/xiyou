《逆道西行》战斗 / 连招完善分析

分析范围：当前战斗真源（V8.46 后）· 连招系统 · 怪物 buff/debuff 针对体系 · 竞品对标（万世剑冢 / 元气骑士 / 哈迪斯 / 暖雪）· 完善路线图。所有结论附 file:line 证据。本轮仅分析 + 给方向，不改代码。

一句话结论：核心战斗骨架（三键主动 + 气势爆发 + 六道进阶 + DOT/护盾内核）已健康成型，V8.45/46 的连招与自动战斗模型也立住了。真正偏薄的是三处：① 手动连招链「combo→burst→pierce」因要求同时解锁三道风格而对绝大多数构筑几乎不可达；② 缺「六道相克」这一本作最该有的主题化深度杠杆（万世剑冢的五行克制同源）；③ 怪物侧无通用易伤/标记、无属性弱点、无增益层数/免疫分层，针对型玩法缺乏落点。

二、连招系统评估：什么立住了，什么偏薄

已立住 基础连击链（comboBasicStep）——每 3 次基础攻击暴击 ×1.5，手动/自动双端生效，自动也出暴击提示（V8.46 已按你的设计落地）。这正是元气骑士「第 N 击必暴」+ 哈迪斯「持续连段越打越痛」的回合制等价物，方向对。
偏薄 手动连招链（combo→burst→pierce）——门槛过高。combat.js:1014-1019 要求链尾出现有序 [combo,burst,pierce] 三式；但三式分别由战道≥3 / 夺道≥3 / 逆道≥3 解锁（game.js:2584）。单局构筑通常只有 1~2 个道途≥3，三式全解锁极罕见，导致这条「串联 ×1.25」对绝大多数玩家是死内容。它把「连招深度」锁在了多道途杂糅的窄门后。
偏薄 无搓招序列 / 无连段分层 / 无状态可视——当前连招只有「风格有序衔接」一种形态，没有元气骑士式的「按序触发不同效果」搓招，也没有武斗家式「第 10 击必暴 + 连段越久越痛」的递增式奖励，更没有「暴击就绪」圆形指示（元气骑士核心反馈）。状态链（咒蚀+裂伤+破甲）也无 UI 图标让玩家规划。

三、可新增连招方向（6 条，均附设计 + 缺口证据）

#连招方向设计要点对标落地难度
1六道相克链P0新增怪物 daoAlign 字段（六道之一）。玩家主道途（构筑中≥3 的那个）克怪物 daoAlign 时，该次攻击 +30% 且额外 +1 气势。相克环：战→夺→缘→隐→逆→渡→战（顺时针）。这是本作主题化最强、万世剑冢五行克制的同源杠杆。万世剑冢·五行克制 +30%中（需怪物数据 + 内核 + UI 提示）
2搓招序列（奥义）P1特定按键序列触发独立「奥义」效果，而非仅风格衔接。例：atk→atk→chant＝蓄力重击式（本次 ×1.4 且破甲）；atk×3→ult＝终结技（绝招伤害 ×1.3）。序列状态机挂在 pending.comboSeq，参照 comboBasicStep 模式。元气骑士·如来神掌搓招中（序列机 + UI 提示）
3连段分层递增P1把「每 3 击暴击」升级为分层：3 击→暴击 ×1.5；6 击→×1.5+破甲；9 击→×1.8+吸血。即武斗家「第 10 击必暴」+ 哈迪斯「连段越久越痛」的回合制等价。纯数值，改 comboBasicStep 即可。元气骑士·武斗家 / 哈迪斯·Demeter Fists低（仅数值真源）
4状态堆叠协同（Privileged Status）P0当怪物同时挂 ≥2 种 debuff（咒蚀/裂伤/破甲/定身/易伤），对其伤害 +15~25%。直接 Reward 现有 DOT/控制 kit，制造构筑多样性，无需新状态。内核在 enemyAttack/伤害结算读取 mDots+mDebuff 计数。哈迪斯·Privileged Status低-中（结算读取 + UI 角标）
5宠物连招协同P2宠物攻击在玩家达成第 3 击连段时同步触发 / 或宠物对「已被定身」怪物伤害翻倍。把独立宠物系统接入连招正反馈。万世剑冢·灵兽助战中（需宠物战斗接口）
6气势-连招联动P2连段达成时额外 +1 气势（与克制命中额外+1 同源）；或在满势(5)时下一次连段暴击升级为「势爆」。让连招与已有的剑意层数(气势)形成闭环。万世剑冢·剑意层数 → 万剑归宗低（复用气势内核）
相克环为建议设计，需经数值平衡；六道词汇受项目硬约束「六道统一」保护，不引入第七道。

4.2 缺口（针对型玩法的落点）

缺失为什么是缺口建议方向优先级
通用易伤/标记只有隐道定身附带 +25%，无「所有攻击对其增伤」的通用 debuff。绝大多数构筑无法稳定增伤怪物。新增 mark debuff：被标记怪物受到伤害 +15%（独立乘区），由特定连招/法宝施加。P0
怪物属性弱点（六道对齐）怪物无 daoAlign 字段（已确认 data_monsters.js 不存在，怪物仅 boss/ironwall 等标签）。无法做「针对弱点」。随 §三.1 六道相克一并落地 monster.daoAlign。P0
怪物增益层数 / 免疫分层狂暴/护盾是固定值，无「每回合叠甲」怪物，也无 Boss 控制免疫。隐道定身对所有敌人等值过强。① 新增「叠甲妖」每回合 +护甲，逼破甲流；② Boss 设 ctrlImmune，控制改为减半增伤不硬控。P1
怪物增益清除 / 转化玩家只能打破护盾，无法驱散/吸收怪物护盾反转为己用。法宝/绝招可「夺盾」：将怪物护盾转为玩家护盾（暖雪式收剑反转）。P2
召唤 / 聚怪 / 仇恨当前怪物各自为战，无多目标协同深度。新增「召唤小妖」怪物（击杀召唤体前本体减伤），制造清场优先级决策。P2
状态 UI 可视怪物身上的咒蚀/裂伤/破甲无图标与回合计数，玩家无法规划「再挂一个触发协同」。怪物血条下方加 debuff 角标（图标+剩余回合），参照玩家气势条。P1
丰富 debuff 类型现有仅 DOT/破甲/定身/减防。缺冻结(跳回合)/沉默(怪物禁用技能)/灼烧(区别于裂伤)/恐惧(降攻)。补 冻结 / 沉默 两种控制型（冻结=跳过攻击；沉默=本回合不出技能），丰富针对维度。P2
