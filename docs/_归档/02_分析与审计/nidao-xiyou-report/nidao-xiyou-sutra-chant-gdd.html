逆道西行 · 经文/装备/劫印/转职耦合设计 · 设计定稿（未改代码）· 数值全 [PLACEHOLDER] 待 10 局采样 · 2026-09-12
本版核心转向：六道（s.fate[道]）从「属性给予者 + 硬门槛」降级为「概率主干 / 权重种子」。它不直接给任何属性，只决定后续装备/劫印/经文在投放池里的出现概率。属性来自装备、拓宽来自劫印、技能来自经文——三者经六道权重偏置后，耦合出常规回合制 RPG 难以直达的多路线组合。

一、架构总览（四层 + 六道概率主干）

主干六道（s.fate）＝权重种子。取消全部直接属性与硬门槛，仅作为下方三池的出现概率偏置向量。
属性层装备＝主路线的属性实体（攻 / 防 / 反伤）。套装共鸣定义路线，转职强制绑定套装。
拓宽层劫印＝对主路线与技能的拓宽（吸血 / 暴伤 / 物法双修 / 特性叠到极致）。【真源已上线 jieseals.js】
技能层经文＝招式衍生（普攻/诵经/绝招变体包），换经即换整套套路。出现概率受六道权重偏置。
真源已对齐：劫印(jieseals.js) 正是「拓宽层」；道途进阶(combat_active.js:35) 早已由「已装备劫印」驱动而非六道 fate；转职(zhuanjie.js) 同时含道途门槛与套装共鸣(combat.js:62 玄武套)。本版只补「六道=概率主干」这一环，并把分层关系写死。

二、六道概率主干（NEW · 本版核心指令）

2.1 取消什么

  • 取消六道直接给属性（原 combat.js fateFlags 战斗机制一律改由劫印 mechanism驱动，已于 jieseals→fateFlags 管线实现，与六道解耦）。
  • 取消六道当硬门槛：逆经需 fate.逆≥1、法宝进化需 fate[dao]≥n、隐藏职需 fate[dao]≥dc、转职 daoGate 读 fate[dao] —— 全部改为概率偏置或由装备+行为达成。

2.2 偏置三池（机制）

每池在投放点读取 s.fate 作为权重向量：

四、劫印层（拓宽 · 真源已上线，本版仅框定定位）

劫印 = 把主路线推到极致、或打通"技能+装备达不到"的维度。jieseals.js 现有词条已覆盖用户全部示例：

拓宽维度真源劫印用户示例对应
越打越狠战·裂魂(critAtkStack +3物攻/暴击)攻击路线极点化
破盾削防战·齐天(critBreakShield)攻击路线极点化
物法双修渡·禅息(法吸转盾)/渡生(护盾普攻吸血)唐僧走物理：劫印"攻附100%法伤"(新增 mech) + 渡经文
护盾弹反夺·残魂(shieldBreakReflect 全场反弹)/逆·蚀骨(hurtStackReflect 受伤叠反伤)八戒弹死流：残魂+蚀骨=挨打弹死
反伤附法逆·流沙(reflectMagic 反伤附等量法伤)防路线极点化+法伤补刀
每回合护盾缘·厚土(regenShieldEachTurn 8%血/回合)防御续航
结论：劫印是"单纯技能与装备达不到"的层——装备给数值、技能给动作，劫印给"动作的规则改写"（暴击永久叠攻、护盾破即反弹、攻附法伤）。这正是用户要的拓宽。

五、经文层（技能衍生 · 沿用 V9.2）

  • 经文 = 招式包：atkVariant + 既有 chantSkill + ultVariant，换经换整套套路，不绑英雄。
  • 道味经文出现概率受 §二 六道权重偏置（渡多→渡经常现），但被动属于经文本身，不属六道。
  • 逆精简（V9.4）：12→8 部，镜像反制（正加血→逆削敌血 / 正加防→逆削敌防）。新增 effect.enemyDebuff + effect.negotiateBonus。

六、群攻统筹（沿用 V9.5）

怪物 2–3 个已成常态（enemies.js compositeMonster）。群攻四源（六道势/经文/劫印/隐藏职）统一阀：aoeEff(0.55–0.7) × 敌数、aoeCap(1.2) 合并封顶、Boss 豁免、被动群攻走回合 tick。六道势(combat_active.js:44) 已归劫印驱动，符合"六道零属性"。

八、与 V9.3 / V9.4 的冲突修正（RED FLAG）

撤销 V9.3「道途被动经 = 六道直接给回血/吸血/反伤/护盾/闪避」——这直接违反「六道零属性」。改为：被动来自道味经文/劫印（物品本身），六道只偏置其出现概率。回血/吸血等效果挂在经文 effect 或劫印 mech，不挂在六道枚举上。
撤销「fate 硬门槛」——逆经/法宝/隐藏职/转职的 fate[dao]≥n 门槛改为 §二 概率偏置或装备+行为达成。
