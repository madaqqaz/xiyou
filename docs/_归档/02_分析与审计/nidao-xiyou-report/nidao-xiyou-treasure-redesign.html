结论先行：法宝系统并非"完全独立"——真源里它已具备六道协同×1.25、counter.tags 软克制、戾伤 fateFlags 放大、斩杀线 save 四重耦合。用户感知的"独立"来自三点真缺口：① 没有"每次普攻触发"的被动类（on-hit）、② 没有战斗内"变小/弱体"减伤 debuff、③ 观音瓶是回血不是净化。本设计补三件套 + 显式化经文/劫印耦合，并以《西游释厄传》名器为风味参照，把法宝从"补给件"升级为"构筑决策件"。

二、法宝系统四大缺口（待补的真东西）

#缺口现状为什么必须补
1on-hit 触发类（每次普攻概率触发）仅 phase:'passive' 的 dmgPctStart（开战削敌）；紧箍有 applyJinguProc 但写死未数据化用户要的"攻击有概率造成…"全部需要它。紫金葫芦/金刚琢/芭蕉扇都靠此落地
2战斗内"变小/弱体"减伤 debuff仅有 weakNext（下战怪物攻-X%），无"本战斗内怪物造成伤害-50%"紫金葫芦"变小-50%伤害"是战斗内持续 debuff，非下战
3观音瓶=净化全部异常ts_bowl 紫金钵是回血（capHeal+evil），非净化；cleanse 仅支持指定类型数组用户明确要"清除玩家全部异常状态，5次，可土地庙补充"
4经文/劫印耦合未显式化法宝 dao 协同存在，但不读 s.chantSutra/s.seals 做组合法宝仍是"单体数值件"，未成为"构筑决策件"

三、法宝重设计：新增 on-hit 类 + 状态词库

3.1 新增 trig:'attack' 触发类（数据化紧箍机制）

把写死的 applyJinguProc 泛化为数据驱动：法宝 effect 加 onHit 块，普攻命中即按 procChance 掷骰触发。

数据结构（在 TREASURES[id].effect 内新增）：
onHit: { proc: 0.25, // 每次普攻触发概率 [PLACEHOLDER]
shrink: 0.5, // 怪物造成伤害×0.5（变小，持续 N 回合）
stun: 1, // 眩晕 N 回合（不动）
burn: 0.04, // 附加灼烧（%最大气血 DoT）
silence: 1, // 沉默 N 回合（禁用怪物技能）
slow: 0.30, // 怪物攻-30% 持续
lifesteal: 0.15, // 此次伤害 15% 回血
reflect: 0.20 } // 反弹 20% 所受伤
结算点：复用 applyJinguProc 改为读 effect.onHit，在 playerAttack 每个命中分支后调用——零新战斗内核，仅扩展入参。

3.2 新增战斗内怪物 debuff 词库

新 debuff语义复用/新增来源
shrink（变小）怪物造成伤害 ×(1-k)，持续 N 回合新增（区别于 weakNext 的下战）紫金葫芦
burn（灼烧）每回合流失 %最大气血已有（玩家侧），需镜像到怪物侧芭蕉扇
stun（眩晕）怪物 N 回合 deal=0已有（combat.js:1263）金刚琢/捆仙绳
silence（沉默）怪物 N 回合禁用技能已有类型（combat.js:1514）飞龙宝杖/九环锡杖
slow（迟缓）怪物攻-X% 持续复用 enemyAtkDebuff（灰烬罩已用）飞龙宝杖
reflect（反弹）受击反弹 X% 伤害已有玩家侧（mReflect）逆经/法宝镜像
状态词库统一在 combat.js:1511 STATUS_DEFS / 1516 PDEBUFF_DEFS 登记，怪物侧 debuff 新增 MDEBUFF_DEFS 单一真源——新增 debuff 只登记不写逻辑，符合现有纪律。

5.3 装备路线耦合（原文"强制绑转职"的伴生）

法宝不绑装备，但与装备主路线互补：攻击装 + 金刚琢（控制）= "控制型 attacker"；防御装 + 观音瓶（净化）= "净化坦"；反伤装 + 紫金葫芦（变小）= "弹死流"补强。这层是玩家自发组合，不需新代码，只需在法宝 desc 标注"适配路线"。

六、数值与通胀护栏 [PLACEHOLDER·待10局采样]

  • on-hit proc 上限：单法宝 proc ≤ 35% [待采样反推玩家 DPS]；同一击多件 on-hit 法宝合并后封顶 50%（防滚雪球，呼应经文群攻 aoeCap 纪律）。
  • shrink 下限：怪物造成伤害最低 ×0.3（变小不能归零，否则 Boss 变木桩）。
  • 观音瓶 charges：5/5 可补，但单场净化全异常 ≤ 3 次（防"无限解控"），其余计入下场。
  • DoT 总 cap：怪物同回合承受 DoT（burn/slow 叠加）期望 ≤ 单体 ×1.2（同 aoeCap 逻辑）。
  • Boss 豁免：boss:true 免疫 shrink/silence 的"永久化"，仅限本场有限回合。
所有来源（on-hit proc）都有对应 sink（回合衰减/charges/单场上限），不重蹈"只加不扣"通胀——这是设计红线。
