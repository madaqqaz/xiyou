0.3目标用户：双画像

画像 A · 叙事驱动型（预计主力，尤其微信端）：被"黑暗西游"四个字点进来的泛用户。玩过《黑神话：悟空》或至少刷到过相关内容；对回合制无抗性；决策偏好"看文案选好看的选项"。他们需要：前 10 分钟有戏剧钩子（现有教学四层：金蝉遭贬→出胎几杀→满月抛江→刘洪 Boss，已经满足）、寿命/心魔等系统有强可感提示、失败不惩罚太狠（轮回赐福 + 劫灰"死也积累"已对应）。

画像 B · 构筑驱动型（TapTap 买断主力）：杀戮尖塔 / 月圆之夜玩家。看重建构深度、难度分层、流派多样性、终局内容。他们需要：劫印词条与道心调制可推演、难度阶梯（lifeTighten）可自选、终局有明确目标链（六道真结局 + 天道劫 100 层 + 混元淬炼已对应）、平衡性改动有 changelog 与理由（见 Part 6 杀戮尖塔 2 反例）。

风险：画像 A 的耐心阈值约 3 次死亡；画像 B 的耐心阈值约 20 小时。当前游戏对两者的服务都不缺内容、缺的是可感知度（Part 8 的核心议题）。

PART 1

乐趣假设与设计支柱

Rev.3 描述了系统"是什么"，没有回答"它们为什么有趣"。本节把散落在 30+ 数据文件里的机制回推为一句可证伪的乐趣假设，与四根（可被未来内容增删检验的）设计支柱。假设若被 playtest 证伪，应改动的是体验层而非推翻系统。

1.1Fun Hypothesis（核心乐趣假设）

H0 · 总假设

"当每一个选择都同时标好『力量』与『代价』，玩家会主动走向自己付得起的最险处。"——逆道西行的所有关键决策（六道、善恶、谈判、劫运骰、绕路）都是同一结构：收益明确、代价明确、且代价 mostly 是"命"（寿命 / 心魔 / 未来选项）。玩家持续的乐趣来源不是"变强"，而是"这次我付得起"的紧绷感与付完之后的叙事回应。

H0 可分解为四个可独立证伪的子假设（每条都给出了当前的支撑系统与"如果被证伪，先动哪里"）：

编号子假设支撑系统（真源）证伪信号 → 第一动作
H1选择压力乐趣：善恶斜率差（善稳 / 恶快但有命债）能产生"纠结的爽"六道 BY_FATE 心魔 0/8/12/15 + 折寿 0/0.3/0.5 + 道心三档 SEAL_MOD（data_daoxin.js）playtest 中玩家无纠结、固定选战 → 强化恶道独占收益（谈判/罪业贸易可视化）
H2构筑兑现乐趣：劫印×道心×法宝×经文的乘区组合能被推演并兑现SEAL_TIER_CHAIN 白蓝金红、合成 3→1、REGION 映射 regionToTier、法宝道途共鸣 ×1.15玩家拿印"哪个数值大用哪个" → 词条差异化（金蝉/禅息/厚土/逐杀）前置教学
H3叙事牵引乐趣：失败被转译成"朝代推进 + 传承积累"，让死亡本身产生收集欲17 朝 dynastyInterp 动态送行 + 劫灰坊 + V8.56 劫印 100% 承继 + 万世剑冢节点（V8.56）连败 3 局后弃游率上升 → 死亡结算页强化"你留下了什么"清单
H4终局攀爬乐趣：81 难通关不是终点，天道劫 100 层 + 真结局让长线有塔可爬TJ_001-100 / TJ_050 业镜 / TJ_099 镜像 / HUNYUAN 三项淬炼（10/20/100）通关玩家流失在天道劫 20 层前 → 业镜/岔路收益不足，检查层奖励曲线

PART 2

三层核心循环（V8.60 口径）

Rev.3 画了「局内环 × 局外承继环」双环，但未按时间尺度分层。本节把循环拆成 回合内（秒）/ 单局（50-90 分钟）/ 跨周目（天-周）三层，逐层标注钩子（让玩家进入下一层循环的具体动机），并按 V8.60 修正资产流向。

2.1第一层 · 时刻循环（moment-to-moment，10-20 秒）

环节内容钩子设计评估
回合结算预模拟回放，蓄力→攻击→掉血一递一还演出已是近期投入重心（水墨战场、金色技能名 callout、crit-burst 粒子、倍速），视觉反馈通道在全游中最厚 ✓
操作点蓄力重击 / 狂暴 / 低血量 / 节奏点，窗口 2.0s（Boss 2.5s）错过则静观——被动容错好，但也意味着"挂机可通关"，操作深度上限低。真正的操作深度在三键时机（Part 3.5）
气势累积0/1/3/5 四档 → 爆发/识破/防备 ×0.6/1.0/1.5"还差 1 点就到档"是经典的接近效应（approach motivation）钩子 ✓
资源滴答mana / 连段窗口 2000ms / 装备充能辅助层，认知负担适中

本层唯一结构性弱点：普攻伤害 GLOBAL_DMG_MUL=0.5 砍半 + 战斗拉长到 2000ms/回合，是为了演出与节奏感——代价是"时刻循环"的决策密度低（多数回合无操作点）。用倍速（2x/3x）可以让熟练玩家自调节奏，这是正确的解法；但需验证 3x 下演出是否仍可读（V8.49 已按 fightSpeed 同比压缩位移，门禁为逻辑测试，视觉需实机确认）。

PART 3

系统设计审计：八个核心系统的 Mechanic Biopsy

Rev.3 的模块章是"现状 + 闭环 + 契合"的清单。本节换手术刀：每系统回答六问——设计目的 / 体验目标 / 输入 / 输出 / 边界与失败态 / 调参杠杆。只收录核心八系统；未尽系统（装备/宠物/神龛/成就）沿用 Rev.3 结论。

4.4新发现：BUG ashFromRun 善恶折算不对称（10 倍）

data_reincarnation.js · ashFromRun

a += (s.good||0) + (s.evil||0)*0.1; // 注释写「(善+恶)×0.1」

问题：运算符优先级使善念按 1:1 计劫灰、恶念按 0.1:1——善道劫灰收入是恶道的 10 倍，与注释意图（善恶同权 ×0.1）不符。

设计层面影响：这与 P2 支柱「善恶皆有力量」直接冲突——恶道在心魔（+12/+15）、折寿（+0.5）之外又背上劫灰惩罚，而劫灰是唯一永久货币。三重惩罚叠加下，恶道长线性价比显著低于善道，"恶有力量"只剩局内短期收益（谈判/深渊态 +15%）。

修复方向（二选一，需用户拍板）：① 改为 ((s.good||0)+(s.evil||0))*0.1 对齐注释；② 若"善道更多劫灰"是有意的（引导新手走善），则把注释改为真实意图，并在游戏内明示"积善者劫灰丰厚"。当前状态下代码与注释互相矛盾，属于真源内部不一致，必须二选一收口。
