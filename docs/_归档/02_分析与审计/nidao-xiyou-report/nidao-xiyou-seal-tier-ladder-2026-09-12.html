一、设计决策（用户拍板）

原阶梯为 白 < 蓝 < 金 < 红（红最强），存在两层隐含冲突，用户拍板重构为 白 < 蓝 < 红 < 金（金=顶阶）：

白劫底档 · 弃印 6
蓝劫精英/心魔 · 弃印 12
红劫融合≥3 / Boss 双源 · 弃印 30
金劫仅三红合金 · 弃印 45
冲突旧设计新设计（落地）
层级倒挂Boss 白送金、融合保底红 → 红比金强、金易得反弱金=顶阶，仅由三红合金合成，来源唯一
合金亏值3 红（各≈金×1.55，合计 4.65×金）合金成 1 金（1×金）→ 蒸发 78% 战力金 = 红×3（SEAL_GOLD_SCALE = SEAL_RED_MULT×3），功率中性，价值在构筑精简 + 顶阶标识

拍板结论：Boss 掉落改红劫；金劫 = 红劫 ×3，三红合金不再亏值。

三、🔴 本轮真 Bug（已修）

红劫四舍五入破坏「金 = 红×3」精确不变量。 补档原用 Math.round(wd.tiers.gold * 1.55 * 100) / 100：

红劫 0.340×1.55 = 0.527 → 被 round 成 0.53 → 3×红 = 1.59 金劫 0.340×4.65 = 1.581（未 round） → 金 = 1.581 差值 0.009 → 合金「功率中性」断言失败

改为不四舍五入后，金 = 金基×4.65 ≡ 3 × (金基×1.55) = 3×红 在数学上严格相等。显示层 ui_panel_2.js 用 Math.round(val*100)% 自行取整（整数百分比），去内部 round 对玩家视觉无影响。
