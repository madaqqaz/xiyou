### 4.1 哪吒 / 杨戬：数量达标，位置系统性错位（P0）

### 4.2 结局系统：三轨并存，还有一颗潜藏崩溃雷（P0）

实际同时存在三套结局口径：
1. **`ENDINGS_CG` 6 条**（文档口径）：正果/逆道/大圣 + 八戒/沙僧/小白龙三张英雄告别卡；
2. **`computeEnding()`（game_meta.js:391，真正生效）**：按英雄+善恶返回 **7 变种**，完全不读 `NDX.ENDINGS`；
3. **`NDX.ENDINGS`（data_trials_story.js:165，死代码）**：战/隐/夺/渡/逆/**衡** 六键——**含"衡"缺"缘"**，与六道不一致；其 `evaluateEnding()` 在"缘"主导时会 `undefined.title` **抛 TypeError**（因未接线暂未触发）。

论道三选本身**已接线且可达**：`game_lundao.js:158` `s.over.ending = ending` 覆盖默认；焚→nidao、重续→zhengguo、存留→dasheng；"存留"门槛（持「旧账·逆道印」+ 全局未用戾骨献祭）条件可达、非死锁，属设计内高门槛。**问题只在三套口径并存**——建议：`NDX.ENDINGS` 死代码直接删除或并入 `ENDINGS_CG`，统一"6 CG + 论道三选改写"的单一真源。

## 五、构筑空间与重复可玩性

### 5.1 心魔系统：已实现，但与设计稿是两套东西（需拍板）

代码实际实现（`data_xinmo.js`）是**六道抉择驱动**模型：
- `BY_FATE`：渡 0 / 缘 0 / 隐 +8 / 战 +12 / 夺 +12 / 逆 +15（上限 100，非 58）；单章累计帽 35；转章涤心 −12、歇息 −8；
- 心魔镜像战：无次数硬上限，战败惩罚 ×1.5 递增（气血上限 −10%/次）+ 随机丢 1 劫印；恶道劫印每章再 +3 心魔；
- 档位铭文 0/30/60/85/100（心明如镜→心魔临门）。

而设计稿 `design/gdd/dual-path-scriptures.md` 描述的是**经文碎片驱动**模型（每片逆经 +1、渡经 −1、上限 58、阈值 25/45 全伤惩罚、9 部逆经代价配方、-25% 软上限、逆天录锁结局）。**两者无一对接**：GDD 的阈值惩罚/代价配方/软上限在代码中均无对应。要么把 GDD 按"已被代码模型替代"归档，要么明确把 GDD 的"代价层"作为 V8.5x 之后的增量设计排期——**当前状态是双真源漂移，最危险**。

### 5.2 保底与防稀释链（完整，是强项）

| 机制 | 实现 | 位置 |
|---|---|---|
| 装备 soft-pity | 阈值 **6** 次未出套装基座→强制保底一件 | `data_equip_core.js:363,417–469` |

| 六道加权 | 当前主道装备三选一池 **×4** 权重（动态主道实时跟随） | `data_equip_core.js:393,437` |
| 轮回感受性保底 | 二周目起每 3 次失败 +1 保底层（至多 3），只降门槛不加数值 | `data_reincarnation.js:308–324` |

### 5.3 可辨识流派（代码证据支撑）

1. **渡道纯经流**：观音/文殊传承经（死亡解锁）+ assureSynergy 保底 + 禅光，稳发育；
2. **逆道高压流**：心魔 85+ 硬扛 + 镜像战赌命 + 9 章逆道真器 + 戾骨爆发——高风险高回报的代价闭环真实存在；
3. **六道转职流**：命数门槛 18/28/38 三阶 + 六残片（每道一条固定获取路线）+ 本命道 `HOME_DAO_MULT` 放大 + 同道装备 ×4 掉落，形成"选道→全线倾斜"的正反馈；
4. **法宝克制流**：25/25 Boss debuff 全映射 + 8/8 解厄 cleanse，打 Boss 前换宝有真实决策；
5. **英雄专属流**：5 英雄 + 4 张告别卡结局 + 英雄专属法宝 tier1–4 自动进阶（不降级幂等）+ 绝招 5；
