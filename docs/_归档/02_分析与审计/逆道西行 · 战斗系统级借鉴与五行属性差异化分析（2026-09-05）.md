# 逆道西行 · 战斗系统级借鉴与五行属性差异化分析（2026-09-05）

> 触发问题：用户指出「战斗中攻击就是攻击，诵经就是法术」——三键（攻/经/绝）只有物伤/法伤的数值差异，没有「属性 × 特效 × 玩法」的差异；并以「万世剑冢式招牌技能（不同五行、不同属性、不同特效）」为理想参照。
> 前置事实：V8.43 曾整体删除五行系统（用户拍板：与六道/装备体系重复度高）。本分析的关键任务之一，是给出**不与六道/装备重复、不重蹈 V8.43 覆辙**的属性差异化方案。

---

## 1. 现状盘点：三键为什么"平"

| 维度 | 现状 | 缺口 |
|---|---|---|
| 伤害属性 | 攻=体伤（atk vs dr）、经=愿伤（matk vs mdef）、绝=气势爆发 | 只有物/法两轴，无属性标签 |
| 状态 | 怪物有 burn/daze/frost/curse/poison/weak（`_BOSS_DEBUFF_MAP`）；玩家侧 pDebuffs（易伤/标记/冻结/沉默/叠甲） | 状态存在但与「攻击/诵经本身」无绑定关系——谁打的、什么属性打的，不改变状态 |
| 特效 | slash/shake/hitstop/climax/粒子全家桶（代码生成，零美术） | 特效是通用刀光/震屏，不随属性变化 |
| 克制 | 法宝克制（counter.tags 命中怪物标签放大效果） | 只有「法宝 vs 怪」，没有「招式 vs 怪」 |
| 身份感 | 英雄本命道（HOME_DAO）、转职显影、万世剑冢金字 callout | 三键动作本身不携带英雄身份 |

**一句话诊断**：招式是"无色"的。借鉴方向不是再叠一套数值克制表，而是给三键"上色"——属性标签 + 专属状态 + 专属演出，让"攻击就是攻击"变成"悟空的攻击是庚金斩、唐僧的诵经是甘露润"。

## 2. 系统级可借鉴清单（战斗模式全景）

| # | 竞品机制 | 核心做法 | 对我们游戏的落点 |
|---|---|---|---|
| 1 | 原神·元素反应 | 附着（上状态）→ 触发（后手属性命中）→ 反应（增幅 ×1.5/2.0 或剧变 AOE）[$TRAE_REF](https://wiki.biligame.com/ys/%E5%85%83%E7%B4%A0%E5%8F%8D%E5%BA%94) | 五行状态积累 + 双属性先后命中触发反应（本文 §4 方案 B） |
| 2 | 哈迪斯·众神祝福 | 神=属性=玩法风格：宙斯=雷电连锁、波塞冬=海浪击退+资源、阿瑞斯=标记延迟爆发、狩猎=暴击 [$TRAE_REF](https://www.gamersky.com/gl/Content-1345242_3.html) | **属性即玩法**而非属性即数值：五行各有独立机制身份（金=破甲、木=控制、水=反应位、火=DoT、土=打断） |
| 3 | 神界原罪2·地表组合 | 元素 × 元素 = 新效果：水+电=感电水（麻痹）、水+火=蒸汽（遮蔽）、火+毒=爆炸 [$TRAE_REF](https://gl.ali213.net/html/197747_32.html) | 双属性反应表（§4 方案 B），每对五行一次反应 |
| 4 | 杀戮尖塔·故障机器人元素球 | 四种球=四种资源循环：闪电=自动输出、冰霜=护甲、黑暗=蓄力爆发、等离子=能量 [$TRAE_REF](https://slaythespire2hub.com/guides/defect-guide) | 长期愿景：五行球栏位（§4 方案 C），与现有气势条形成双资源 |
| 5 | 太吾绘卷/鬼谷八荒·五行 | 内力属性五行相生相克（金生水、水生木…金克木、木克土…），功法流派绑属性 [$TRAE_REF](https://gl.ali213.net/html/2018-12/292387.html) | 文化底蕴素材：**原著金公/木母/黄婆/心猿/意马**对应悟空金、八戒木、沙僧土、白龙火、唐僧水（§3） |
| 6 | 暗黑4·灌注（Imbuement） | 技能可被灌注为毒/火/冰，同一技能换属性换状态；状态联动（中毒敌人被冰冻额外减速）[$TRAE_REF](https://www.rpgstash.com/blog/diablo-4-season-9-horadric-spellcraft-guide) | 方案 C：经文/法宝/事件给三键"灌注"五行，肉鸽构筑层可换属性 |

**核心提炼**：六种机制的共同点是「属性不是第二张数值表，而是身份、状态、演出、构筑的载体」。这正是 V8.43 被删五行系统所缺的——当时五行落在饰品/克制数值上（与装备重复），这次落在三键操作层与演出层（不碰装备、不碰六道数值）。

## 3. 方案骨架：五行 × 三键 × 英雄（原著身份映射）

### 3.1 英雄五行本命（西游记原著背书，零额外数值）

| 英雄 | 原著代号 | 五行 | 三键语义化 |
|---|---|---|---|
| 悟空 | 金公（心猿） | 金 | 攻=「庚金斩」（锐利破甲）、经=「定心猿」（自净）、绝=「如意金箍」（横扫） |
| 八戒 | 木母 | 木 | 攻=「钉耙裂土」、经=「九齿生发」（缠绕控制）、绝=「倒打一耙」 |
| 沙僧 | 黄婆 | 土 | 攻=「流沙震击」（打断蓄力）、经=「担经护体」、绝=「流沙陷阵」 |
| 白龙 | 意马 | 火 | 攻=「龙火灼蹄」、经=「龙涎」（火系治疗变体）、绝=「白马惊雷」 |
| 唐僧 | 江流儿 | 水 | 攻=「锡杖点水」、经=「甘露润泽」（水系治疗）、绝=「紧箍真言」 |

- **攻/经/绝三键本身不变**，属性由英雄本命决定——「攻击就是攻击」升级为「悟空的攻击是庚金攻击」。身份感 = 万世剑冢式招牌感，成本为零（只加标签 + 特效 + 状态）。
- 与既有「本命道 HOME_DAO」概念同构、不冲突：本命道管数值收益，五行本命管属性演出，各司其职。

### 3.2 五行属性 × 专属状态 × 专属演出（P0 主体，全部复用现有系统）

| 五行 | 状态 | 效果 | 演出（代码生成，零美术） |
|---|---|---|---|
| 金 | 裂甲 | 易伤 +1 层（复用 pDebuffs 脆弱系），持续 2 回合 | 金色斩击 + 护甲碎裂粒子 |
| 木 | 缠绕 | 速度 -30%（复用 weak/沉默减速系），持续 2 回合 | 藤蔓缠绕 + 绿色粒子 |
| 水 | 浸润 | 反应触发位（本身微缓速 10%）；与其它属性先后命中触发反应 | 蓝色水波涟漪 |
| 火 | 灼烧 | DoT 每回合 8% 愿伤（复用 burn） | 火焰粒子 + 灼热震屏 |
| 土 | 震击 | **打断怪物蓄力重击**（telegraph 回合被土系命中 → 次回合不重击） | 褐色震波 + 地面裂纹 |

- **土系打断 = 与"识破"平行的第二条反制线**：识破是"格挡反制"（反应型），震击是"打断反制"（先发型）——两条反制路径给玩家选择，且直接增强对蓄力重击的博弈（对应竞品借鉴分析里"意图预告"的配套动作）。
- 状态全部复用既有 debuff 体系（burn/weak/frost 等），只新增「五行标签」与「反应结算」，不新增数据层。

### 3.3 与 V8.43 被删五行系统的边界切割（防重蹈覆辙铁律）

| V8.43 被删内容 | 本次方案 | 差异 |
|---|---|---|
| 五行饰品 / trinket 槽 | 不做任何新装备槽 | 零装备层改动 |
| 五行 × 装备词条 | 不绑定词条 | 零数值构筑改动 |
| 战斗克制数值结算（×1.5 之类） | 克制降级为「状态优先级 + 反应触发条件」，不直接乘伤 | 无第五套数值表 |
| 地区五行对齐（REGION_WUXING） | 仅叙事层保留（地区氛围） | 不参与战斗数值 |
| 五行 × 六道双矩阵 | 五行归英雄、六道归流派，两轴正交 | 不产生矩阵复杂度 |

## 4. 分步落地（按批次，与既有 P0/P1/P2 节奏衔接）

### 批次一（P0）：属性上色 + 状态 + 演出（零数值风险，立即可上）

1. `data_heroes_data.js`：英雄加 `wuxing: '金'` 字段（金/木/水/火/土）。
2. `combat.js`：玩家攻击回合打标 `pTurn.wx`（英雄本命五行）；怪物新增可选 `wx` 标签（妖属五行，供反应/叙事用）。
3. 状态结算：命中时若目标无对应状态则施加（裂甲/缠绕/浸润/灼烧/震击），**沿用现有 debuff 计时与 UI 角标**。
4. 演出层（`main.js`/`ui_misc_3.js`）：`dmg-fly` 的 `_kind` 之后追加 `_wx` 维度，粒子/飘字颜色随五行切换（金#ffd700/木#6fcf6f/水#4aa8ff/火#ff6b3a/土#c8925a）；震击命中额外播"地震波"动画。
5. 意图联动：怪物 `telegraph` 回合被土系命中 → 打标 `interrupted: true`，次回合意图降级为普通攻击。

**门禁**：`_smoke_wuxing_basic.js`（五行标签落位 / 五状态施加与到期 / 土克蓄力打断 / 演出事件携带 wx 字段）。回归 regression/combo 不受影响（零数值改动）。

### 批次二（P1）：五行反应（原神附着-触发 的回合制简化版）

规则（控制在 8 条以内，贴西游记语义）：

| 反应 | 触发（目标已有 A，后手命中 B） | 效果 |
|---|---|---|
| 熔炼 | 金 + 火 | 目标减伤（dr/mdef）减半 2 回合 |
| 削伐 | 金 + 木 | 缠绕加深为「禁锢」：跳过目标下一回合行动 |
| 陷落 | 木 + 土 | 震击强化：打断 + 目标下回合速度清零 |
| 淤滞 | 土 + 水 | 目标闪避归零 + 减速 2 回合 |
| 雾隐 | 水 + 火 | 我方获得 1 回合闪避 +50%（蒸汽遮蔽） |
| 生发 | 水 + 木 | 我方回复 maxHp 8%（渡道/奶经友好） |
| 淬锋 | 金 + 水 | 我方下次攻/绝必暴击 |
| 熔岩 | 火 + 土 | 灼烧 DoT 翻倍 |

- 触发规则：敌人身上已有状态 A（附着），玩家用属性 B 命中 → 触发反应 AB；**同敌人每场战斗每种反应限 1 次**（防刷，与操作点/识破节奏一致）。
- 灌注入口（暗黑4 式构筑）：经文「五行」标签或特定法宝可将三键"灌注"为指定五行（如持「芭蕉扇」→ 经/绝转火），改变后手属性 → 反应可被玩家主动构筑而非随机碰运气。与既有「经文六道标签 ×1.5 路由」「法宝克制 counter」体系并列，互不重叠。
- 敌人侧：精英/Boss 可带五行词缀（如火行妖身 → 被水克时反应优先级提升），走既有 affix 通道，不加新系统。

**门禁**：`_smoke_wuxing_reaction.js`（8 反应逐一构造命中序列验证 + 每反应每场限 1 次 + 灌注改属性生效）。回归重点关注 build_match_fight（反应不改变 build 承伤预算，仅怪物承伤侧增益，需复核压力钳制不破）。

### 批次三（P2）：五行球资源循环（StS Defect 式，长期愿景）

- 每个英雄一条「本命五行球」栏（3 球）：攻/经/绝命中填充对应元素能量（金攻+1金球、经+1水球…），满 3 球可「五行爆发」——本命五行大招（如悟空金球满 = 金箍横扫全屏）。与现有气势条（通用爆发）并存：气势=通用小爆发，五行球=属性大招，双资源给玩家两条攒爆路线。
- 五行爆发演出复用 climax 家族（全屏金光/大字已具备），零美术。

## 5. 落地顺序与开发计划衔接

| 批次 | 内容 | 风险 | 门禁 |
|---|---|---|---|
| P0（手感层） | 英雄五行本命标签 + 五状态 + 五色演出 + 土克蓄力 | 零数值，纯标签/状态/演出 | `_smoke_wuxing_basic.js` |
| P1（决策层） | 8 条五行反应 + 灌注入口（经文/法宝） | 怪物承伤侧增益，需复核 build_match_fight 压力钳制 | `_smoke_wuxing_reaction.js` |
| P2（资源层） | 五行球栏位 + 本命五行大招 | 双资源并存需实测节奏 | 随五行球门禁 |

- **三端**：P0 演出层 DOM 专属（小游戏/Canvas 需等价实现）；P1 反应与灌注全在 combat.js 纯逻辑层，三端共享；P2 五行球为逻辑 + 演出双层。
- **不触碰**：装备三选一系统、六道数值、经文 ×1.5 路由、法宝克制、Build 匹配采样——五行差异化全程与这些正交。

## 6. 决策留白（需用户确认）

1. **五行归属**：攻/经/绝属性绑定**英雄本命**（方案 A，推荐：身份感强、零成本、呼应金公/木母/黄婆/意马/江流儿），还是绑定**三键固定**（攻=金、经=水、绝=火，简单直接），还是两者皆可被灌注覆盖（方案 C，构筑深但 P0 成本高）？
2. **土系打断的强度**：震击打断蓄力是否消耗识破窗口（打断后当回合不再可识破，避免双反制叠加过强）？推荐：打断优先、识破让位。
3. **反应表规模**：8 条全上（推荐，语义完整）还是先 5 条核心（熔炼/陷落/雾隐/生发/淬锋）？
4. **五行球与气势条**：并存双资源（推荐，P2 验证）还是五行球取代气势爆发（改动大，不推荐）？
