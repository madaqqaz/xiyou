# 《逆道西行》竞品机制借鉴备忘（2026-08-29）

> 本文是**设计草案备忘，非代码真源**。目标：在已有十几个系统之上，用"机制深度装置"而非"堆系统量"来补强招牌手感。
> 借鉴对象均经筛选，只取与现有系统对口、改动可收敛者。实现以代码 + 主开发文档为准；本备忘与代码冲突时以代码为准。
> Owner 规则：新玩法若落地，**共享语义必须进入其唯一 owner 数据文件**，ui.js/main.js 只做渲染接线。

## 0. 原则与不做什么

- **不加新系统**：现有系统已足够丰富，只借"让已有属性变成玩家主动经营/冒险"的深度装置。
- **三端同步**：若落地为主玩法，按 §七·五 须三端（浏览器 H5 / 微信小游戏 / TapTap）对齐，不可某端独有。
- **零新增美术预算优先**：三条均以逻辑层 + 既有立绘/图标复用为主，符合"0–500 元美术、零成本执行"约束。

## 1. 【主推·先落地】暖雪式"罪业可交易化" → 深化「善恶命运 + 心魔」

### 1.1 借鉴点
暖雪的灵魂是"杀业越重越近魔、越接近黑暗结局"，力量与代价强绑定。现善恶/心魔更像被动计数器，缺"可主动经营的能量"。
### 1.2 接到的现有系统
- **善恶**：`s.good` / `s.evil`（`data.js` 命运线、`_gainFate`）
- **心魔**：`s.xinmo` / `s.xinmoLevel`（`_gainXinmo`，game.js，随入魔层数变化）
- **六道道途**：渡（度化）/ 逆（堕落）两系（`jieseals.js SEAL_DAOTU`、`mainDao`）
- **观音好感**：`s.favors`（game.js §3.4）
### 1.3 玩法规则草案（"黑暗神通 / 度化祝福互换局"）
- 新增一个**局内主动兑换入口**（你方阵营卡/劫印面板一角）：把当前善恶值折算为可兑换的代币。
- **逆道路线（堕落）**：用 `evil` 兑换"黑暗神通"——高上限、高爆发（贴合"破爆发"），换取观音好感下降、心魔加深（更高负面事件概率）。撑起"越逆命越强、越接近黑暗结局"。
- **渡道路线（度化）**：用 `good` 兑换"度化祝福"——安稳发育、治愈/经文/减伤，换取初期上限略降、爆发略低。撑起"越向佛越稳"。
- **不可无代价白嫖**：兑现代币只能二选一路线投入，且每次兑换抬升下一次门槛（边际递减），防止无限刷善恶。
- **MVP 边界**：仅涉及数值/条目兑换与心魔/好感联动，不做独立新结局（黑暗/光明结局已有二周目基调，可在 MVP 后接）。

### 1.4 数据表草案（owner）
- `data.js`：`NDX.SIN_EXCHANGE`（兑换表：档位、所需善恶值、给付神通/祝福条目、下一次边际系数）、`NDX.SIN_GIFTS`（黑暗神通）`/ NDX.LIGHT_BLESSINGS`（度化祝福）条目录。
- `game.js`：`exchangeSin(dao, idx)` 校验善恶、扣值、发条目、联动 `favors`/`_gainXinmo`；状态 `s.sinUsed:{evil:[], good:[]}` 防止重复兑换。
- 数值公式：属现有战斗/数值口径，修改后必须同步主开发文档 §三（命运/心魔）、§四（劫印）对应章节。
### 1.5 验收入口
- `node --check data.js game.js ui.js`。
- node mock：善恶不足拒绝 / 兑换后好感-心魔联动 / 边际递减 / 防重复兑换。
- 实机（浏览器 v++）：进入兑换面板、兑换黑暗神通后 atk/爆发提升 + 心魔加深、兑换度化后安稳发育；无 console 错误。
- 三端：核心逻辑进 `data.js/game.js`（三端共享），仅入口按钮在 DOM UI 与 Canvas UI 分别布线。

### 1.6 改动规模估算
核心逻辑改动小（一张表 + 一个 exchange 函数 + 入口渲染），是三条里**成本最低、最立招牌**的一条。

## 2. 【候选二】Loop Hero 式"给旅途铺路" → 深化「篝火/土地庙 + 十七地区」

- **借鉴点**：反向构筑——给循环铺设的设施决定下一圈强度/收益。
- **接收现有系统**：休息节点（土地庙/篝火，`events.js`）、十七地区 `ACT_RANGES`（`data.js`）。
- **玩法草案**：把土地庙从"单次休息节点"升级为**可升级营地挂件**（加回血 / 给药 / 触发经文 / 改难名）+ **主动部署开关**（舍利塔加固 = 提高本区风险与收益）。让"休息节点"变成每难都在经营的 meta 布点。
- **owner**：`events.js`（营地挂件表 + 升级规则）、`data.js`（地区加固档位）、`game.js`（进入休息节点结算）。
- **验收**：升级前后营地效果 / 部署开关风险-收益 / 跨地区持久。
- **规模**：中——需要休息节点状态持久化与界面改动。

## 3. 【候选三·已重新定位】欺诈之地 Griftlands 式"谈判即战斗的另一解" → 逆道「以经为质·收服妖王」

> 2026-08-31 重新定位：原"渡化替代战斗"否决不变；本条改为**逆道专属谈判**（通关后解锁），以佛经积累为谈判强度，收服妖王为随从。

- **借鉴点**：谈判/交涉是与战斗平行的硬核资源交锋（Griftlands）。
- **接到的现有系统**：逆道（`jieseals.js SEAL_DAOTU`、`mainDao`）、佛经全本/散件（`data.js SUTRA_FULLS`、`s.sutras/sutraFrags`）、逆道经文（`s.niSutras/niSutraFrags`）、心魔（`data.js NDX.XINMO`）、观音好感（`game.js s.favors.gods`）、白骨令牌（第10难【隐】潜行侦查伏笔）。
- **玩法规则草案**：
  - **逆道通关后全锁**：逆道整体二周目开放（反转 V8.16 一周目开放）；佛经系统本就通关后激活，与逆道解锁天然同步。
  - **谈判触发**：局内 `mainDao=逆` + 节点为精英/Boss + 佛经全本≥1 或散件≥N；进入节点时「【逆】以经为质·谈判」与「战斗」并列。
  - **谈判强度（佛经不消耗）**：佛经全本数×8% + 佛经散件数×0.5%（碎片数量本就不同，不作货币消耗）；修正：心魔+3%/层、逆道经文+5%/部、恶值+1%/10；妖王难度：精英×1.0 / Boss×0.6；封顶 85%；白骨令牌 Boss 谈判 +20%。
  - **谈判代价**：成功→跳过战斗**无战斗掉落**（装备/材料/金币，核心代价）；失败→妖王激怒（本场战斗 atk+10%）。
  - **心魔**：谈判成功 +0 / 失败 +8（低于逆道抉择 +15）；计入单章封顶 35，转章涤心 12、歇息 8 释放阀——三重保护防早期爆满 100 触发镜像战死局。
  - **观音好感（方案 A）**：不引入数值扣减（现为二值 gods 数组）；收服随从后观音好感钩子暂停——每收 1 随从，favorGate 的愿力/善加成少触发 1 次。无死局。
  - **收服随从**：成功→妖王臣服为随从，跳过本场战斗；随从战斗助战（类似观音助战/灵宠）；上限 3 个，满需替换。
- **owner（落地时）**：`data.js`（谈判表 `NDX.NEGOTIATE`、随从效果表 `NDX.FOLLOWERS`）、`game.js`（`negotiate()` 判定结算、状态 `s.followers`）、`combat.js`（随从助战结算）、`events.js`（谈判入口事件）、`ui.js`（谈判界面渲染）。
- **平衡风险**：佛经不消耗（碎片数量不同，非货币）；跳过战斗无掉落是核心代价，随从强度需对得起放弃掉落；三端同步，核心逻辑进 data.js/game.js。
- **规模**：中高——需新的节点内分支、随从系统与数值平衡。

## 5. 落地顺序建议

1. **先做第 1 条（暖雪罪业可交易化）**——成本最低、最立"黑暗西游"招牌、最贴合"破爆发"爽感。
2. 第 2 条（营地 meta）在休息节点体验被诟病时再上。
3. 第 3 条（逆道谈判·以经为质）为二周目内容，随逆道通关后解锁一起上；需先落地逆道全锁与随从系统。

## 6. 决策留白（需用户最终确认的问题）
- 第 1 条 MVP 是否就**只做兑换 + 数值/联动**，不做新结局？（本文默认是）
- "黑暗神通/度化祝福"倾向**局内消耗型 buff（次/局）**还是**常驻档位成长（整局）**？建议常驻档位，更贴"经营一条路线"。
- 兑换后善恶值是否保留原善恶线判定（结局/观音/入魔）？建议**消耗不影响善恶线本身**，只影响后续兑换额度。

## 7. 落地与命名定稿（2026-08-29）

> 按用户确认落地第 1、2 条；第 3 条（渡化替代战斗）**否决**——渡化仍走战斗，善路功德只做属性成长，不新增跳过战斗的渡化通道。

- **常驻档位成长（整局）**：每档全局可购一次，`s.sinUsed[route]` 记账；善恶消耗不影响善恶线判定。
- **命名定稿**（原草案命名不符西游背景，已替换）：
  - 「黑暗神通」→ **妖魔法相**（逆路·以恶抵业换杀伐上限）
  - 「度化祝福」→ **度化功德**（渡路·善缘换安稳发育）
  - 「营地图腾」→ **土地神龛**（土地庙休息节点的 meta 布点，添香加固 · 立龛相）
