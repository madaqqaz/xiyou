一、当前真问题（仍成立，需整改）

阻断级 1. 运营数据闭环缺失（零埋点）

grep telemetry|analytics|trackEvent|埋点|logEvent|track\( → js/ 全库 0 命中

全库没有任何埋点 / 遥测 / 事件追踪代码。游戏上线（三端同步）后，无法定位流失节点、卡关难度、选项道分布、Boss 时长等关键运营指标。

推荐：在 owner 层（game.js 结算、trial 进入/离开、掉落结算）加轻量事件埋点——不引第三方，仅 localStorage 环形缓冲 + 开发期导出；至少采集每难 进入/胜/负/弃、六道选项分布、掉落、Boss 时长。

设计风险 2. 劫印 / 装备掉落无保底

存在：equipment.js:1487 petEvolPity（宠物进化保底）· events.js:87 / game.js:1178 eventPity（缘节点遭遇战保底） 缺失：grep 保底|pity 于 jieseals.js → 0 命中；game.js:2194 劫印"只有劫难才必掉"，无 pity 计数

保底系统已覆盖 宠物进化 与 缘节点遭遇类型，但物品掉落（劫印 / 装备）没有任何 soft-pity。长线构筑体验波动大，非酋玩家易被卡在构筑瓶颈。

推荐：为劫印 / 装备掉落加 soft-pity（如连续 N 次未出金劫印 / 高阶装备后概率阶梯上升），与既有 petEvolPity 同层实现。

设计风险 3. 自动战斗削弱操作参与感（需重新定性）

game.js:2731 "V8.29 回合制自动战斗 AI：每回合择最优三键技能（atk/chant/ult）" ui.js:4197 前3地区强制手动，第4地区起可切自动（main.js 强制1x） combat.js:1030 三键 combat：combo(战)=连击多段 / burst(夺)=连爆爆发 / pierce(逆)=透骨穿刺；combat.js:293 小白龙·疾风连击

自动战斗 AI 真实存在（参与感弱成立）。但旧结论「连招不存在」已过时——combat.js:1030 已有 combo(战) 连击多段机制，三键战斗也已落地。真实缺口是：手动连招链深度有限 + 自动战斗过早开放稀释操作权重。

推荐：① 限制自动战斗（如仅非 Boss / 手动连招可叠加倍率奖励）；② 深化手动 combo 链（连击→连爆→透骨 串联奖励），让手操有正反馈。
