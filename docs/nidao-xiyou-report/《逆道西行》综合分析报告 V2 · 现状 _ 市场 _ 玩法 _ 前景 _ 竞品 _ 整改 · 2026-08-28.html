02玩法分析

2.1 核心循环拆解

双层循环结构清晰：局内是「抉择 → 收集 → 构筑 → Boss 验证」的肉鸽循环，局外是「死亡 → 传承 → 更强来世」的轮回循环。经文收集制（191 片）与 BD 流派多样性让两层循环产生耦合——单周目注定收不齐，跨周目图鉴成为长期目标，这正是梦幻西游式收集长线的设计意图落地。

2.2 五大玩法支柱评估

① 六道命运抉择 —— 最强差异化

81 难 × 六道选项的道德网格在竞品中没有对等物。渡/逆双主线对称（逆数值高于渡同档）+ 一周目全开的设计，把「叛逆叙事」从二周目彩蛋升格为首发卖点。地区配额制又把「道」从叙事标签变成了资源分配策略。

② 识破战斗 —— 自动战斗中的主动权

「自动紧凑播放 + 择机决策」解决了 H5 肉鸽最大的矛盾（速刷效率 vs 操作深度）：识破窗口、气势爆发、法宝克制、三键 CD 形成四个决策层。V8.29 自动战斗 AI 进一步把重复小怪战压缩为速通。

③ 经文收集制 —— 长线钩子已就位

渡 133 / 逆 58 片、碎片独立命名、华严/逆天录终极赌局（单局限量 vs 全加成），供给核算已做过（纯诵经路线极限 127/133 片，差 6 片跨局补）。收集图鉴是留存的核心抓手。

④ Boss 变身 —— 演出密度足够，节奏待验证

8 个三段 Boss + 三戏轮转（白骨夫人每 3 回合切相）提供了同类 H5 产品罕见的 Boss 战层次；但三段 = 战斗时长 ×1.5 以上，中后段连续高难 Boss 的疲劳曲线需要实测校准。

⑤ 地区配额 —— 策略性成立，反噬风险待观察

配额满才解锁 Boss 强化了地区内探索动机，避免「直冲 Boss」的速通流；但若配额目标不透明或补配额体验重复，会变成负反馈（被引导回去刷）。建议配额进度常驻 HUD + 地区内剩余配额来源可视化。

2.3 玩法短板（按影响排序）

短板表现影响严重度
系统复杂度前置六道/劫印/识破/气势/经文/法宝/配额在开局 30 分钟内全部压向玩家，教学依赖首次弹窗文案新玩家前 3 难流失风险高——小游戏平台用户耐心以分钟计高
中后段内容同质地区 12–17（祭赛国→凌云渡）以通用随机池兜底，专属叙事/英雄文本未补「通关凌云渡」的终局体验与前段落差大，二周目动机受损高
数值标尺错位装备/红材/转职仍按旧四章/九章标尺，与 17 地区号错位：凌云级装备从难 14 起掉落（设计难 61+），转职门槛整体前移中局数值膨胀、难度曲线被压平，「后期变强」的成长感知被稀释高
普通战斗决策密度小怪战多数仅 1–2 个决策点（识破窗口），自动 AI 上线后更偏「观看」中期体验疲劳；依赖 Boss 战与事件拉回注意力中
局外成长入口分散拓印/继承匣/难簿/成就各自为政，缺统一「传承阁」式界面跨周目动机感知弱，收集目标不直观中
死亡归因模糊败北后缺「构筑哪里断了」的复盘信息肉鸽「失败归因运气而非水平」的设计目标未完全达成中

2.4 单局体验曲线（预估，待实测校准）

设计目标为单局 2–2.5 小时、全收集 10–25 小时。按当前结构：前段（地区 1–4，难 1–18）内容最厚、英雄专属文本最全；中段（地区 5–11）Boss 演出密度高峰（红孩儿/车迟/六耳/牛魔王四个三段 Boss 集中于此）；后段（地区 12–17）内容最薄但恰好是配额制+经文大成期——「内容厚度」与「构筑大成」的曲线目前是错位的：玩家构筑最强时玩到的内容反而最通用化。内容补齐的优先级应向地区 12–17 倾斜。

03市场分析（2026-08 最新数据）

3.1 宏观大盘：2026H1 增速创近年新高

游戏工委《2026 年 1—6 月中国游戏产业报告》（2026-07-30 CDEC 发布）：国内游戏市场实际销售收入 1884.5 亿元，同比 +12.17%；用户规模 6.84 亿（+0.82%）[1]。结构性亮点：客户端游戏 452.88 亿元（+27.92%）强劲反弹；自研游戏海外收入 123.72 亿美元（+30.22%）[1]。对项目最关键的一条：小程序游戏 316.57 亿元，同比 +36.01%（IAP 211.37 亿 +38.12%，占 66.8%；IAA 105.20 亿 +31.94%）[1]——IAA 广告变现赛道本身就在以 30%+ 增速扩张，与本项目「个人开发者免版号先行验证」路径直接对口。

一个必须正视的信号：网页游戏 -8.47%

2026H1 网页游戏收入 20.16 亿元，同比 -8.47%，仅占大盘 1.07%[1]。「纯 H5 网页」作为发行形态已不可行；但本项目的技术形态（纯前端、零依赖、单文件可部署）恰好是小程序游戏的理想宿主——同一份代码包，网页是开发调试环境，小游戏是发行环境。结论：形态定位应从「H5 网页游戏」正式改写为「小游戏优先（Web 端仅作开发/分享用）」。

3.2 小程序游戏赛道：量与钱都在扩张

2026 微信小游戏开发者大会（5-27）披露：MAU 超 5 亿（日均时长 60 分钟+）、开发者超 50 万（八成不足 30 人）、80 款产品 DAU 超百万、300+ 款季度流水破千万；IAP 月活 3 亿（月活破百万的 IAP 游戏 700+ 款）、IAA 月活 4 亿（年流水破百万产品 1400+ 款）[2]。2026 微信公开课 PRO（1-15）将 IAP 首发新游激励上限提升至 400 万元[3]。第三方（DataEye）测算 2026 年小游戏市场将破 700 亿元、在投产品 5.1 万款（+54%）[4][单一来源]。

含义：买量竞争在加剧（在投产品 +54%），但中小团队靠玩法留存自然起量的窗口依然存在——「80 款 DAU 百万」里多数并非买量大厂。对单机向肉鸽而言，激励视频 IAA（复活/额外篝火/经文碎片双倍）是最自然的变现接口。

3.3 肉鸽品类：全球稳增，头部效应极强

各研究机构对全球 Roguelike 市场口径差异大（2025 年 4.8 亿～38 亿美元不等），但增速共识在 CAGR 9.6%–15%[12][13]；中国市场 2026 年预计 110–120 亿元、CAGR 约 12.6%–14.3%[13]。品类标杆《杀戮尖塔2》2026 年 3 月开启抢先体验，三周销量约 460 万份、收入超 9200 万美元、峰值同时在线 57.5 万人[10][11]；截至本报告日仍在 EA 阶段（1.0 预计 2027–2028），其间释放的内容空间正是同类产品的机会窗口。移动端爆款持续出现：肉鸽塔防 Cell Survivor 月流水约 6761 万元（2026-02）[14]；「无限轮回」上线 3 天冲入微信小游戏畅销 Top10[15]；「向僵尸开炮」8 月霸榜畅销 Top100[16]。

品类铁律依旧：肉鸽玩家为「构筑深度 + 可解释随机 + 局外成长」付费，头部产品吃走绝大部分流量——差异化题材（西游）+ 独特机制（六道抉择）是切入的必要条件而非充分条件。

3.4 西游题材：热度长效化，但供给分层

《黑神话：悟空》第三方口径全球销量已突破 3000 万份（游戏科学官方口径为「未达 3000 万」，取保守表述：约 2900 万+，海外占比约一半）[17]，获 TGA 2025「最佳动作游戏」与「玩家之声」，腾讯持股升至 24% 成为唯一外部投资方（据证券时报报道），续作《黑神话：钟馗》已官宣并放出 15 分钟实机。「西游 = 中国顶级 IP 认知度」已被彻底教育，且高端市场验证了暗黑解构叙事的接受度。供给端则明显分层：3A/端游级稀少，中小团队集中在放置卡牌（《守愿者》v2.0.5[18]）、互动影游（《不好啦！师父被女妖精抓走了！》Steam 好评率 98%）、单机肉鸽卡牌（《齐天破界》2026-04 上架、反向设定的《I Am the Demon King: Stop Sun Wukong》2026-07 上架）[19][20]——「深度单局构筑 + 黑暗解构叙事」的组合仍是空位，尚无一款形成头部。

4.4 竞争定位结论

定位结论

在「单局构筑深度」上本作对标杀戮尖塔仍有距离（但其为端游买断制，非同场竞技）；在「叙事厚度」与「题材差异化」上本作领先全部中小型竞品；「收集/局外成长」维度经文收集制已具备与梦幻式长线掰手腕的骨架；唯一显著落后的是「商业验证度」为零——这是所有维度中最容易被高估设计、低估执行的一项。竞争窗口存在，但每拖一个月，跟风供给（《齐天破界》类）就多一批。

07完善意见

7.1 工程基线：先上保险，再谈其他

  • git 基线是所有后续工作的前置条件（P0-1），半天成本，无限收益。
  • 建立「功能日提交」习惯：每个 V8.x 版本号对应一个 commit，开发文档同步入版本库。
  • smoke 测试固化为本地脚本：node test_region.js（已有）+ 重写后的浏览器链路测试，任何重构前先跑通。

7.2 内容生产：用流水线补地区 12–17

  • 前段地区已沉淀出「劫难 + 英雄专属文本 + 呼应链 + 掉落」的内容模板，中后段按模板批量生产，单地区预估 2–3 天。
  • 优先顺序建议：凌云渡（终局，含 81 难湿经收束）→ 灵山（无字真经真相）→ 天竺·玉兔（9 难最长地区）→ 比丘国 → 祭赛国——按叙事权重而非地区序号补，终局体验优先。
  • 每地区至少一条「echo 呼应链」（前段难簿记录在后段兑现），这是解构叙事的灵魂，也是普通文案替代不了的。

7.3 玩法深化：三个具体切口

渐进式教学（前三难）

难 1 只教六道抉择；难 2 只教识破；难 3 只教气势爆发；经文/法宝/配额全部延后到首次自然遇到时才弹教学。现有 localStorage 首次标记机制（introSeen 等）可直接复用为教学开关。

传承阁（局外统一入口）

死亡界面直接展示「此世攒下的，下世接着带」的清单：拓印进度 / 继承匣内容 / 难簿新条目 / 经文图鉴新增——把现有分散系统拼成一个有仪式感的「轮回结算画面」。

死亡归因复盘

败北画面加三行数据：本局构筑核心（主攻道/关键经文/劫印组合）、败于何种伤害类型、下世建议（如「识破窗口再早半拍」）。把「输了」变成「学到」。

种子分享玩法化

withSeed 已能复现地图——加一个「同种子挑战」入口（本周种子速通榜），是零服务器成本的最简社交循环。

7.4 发行验证路径（顺序不可颠倒）

  1. M2 微信小游戏 IAA：激励视频点位设计为「复活一次 / 篝火额外奖励 / 经文碎片双倍」三处——均为增强而非打断，符合 IAA 政策对时长的要求[22]。上架前完成备案（个人主体 IAA 路径）[21]。
  2. M3 TapTap 买断：端手互通买断制占新增买断游戏的 36.1%[23]，TapTap PC 版 DAU 50 万+是免费的自然流量；定价参考国产独游区间（12–30 元）。
  3. 合规预检：暗黑元素以「墨色叙事」呈现（现有水墨风已是正确方向）；避免直给血腥；宗教角色名号保留文学化处理。

7.5 数据埋点：上线前必须就位

当前无任何数据采集能力，上线后将无法回答「玩家死在哪、为什么流失」。最低配置埋点清单：开局→首难→首 Boss 的漏斗；各难死亡分布；六道选项占比（验证渡/逆平衡）；经文碎片获得/弃置率；配额补刷次数；单局时长分布。小游戏容器内可用平台自带分析 + 自建 localStorage 聚合上报。

收束

一周前的报告说「玩法已验证、内容未闭合」；今天的情况是「系统已大成、收尾欠三件事」——git 基线、地区 12–17 内容、真实玩家数据。市场三曲线（大盘 +12%、小游戏 +36%、肉鸽 CAGR 10%）与细分空位（暗黑西游×单局构筑无头部）都还站着，但跟风供给正在入场。建议未来三周只做 P0 三件事，把项目从「开发者视角的完成」推进到「玩家视角的可交付」，其余一切（IAA 变现、买断扩展、赛季化）都建立在这个地基之上。窗口仍在，但已经进入倒计时。
