§一 寿命总账重制：天数制 × 两段式计费——六道的区别是「日程」

定调（22:28 → 22:48 两轮拍板收敛）：① 按万世剑冢的玩法，走的每一个节点都消耗寿命——多事件、多刷怪、多耗命、多装备、多战力，取舍权交给玩家；② 单位不能是小数岁，改用「天」——原典取经就是按天过日子：黄风岭自己打一次一天、连战三次三天；走渡请神仙，耗费十天。③ 消耗大头在「节点之间的赶路」（如 5 天/段），节点本身只加小头（打怪 1 天）；六道的区别从此落在日程表上——走战就是快，走渡就是简单安全但耗命多，「走战打得多不是错，并不一定多耗命」。

1.2 根因诊断：现行账为什么走不完

按现行 COST 表粗算一局全程（17 章 × 每章约 5 难 + 3 小怪 + 2 精英 + 1 Boss + 若干功能节点）：

现行一局名义总耗 ≈ 30~38 岁：81 难×0.3≈24.3 + Boss×0.6≈10 + 精英×0.5≈8.5 + 小怪/事件≈5 —— 还没算恶道 每次 +0.5（走逆道流 40 次抉择 = 再 +20）。而大限 55、出发 27，预算只有 28 岁。
结论：现行账下必然寿中途尽——你实测 806 步自然终局停在难 50 正是这一账本的结果。玩家被迫每步精打细算，「刷的爽 / 装备快感 / 转职 / 成就收集」四个诉求全部被过路费挤压。

1.3 天数制总账：赶路费 + 节点附加费 + 六道日程表

单位体系：1 岁 = 360 天（[PH] 游戏化整除）。寿命单一真源 s.life 直改存天（起点 27 岁 = 9720 天），UI 显示「X 岁 X 天」——「二十七岁零三天上路」，原典味即出。结局判定 PERFECT_R / SHRINE_R、转阶 costYear、舍寿仪、WARN 阈值全部按天重定。天数粒度反而让消耗感知更清晰：每步 -5、-6 天看得见，比 0.1 岁的碎小数「爽」得多。

§二 万世剑冢 × 寿命：两个循环的对比设计

现行万世剑冢（data_vault.js）已经实现：死亡立衣冠冢（装备/组件二选一）、返程坐化立舍利塔（装备/经文二选一），跨周目地图节点回访拾取、衰减 1/0.7/0.4、同区唯一、至多 3 座。它与寿命是同一枚硬币的两面：

维度寿命（单局轴）万世剑冢（跨世轴）对比设计结论
资源语义第二货币：每节点都收，花在哪由玩家定遗产：死得越富留得越多寿命是消耗，剑冢是补偿——两轴共同构成「花命→变强→走更远 / 换更多遗产」的循环；新账把单价校准后，取舍才真正成立：现行单价下账都凑不齐，谈不上取舍
消耗节奏现行：每步滴漏且单价虚高 → 焦虑常驻却无取舍空间拾取衰减 1/0.7/0.4 → 三代枯竭新账节奏=以天过日子：赶路 5 天/段打底，节点附加 1~10 天，六道各有日程——每一步都是「这几天花在哪」的记账；剑冢衰减维持不变（三代枯竭是对的，防滚雪球）
恶念耦合恶道折寿（现行 0.5 过重 → 0.05）善恶向偏袒（data_monument：善→天眷/恶→恶念偏袒掷骰）保留双向耦合但换语义：寿命轴上恶道只付「小额通行费」，剑冢轴上恶念偏袒才是恶道玩法的真实代价（碑位被恶念侵蚀 → 拾取时 30% 概率产出残缺档 ×0.7，[PH]）——恶的代价从「走不到」移到「留不正」
终局判定45 完美 / 45-50 不完美 / >41 到西天坐化死亡→tomb / 坐化→shrine新账下多数局能走到 45+，舍利塔（坐化）变稀有 → 建议给 shrine 保留经文独家（现行已是），并在结算页强化「45 岁·功德圆满」仪式感
玩家动机刷得爽 + 走得完死了也不白死两轴合起来 = 《哈迪斯》式「失败也是前进」：新账保证普通局能通关看结局，剑冢保证翻车局有遗产
定位修正（对应你上轮「衣冠冢/舍利塔作为特殊节点存在于路径中」）：二者已是每周目刷新的地图节点（VAULT_MAX=3、同区唯一），无需再设锚点制。唯一建议：进入新地区时若该区有成亡节点，地图上给醒目标记（碑影/塔影贴图位），首见触发观音偈语引导（game_vault.js 已有）。

3.2 3合1 合成链：数量经济，不是数值爆炸

3合1 的直觉是「3 件低档 = 1 件高档」，若数值也 ×3，红=27×白直接爆炸。合成按数量走、数值按档位表跳，价值闭环靠弃印定价（现行白6/蓝12/红30/金45）校准：
