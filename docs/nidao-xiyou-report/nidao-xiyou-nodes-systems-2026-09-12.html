节点全景：地图由 NDX.generateMap / _buildRegionSegment（data_map.js）按 17 地区连续拼接，共 14 种节点类型经 game_core_2.js enterNode → switch(node.type) 分发。全部节点在进入时统一穿过 四道横切闸：① 关隘必修任务计数 s.mission；② 地区配额 addQuota（含 S1-4 修复的 shop/event 键）；③ 业镜层效果清理 + 踏尸进层掉血；④ 劫难转事件改写（难8/难73）。

二、逐节点 × 系统结合详析

2.1 trial 劫难 —— 全系统超级枢纽 game_core_2.js:303-472 / game_event_3.js

承载内容：难号收束（V8.52 _assignTrialDiffs 每层固定绑定全局难号，杜绝随机刷新）→ TRIAL_LIB[难号] 精确叙事（normalizeTrial 出 opts）→ 六道抉择面板 → 选项结算。
系统结合点（一难七结）：
  • 六道 fate：选项经 _gainFate（game_event_3.js）只写 s.fate[dao] 驱动六维雷达 + 投放池概率偏置（daoPoolWeights 软饱和 1.5/4），零属性；trialFateLog 记录命运链，首印触发「六道第一印」仪式播报（game_core_2.js:460）。
  • 善恶：选项 effect.alignGood/alignEvil 显式签署，渡/缘+善、逆/夺+恶、战/隐按剧情后果——与六道解耦。
  • 心魔：争/夺/逆/隐选项经 _gainXinmo→gainXinmo(dao)（game_event_3.js:705）累计；满 70 触发镜像战（纯惩罚战）。60-85 敌人强化档仍无实现（见 §五-4）。
  • 劫印：非战斗劫（兵不血刃）掉善印 offerSealsAligned('good')（game_event_2.js:518）；战斗劫走 finishFight 掉恶印（game_combat_2.js:316）。档位统一 rollSealTier('good'/'trial',s)。
  • 掉落/装备：难专属法宝 → lootById 校验 → 兜底英雄基座；材料按 0.22+layer×0.025（封顶 60%）概率掉落。
  • 隐藏职：进入即记 trialsPassed（全局难号口径）→ hiddenTrialsMet 解锁隐藏资格（game_core_2.js:360）；隐藏职必经难号由 _ensureHiddenTrials 保必现。
  • 难簿/伏笔/配额：卷边界（20/40/60/81）解锁难簿分卷成就（永久微量加成）；41-80 难触发 echoPayoff 前后呼应材料回报；mission.trials + quota.battle 计数。
教学链（第一章专属）：难1 接引使者教学战（攻/经/绝逐回合引导）→ 六道抉择教学；难2 观音寿命偈语（V8.62 两层包裹不吞选项）；难3 劫印教学。game_core_2.js:424-454

2.2 boss 关隘 —— 压力顶点 × 手动收益分水岭 game_core_2.js:474-642

承载内容：本章末难号即 Boss 难（计入 trialsPassed，隐藏职 81 难等必经口径在此补记）。系统结合点：
  • 两相劫/三段变身：bossStageSetup(bossName, s.fate) —— 八个三段变身 Boss 走 BOSS_FORMS 装配；尸魔相由你一路六道 fate 决定（setup.fateDao：六道选择反向塑造 Boss 形态，核心闭环）。
  • 破韧/手动收益：韧性条主导面决定 breakWith='bf_bajiao/bf_baolu'（需持特定真器法宝才能临阵破韧领「阶段厚赏」，否则挂机兜底 30/40 金）——主动操作有明确回报分水岭。
  • 逆道侵蚀：act≥10 两段 Boss 附「逆道·裂界」词缀 + comboAllowed 手动法宝连锁 COMBO + routine=3 择机窗口。
  • 收束矩阵：车迟国（三场全战→compositeMonster 三妖合体一打三 1700/2000/2300 血；任一选隐→避战收束；斗法折服→免战）；通天河（全渡→观音鱼篮收伏免战；全逆→河神反噬金鱼精攻势 +15%）。game_core_2.js:476-503,529-541
  • 逆道谈判「以经为质」：主攻道=逆 + 妖王 + 佛经积累 → 先弹谈判面板（成功率公示：佛经全本/散件/心魔层/逆经/恶值五因子），谈判成功/失败分别接入 gainXinmo（game_meta.js:340/347）。
  • 战前调节：scaleRunMods（逆道 monStr 增益 − 渡道 monWeak 弱化，clamp [0.55,1.6]，多阶段血条同步缩放）——剧情抉择立刻改变对局难度；nextWeak（他 node 事件的临时弱化）在此一次性消费。

2.3 elite / mob —— 压力阶梯与经济底盘 game_core_2.js:240-292

mob 妖兵：强度按真实难号线性爬升（hp=160+gp×45, atk=18+gp×4，matk 取档位 7 折）；rollMob 按地区抽名字+阵营 tags（供法宝 counter 克制命中）；固定 3-6 回合节奏保障；收益=金+固定掉落（装备池优先 setTier1 未持有）+50% 材料+5~10% 基本装（_mobBasicLoot）。V8.52 起超额 trial 节点降级为 mob，是配额体系的泄压阀。
elite 精英：按节点难号缩放（历史上曾误用 bossDiffForAct 致开局精英=Boss 级，V42 修复，注释保留在 game_core_2.js:522）；enemyDefOf 从 enemies.js 取权威掉落覆盖模板；首次精英触发词缀机制教学；elitereward 结算。
共同：mission 计数（mob/elite 分列）、quota 计数、scaleRunMods 战前调节、恶印掉落。

2.4 event 缘（?） —— 保底博弈 × 四重事件源 game_core_2.js:644-801

核心博弈：遇战保底 p=10%+10%×连续未遇战次数（rollYuan）——遇战即重置；未遇战先得 TREASURE_GOLD×0.5 保底金再弹奇遇。四重事件源按优先级：
  • ① 送行事件强制插入：历经英雄 initTrial 后的下一个问号必触发 INIT_GIFT_EVENTS（三件初始装备+法宝，gotInitGift 幂等）。
  • ② 灵兽进化事件：rollPetEvolution（约 35%+保底，本章指定进化）。
  • ③ 双线经文事件池（V8.53 分池+加权+保底）：30% 装备池 / 70% 普通池；顶级 ×1.5 加权；六道属性 side 加权；连续 3 问号未出装备 → 100% 强制装备池（_gearEventMiss）。
  • ④ 通用奇遇池 pickEvent（回血/得宝/善恶抉择/可战可避）。
系统结合：fateStats.events（缘分门槛·缘遇）、quota.event、节点资源隔离——缘节点只给金+奇遇，不产命痕（命痕严格只产精英/Boss，保「劫 vs 精英」博弈纯度）。特例：songEvent 长安送行（观音指引→song-gift 五步教学：装备+法宝+地图）；fixedEventTrial 难8/难73（story 劫以缘节点承载剧情，进入时改写回 trial 分支）。

四、节点生成规则中的系统暗线

  • 教学三线分立：前 3 层差异化路线（L1 历练/小怪 → L2 劫印线/劫难 → L3 精英线）让玩家开局即看到「路线=玩法」；第一章再叠 4 层固定线性 + songEvent 收口，教学节点全部 skipPostProcess 防后处理覆盖。
  • 保底四件套：event 遇战保底（pity 递增）、装备事件 3 连保底、Boss 前 rest 强制、隐藏职必现——四条保底全部是「给机会不强制」，与「逃课自担」哲学一致。
  • 降级链：超额 trial→mob（配额）、超量 shop→mob（密度）、mob→elite/event（MAP_TUNE 概率改写，act≥3）——后处理全部 _replaceNode 保留 next 边不破坏连通。
  • 难度双口径：mob/elite 用真实难号 gp 平滑爬升；关隘 Boss 独用 bossDiffForAct 随章递增（1章≈20档2300血 → 终章压迫感）。两套口径的边界在 game_core_2.js:522 注释中有历史事故记录。

五、结构性发现与风险（按优先级）
