§2.1 收口 —— 六道 = 纯概率主干

《逆道西行》· 落地报告 · 2026-09-12 · 承接「六道概率主干四池偏置」（§2.2/2.3 已落），本轮收口 §2.1

一句话结论：2026-09-01 用户已双次拍板「六道选择不加任何属性、只加善恶」，但代码里 _gainFate 仍在自动加属性——本轮清掉这条未落地残留，并把 §2.1 的四条契约全部对账、用门禁锁死。

一、真源核查：一条被漏掉的用户决策

依「代码为真源」先核，发现 docs/81难地理重排_映射表_2026-09-01.md 记着同一件事的两次决策：

§十（v=351）：六道选择回归最简——不加任何属性，只加善恶（选项仅保留叙事奖励），属性体系全部由劫印承担；劫印六道属性对齐 战+攻 / 渡+血 / 缘+防 / 夺+反 / 隐+闪 / 逆+全加。
v=352（最终拍板）：六道选项纯善恶、不带任何属性或奖励——只作剧情点控制（道心/成就/心魔/善恶）。

当时的验收写了「六道选项残留奖励 = 无」，清了 72 处选项 effect 奖励键——但 _gainFate 里那段自动施加的 DAO_STAT_BONUS（不是选项 effect，而是每次抉择都跑）从未被清。这是典型的「改一处漏一处」。

为什么它今天才浮出来

上轮刚落地 §2.2/2.3「六道 → 四池概率偏置」后，六道变强的路径已经完整（投渡 → 多出渡道装备/劫印/经文/法宝）。此时再保留「六道直接加属性」，就是同一份设计意图被实现了两遍，且第二遍（直接加属性）恰好是用户明确否决的那种。

关键设计点：删除不是「削弱」，是「去重」

  • 同一条属性现在只有一个来源：以前「选渡 → 直接 +20 气血」与「选渡 → 多出渡道劫印（劫印加 maxhp）」两条路并存，是重复计功。
  • 非回归：② 采用 Math.max 只加不减——凡旧路径能进化的仍能进化，只多出「纯靠劫印筑起道途」的新路径。
  • 与上轮闭环：六道去掉直接属性后，玩家因六道变强的唯一路径就是四池偏置（NDX.daoPoolWeights）——这正是「六道是主干」的字面实现。
