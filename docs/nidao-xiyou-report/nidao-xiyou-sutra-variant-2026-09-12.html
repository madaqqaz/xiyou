《逆道西行》· 2026-09-12 · GDD V9.6 §五「换经换整套套路」收口 · 顺带清理拆分残留

本轮两件事：① 补齐 GDD §五 明列却一直空缺的 atkVariant / ultVariant——此前三键里只有「诵经」吃经文，普攻与绝招是英雄专属，玩家换经只换来一个技能；现在持诵哪部经，普攻 / 诵经 / 绝招三键同时换套路，经文真正成为「招式包」。

② 清理一处真源分裂：combat.js 里躺着 2026-09-09 拆分到 combat_active.js 时未删除的整段旧副本（activeSkill / applyHeroKeyFeel / applyActiveIntervention 三函数，405 行）——按加载顺序它被后加载的新版覆盖，是典型「改一处漏一处」隐患，已删除。

一、真源核查：三键里，「诵经」早已吃经，另两键没吃

按宪法「代码是真源」先核 js/combat_active.js NDX.activeSkill 的三分支，得到决定性事实：

键变体来源经文驱动判断
atk 普攻道途进阶（_sa.atk）/ 六道攻式（daoAtk）/ 本命攻式（applyHeroKeyFeel）缺从未路由经文变体
chant 诵经持诵位 S.chantSutra → 该经 chantSkill已成2026-09-05 方案 X1 已落地
ult 绝招英雄 ultimateOf(heroId, tier) + 道途进阶缺与经文无任何连线
结论：GDD §五写「经文 = atkVariant + chantSkill + ultVariant」，实际只兑现了中间一项——这正是「经文系统落空」观的残根：经文拿在手里，只有 1/3 的战斗交互。本轮补另外 2/3。

二、设计：一张模板派生三键套路

34 部经若逐一手写三套招式包 = 102 项，既易漂移也无必要。改用「以 chantSkill.kind 为骨」的单一真源：6 种语义各派生一组 atk / ult 变体，经文可自带字段覆盖。

kind（6 种）语义普攻变体绝招变体

强度标量：由经文自身强度派生，零额外数据

scale = chantSkill.mult / 1.7（clamp [0.5, 1.5]）。大经（梵网 2.0、逆天录 2.0）招式更重，小经（法华 1.5）更轻——同一 kind 的不同经手感同型、强度有别，无需逐经标注。

确定性铁律：所有变体不含随机。因 activeSkill 会被「拍差 CD 探测」与「正式结算」各调一次，任何随机都会致两次结果不一致（探测显示就绪、结算却落空）。数值全为 [PLACEHOLDER · 待 10 局采样]。
