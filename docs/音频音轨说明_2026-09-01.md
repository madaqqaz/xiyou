# 《逆道西行》音频音轨说明（2026-09-01 · v=353）

> 本文档记录游戏音频整改（v=353）的**自制音轨清单、自制与授权凭证、接入方式与验收证据**。
> 代码真源：`js/sound.js`（BGM/音效文件播放 + Web Audio 合成降级）；音频资源：`assets/sound/*.mp3`。

## 一、整改背景

- 原 `sound.js` 为**纯 Web Audio 程序化合成**（五声音阶单音循环 + 持续垫音），无任何外部音频文件。
- 体验问题（用户反馈）：**背景音频为噪音，引起玩家不适**——合成 BGM 无乐句结构、垫音持续嗡鸣，静音/噪音并存。
- 整改目标：以**自制氛围音轨**替换程序化 BGM，最低成本满足「战斗/地图/诵经/UI 点击/转职觉醒」5-8 条音轨要求。

## 三、自制方式与授权凭证（合规留存）

- **自制方式**：8 条音轨全部由 **AI 音频生成工具（T2A，seed-audio 体系）**按游戏氛围定制生成（黑暗西游·诵经·禅唱），原始产物为 WAV，经 **MediaKit `transcode-audio`** 转码为 **MP3 128kbps / 单声道 / 44.1kHz**。
- **授权状态**：**全部为项目自制品，无任何第三方素材，无第三方版权/授权依赖**——不涉及 CC0 库下载，无需外部授权凭证。原始 WAV 保留于 `assets/sound/raw/`（生成原始凭证）。
- 与「预算为零用 CC0 免费音效库」的备选方案相比，自制品更贴合游戏氛围、授权风险更低；如需再次生成/调整音轨，可复用本说明的生成流程。

## 四、接入方式（sound.js）

- **BGM**：`NDX.sound.music(scene)`（scene ∈ title/map/fight/boss/home/none）→ 用 `HTMLAudioElement` 播放 `BGM_FILES[scene]`（`loop=true`），替换原程序化合成；`musicStop()`/`bgmScene()` 接口不变。
- **音效**：`NDX.sound.play(name)` 的 `click`（木鱼点击）/`levelup`（转职觉醒）优先播放 `SFX_FILES` 对应音频文件；新增 `play('worship')`（诵经梵呗）。**Web Audio 合成保留为降级方案**（文件缺失/播放失败时回退，不影响主逻辑）。
- **音量联动**：BGM 音量 = 主音量 × 0.9 × 0.35（明显低于音效）；`setVolume()` 同步 BGM/音效音频文件音量；静音开关（toggle）停 BGM 并保留场景意图，恢复时重启。
- **编码**：`serve.ps1` content-type map 新增 `mp3='audio/mpeg'`（本地 HTTP 预览正确提供音频）。
- **缓存版本号**：`index.html` ?v=353。

## 六、三端与后续

- **浏览器 H5**：`file://` 双击可玩（Audio 相对路径，同图片加载）；HTTP 预览（serve.ps1）已适配 mp3 MIME。
- **微信小游戏**：web-view 承载 H5，音频文件入首包/分包（当前总计约 2.6MB，首包 4MB 内）；若需进一步压缩可降码率至 96kbps 或转 OGG。
- **TapTap 买断版**：离线资源，本地播放，无联网依赖。
- **后续可选**：BGM 无缝循环处理（现为 loop 跳变）、音量独立滑杆、诵经音效接入具体场景触发点（当前提供 `play('worship')` 接口供调用）。
