# 《逆道西行》职业与隐藏职 · 深度补齐设计（v1.0）

> **性质**：N1 议题设计提案 · 待拍板后升真源
> **提出**：用户 2026-09-24「英雄的职业与隐藏参照的冒险日记，但深度不够」
> **实读基线**：`data_trials.js`（`HIDDEN_JOBS` 注册表 45 条）/ `data_skill_variant.js`（`JOB_STYLE` 45 条、10 个流派标签、`ULT_STYLE_MOD` 10 条）
> **一句话结论**：职业现在只有**两层**（数值 + 被动），缺**第三层「套路层」**——所以看起来像"换了个称号和几个数值"，而不是"换了个玩法"。

---

## 〇、诊断：为什么"深度不够"

| 层 | 内容 | 现状 | 判定 |
|---|---|---|---|
| L1 数值层 | `effect.bonus`（hp/atk/dr/matk…） | ✅ 有 | 玩家感知＝「变强了一点」 |
| L2 机制层 | `effect.passive`（buddha_def / reverseScale / empty / glutton / restored…）+ 大招变体（`ULT_STYLE_MOD`） | ✅ 有 | 玩家感知＝「多了个被动」 |
| **L3 套路层** | **职业改变「我怎么打」**——三键形态、资源规则、适配禁忌 | ❌ **完全没有** | **这就是"深度不够"的根因** |

对照：《冒险日记》的深处在**事件/装备驱动 build** —— 装备与事件共同决定你这局"怎么打"。本项目 `data_trials.js:170/374` 已参照它做了**门槛层**（日记装备≥N、出阵灵兽≥3），但门槛只是"能不能转"，**没说转了之后怎么玩**。

**证据**：10 个流派标签（`summon/reflect/combo/crit/burn/drain/evade/purify/reverse/ward`）里，只有 `summon` 有实打实的玩法改造（大招「万兽朝元」召唤灵兽助战）；其余 9 个**只改数值和被动**。

## 一、目标（goal-framing）

| 项 | 内容 |
|---|---|
| **目标** | 让「隐藏职业」从**称号+数值**升级为**玩法路线**：转职后，玩家的三键操作、资源循环、装备/经文取舍**都发生可感知变化** |
| **为什么** | ① 用户明确判定深度不足 ② 隐藏职 45 条是本项目**内容量最大的系统之一**，却无法支撑多周目差异 ③ 与「路线配装 BD」主玩法脱节——BD 只由装备/经文决定，职业没参与 |
| **契合** | 职业成为 BD 的**第三根支柱**：路线（六道）× 装备/经文 × **职业** 三者共同决定 build |
| **成功标准（玩家侧）** | ① 玩家能一句话说清"我这个职业该怎么打" ② 同一个英雄、不同隐藏职，通关录像看得出操作差异 ③ 论坛/评论区出现"XX 流怎么配"的讨论 |
| **成功标准（KPI 侧）** | ① 单周目内转职率 ② 多周目**换流派**重玩比例 ③ 转职后三键使用分布发生变化（可埋点） |
| **约束** | ① 不改战斗架构（`calcCombat` 一次性预结算，逐回合决策不可行）② 不新增美术资源 ③ 优先复用现有 10 个流派标签，不扩标签 ④ MVP 只做 3 个流派验证 |

## 二、三层模型（核心设计）

```
L3 套路层（新增）→ jobspec：三键形态 / 资源规则 / 适配与禁忌
L2 机制层（已有）→ passive + 大招变体
L1 数值层（已有）→ bonus
```

**L3 套路层四要素**（每个流派填一张卡）：

| 要素 | 说明 | 例子（summon） |
|---|---|---|
| ① 核心资源 | 这个流派"攒什么、花什么" | 灵兽数（槽位/等级） |
| ② 三键改造 | 攻/诵/绝 各自变成什么 | 诵经＝唤伴（宠物立即行动） |
| ③ 适配 | 推荐经文/装备/套装 | 缘系经文、御兽套 |
| ④ 禁忌/弱点 | 明确的反面（让 BD 有取舍） | 宠物被清场则战力腰斩 |

## 五、MVP 范围（建议）

1. 只做 **summon / combo / reflect** 三个流派的 L3 套路卡（覆盖"召唤 / 进攻 / 防守"三种体验）
2. 每派只做 ② 三键改造中的**诵经 + 普攻**两键（大招已通）
3. 不做：新美术、新职业、新流派标签
4. 验证：转职前后打同一场战斗，三键伤害构成与操作序列应可区分
