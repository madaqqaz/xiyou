# 《逆道西行》劫难系统基本原则（硬性规定）

> 本文件是《逆道西行》劫难系统的唯一硬性规定真源。所有劫难设计、文本编写、代码实现必须遵循本文件。
> 与本文件冲突的旧设计、旧文本、旧代码，以本文件为准。
> ⚠ **结构 / 选项 / 流向 / 产出 / 六道判定 / 劫印档位**的最终真源 = 《逆道西行》81难骨架·攻略总表（v1.6）；本文件与之冲突时，以骨架总表为准。

---

## 一、设计核心原则

### 1.1 原著剧情为主线
- **所有劫难主线基本符合《西游记》原著剧情**
- 该请菩萨请菩萨，该搬救兵搬救兵——原著剧情是默认路线
- 在原著渡（请菩萨）的基础上，扩展出战与夺的平行路线
- 再在战的基础上，增加逆道选项

### 1.2 六道的逻辑层次
```
原著渡（请菩萨）→ 基础路线，符合原著
    ↓
战（强行战斗，不请救兵）→ 扩展路线，靠实力取胜
    ↓
逆（战且未用法宝/未请救兵，怪物折服）→ 深层路线，收服怪物一同反抗西天
```

### 1.3 战、夺、逆的关系
- **战**：强行战斗，不用法宝、不请救兵，靠实力打败怪物
- **夺**：战斗胜利后，见宝起意，夺取怪物/菩萨的特有法宝（难度最大，奖励最丰厚）
- **逆**：战且未使用任何法宝、未请任何救兵，纯靠实力击败，怪物心服口服，愿意跟随一起反抗西天

> **逆道逻辑**：只有强行获胜的战（不用任何法宝、不请救兵），才能让怪物真正折服，才能让怪物跟随你一起反抗西天。这是逆道的核心逻辑。

## 二、六道选项触发规则

### 2.1 渡选项（基础路线，原著剧情）
- **触发条件**：所有有菩萨收妖剧情的劫难，都有渡选项
- **设计原则**：完全符合原著剧情，菩萨/神仙收走妖怪
- **渡的方式**：
  - 请对应菩萨收妖（如灵吉菩萨收黄风怪、观音收红孩儿、昴日星官收蝎子精等）
  - 请神仙帮忙（如太上老君收青牛精、弥勒佛收黄眉童儿等）
- **渡的结果**：菩萨收走妖怪，玩家获得善值和对应奖励
- **渡的代价**：消耗天数（请菩萨需要时间），损失部分战斗奖励

### 2.2 战选项（扩展路线，必选项）
- **触发条件**：劫难中有怪物，就必有战选项
- **设计原则**：不请菩萨、不请救兵，靠自己实力强行战斗
- **战的结果**：
  - 战斗胜利，获得对应装备（怪物特有武器/防具）
  - 劫印档位按**章**定档（一二章 白/绿、三四章 绿/蓝、五六七章 单绿·复蓝/Boss 红、八九章 单复全蓝/Boss 红）
  - 详表见 §5.2 及《逆道西行》81难骨架·攻略总表
- **战与渡的区别**：渡是请菩萨帮忙，战是自己上

### 2.3 夺选项（条件触发，难度最大）
- **触发条件**：劫难中出现特殊法宝或特殊装备时，出现夺选项
- **设计原则**：夺必须夺取怪物/菩萨特有的法宝，为剧情服务
- **夺的对象**：
  - 菩萨/神仙的法宝（如飞龙宝杖、金刚琢、人种袋、紫金铃、芭蕉扇等）
  - 怪物的本命法宝（如火尖枪、随心铁杆兵、倒马毒桩、九瓣赤铜锤等）
  - 特殊宝物（如舍利子、舍利子玲珑内丹、老君三宝等）
- **夺的前提**：通常需要先战斗胜利，然后见宝起意，继续与菩萨/怪物战斗夺取
- **夺的难度**：夺是六道中难度最大的，因为要同时击败怪物和菩萨
- **夺的奖励**：获得特殊法宝/装备，奖励最丰厚
- **没有夺的劫难**：添加隐选项（躲开/逃离）作为替代

### 2.4 逆选项（深层路线，收服怪物）
- **触发条件**：在战的基础上，未使用任何法宝、未请任何救兵，纯靠实力击败特殊怪物
- **设计原则**：强行获胜的战，怪物心服口服，愿意跟随一起反抗西天
- **逆的对象**：
  - 知名度高的妖怪（如白骨精、黄风怪、红孩儿、牛魔王、六耳猕猴等）
  - 被菩萨收付的妖怪（如黄风怪→灵吉菩萨、红孩儿→观音、黑熊精→观音等）
  - 人民熟知的经典妖怪
- **逆的结果**：怪物加入队伍，成为宠物/随从，战斗中可释放特有技能
- **逆的前提**：
  - 必须是战路线（不请菩萨、不请救兵）
  - 必须未使用任何法宝
  - 纯靠实力击败，让怪物真正折服
  - 怪物有"人性"一面，值得被收服

### 2.5 缘选项（特殊剧情触发）
- **触发条件**：特定剧情节点触发，不是所有劫难都有
- **设计原则**：缘代表"因缘际会"，由特殊剧情推进产生，不是简单的路线变更
- **缘的触发场景**：
  - 特殊剧情选择（如女儿国唐僧留下/承诺归来）
  - 复合劫难中多次变更路线，因缘际会产生特殊结局
  - 前期埋下的钩子，在后期触发
- **缘的结果**：获得缘道提升和劫印，可能触发特殊结局或隐藏节点

**女儿国缘选项示例**：
- **唐僧留在女儿国**：保留全部装备及法宝，作为特殊结局
- **唐僧离去，但承诺取经后回来**：触发特殊结局
  - 前期埋下钩子：随从落坑可选择救下
  - 如随从未死，可由随从继承唐僧名号回长安
  - 唐僧本人回女儿国
  - **最终特殊隐藏结局**：
    - 长安继承经文（显性成就）
    - 女儿国获得特殊舍利塔及衣冠冢（双重隐藏节点）

### 2.6 隐选项（补充选项，强制性优先）
- **触发条件**：所有劫难都应有隐选项（躲开/逃离/无视）
- **设计原则**：隐代表"逃避/放下"，玩家选择不战斗、不争夺、不渡化，直接离开
- **隐的强制性优先**：
  - 在复合劫难中，如期间选择了隐（逃离），则六道最终抉择为隐，强制性优先
  - 因为隐造成的结果最恶劣（妖怪继续祸害人间），所以优先级最高
- **隐的结果**：
  - 无战斗，仅获得劫印
  - 之前战斗正常获得装备
  - 劫印仅在劫难结束后统一获得
  - 妖怪继续祸害，后续相关劫难难度可能增加

## 三、劫难结果数量规则

### 3.1 普通劫难
- 至少有3个不同结果：渡（原著）+战+隐
- 有特殊法宝的劫难：增加夺选项，4个结果
- 有特殊怪物的劫难：增加逆选项，4个结果

### 3.2 复合劫难
- 尽量有4-5个不同结果
- 复合劫难必须包含：渡、战、隐，有特殊法宝/怪物时增加夺/逆
- 有特殊剧情节点时增加缘选项
- 复合劫难的多阶段结构允许玩家在中途变更路线

## 四、六道提示规则

### 4.1 选项中不出现六道具体提示
- 所有选项文本中不出现"战""隐""渡""缘""逆""夺"等六道标签
- 选项只描述玩家的行为和选择，不告诉玩家这属于哪一道
- 示例：
  - ❌ 错误："【战】以力降妖，击败怪物"
  - ✅ 正确："以力降妖，击败怪物"

### 4.2 劫难完成后提示
- 劫难完成后，统一提示："你的X道提升了"，同时获得劫印
- 提示中只显示最终的六道归属，不显示每个选项的六道归属
- 复合劫难中，根据玩家的整体选择路线确定最终六道归属

## 五、劫印获得规则

### 5.1 每个节点必获劫印
- 每一个节点（含复合节点），不管是否触发战斗，均会获得劫印
- 劫印是劫难完成的标志，不与战斗结果挂钩

### 5.2 劫印等级（**按章定档** · 2026-09-18 修订）

| 章 | 普通劫难 | 复合劫难 | 章末 Boss |
|---|---|---|---|
| 第一 · 二章 | 白 | — | 绿 |
| 第三 · 四章 | 绿 | 绿 | 蓝 |
| 第五 · 六 · 七章 | 绿 | 蓝 | 红 |
| 第八 · 九章 | 蓝 | 蓝 | 红 |

- **红劫印**：**章末 Boss 档**（第五~九章各 1，共 5 颗）＋ 既有「融合 ≥3 难」来源（车迟国 1 颗；地图融合节点计法，与劫难结算档位无关）。红是合金素材，**三红合一金**
- **金劫印**：**仅由「三红合金」产出，任何来源不直给**
- **不锁总数**：红／金产出不做 3 的倍数约束
- **容量扩展**：劫印格子可由**特殊成就**开发
- 每个节点（含复合节点）必获劫印；复合劫难劫印**统一结算**（见 5.1 / 5.3）
- 详表见《逆道西行》81难骨架·攻略总表（v1.6）§〇 规则 2

### 5.3 复合劫难劫印统一获得
- 复合劫难中，劫印仅在劫难结束后统一获得
- 避免出现多次战斗获得多个劫印
- 之前战斗正常获得装备，但劫印最后统一结算

## 六、战斗规则

### 6.1 通常劫难至少一场战斗
- 通常劫难都会有至少一场战斗
- 选择隐选项（逃离）可以无战斗，但仅获得劫印

### 6.2 原著战斗流程
- 完全符合原著剧情的战斗流程
- 该菩萨收妖就菩萨收妖
- 该请救兵就请救兵
- 在原著基础上扩展战路线（不请救兵，自己打）和夺路线（夺法宝）

### 6.3 唐僧慈悲机制
- 唐僧慈悲为怀，不忍下手时，**玩方对其伤害 −80%**，战斗难度最高
- 通常出现在复合劫难的前期阶段
- 玩家可以选择请土地山神作证来解除慈悲状态
- ⚠ **与「人形态减伤 · 唐僧斥语」区分**（骨架 v1.19 §〇 规则 5）：**本机制按「劫难阶段」触发**（复合劫难前期阶段，唐僧不忍下手）；**规则 5 按「怪物形态」触发**（人形态怪物在场 → 唐僧斥语 → 玩方对其伤害 −80%）。两者数值同为 −80%，触发条件不同，同场出现时分别判定。

## 七、复合劫难设计规则

### 7.1 多阶段结构
- 复合劫难采用多阶段结构，每个阶段有独立的文本和选项
- 玩家可以在不同阶段选择不同路线
- 原著剧情是基础，战/夺/逆是扩展

### 7.2 路线变更规则
- 复合劫难中，玩家可以在任意阶段变更选项路线
- 多次变更路线可能触发缘选项（因缘际会）
- 如期间选择了隐（逃离），则六道最终抉择为隐，强制性优先

### 7.3 天数消耗机制
- 请菩萨/土地山神作证需要消耗天数（通常每次10天）
- 文斗/斗法时间拖长会造成寿命减少
- 天数和寿命是复合劫难的重要资源

### 7.4 战斗合并机制
- 复合劫难中，多次选择同一非战斗选项后，怪物会显出原型进行战斗
- 相当于多次战斗合并为一场，怪物战力最强

## 八、经典复合劫难设计模板

### 8.1 三打白骨精（第20难）

**原著剧情**：白骨精三次幻化（村姑→老妪→老头），三次被悟空打死，最后现出原形。

**结构**：三次文本，每次有独立选项

**每次选项**：
1. **战**：**人形态减伤**——怪物呈人形态在场时，**唐僧飘出斥语（「悟空／八戒／沙僧，不可伤人」）→ 玩方获得 debuff「不可伤人」：对其造成伤害 −80%**（骨架 v1.19 §〇 规则 5），战斗难度最高
   - 强行击败白骨精（未请菩萨、未用法宝）→ 可触发逆选项（白骨精心服口服，愿意跟随反抗西天）
2. **隐**：无视继续前行，无战斗
   - 三次都选隐后：白骨精显出原型进行战斗，三次合并为一场，怪物战力最强
3. **渡**：召唤土地及山神作证
   - 每次消耗10天
   - 白骨精显出原型，战斗难度正常

**最终六道判定**：
- 全程战且未用法宝→逆（白骨精折服，加入队伍）
- 全程渡→渡（土地山神作证，白骨精现原形被收）
- 全程隐→隐（强制性优先，白骨精三次幻化都没被识破）
- 🔒 触发隐藏缘（**主角为悟空 ＋ 未选隐**；**v2.2 取消「持救命毫毛」要求**）→ 缘（白晶晶）——**悟空离队，携白晶晶同回花果山**，产【白晶晶的红绳】
- **悟空离队分路（v2.2）**：战 / 渡 / 隐 → 被唐僧逐走离队；缘 → 主动离队；**逆 → 不离队**。离队后第 21-23 难阶段3 可请回（八戒花果山请救兵）

### 8.2 车迟国（第33-35难）

**原著剧情**：唐僧与虎力、鹿力、羊力三大仙斗法（求雨、坐禅、隔板猜物），最后悟空杀死三大仙。

**结构**：三场文斗 → 武斗（可随时替换选项）

**文斗阶段选项**：
1. **战**：直接战斗，跳过文斗
   - 三场全部取胜后进入武斗，一次性对抗3个怪物（每个2种形态）
2. **渡**：原著剧情文斗
   - 三次文斗后进入三次武斗，依次进行三场战斗（三个怪物仅出现第一形态）
   - 获得渡选项，但因斗法造成时间拖长，寿命减少30天
3. **隐**：放弃抵抗，逃离车迟国
   - 3妖继续祸害，无战斗，仅获得劫印
   - 之前战斗正常获得装备
   - 劫印仅在劫难结束后统一获得

**武斗阶段机制**：
- 三妖呈**人形态**在场 → **唐僧飘出斥语（点名当前出手的徒弟）→ 玩方获得 debuff「不可伤人」：对其伤害 −80%**（骨架 v1.19 §〇 规则 5）；破法二选一：**照妖镜**（破后转本相）/ **唤土地山神作证**（渡 · 每次耗寿 10 天）
- **【避雷珠】**免疫虎力大仙雷部麻痹（渡线·文斗全胜后雷部收雷时赐 ／ 缘线·第33难前宝物节点；**配件＋法宝双用·不消耗**）
- 未用法宝强行获胜→可触发逆选项（三大仙折服，加入队伍；逆随从呈**·人形态**）
- 文斗路线变更多次→缘

**最终六道判定**：
- 全程战且未用法宝→逆
- 全程渡→渡
- 选了隐→隐（强制性优先，结果最恶劣）
- 多次变更路线→缘

### 8.3 女儿国（第42-43难）

**原著剧情**：唐僧路过女儿国，国王招亲，唐僧坚守取经信念，离去。

**结构**：子母河 → 解阳山 → 女王招亲

**阶段1 选项（子母河 · 3 选 1）**：
- **战**：直奔解阳山，强夺落胎泉
- **隐**：不喝泉水，带身孕西行
- **渡**：用计谋换泉水（变作牛魔王骗如意真仙）

**最终抉择（女王招亲 · 六道全集）**：
1. **战**：强行突破女儿国防线 → 战斗：**女儿国禁军为凡人 → 唐僧慈悲 → 玩方对其伤害 −80%**（§6.3；可选「请土地山神作证」解除慈悲状态）
2. **渡**：接受女王招待，礼貌拒绝（原著）
3. **隐**：逃离女儿国，不告而别（**强制性优先**）
4. **缘**：不负如来不负卿〔🔒 前置 · 第 28-31 难红孩儿走缘 / 渡 / 逆（被救）；红孩儿走**战**则本项**灰显**，并转入【逆】推荐〕 → ◆成就【不负如来不负卿】＋**【女儿国国王的红绳】**（可合成三生红绳葫芦）
5. **逆**：放弃西游，留收女儿国 → ◆逆道经文 ＋ 逆道随从**【女儿国国王 · 人形态】**（骨架 A6.5）

**人形态减伤**：**玉兔精假扮公主 → 拟态人形** → **唐僧斥语 → 玩方对其伤害 −80%**（规则 5）；破法二选一。

**八戒本心线 · 终局（A6.7 第⑥点）**：八戒**守本心只等嫦娥**；守到最后 → **嫦娥亲自现身揭穿**「嫦娥只是**王母设下的一个套**」→ 八戒**大彻大悟**（守的是自己的本心，不是嫦娥）→ 走逆道（猪刚鬣）。与 A7.2「八戒情缘结局」按所走之道各自触发、**互不冲突**。

**结算**：六道 +1 · **蓝劫印**（单劫难 · 八·九章档）｜本难**无夺**
**后续钩子**：缘 ／ 逆线（玉兔精在队）→ 后续寒雾相关劫难难度降低。

### 8.20 铜台府 · 寇员外（第79难）

**原著剧情**：铜台府地灵县**寇员外**斋僧一万，唐僧师徒恰是第一万个，留宿半月；当夜强盗闯门**打死寇员外**、抢了家产，**寇妻反告唐僧师徒**，官府将师徒下狱；悟空设计让寇员外还魂，真相大白。

**结构（单劫难）**：**无直接战斗**，主要为剧情抉择（六选一）

**最终抉择（六选一）**：
1. **战**：直接打出大牢，强行洗清冤屈 → ◆装备〔恶+5〕
2. **渡**：用计让寇员外还魂，真相大白 → ◆经文〔善+8〕
