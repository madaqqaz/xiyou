## 二、依赖关系（谁卡谁）

```
L0 六道 ✅  ← 已完成，不再阻塞任何系统
     │
     ├─→ L1 装备 🟢 ──┐
     ├─→ L1 职业 🔴 ──┼─→ L3 宠物 🔴 ──→ L3 随从 🔴
     └─→ L1 技能 🟡 ──┘        │
              │                └─（召唤师职 → 宠物 6 格）
              └─→ L2 经文 🟡 ──→ L1 技能（变体源）
                       │
                       └─（劫印/道心/心魔 ✅ 已收口，不再阻塞）

L4 结算层（属性/Buff/战斗）  ← 最后的数值锚定，必须等 L1/L2/L3 全定
L5 框架层 / L6 元层          ← 独立推进，不阻塞 BD 线
```

**三条硬依赖（顺序不能换）**：

| 依赖 | 说明 |
|---|---|
| **职业 → 宠物 → 随从** | 召唤师是隐藏职（`JOB_STYLE='summon'`），宠物 6 格与随从合成挂在它上面；职业不定，宠物/随从的顶格数值无从校准 |
| **职业 → 技能 → 经文** | 职业 L3 套路要改「三键形态」，三键改造落在技能层，变体模板在经文层。**三者的改动必须同批**，否则接口反复改 |
| **L1/L2/L3 → L4** | 属性/Buff/战斗是**结算出口**，等上游定完再锚定，否则每改一个上游就要重测一次战斗平衡 |
