## 2. 六道属性轴（新 · 唯一真源表）

**设计原则**：六道各绑定一个**互不重叠**的属性轴，使「走哪条道」=「堆哪条属性」，形成六条清晰差异化的成长线。当前代码 `SEAL_DAOTU` 中 夺、逆 同取 `reflect`（重叠），本节为修正后的权威轴。

| 道 | 主属性 | 含义 | 当前代码状态 |
|---|---|---|---|
| **渡** | 气血上限（maxHp） | 堆血、养身 | ✅ 已对齐（SEAL_DAOTU.stat=maxhp） |
| **战** | 攻击（atk） | 物攻爆发 | ✅ 已对齐（stat=atk） |
| **缘** | 防御（dr + mdef） | 减伤 + 法防 | ✅ 已对齐（stat=dr+mdef） |
| **隐** | 闪避（eva） | 身法、回避 | ✅ 已对齐（stat=eva） |
| **夺（贪）** | 吸血（lifesteal） | 以战养战 | ⚠ 待改：stat 由 reflect → lifesteal |
| **逆** | 最终伤害（finalDamage） | 终伤放大、无视前序折扣 | ⚠ 待改：stat 由 reflect → finalDamage（**新增战斗属性**） |

> **完全不冲突**：六属性分别落在 血上限 / 攻 / 双防 / 闪避 / 吸血 / 终伤 六个不同维度，无交叉。原设计中 夺、逆 同取反伤（重叠）是本次修正的核心。

## 3. 经文系统重设计（V9.27）

### 3.1 设计哲学
- **装备 = 属性 / 数值**：平铺属性、套装共鸣、经济套（盘缠/巡游）提供成长底盘。
- **经文 = 两种**：① **属性经**（被动加属性，包裹即生效）；② **技能经**（改攻击 / 诵经技能，提供构筑多样性）。
- 经文因此从「纯被动收集」升级为「**BD 双支点之一**」——与装备装配并列，对标《万世剑冢》的技能系统。

### 3.2 经文两分型
| 类型 | 作用 | 生效方式 | 示例 |
|---|---|---|---|
| **① 属性经** | 加属性（按 §2 六道轴或通用属性） | **包裹生效**（进入背包/已持即常驻，不占经位） | 《无量寿经》气血+吸血、《金刚经》破甲真伤 |
| **② 技能经** | 改普攻 / 绝招 / 诵经的行为 | **装入经位**（见 §3.4）才生效，可替换 | 概率连击、暴击+、暴伤+、每回合回血、开局护盾、法术吸血 |

> 属性经「包裹生效」＝收集即强，零决策成本；技能经「装经位」＝主动构筑，是 BD 玩法的决策点。二者分工：属性经保底成长，技能经拉开流派。

### 3.3 获取方式（V9.32 定稿 · 单一 34 部目录 + 残片 X/N）
- **唯一目录**：既有 **34 部**（渡 22 + 逆 12）为经文唯一真源——真经名 + 命名表残片数（近似真经长度：心经 5、金刚经 7、法华/楞伽 10、涅槃/坛经/金光明 12、仁王 14、法句/华严 16、梵网 20），合计 **279 片**。
  - ⚠ **V9.28 曾自造 16 部「启程经/破障经…」章末经，用户 2026-09-23 拍板作废删除**（另造目录＝双真源冲突）。经位身份改由 34 部现有 `chantSkill.kind` 派生（见 §3.5.C）。
- **残片计量**：一切以「残片 X/N」计（N = 命名表长度）。集满 N 即合成整本；**半部 = ⌈N/2⌉ 片**（未集满不生效，超出作废）。
- **获取源（两条）**：
  1. **章末正常结算**：`NDX.grantChapterSutraShards(s, act, n)`，默认 **6 片/章**（`CHAPTER_SHARD_N`）；逆道开启（`s.fate.逆 ≥ 1`）后渡/逆交替。
  2. **章节起点·土地庙二选一**（用户拍板）：**增寿**（`gateMeditate`，寿元 +N 天）／**念经**（`gateChant`，给一部未完成经的**半部**）。二者互斥，每处土地庙一次。
- **念经定向**：`NDX.sutraHalfPick(s, act, side)` —— 优先本地区池 → 再优先玩家主道，保证「给得上的那半部」与所走路线一致。
- **二周目锁**：`ni_full_nitian`（逆天录）/`ni_full_duotian`（堕天录）/`ni_full_mieshi`（灭世咒）带 `cycleReq:2`，首周目不进候选池——即「原设计需二周目集齐」的落地。

### 3.4 经位（2 格 · V9.32）
- **2 个经位**：`经位·攻击`（`atk`，改写普攻/绝招）、`经位·诵经`（`chant`，改写诵经）。
- **34 部经均可入经位**：经位身份由 `chantSkill.kind` 派生（§3.5.C），**不另造目录**；同一部经既可「包裹生效」（属性经，`effect` 被动）又可「装经位」（技能经，`mod` 行为改写）。
- **slot 双向匹配**：`jingSlotMods` / `jingSlotDefStats` 均要求 `经位身份.slot === 所装格`；atk 身份经装进 chant 格**不生效**（防误配）。
- **唐僧**：⚠ **有普攻**（`baseAtk: 78`，`attackFeel`＝攻命中回微血）；`mainKey:'chant'` 仅影响 UI 手感标签、**不驱动战斗行动**。故 **atk 格对唐僧同样有效**（V9.28「唐僧无普攻、atk 格无效」为误判，已废止）。
- **舍攻为盾**（V9.30 `data_skill_variant.js` ATK_VARIANTS）：取消本次物理攻击、改为获得护盾——**全英雄适用**，非唐僧专属。
- 状态字段：`s.jingSlots = { atk: <fullId|null>, chant: <fullId|null> }`；由 `attr_calc.js`（`def`）与战斗构建期（`mod`）双路消费。

### 3.5 技能经修饰枚举（V9.28 全套路 · 对标万世剑冢 · 技能多重性）
技能经通过「修饰」改变攻击/诵经，使战斗不再是「普攻 + 法术大招」二选一，而是多重叠加——覆盖常规 RPG 基本套路（护盾·反伤·吸血·闪避·暴击·攻·防）。分两类挂载：

**A. 攻击/诵经行为修饰（`mod`，战斗内改写普攻/绝招/诵经）**

| 修饰 | 字段 | 效果 | 对应战斗原语（已存在） |
|---|---|---|---|
| **概率连击** | `combo` | 攻击/绝招有概率追加一段伤害 | `multi` / combo（combat 已支持） |
| **增加暴击** | `crit` | 暴击率 +X% | `crit`（已支持） |
| **增加暴伤** | `critDmg` | 暴击伤害 +X% | `criMult`（已支持） |
| **每回合回血** | `regen` | 每回合开始回血 | `hpRegen` / heal（battleModsOf 已支持） |
| **开局护盾** | `shield` | 每战开局获得护盾 | `shieldPct`（battleModsOf 已支持） |
| **法术吸血** | `spellLifesteal` | 法术/技能伤害按比例回血 | `lifesteal`（法术侧已支持） |
| **攻强（物）** | `atkPct` | 攻击/技能伤害 ×(1+X%) | 伤害乘区（applyJingSlotMods 已支持） |
| **法强（法）** | `matkPct` | 法术/技能伤害 ×(1+X%) | 伤害乘区（applyJingSlotMods 已支持） |
| 破甲 | `armorBreak` | 攻击无视部分防御 | `ignoreDef`（已支持） |
| 必中真伤 | `trueDmgPct` | 造成无视闪避的真伤 | `trueDmgPct` + `ignoreDef`（已支持） |

**B. 经位被动属性（`def`，经 `attr_calc.js → sutraEffs → computeStats` 实时结算，与渡藏/逆藏同管线）**

| 被动属性 | 字段 | 效果 | 真实结算字段 |
|---|---|---|---|
| **减伤** | `ti.dr` | 受到伤害 ×(1−X%) | `dr`（已消费） |
| **闪避** | `ti.eva` | 概率回避攻击 | `eva`（已消费） |
| **暴击率** | `ti.cri` | 暴击率 +X% | `cri`（已消费） |
| **体攻** | `ti.atk` | 攻击 +X | `atk`（已消费） |
| **气血** | `ti.hp` | 气血上限 +X | `maxHp`（已消费） |
| **法防** | `mdef` | 法术减伤 +X% | `mdef`（已消费） |
| **法强** | `matk` | 法术攻击 +X | `matk`（已消费） |
| **受击反伤** | `reflect` | 受击反伤 X%（反伤流核心） | `reflect`（已消费，V9.28 修复） |

> `mod` 类（连击/暴击/暴伤/回血/护盾/吸血/攻强/法强）由 `applyJingSlotMods` 在战斗内注入 atk/chant 行为；`def` 类（减伤/闪避/反伤/法防/攻防）由 `jingSlotDefStats` 经 `attr_calc` 并入 `sutraEffs` 实时结算。二者分工：`mod`=行为改写，`def`=属性底盘。

### 3.5.4 从怪状态逐层独立计时（V9.41 · 条数语义）

> 本节收口 V9.39 §6 第 6 条「仍开」①（用户 2026-09-23 拍板「改独立计时」）。至此 V9.39 遗留三项全部关闭。

### 3.5.5 从怪叠层强度回归：poolRounds 与 rounds 解耦（V9.42）

### 3.6 与战斗系统结合（三系统耦合闭环）
结算管线顺序（现状，`computeStats`）：
```
基础 → 装备平铺 → 劫印(SEAL_DAOTU) → 转职 → 套装共鸣 → 跨系统协同 → 经文(属性经+技能经经位) → 封顶
```
- **属性经**：实时并入属性（按 §3.2 包裹生效）。
- **技能经（经位）**：在战斗内改写普攻/绝招/诵经的行为（§3.5 修饰）。
- **最终伤害（逆）**：在伤害公式末端作为终乘区，放大已计算伤害，不与其他乘区重叠。
- **道途一致性强耦合**：走夺道既吃夺套共鸣（吸血向）、夺印（lifesteal）、夺经（吸血+技能经修饰），天然形成「道途一致 BD」——这是竞品《冒险者日记》没有的深度。

### 3.7 逆道获取规则（开局选择不影响经文获取）
- **开局选择「正常（非逆）」**：经文按 §3.3 正常获得（十六章本·上下两卷）。
- **开局选择「逆道」**：经文**同样正常获得**（不锁、不减半）；唯一差异——经文三选一（若保留三选一保底机制）时，**优先刷新逆道经文**作为候选，使逆线玩家更易凑齐逆经流派。
- 即：逆道是「经文池加权」而非「经文封锁」，保证逆线也有完整经文成长。
