# 《逆道西行》战斗节奏与手感 · 竞品借鉴分析（2026-09-05）

> 本文聚焦**战斗层**（回合节奏 / 打击手感 / 反馈表现），对照卡牌、动作、数值三类肉鸽标杆，输出可落地的借鉴建议。
> 前置阅读：`逆道西行_竞品机制借鉴备忘_2026-08-29.md`（系统级机制借鉴，暖雪/循环英雄/欺诈之地）；本文与其不重复，只谈战斗手感。
> 约束对齐：全部建议以**逻辑层 + 既有资源复用**为主，符合「0–500 元美术、零新增美术预算优先」；核心逻辑进 owner 数据/逻辑文件，ui.js/main.js 只做渲染接线。

---

## 0. 结论先行

当前战斗系统已具备**三类肉鸽标杆的核心骨架**：意图预告（杀戮尖塔）、血条延迟与击退（哈迪斯）、连击档位（死亡细胞）、Build 成型判定（吸血鬼幸存者系）。骨架在，**差距全在"表现层的打击重量"与"决策层的预告时机"**：

1. **缺命中停帧与受击白闪**——打击感"轻"，爆发/识破瞬间无重量感（对标 Hades 技术栈）。
2. **缺伤害数字分级**——暴击/识破/爆发与普攻同权，爽点无放大。
3. **蓄力重击意图当回合才揭示**——有"反应"无"规划"，缺 StS 的提前一轮决策感。
4. **缺战斗小结与成型宣告**——单场表现与 Build 成型缺乏"仪式感"反馈。
5. **小怪回合上限偏宽**（6 回合）——节奏重心可向精英/Boss 的操作点密度转移。

以下为盘点与逐条建议。

## 2. 竞品拆解与对照

### 2.1 卡牌类标杆 · 杀戮尖塔 Slay the Spire（及月圆之夜 / 欺诈之地）

**核心设计**：
- **意图系统**：完整展示敌人*下一回合*行动 → 玩家提前一轮规划（决策感，非反应）。
- **战斗加速**：局内快速模式开关，中后期跳过冗长演出。
- **单场节奏**：普通战 1–3 分钟，Boss 3–5 分钟；地图节点"战斗-事件-休息-商店"交替制造喘急曲线。
- **战后仪式**：胜利后卡牌三选一，构筑方向感即时强化。

**对照《逆道西行》**：
| 已具备 | 差距 |
| --- | --- |
| ✅ 意图预告（当回合揭示） | ❌ 意图是"当前回合"而非"下一回合"——有反应无规划 |
| ✅ 战斗加速（1x/2x/3x） | ❌ 战斗小结（回合数/峰值伤害/识破次数）缺失 |
| ✅ 地图节点喘急交替（25 节点） | ❌ 战后三选一有，但缺"构筑方向感"的局内宣告 |

### 2.2 动作类标杆 · 哈迪斯 Hades（及死亡细胞 / 暖雪）

**核心设计**：
- **打击感技术栈**：命中停帧（hit-stop，命中瞬间 2–4 帧停顿）+ 受击白闪（hit-flash）+ 血条延迟 + 震屏 + 击退。四件套让每次命中"有重量"。
- **伤害数字分级**：暴击/背刺数字更大、颜色更金、带缩放/上跳动画。
- **取消窗口**：攻击后摇可被闪避/技能取消（死亡细胞尤甚），手操上限高。
- **死亡节奏**：死亡快速回大厅重来，挫败感→再来一把的循环。

**对照《逆道西行》**：
| 已具备 | 差距 |
| --- | --- |
| ✅ 血条延迟动画（500ms 冲撞） | ❌ 无命中停帧——爆发/识破瞬间画面无停顿重量 |
| ✅ 击退/震屏/刀光 battle-fx | ❌ 无受击白闪（怪物受击无 1–2 帧高亮） |
| ✅ 识破窗口 ≈ 回合制"取消窗口" | ❌ 伤害数字未分级（暴击/识破/爆发与普攻同视觉权重） |
| ✅ 连击档位 3/6/9 | ❌ 爆发无全屏/强震宣告 |

### 2.3 数值/生存类标杆 · 吸血鬼幸存者 / 土豆兄弟 / 以撒

**核心设计**：
- **Build 成型感知**：关键升级瞬间全屏清怪/金光宣告，"我成型了"的爽感。
- **短局节奏**：土豆兄弟 15–20 分钟一局，失败 10 秒内重开，局外成长钩子。
- **三选一强度抉择**：每步选择可视化影响当前 Build 方向。

**对照《逆道西行》**：
| 已具备 | 差距 |
| --- | --- |
| ✅ 装备三选一掉落 | ❌ Build 成型（auditBuild/共鸣达成）无"宣告瞬间"——玩家不知自己已成型 |
| ✅ 六道流派 + auditBuild 验收 | ❌ 战斗时长重心偏小怪，精英/Boss 操作点密度可更高 |

## 4. 借鉴建议（P0 / P1 / P2）

### P0 · 表现层打击重量（低风险 · 立竿见影）✅ 已落地（2026-09-05）

#### P0-1 命中停帧（hit-stop）
- **借鉴**：Hades 命中停帧——命中瞬间全演出暂停 60–80ms，再继续。
- **改动**：`main.js` 战斗演出层，在 `battle-fx` 的 slash/knockback 触发处，命中瞬间 `delay` 该回合后续动画 60–80ms；**爆发（applyMomentumBurst）/识破（applyShiPo）回合强制停帧 120ms + 震屏幅度加大**（已有 shake fx，加大 kind 参数即可）。
- **验收**：实机观感——普通命中"顿一下"，爆发/识破"重顿 + 震屏"；不影响 2.5s 操作点限时（停帧只作用于演出，不占决策窗口）。

#### P0-2 受击白闪（hit-flash）
- **借鉴**：Hades 受击白闪——怪物受击瞬间 1–2 帧 `filter: brightness(1.8)`。
- **改动**：`ui_panel_2.js` 怪物立绘受击时加 1 帧高亮 class（纯 CSS transition，40ms 恢复）。
- **验收**：每次命中怪物闪白一次；爆发回合闪白 + 横向微颤。

#### P0-3 伤害数字分级
- **借鉴**：Hades 暴击数字更大更金。
- **改动**：`ui_panel_2.js` 伤害数字按来源分级：普攻（白·常规）/ 连击暴击（橙·×1.25 缩放）/ 识破反制（金·×1.5 上跳）/ 气势爆发（红·×2 全屏震 + 数字冲屏）。
- **验收**：四种数字视觉可区分；爆发数字带缩放弹跳。

### P1 · 决策与仪式感（逻辑小改 · 中风险）✅ 已落地（2026-09-05）

#### P1-1 蓄力重击提前一轮预告（StS 式规划感）
- **借鉴**：StS 意图展示"下一回合"。
- **现状**：telegraph 回合当回合才亮"💥蓄力重击"，玩家纯反应。
- **改动**：`combat.js` 在 telegraph 前 1 回合打标 `telegraphSoon`，`ui_panel_2.js` 意图区显示次级预警「🌀 妖气凝聚」；telegraph 回合仍显示"💥蓄力重击"并进入识破窗口。**保留实时反应型**（当回合 2.5s 窗口仍可识破），预警只是给玩家"准备感"，不强制。
- **平衡**：预警回合不暂停、不占操作点，仅 UI 提示；避免"提前预告 = 必可识破"的简化（保留低血量/狂暴等干扰）。
- **验收**：蓄力重击前 1 回合出现次级预警；telegraph 回合识破窗口正常；预警回合不打断演出节奏。

#### P1-2 战斗小结（StS 战后仪式）
- **借鉴**：StS 战斗结算卡牌三选一的仪式感；土豆兄弟每波统计。
- **改动**：胜利结算浮层增加一行小结（复用现有结算 UI）：回合数 / 最高单击伤害 / 识破次数 / 爆发次数 / 气势峰值；小怪战只显示一行，精英/Boss 显示完整五维。
- **验收**：战斗结束浮层出现小结；数据取自 `res`（roundsDetail 已有 momentum/telegraph/shpDmg/burstTier 全量数据，纯聚合，零新状态）。

#### P1-3 Build 成型宣告（VS 式"我成型了"）
- **借鉴**：吸血鬼幸存者关键升级全屏清怪 + 金光。
- **改动**：`data_audit.js` `auditBuild(s)` 首次返回"验收达标"时，挂一次全局事件（沿用 `battle-fx` 通道）：全屏金光 + 震屏 + 横幅「道途圆满 · 诸法归一」；仅每局首次，不重复。
- **验收**：成型瞬间一次金光宣告；不打断战斗（横幅 1.2s 淡出）；后续战斗不再触发。

### P2 · 节奏重心（数值微调 · 需实测）✅ 已落地（2026-09-05）

#### P2-1 小怪回合上限收紧 + 精英操作点增密
- **现状**：小怪 3–6 回合（6 为上限），精英 6–12。
- **改动**：
  - 小怪目标回合收窄为 **3–5**（`Math.round(3 + (diffLv - 1) * 0.15)` 的 max 由 6 降 5）；省下的时间不摊薄，直接让玩家更快进入"下一个选择"。
  - 精英战 `routine` 操作点由"每 5 回合"改"每 4 回合"（`round % 5 === 0` → `round % 4 === 0`），提高精英战主动参与密度。
- **风险**：小怪血量下降可能让低难度更"速通"——以 `pressureFactor`（Build 匹配采样）兜底，血量校准仍按单回合有效伤反推，仅上限收紧，不破坏校准公式。
- **验收**：小怪实测 3–5 回合收尾；精英战 4 回合节奏点可感知；高难度压力不因血量上限变化而失衡（回归门禁）。

## 5. 落地顺序与开发计划衔接

| 批次 | 建议 | 与既有计划关系 |
| --- | --- | --- |
| 第一批（手感四件套） | P0-1 停帧 / P0-2 白闪 / P0-3 数字分级 | 纯表现层，不动数值，不碰门禁，可先上 |
| 第二批（决策感） | P1-1 预告 / P1-2 小结 / P1-3 成型宣告 | 涉及 calcCombat 打标与结算聚合，需补门禁 |
| 第三批（节奏重心） | P2-1 回合收窄 + 操作点增密 | 数值微调，需全量门禁回归（regression/combat/combo） |

- **门禁影响评估**：P0 三件不影响任何现有门禁（仅 UI/演出）；P1-1 在 `combat.js` 增加 `telegraphSoon` 标，需在 `_smoke_combat_shipo.js` 补 1 例；P1-2 为纯聚合展示，加 `_smoke_fight_summary.js`；P1-3 复用 `_smoke_audit_resonance.js` 断言事件触发；P2-1 需回归 `_smoke_build_match_fight.js`（血量校准口径不变，仅上限参数）。
- **三端同步**：P0-1/2/3 为 DOM 演出层，小游戏/Canvas 端需各自实现等价效果（核心判定仍在 combat.js，跨端只差表现）；P1/P2 全部逻辑进 `combat.js`/`data_audit.js`，三端共享。

## 6. 决策留白（需用户确认）→ 已按建议项定案（2026-09-05）

1. **P1-1 预告时机**：✅ 采用「次级预警 + 当回合仍可识破」——`combat.js` 新增 `telegraphSoon` 标（`(round+1) % heavyEvery === 0 && mHp > 0`），`ui_panel_2.js` 意图区在识破窗口前一轮显示「🌀 妖气凝聚」（紫）；telegraph 回合仍亮「💥 蓄力重击」金并进入识破窗口，两者互斥。
2. **P0-1 停帧时长**：✅ 采用分级方案（沿用既有 crit/break 档并补足普通档）——crit（暴击/爆发）80ms、break（破韧/识破）60ms、heavy 65ms、hit（普攻）50ms；识破命中额外叠震屏（break 级）+ 大字「识破!」，爆发命中 crit 级停帧 + 大字「势·爆发!」。实机如需更"重"可再调常量。
3. **P2-1 小怪收窄**：✅ 收窄至 3–5 回合（`Math.min(5, ...)`）；**教学战（tutorial）保留原有精确校准不走节奏校准**，不受收窄影响；精英 routine 操作点由每 5 回合加密至每 4 回合（`_routineEvery = elite ? 4 : 5`）。
4. **P1-3 成型宣告**：✅ 每局仅首次——`s.flags.buildAnnounced` 守卫 + `auditBuild(s).formed` 触发一次全屏金光/横幅「道途圆满 · 诸法归一」；横幅 1.8s 淡出，不打断战斗。
