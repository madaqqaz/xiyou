# 《逆道西行》劫难系统重设计方案

> 参考《不一样西游》模板，重新设计81难的劫难链接、复合劫难多重选项和选择后果系统。

## 一、当前问题分析

### 1.1 现有设计的问题

1. **选项单一**：每个劫难只有3个选项，每个选项对应一个六道（战/隐/夺/渡/逆）
2. **纯数值导向**：选项效果主要是数值加成（体攻、气血、善恶等），没有故事后果
3. **无因果链接**：劫难之间没有因果关系，选择不影响后续劫难内容
4. **复合劫难单薄**：车迟国、女儿国、火云洞等大型复合节点只是合并了多个劫难，没有多重选项和分支
5. **黑暗内容堆砌**：选项纯粹是为了六道的抉择而编写的黑暗内容，没有玩家选择造成的不同故事路线

### 1.2 目标设计

1. **劫难链接**：劫难与劫难之间、复合劫难之间要有因果链接
2. **多重选项**：大型复合节点需要多重选项，产生不同的故事路线
3. **选择后果**：玩家的选择产生不同的后果，影响后续游戏内容
4. **六道收束**：最终抉择后告诉玩家选择了某一项六道即可

## 二、劫难链接系统设计

### 2.1 链接类型

#### 2.1.1 因果链接（Cause → Effect）

- **前置选择影响后续内容**：玩家在A劫难的选择会影响B劫难的剧情和选项
- **示例**：
  - 车迟国选择"放过三妖" → 后续通天河三妖前来报恩
  - 车迟国选择"斩杀三妖" → 后续通天河三妖的师弟前来复仇

#### 2.1.2 伏笔链接（Foreshadowing → Payoff）

- **前期伏笔后期回收**：在前期劫难中埋下伏笔，在后期劫难中回收
- **示例**：
  - 观音禅院老僧提到"锦襕袈裟的因果" → 后期黑风山黑熊精盗袈裟
  - 五庄观镇元子说"你我还有一拜" → 后期孙悟空为救人参果树求遍三岛

#### 2.1.3 回响链接（Echo）

- **相似主题的劫难互相呼应**：主题相似的劫难在不同阶段出现，形成回响
- **示例**：
  - 前期"两界山·金箍之择" → 后期"真假美猴王·本心之择"
  - 前期"白骨精·三戏" → 后期"六耳猕猴·三心"

### 2.2 链接数据结构

```javascript
// 劫难链接定义
NDX.TRIAL_LINKS = {
  // 车迟国 → 通天河
  'chechi_tongtian': {
    trigger: { trial: 30, choice: 'spare_three' },  // 触发条件：第30难选择"放过三妖"
    effect: {
      trial: 33,  // 影响第33难
      modify: {
        text: '通天河灵感大王听闻车迟国三妖被取经人放过，特来报恩...',
        opts: [
          // 修改后的选项
        ]
      }
    }
  }
}
```

## 三、复合劫难多重选项设计

### 3.1 复合劫难结构

大型复合劫难（车迟国、女儿国、火云洞等）采用**多阶段多重选项**结构：

```
复合劫难入口
  ↓
阶段1：初遇（2-3个选项）
  ↓
阶段2：深入（根据阶段1选择，出现不同选项）
  ↓
阶段3：抉择（最终抉择，2-3个选项）
  ↓
结局：根据所有选择，产生不同结局
```

### 3.2 车迟国复合劫难设计示例

#### 3.2.1 背景

车迟国虎力、鹿力、羊力三妖以"斗法"替天庭牧民，百姓跪在台下喊"国师万寿"，眼里却没光。

#### 3.2.2 阶段1：初入车迟国

**选项A：暗访民情**
- 效果：了解三妖治下百姓的真实生活
- 后续：阶段2出现"利用民情"选项

**选项B：直接挑战**
- 效果：直接向三妖发起挑战
- 后续：阶段2出现"斗法"选项

**选项C：混入僧众**
- 效果：混入被压迫的僧众中
- 后续：阶段2出现"策反僧众"选项

#### 3.2.3 阶段2：深入（根据阶段1选择）

**如果阶段1选A（暗访民情）**：
- 选项A1：利用民情，煽动百姓反抗
- 选项A2：同情三妖，认为他们也是被天庭利用
- 选项A3：暗中保护百姓，不与三妖正面冲突

**如果阶段1选B（直接挑战）**：
- 选项B1：云梯显圣（比坐禅）
- 选项B2：隔板猜物（比智慧）
- 选项B3：砍头剖腹（比性命）

**如果阶段1选C（混入僧众）**：
- 选项C1：策反僧众，里应外合
- 选项C2：利用僧众身份，盗取三妖法宝
- 选项C3：带领僧众逃离车迟国

#### 3.2.4 阶段3：最终抉择

**选项1：战·以力破劫**
- 斩杀三妖，车迟国恢复佛法
- 后果：三妖的师父（太上老君）前来问罪，后续劫难难度增加
- 六道：战

**选项2：渡·渡人向善**
- 点化三妖，让他们弃道从佛
- 后果：三妖成为护法，后续劫难提供帮助
- 六道：渡

**选项3：隐·避锋修心**
- 不与三妖正面冲突，暗中保护百姓后离开
- 后果：车迟国维持现状，但百姓暗中感激取经人
- 六道：隐

**选项4：逆·跳出簿子**
- 自封"车迟国王"，取代三妖统治
- 后果：天庭震怒，后续劫难出现天兵天将围剿
- 六道：逆

#### 3.2.5 结局分支

| 阶段1 | 阶段2 | 阶段3 | 结局 |
|---|---|---|---|
| 暗访民情 | 同情三妖 | 渡·渡人向善 | 三妖弃道从佛，成为护法 |
| 暗访民情 | 利用民情 | 战·以力破劫 | 百姓暴动，三妖被斩杀 |
| 直接挑战 | 砍头剖腹 | 战·以力破劫 | 三妖斗法失败，被斩杀 |
| 直接挑战 | 云梯显圣 | 隐·避锋修心 | 比坐禅平局，双方和解 |
| 混入僧众 | 策反僧众 | 逆·跳出簿子 | 僧众暴动，取经人自封国王 |
| 混入僧众 | 带领逃离 | 渡·渡人向善 | 带领僧众逃离，三妖追悔 |

### 3.3 女儿国复合劫难设计示例

#### 3.3.1 背景

女儿国国王欲招唐僧为夫，悟空等人陷入"情劫"。

#### 3.3.2 阶段1：初入女儿国

**选项A：隐瞒身份**
- 效果：隐瞒取经人身份，混入城中
- 后续：阶段2出现"身份暴露"选项

**选项B：公开身份**
- 效果：公开取经人身份，直接面见国王
- 后续：阶段2出现"国王招亲"选项

**选项C：绕道而行**
- 效果：试图绕道离开女儿国
- 后续：阶段2出现"子母河"选项

#### 3.3.3 阶段2：深入（根据阶段1选择）

**如果阶段1选A（隐瞒身份）**：
- 选项A1：身份暴露，被国王召见
- 选项A2：暗中调查女儿国秘密
- 选项A3：盗取通关文牒，偷偷离开

**如果阶段1选B（公开身份）**：
- 选项B1：接受国王招亲
- 选项B2：婉拒国王，请求通关
- 选项B3：悟空变身唐僧，替师父应亲

**如果阶段1选C（绕道而行）**：
- 选项C1：误饮子母河水，怀胎
- 选项C2：遇到如意真仙，索要落胎泉水
- 选项C3：被女儿国守军发现，押回王宫

#### 3.3.4 阶段3：最终抉择

**选项1：缘·羁绊**
- 接受国王情意，留下一段姻缘
- 后果：取经人获得"女儿国国王的信物"，后续劫难可召唤女儿国军队相助
- 六道：缘

**选项2：渡·渡人向善**
- 点化国王，让她明白"情爱皆空"
- 后果：国王弃国修行，成为一代高僧
- 六道：渡

**选项3：隐·避锋修心**
- 不告而别，偷偷离开女儿国
- 后果：国王相思成疾，后续劫难出现"女儿国追兵"
- 六道：隐

**选项4：逆·跳出簿子**
- 留在女儿国，与国王成亲，放弃取经
- 后果：触发"情劫结局"，游戏结束（可重开）
- 六道：逆

### 3.4 火云洞复合劫难设计示例

#### 3.4.1 背景

火云洞红孩儿吐三昧真火，火里映出孙悟空大闹天宫的旧影。

#### 3.4.2 阶段1：初遇红孩儿

**选项A：以力降服**
- 效果：直接与红孩儿战斗
- 后续：阶段2出现"三昧真火"选项

**选项B：以智取胜**
- 效果：用计谋对付红孩儿
- 后续：阶段2出现"假扮牛魔王"选项

**选项C：以情感化**
- 效果：试图用亲情感化红孩儿
- 后续：阶段2出现"牛魔王夫妇"选项

#### 3.4.3 阶段2：深入（根据阶段1选择）

**如果阶段1选A（以力降服）**：
- 选项A1：硬抗三昧真火
- 选项A2：请龙王降雨灭火
- 选项A3：变作小虫，钻入红孩儿肚中

**如果阶段1选B（以智取胜）**：
- 选项B1：假扮牛魔王，骗红孩儿
- 选项B2：盗取三昧真火的修炼法门
- 选项B3：利用红孩儿的好胜心，激将法

**如果阶段1选C（以情感化）**：
- 选项C1：请来牛魔王，父子相认
- 选项C2：请来铁扇公主，母子团圆
- 选项C3：讲述五百年前大闹天宫的往事，触动红孩儿

#### 3.4.4 阶段3：最终抉择

**选项1：战·以力破劫**
- 请来观音，用金箍降服红孩儿
- 后果：红孩儿成为善财童子，后续劫难可召唤相助
- 六道：战

**选项2：缘·羁绊**
- 认红孩儿为义子，带他一起取经
- 后果：红孩儿成为随行弟子，战斗中提供三昧真火援助
- 六道：缘

**选项3：渡·渡人向善**
- 点化红孩儿，让他明白"真火非火，是心"
- 后果：红孩儿弃妖从善，在火云洞修行，后续劫难提供帮助
- 六道：渡

**选项4：逆·跳出簿子**
- 传授红孩儿大闹天宫的本事，让他反出天庭
- 后果：红孩儿成为新一代妖王，天庭震怒，后续劫难难度大增
- 六道：逆

## 四、选择后果系统设计

### 4.1 后果类型

#### 4.1.1 即时后果（Immediate）

- **数值变化**：体攻、气血、善恶等数值变化
- **获得物品**：获得装备、法宝、材料等
- **解锁能力**：解锁新技能、新被动等

#### 4.1.2 短期后果（Short-term）

- **后续劫难修改**：影响接下来1-3个劫难的剧情和选项
- **NPC关系变化**：与某个NPC的关系变化（友好/敌对/中立）
- **区域状态变化**：某个区域的状态变化（和平/战乱/荒芜）

#### 4.1.3 长期后果（Long-term）

- **结局分支**：影响最终结局
- **隐藏路线**：解锁隐藏剧情路线
- **周目继承**：影响下一周目的初始状态

### 4.2 后果数据结构

```javascript
// 选择后果定义
NDX.CHOICE_CONSEQUENCES = {
  // 车迟国·放过三妖
  'chechi_spare': {
    immediate: {
      good: 20,
      item: '三妖的信物',
    },
    short_term: {
      // 影响通天河
      trial_33: {
        text_modify: '通天河灵感大王听闻车迟国三妖被取经人放过，特来报恩...',
        opts_add: [
          { text: '接受三妖报恩，获得帮助', effect: { ti: { atk: 30 } } }
        ]
      }
    },
    long_term: {
      ending_modifier: '三妖护法',
    }
  }
}
```

## 六、与现有系统的兼容

### 6.1 六道系统

- 保留六道（战/隐/夺/渡/缘/逆）作为最终抉择的收束
- 每个复合劫难的最终抉择对应一个六道
- 玩家在最终抉择后，系统告诉玩家选择了某一项六道

### 6.2 肉鸽系统

- 保留肉鸽的随机性和重玩性
- 复合劫难的多阶段选项增加了每次游玩的多样性
- 选择后果系统增加了周目继承的深度

### 6.3 战斗系统

- 保留战斗系统作为核心玩法
- 复合劫难的某些选项会触发战斗
- 选择后果会影响战斗难度和敌人配置

---

## 七、总结

本设计方案通过以下方式重新设计81难系统：

1. **劫难链接**：因果链接、伏笔链接、回响链接，让劫难之间产生关联
2. **复合劫难多重选项**：3阶段结构，每个阶段2-3个选项，产生12+种结局分支
3. **选择后果系统**：即时后果、短期后果、长期后果，让玩家的选择真正影响游戏
4. **六道收束**：最终抉择对应六道，保留现有六道系统

参考《不一样西游》的模板，让玩家通过不同的抉择产生不同的故事路线，而不是简单的数值选择。
