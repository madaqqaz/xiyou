## §零 · 后续复合劫难通用规则（设计原则）

你给出的方向，作为**所有复合节点**的统一范式：

1. **主轴 = 全渡 + 全逆**：复合节点的子难应优先提供 渡 / 逆 双主轴选项（对应"渡化/造反"两条价值线）。
2. **逆 = 连续触发选项**：选「逆」不只记一笔道德值，还作为**解锁钥匙**——连锁开启后续逆支线（参照 难11逆→解锁12/13逆、难39逆→解锁后续逆）。
3. **混合**：在 渡/逆 主轴之外，混合 战 / 夺 / 隐 等其他道作为支线分支，丰富构筑。
4. **终局结算**：复合节点按"子难组合"给奖励矩阵（参照车迟国 / 黄风岭 hf 范式）——全渡、全逆、混合、全战各有不同回报。
