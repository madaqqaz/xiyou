## 一、配音系统概述

### 1.1 配音系统架构

游戏配音系统采用三层架构：

1. **配音配置层**（voice_config.js）
   - 英雄配音配置（5个英雄）
   - Boss配音配置（8个主要Boss）
   - 通用怪物配音配置（3种类型）
   - 配音文件路径映射
   - 配音播放API

2. **音效系统层**（sound.js）
   - 音量控制（独立的配音音量）
   - 静音记忆
   - 文件格式自动回退
   - 播放失败静默处理

3. **游戏集成层**（战斗/UI代码）
   - 战斗事件触发配音
   - 出场/胜利/死亡事件触发配音
   - 技能释放触发配音

### 1.2 配音类型

| 配音类型 | 触发时机 | 说明 |
|---|---|---|
| enter（出场） | 战斗开始时 | 角色出场台词 |
| attack（攻击） | 普通攻击时 | 攻击呐喊 |
| skill（技能） | 释放技能时 | 技能台词 |
| ult（绝招） | 释放绝招时 | 绝招台词 |
| victory（胜利） | 战斗胜利时 | 胜利台词 |

## 七、配音系统集成建议

### 7.1 战斗系统集成

在战斗系统的关键事件中添加配音播放：

```javascript
// 战斗开始时
function onBattleStart(heroId, bossId) {
    NDX.playHeroVoice(heroId, 'enter');
    if (bossId && NDX.BOSS_VOICES[bossId]) {
        setTimeout(() => NDX.playBossVoice(bossId, 'enter'), 1000);
    }
}

// 英雄攻击时
function onHeroAttack(heroId, isCrit) {
    if (isCrit) {
        NDX.playHeroVoice(heroId, 'crit');
    } else if (Math.random() < 0.3) { // 30%概率播放攻击配音
        NDX.playHeroVoice(heroId, 'attack');
    }
}

// 释放技能时
function onHeroSkill(heroId, skillType) {
    if (skillType === 'ult') {
        NDX.playHeroVoice(heroId, 'ult');
    } else {
        NDX.playHeroVoice(heroId, 'skill');
    }
}

// 战斗胜利时
function onBattleVictory(heroId) {
    NDX.playHeroVoice(heroId, 'victory');
}

// 战斗失败时
function onBattleDefeat(heroId) {
    NDX.playHeroVoice(heroId, 'defeat');
}
```

### 7.2 音量控制

配音音量使用音效音量控制：

```javascript
// 设置配音音量（使用音效音量）
NDX.sound.setSfxVolume(0.8);

// 静音时配音也会静音
NDX.sound.toggle();
```

### 7.3 性能优化建议

1. **配音预加载**：预加载当前英雄和Boss的配音文件，减少播放延迟
2. **播放频率限制**：攻击配音设置概率触发（如30%），避免频繁播放
3. **配音互斥**：同一时间只播放一个配音，新配音会打断旧配音
4. **音量平衡**：统一配音音量，避免不同配音音量差异过大
