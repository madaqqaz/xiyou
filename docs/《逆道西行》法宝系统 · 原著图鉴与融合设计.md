# 《逆道西行》法宝系统 · 原著图鉴与融合设计

> 版本：V816 · 法宝系统设计稿
> 定位：**独立主动系统 · 战斗中手动祭出 · 专破 Boss 特殊阶段 · 克制为辅**
> 取材：以《西游记》原著法宝为全量图鉴根基，映射到本作 Boss 阶段机制
> 对齐字段：`NDX.TREASURES`（equipment.js）/ `SEAL_WORDS.link`（jieseals.js）/
> `FATE_WORDS`（jieseals.js）/ `SET_RESONANCE`（equipment.js）/ `SUTRA_FULLS`（data.js）/ `NANBU`（achievements.js）

---

## 一、设计定位（承接决策）

| 决策点 | 结论 |
|---|---|
| 形状 | 独立主动系统，`treasure` 槽位，战斗中手动祭出 |
| 核心目标 | 打破 Boss 特殊阶段，不替代属性成长 |
| 手感 | **破局为主（临场打断）+ 克制为辅（备战加伤）** |
| 使用约束 | 保留 `charges` 充能制，破局法宝次数极少（1–3 次） |
| 权重 | **独立优先**，命痕/劫印/转职/佛经/难簿/善恶仅作成长与解锁来源 |
| 取材 | 西游记原著全量法宝图鉴 |

**一句话**：法宝是唯一"战斗内主动打破规则"的系统——平时沉默，Boss 进入特殊阶段时，玩家手动祭出对应法宝，一锤定音。

## 二、Boss 特殊阶段定义（破局目标）

本作战斗内核（combat.js + 词缀系统）目前可被"针对性破解"的阶段，统一纳入 `break` 目标：

| 阶段 ID | 机制名 | 触发条件 | 危险点 | demo 对应字段 |
|---|---|---|---|---|
| `enrage` | 狂暴 | 残血 < 阈值 | 攻势 ×1.5（可 ×1.8） | `enrageThreshold/enrageMult` |
| `telegraph` | 蓄力重击 | 蓄力回合 | 伤害 ×1.6 | demo 已有 telegraph 提示 |
| `revive` | 不灭复活 | 首次死亡 | 复活回 50% 血 | `reviveOnce` |
| `regen` | 再生回复 | 每回合 | 每回合回 3–5% 血 | `regen` |
| `dot` | 咒蚀蚀心 | 持续 | DOT 每回合掉血 | `dotChance/dotMult` |
| `buff` | 全面强化 | 出场即带 | 全属性 ×1.2 / 高血回复 | `妖王/佛陀` 词缀 |
| `shield` | 护盾护体 | 阶段存在 | 吸收伤害、免疫控制 | 护盾机制 |

> `break` 字段设计：给每件破局法宝声明它破解哪些阶段，战斗内核在对应阶段触发时，先行判断"玩家是否持有可破件"，并给出明确提示（`此刻祭宝必破`）。

## 四、法宝 → Boss 阶段映射（破局表）

将 §二 的 7 个阶段与 §三 的 A 档法宝一一对应，形成"见到阶段 → 想起法宝"的直觉：

| Boss 阶段 | 首选破局法宝 | 备用 | 手感 |
|---|---|---|---|
| 狂暴 `enrage` | 芭蕉扇（扇熄攻势） | 镔铁棍 | boss 残血狂暴时，一扇打断，反打 |
| 蓄力重击 `telegraph` | 乾坤圈 / 幌金绳 | 金铙 | 蓄力回合祭出，打断必中 |
| 不灭复活 `revive` | 紫金红葫芦 / 阴阳二气瓶 | 九龙神火罩 | 一收或一炼，杜绝二段 |
| 再生回复 `regen` | 三昧真火（持续灼烧） | 火尖枪 | 断其回血，压血线 |
| 咒蚀蚀心 `dot` | 玉净瓶（圣水净化） | 照妖镜 | 净化自身 DOT |
| 全面强化 `buff` | 金刚琢（套走强化） | 人种袋 | 破词缀，反制妖王/佛陀 |
| 护盾护体 `shield` | 降魔杵 / 九龙神火罩 | 金砖 | 破盾高伤 |

> **克制为辅**：保留现有 `counter` 标签（对妖/魔/天庭/佛门），破局法宝同样可带克制标签，命中相克阵营时额外加伤（`dmgX:1.5`），但**破阶段是主机制，克制只是锦上添花**。

## 五、七系统接入点（对齐 demo 真实字段）

> 原则：**独立优先**——法宝永远是独立主动系统；融入只发生在"成长 / 获取 / 形态解锁"，不改变战斗内主动定位。

| 系统 | 融入方式 | 代码接入点 |
|---|---|---|
| 装备系统 | 槽位独立（treasure）；强化材料与散装掉落共享，避免两套养成抢资源 | `EQUIP_POOL` / `BASIC_EQUIPS` |
| 劫印 | 落地空字段 `SEAL_WORDS.xxx.link`：道途劫印给对应法宝 +%伤（如"战·杀伐"→攻击型法宝 +X%） | `jieseals.js` |
| 命痕 | 保留并深化现有 treasure 机制词条（逐杀·免充能 / 戾伤·祭宝增伤 / 焚天·冷却减半 / 逐风·重置冷却） | `FATE_WORDS` |
| 隐藏转职 | 已是门槛件（金箍系列/避水珠系列/六耳印/无字天书），A 档破局法宝可设为二周目转职专属解锁 | `HERO_SEAL_JOBS` / `TREASURES` |
| 佛经 | 集齐某部经 → 解锁对应佛法破局法宝 / 诵经给法宝充能 | `SUTRA_FULLS` / `availableSutras` |
| 成就难簿 | 高难簿 / 稀有成就解锁"名器级"破局法宝 | `NANBU` / `ACHIEVEMENTS` |
| 善恶命运 | 同一法宝善恶分化形态（光明/魔化），命运门控解锁（金箍棒→魔化/降魔→光明） | `s.good` / `s.evil` |

## 六、代码数据字段建议（可直接比照改造）

```javascript
// NDX.TREASURES 新增/扩展字段
// 破局声明：标明该法宝破解哪些 Boss 阶段
{
  id: 'baojiao',           // 芭蕉扇
  name: '芭蕉扇',
  phase: 'in',             // 战中祭出
  charges: 1,              // 保留充能制，破局件次数极少
  break: { stage: ['telegraph', 'enrage'], kind: '打断', save: true },
  counter: { tags: ['妖'], dmgX: 1.5, note: '克制妖系' },  // 克制为辅
  effect: { dmgPct: 0.35, dmgFlat: 60, save: true },
}
```

```javascript
// 破局命中判定（combat.js 内）：Boss 进入某阶段时，检查玩家持有 break.stage 命中件
function findBreakTreasure(s, stage) {
  return (s.treasures || []).find((t) => {
    const T = NDX.TREASURES[t.treasureId];
    return T && T.break && (T.break.stage || []).includes(stage);
  });
}
// 命中 → 该回合祭宝判定为"必破"，进入打断/破除分支
```

1. **V1 破局骨架**：给 `TREASURES` 加 `break` 字段，combat 加 `findBreakTreasure`，接入 `telegraph`/`enrage` 两个最直观的阶段。
