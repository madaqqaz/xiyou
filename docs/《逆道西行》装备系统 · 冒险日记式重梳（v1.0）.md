## 一、冒险日记的定义（先把锚点钉死）

真源原文（2026-09-12 §二）：

> 「冒险日记」= 事件中以 `gear:` 授予、**仅事件可得、不入掉落/商店** 的专属装备
> （武器 `ev_w_*` / 甲 `ev_a_*` / 冠 `ev_h_*` / 靴 `ev_b_*` / 法宝 `ev_t_*`）。

**三条硬规则**：

| # | 规则 | 判定 |
|---|---|---|
| 1 | 获得方式＝**仅事件发放** | `eventOnly` |
| 2 | **不入**随机掉落 / 坊市 | `rollEquips` 显式排除 |
| 3 | 作用＝**隐藏转职凭证** | `日记装备≥N` / `持ev_<id>` |

⚠ **注意第 0 条**：`ev_` 是**命名习惯**，不是定义。把它当判据，正是本轮修掉的那个 bug（见 §三）。

> ① 与 ② 的区别很关键：**两者都不入掉落，但只有 ① 是日记凭证**。

### 2.2 身份层（正交于渠道）

一件东西可以同时是「渠道⑤」和「身份⑥」——这是 `treasure:` 字段混乱的根源。

| 身份 | 字段 | 说明 |
|---|---|---|
| 法宝（祭出式） | `treasure:true` / `treasureId` / `charges>0` | 由 `NDX.isActiveTreasure` 判定 |
| 被动件（器胚） | 非祭出 | `equipSlotOf` 归一到 `special` 栏 |
| 宠物 | `slot:'pet'` | 场域改写者（不出手改规则） |
| 随从 | `slot:'companion'` | 行动补位者（周期出手） |

## 三、本轮修掉的两个硬缺陷

### 🩸 缺陷 1：21 件日记装备被漏计，隐藏职静默卡死

| 项 | 内容 |
|---|---|
| **原判据** | `data_trials.js` 旧实现：`String(e.id).indexOf('ev_') === 0` |
| **真相** | `NDX.SUTRA_EVENT_GEAR` 的 **21 件**（`jade_vase`/`wuchao_robe`/`dizang_staff`/`sanjian_p1..p6`/`bajiao_fan` 等）**实质完全符合定义**（eventOnly、不入掉落商店、仅事件发放），只是 id 没起 `ev_` 前缀 |
| **后果** | 玩家拿到这 21 件，日记计数**不涨** ⇒ 「日记装备≥N」类隐藏职（定风金蝉 / 九头·掠宝 / 净坛·拾遗 / **行旅录主**）永远差一块，**且不报错、不给提示** |
| **修法** | 单一真源 `NDX.isDiaryEquip(e)`＋`NDX.DIARY_EQUIP_IDS`；判定＝`diary:true` ∪ `id 兜底` ∪ `ev_ 前缀兼容` |
| **为何不改 id** | 老存档里装备 id 已被持久化，改名 = 存档迁移。**用标记而非命名约定，才是能扛住时间的判据** |

### 🩸 缺陷 2：`treasure:` 是杂物筐，73 个 id 查无此物

| 项 | 内容 |
|---|---|
| **规模** | `treasure:` 共 94 处出现 / 83 个去重 id，**73 个查无此物** |
| **消费真相** | `game_event_2.js` 的 `lootById(tid)` 返回 null ⇒ 落到 `else` 分支 `addMaterial(tid)` ⇒ **英文 id 当材料塞进背包**，日志写「拾得 tre_huojianqiang」 |
| **更狠的一处** | 夺宝战胜（`game_combat_2.js`）**连 else 都没有** ⇒ 玩家拼死打赢，什么都没得到，日志全无痕迹。夺道唯一的产出渠道，静默失效 |
| **修法** | ① 新增 `NDX.isUnresolvedTreasureId` 区分「中文材料名」与「未建实体的编码 id」，后者**不入库**、给体面文案 ② 补建 **28 件实体** ③ 门禁基线锁定剩余缺口 |

### 附：为何「EST avoid 是 KaTeX.getById」

`treasure:` 里混装了 5 类语义，这是所有问题的共同根源：

| 类别 | 数量 | 该走的字段 |
|---|---|---|
| 真法宝 | 32 | `treasure:` ✅ 名正言顺 |
| 配件/舍利（`chan_*` 等） | 15 | `material:`（六珠/六赐/六纤/六舍利体系**本来**走 material） |
| 装备（`equip_*`/`shanwen*`） | 17 | `treasure:` 可以，但必须有实体 |
| 经文 | 15 | `sutra:` / `niSutra:` |
| 中文材料名 | 若干 | `material:` |
