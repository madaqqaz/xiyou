> 整理：2026-09-05 ｜ 版本基线：V8.6x（模块一 · 三键手感收口后）
> 性质：**设计分析**（非代码改动真源）。两张循环网以代码事实为准（`js/game/*.js`、`js/ui/ui_changan.js`、`js/ui/ui_misc_2.js`）。

## 0. 一句话

单局循环网 = 「**启程 → 地图 → 战斗·三键 ↔ 收获·成长/转职 → 关隘终局 →（生结局 / 死承继）**」；
跨周目循环网 = 「**单局成果 → 长安回收 → 永久成长·解锁 → 转世承继 → 更强起点 → 再入单局**」的**上行螺旋**。
两网以「死亡承继 / 通关结局」为咬合口，单局每世交出一条成果线，跨周把成果沉淀成永久刻度。

## 1. 单局循环网

```
   启程·择道（英雄 / 本命 / 六道择道；体-愿双体系）
        │
        ▼
   地图推进·难  enterNode：战斗 / 劫难 / 奇遇 / 宝库 / 关隘
        │  ▲
        │  └────────────（通关：续行下一难 / 复合子难推进）
        ▼
   战斗·三键（攻 / 经 / 绝 · 气势爆发 · 识破 QTE · 三键手感透镜）
        │
        ▼
   收获·成长（掉落 · 装备随章进阶 upgradeHeroGear · 劫印 · 经文 · 法宝 · 合成 · 转职/隐藏职）
        │
        ▼
   关隘·终局（地区关隘 Boss · 逆道谈判）
   ├── 生 ──► 通关结局（CG / 英雄告别卡 / 完美通关 savePerfectClear / clearedHeroes）
   └── 死 ──► 承继·新世（引渡匣 · 世衰减 −20% · 5 世破损 · 本命法宝随世而散）
```

- **手感张力内核（本模块标的心脏）**：战斗 ↔ 收获 ↔ 转职 三者互喂——三键手感（攻式/主键）牺牲战斗反馈，战斗产出掉落/劫印/经文供收获成长，转职把道的倾向显影回攻键。模块一即在此环上强化「手感透镜」。

## 2. 跨周目循环网

```
   单局成果（通关结局 / 死亡 · 承继物 / 劫印 / 完美通关 / 告别CG）
        │  入城·回收
        ▼
   长安·逐周收藏（藏品库 / 小雁塔拓印 / 降妖簿图鉴 / 录难阁难簿 / 大雁塔行迹 / 钟楼功德榜）
        │  收藏 → 成长
        ▼
   永久成长·解锁（轮回殿赐福 · 劫灰坊升阶 · 新英雄 / 逆道 / 告别CG 解锁）
        │  解锁 → 转世
        ▼
   转世承继·新世（引渡匣 · 每世 −20% · 上限定世破损 · 开启下一世）
        │  更强起点（上行动力：承继刻度更高，再入单局）
        └────────────►  单局成果
```

- **现状落点（代码事实）**：长安八塔各自管一段收藏/成长；**已存在「轮回总鉴」**（`ui/ui_misc_2.js` `metaOverviewHtml`，入口 `ui_map.js:487` HUD 🧭）一屏聚合承继家当 / 六道拓印 / 八十一难簿 / 隐藏职 / 结局 CG / 跨周永久加成。

## 4. 结论

- **无阻断级断裂**：两网结构完整、方向自洽，核心闭环（手感张力内核 / 跨周上行螺旋）成立。
- **推荐主线（非多选题）**：
  1. **总览章落地为「长安可达」而非新建**——已有 `轮回总鉴` 复用，仅补在地图 HUD 外的**长安入口**，并在其中增补「家当三档边界」与「下一毕业目标」两格（即跨-1/跨-2/咬-2）。不另起并行总览。
  2. **文档条款**：把单-2（多世短冲 vs 单局纵深长约）、单-5（前段手感 vs 后段跳步）写成设计约束条款，防未来改动互踩。
  3. 可记录债务：单-3（隐藏职前置可查性）、咬-1（入世预算预览）。
- 本文件即「总览章 · 新增」的定稿；若后续把第 1 条落地为长安入口，改动owner 为 `ui/ui_changan.js`（入口）+ `ui/ui_misc_2.js`（补两格），聚合真源仍为 `metaOverviewHtml` 既有一套。
