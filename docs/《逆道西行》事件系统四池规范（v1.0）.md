## 三、六道池（15 条）

### 3.1 刷新口径（用户定调：按“选项最多”）

```js
// js/data_quota.js（V9.22 新增）
NDX.mostDaoOf = function (s) {
  const order = NDX.MAIN_DAO_ORDER || ['渡','战','缘','夺','隐','逆'];
  const f = (s && s.fate) || {};          // 计数真源：s.fate[道]（每次六道抉择 +1）
  let best = null, bestN = 0;
  for (const d of order) { const n = +f[d] || 0; if (n > bestN) { bestN = n; best = d; } }
  if (best) return best;                  // 取累计最多的一道
  return NDX.mainDaoOf(s);                // 全零回退地区锚点（永不为空）
};
```

- `pickEvent` 的 `dao` 过滤由 `mainDaoOf` 改为 **`mostDaoOf`**（`js/events_part1.js`）。
- 平手时按 `MAIN_DAO_ORDER`（渡→战→缘→夺→隐→逆）先到先得；全零时回退 `mainDaoOf`。
- 设计含义：玩家越偏某一道，越容易刷到该道的六道事件；**链式六道事件**（S3）沿该道推进。
