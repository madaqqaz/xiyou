# 《逆道西行》法宝钩子系统 · 通用规则

> 本系统为《逆道西行》游戏的法宝钩子通用规则，所有章节的法宝钩子均遵循本规则。
> 核心设计：每个法宝都有原著依据，法宝之间有联动，需要组合使用才能应对高难度战斗。

---

## 一、唐僧的袈裟升级·六颗宝石系统 💎

六颗宝石对应六种攻击类型，集齐六颗可升级唐僧袈裟为"锦襕袈裟·完整版"，获得全属性抗性加成。

### 1. 定风珠 🌪️
- **克制类型**：风系攻击
- **应用场景**：
  - 黄风怪（三昧神风）
  - 铁扇公主芭蕉扇
- **战斗作用**：使用定风珠可破除风系攻击，降低战斗难度
- **来源**：
  - 劫难节点：第2-4难缘选项中获得
  - 宝库：第一章宝库节点
  - 市场：第一章市场节点兜底刷出（100%）

### 2. 避水珠 💧
- **克制类型**：水盾/水系攻击
- **应用场景**：
  - 通天河
  - 黑水河
  - 碧波潭（九头虫）
- **战斗作用**：使用避水珠可破除水盾减伤80%，恢复正常伤害
- **来源**：
  - 劫难节点：第7难宝物节点三选一，必有避水珠
  - 宝库：第六章宝库节点
  - 市场：第六章市场节点兜底刷出（100%）

### 3. 避火珠 🔥
- **克制类型**：三昧真火/火系攻击
- **应用场景**：
  - 红孩儿（三昧真火）
  - 火焰山
  - 九曲盘桓洞火气
- **战斗作用**：使用避火珠可免疫火系伤害，降低战斗难度
- **来源**：
  - 劫难节点：第23难（火云洞前）宝物节点三选一，必有避火珠
  - 宝库：第三章宝库节点
  - 市场：第三章市场节点兜底刷出（100%）

### 4. 定魂珠 👻
- **克制类型**：幻术/精神攻击/魅惑/摄魂
- **应用场景**：
  - 蜘蛛精梦魇
  - 小雷音寺假佛迷心
  - 荆棘岭树精摄魂
- **战斗作用**：使用定魂珠可稳定心神，免疫幻术/魅惑/摄魂，降低战斗难度
- **来源**：
  - 劫难节点：四圣试禅心（第？难）缘选项中获得
  - 宝库：第二章宝库节点
  - 市场：第二章市场节点兜底刷出（100%）

### 5. 避毒珠 ☠️
- **克制类型**：毒系攻击
- **应用场景**：
  - 七绝山蜈蚣/蛇毒
  - 盘丝洞蛛毒
  - 百眼魔君金光毒
- **战斗作用**：使用避毒珠可免疫毒系伤害，降低战斗难度
- **来源**：
  - 劫难节点：第？难宝物节点三选一，必有避毒珠
  - 宝库：第五章宝库节点
  - 市场：第五章市场节点兜底刷出（100%）

### 6. 避雷珠 ⚡
- **克制类型**：雷系攻击/麻痹/雷音
- **应用场景**：
  - 车迟国虎力大仙召雷部（攻击带麻痹效果）
  - 小雷音寺黄眉怪"金铙雷音阵"（钟磬雷音震碎心神）
  - 狮驼岭大鹏阴阳二气瓶"天雷淬瓶"（雷火齐发）
- **战斗作用**：使用避雷珠可免疫雷系伤害/麻痹效果，降低战斗难度
- **来源**：
  - 劫难节点：第28难（车迟国前）宝物节点三选一，必有避雷珠
  - 宝库：第四章宝库节点
  - 市场：第四章市场节点兜底刷出（100%）

## 二、平顶山（第24难）宝物三选一系统 🎁

**夺路线可选宝物三选一**，选完后其他两件进入法宝池，可在宝库及市场获得。

### 1. 芭蕉扇 🌴
- **克制对象**：青牛精的金刚琢
- **战斗作用**：金刚琢能收一切兵器，但收不了芭蕉扇；使用芭蕉扇可扇飞金刚琢，降低战斗难度
- **升级/合并路径**：
  - 芭蕉扇（平顶山获得）
  - ↓ 与铁扇公主的芭蕉扇合并
  - **阴阳芭蕉扇**（可扇风可扇火，全属性攻击）
- **原著依据**：原著中太上老君就是用芭蕉扇收了金刚琢

### 2. 羊脂玉净瓶 🏺
- **法宝类型**：辅助型法宝
- **战斗作用**：可装人/救人/攻击，多功能辅助法宝
- **升级/合并路径**：
  - 羊脂玉净瓶（平顶山获得）
  - ↓ 与观音的玉净瓶合并
  - **观音净瓶**（可救人可攻击）
  - ↓ 与大鹏的阴阳二气瓶合并
  - **三才净瓶**（可装天可装地，终极辅助法宝）
- **原著依据**：羊脂玉净瓶是太上老君的法宝，观音的玉净瓶是观音的法宝，阴阳二气瓶是大鹏的法宝

### 3. 幌金绳 🪢
- **克制对象**：牛魔王
- **战斗作用**：使用幌金绳可捆住牛魔王，限制其变化和移动，降低战斗难度
- **原著依据**：原著中幌金绳是太上老君的腰带，用来捆妖怪

## 四、法宝联动设计（核心亮点）🔗

### 1. 小雷音寺（第57-58难）：避雷珠+定魂珠双开
- **黄眉怪**放"金铙雷音阵"
- **不用避雷珠**：唐僧会被钟磬雷音震碎心神
- **避雷珠+定魂珠双开**：才能站桩念经，破解金铙雷音阵
- **设计逻辑**：避雷珠扛物理雷音，定魂珠扛精神冲击，双珠合璧才能破阵

### 2. 狮驼岭（第62-64难）：避火珠+避雷珠双开
- **大鹏**"扶摇九万里+阴阳二气瓶"
- **瓶中改版**：本来火烧蛇咬，改版加"天雷淬瓶"→**雷火齐发**
- **避火珠扛火，避雷珠扛雷**，缺一个就残血
- **设计逻辑**：阴阳二气瓶是终极法宝，需要双珠合璧才能扛住

### 3. 车迟国（第28-31难）：避雷珠单开
- **虎力大仙**召雷部，攻击带**麻痹效果**
- **避雷珠**：免疫麻痹效果
- **设计逻辑**：避雷珠的基础应用，单珠即可应对

### 4. 蝎子精（第40-41难）：避毒珠单开
- **蝎子精**倒马毒桩，带**毒系伤害**
- **避毒珠**：免疫毒系伤害
- **设计逻辑**：避毒珠的基础应用，单珠即可应对（取消鸡鸣鼓）

### 5. 女儿国/四圣试禅心：定魂珠单开
- **妖怪勾引唐僧**，带**精神魅惑**
- **定魂珠**：稳定心神，不受魅惑
- **设计逻辑**：定魂珠的基础应用，单珠即可应对

## 七、法宝钩子三来源规则 📌

所有影响战斗的特殊法宝都要有三个钩子作为获得来源：
1. **劫难中的节点**：在对应章节的宝物节点或缘选项中获得
2. **宝库**：在对应章节的宝库节点获得
3. **市场**：在对应章节的市场节点兜底刷出（100%）

从而让玩家一定能获取到，至于是否选择使用是玩家的自由。

## 八、战斗难度分级体系 ⚔️

战斗难度依次降低：
1. **夺（难度1）**：夺取Boss的法宝/装备，难度最大
2. **逆（难度2）**：纯实力击败Boss，收为逆道随从，难度第二
3. **针对性法宝（难度3）**：使用法宝钩子降低战斗难度，难度第三
4. **请菩萨搬救兵（难度4）**：请神仙帮忙，尊重原著，难度最低

## 九、设计说明 📝

### 设计亮点
1. **法宝联动**：小雷音寺需要避雷珠+定魂珠双开，狮驼岭需要避火珠+避雷珠双开，不是单一克制
2. **难度递进**：低难度劫难单珠即可，高难度劫难需要双珠合璧
3. **原著依据**：所有法宝都有原著依据，不突兀
4. **升级深度**：法宝有升级/合并链，有收集价值
5. **袈裟系统**：六颗宝石集齐可升级唐僧袈裟，有长期目标

### 设计原则
1. 每个法宝都有原著依据，不能凭空捏造
2. 法宝可以跨章节使用，形成联动
3. 每个法宝都有三个来源（劫难节点、宝库、市场）
4. 高难度劫难需要组合使用法宝，不是单一克制
5. 法宝有升级/合并系统，有收集价值
