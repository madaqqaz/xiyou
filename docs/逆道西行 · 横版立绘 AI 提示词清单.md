# 逆道西行 · 横版立绘 AI 提示词清单

> 版本：V2 · 2026-08-26 · 横版适配版
> 变更：游戏改为横版布局，所有立绘从竖屏正面构图改为横版侧视构图，角色面向右方（行进方向）
> 用途：照此表即可在即梦AI/可灵AI（中文）或 SD/MJ（英文）批量生成全部立绘
> 风格：暗墨·佛光（水墨 + 佛光高光 + 经文金字）

## 一、通用规格与风格底座（横版适配）

### 1.1 横版规格变更

| 类别 | 旧版（竖屏） | 新版（横版） |
|------|-------------|-------------|
| 英雄立绘 | 透明PNG 720×960(半身) | 透明PNG 960×720(半身·侧视) |
| 英雄头像 | 256×256 裁切 | 256×256 裁切（不变） |
| 妖怪/小怪 | 透明PNG 480×640(半身) | 透明PNG 640×480(半身·侧视) |
| Boss立绘 | 透明PNG 900×1200(全身) | 透明PNG 1200×900(全身·侧视) |
| 灵兽立绘 | 透明PNG 512×512(站姿) | 透明PNG 640×512(侧视站姿) |
| NPC立绘 | 透明PNG 720×960(半身) | 透明PNG 960×720(半身·侧视) |
| 换肤变体 | 基于本体PNG配色/法器叠加 | 不变（基于横版本体PNG叠加） |

**横版构图要点：**
- 角色统一 **面向右方**（行进方向），侧视或3/4侧面
- 构图偏左放置，右侧留出前景/氛围空间
- 动势从左向右，配合横版卷轴阅读方向
- 透明底PNG，便于 `background-image` + 外框裁切

## 八、落地须知

### 8.1 生成流程

1. **Lora训练**：每个角色20-30张训练素材，角色一致性核心
2. **基础图生成**：按提示词生成凡器(q0)版本作为本体PNG
3. **品质差分**：灵兽在凡器基础上叠加品质光效（灵器微光/宝器强光）
4. **进化派生**：灵兽进化形态在基础本体PNG上做配色/光效叠加，不重绘
5. **横版裁切**：生成后统一裁切为横版尺寸（960×720/640×480/1200×900/640×512/960×720）

### 8.2 横版适配要点

- **构图统一**：所有角色面向右方（行进方向），侧视或3/4侧面
- **偏左放置**：角色偏左1/3处，右侧留出前景/氛围空间
- **透明底PNG**：便于CSS `background-image` + 外框裁切
- **反向提示词必加**：`front-facing, facing left, vertical composition` 防止竖版正面构图

### 8.3 灵兽换肤派生流程

1. 生成基础灵兽凡器版PNG（横版640×512）
2. 灵器版：在本体上叠加"微光流转+配色提纯"光效层
3. 宝器版：在本体上叠加"强光溢出+金紫光晕"光效层
4. 进化形态：配色替换+光效叠加+体型微调（不重绘）

### 8.4 NPC事件关联

| NPC | 事件ID | 事件效果 |
|-----|--------|---------|
| 龙王·敖广 | longwang_evolve | 小黑龙三分支进化（水/火/光） |
| 菩提祖师 | puti_dianhua | 灵宠品质提升（凡→灵→宝） |
| 观音菩萨 | guanyin_dianhua | 品质提升+回血 |
