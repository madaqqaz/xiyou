# 《逆道西行》五英雄养成总表 · 按英雄调数值用

> **版本**：v1.7（2026-09-20）
> **这份文档解决什么**：《81难骨架·攻略总表》按**章节**排（便于逐章写正文），但**调数值 / 调掉落时按章翻很痛苦**。本表**按英雄重排**——每个英雄一节：转职要什么、在第几章第几难、怎么出现、现在缺什么。**要调某个英雄，只看他那一节就行。**
> **真源关系**：本表是**索引**，不新增设计。结构以《81难骨架·攻略总表 **v1.19**》为准；配件 / 转职以《装备与转职体系·总纲 **v5.13**》《取经人四件套 **v5.6**》《四英雄本命装备 **v5.8**》《特殊装备系统·开发文档 **v1.4**》《Boss 与精英怪物设定总纲 **v1.11**》为准。若与骨架冲突，**以骨架为准**。
> **维护约定**：改结构 → 先改骨架，再回填本表。本表只做映射，不独立定稿。

---

## 〇、怎么用（30 秒）

1. 想调某英雄的转职节奏 → 直接翻他那一节，看「转职一览」+「配件清单」两张表。
2. 想知道某配件第几难拿、怎么拿 → 看该英雄表格的「章 / 难 / 走哪道 / 怎么出现」四列。
3. 只想看「哪里有坑」→ 每节末尾的「⚠ 缺口」+ 文末 **§七 缺口总清单**。

> **核心机制一句话**：**道 = 入口**。每个配件都挂在某一难的某个**六道选项**上；**该难若没有这道选项，配件就拿不到**——这就是转职卡点的成因。
