## 0. 一句话总纲

装备来源按「六道归属」分四线保障 + 三条通用掉落规则；六道只对**节点刷新权重**做温和偏置（是倾向，不是强制），隐道额外拥有「多宝箱路径」并在躲避未战时获补偿宝箱；金钱装备拆为两套——盘缠（打怪掉金）服务战/夺，巡游（爬节点生金）服务渡/缘/逆/隐。

---

## 1. 四线保障（按六道归属的来源保证）

| 六道 | 保障来源 | 说明 |
|---|---|---|
| 战 / 夺 | 精英节点必掉装备 | 战斗向收益最高，开打精英胜后必得 drop + 高额三选一 |
| 缘 | 事件节点偏置提高，事件必给 | 事件含装备 / 材料 / 随从，缘道事件权重 ×1.8 |
| 隐 | 宝箱偏置最高 | 每章隐道多出「比其他道多 2 个宝箱」的路径（地图生成期权重放大），玩家自由选；隐共鸣宝箱 |
| 渡 / 逆 | 寺庙（休 / 事件）偏置最高 | 续航与心魔线，休整回寿 + 事件权重升 |

---

## 2. 通用掉落规则（覆盖所有道，三条）

- **A · 精英必掉**：`elite` 节点固定掉落 1 件装备（入包 / 三选一），降低随机性焦虑。
- **B · Boss 必掉**：每章关隘 Boss 必掉保底金 / 红名器 + 重金（类杀戮尖塔宝箱）。
- **C · 小怪随机材料**：`mob` 节点随机掉材料，**不保底装备**，压制普通战斗的装备膨胀（普通战斗偏多问题的主要解法之一）。
- 战斗奖励优于选项夺宝：战 / 夺开打精英胜后必得 drop + 高额三选一，夺宝战走独立 `duo` 路径。

## 3. 六道节点偏置表（`NDX.DAO_NODE_BIAS`，`js/data_map.js`）

权重为温和乘子：`preferred ≈ ×1.8`，其余保持 `×1`，最低 `×0.8`。`_expandBias` 按玩家当前主导六道（`mostDaoOf`）展开基础池；无道时退回原池。

| 道 | mob | elite | event | trial | rest | shop | treasure |
|---|---|---|---|---|---|---|---|
| 战 | 0.8 | **1.8** | 0.9 | 1 | 0.9 | 0.9 | 0.9 |
| 夺 | 0.8 | **1.8** | 0.9 | 1 | 0.9 | 0.9 | 1.2 |
| 缘 | 0.8 | 0.9 | **1.8** | 1 | 1 | 1 | 0.9 |
| 隐 | 0.8 | 0.9 | 1 | 1 | 1 | 0.8 | **1.8** |
| 渡 | 0.8 | 0.9 | 1.2 | 1 | **1.6** | 0.9 | 1 |
| 逆 | **1.1** | 1 | 1.2 | 1 | **1.6** | 0.9 | 1 |

说明：
- 偏置是**倾向不是强制**；隐的「+2 宝箱路径」是地图生成期的权重放大，玩家可不选（自由）。
- `mob` 全道下调（0.8~1.1），是「普通战斗偏多」的结构性修正（配合 V9.26 侧池 mob 权重 4→2）。
- `trial` 恒定 1：劫难数量由章节结构决定，不随道漂移。

## 4. 2 级差异（六道路线倾向定调，V9.26）

差异是「路线倾向」，不锁死玩家跨道选节点。

| 道 | 倾向 | 机制落点 |
|---|---|---|
| 渡 | 恢复 / 续航 | 寺庙休整回寿；事件续航；属性奖励每选渡 ×1.12（`sustain` 倍率） |
| 逆 | 心魔 | 心魔增长线；明镜套 tier3 心魔 −15%（唯一减幅来源） |
| 战 | 装备 | 精英必掉；破军套攻击爆发（`atkPct` / `cri`） |
| 夺 | 夺宝 | 夺宝战；饕餮套掠夺（`atkPct` / `cri`）；宝箱略升（treasure ×1.2） |
| 缘 | 事件 | 事件偏置 ×1.8；贪狼套攻血双修 |
| 隐 | 宝箱 | 宝箱偏置 ×1.8；影遁套闪避；躲避未战补偿宝箱（见 §5） |

## 5. 隐道安慰机制（躲避未战 → 补偿宝箱，V9.26）

- **触发**：隐道在车迟国等「躲避 / 避战」抉择，导致劫难未战斗时。
- **效果**：
  1. `s.flags._hiddenAvoidTreasure` +1（计数 / 可展示）；
  2. 即时 `+（40 + 层 ×10）` 金；
  3. 赠 1 次开箱机会：`NDX.rollEquips(1, s)` 装备单选（`s.pending = { kind: 'equip', items, title: '隐道·躲避生金（补偿宝箱）' }`）。
- **落点**：`js/game/game_event_2.js` 车迟国「隐」分支。
- **复用约定**：其他「躲避 / 规避」路径若致劫难未战，须复用同逻辑（增 `_hiddenAvoidTreasure` 并发宝箱），保持隐道战力缺失有统一补偿口径。

## 6. 经济套（金钱装备，两套）

> 「钱套 ≡ 盘缠套」：金钱装备的总类叫盘缠；它落地为两种设计——盘缠（打怪掉金）与巡游（爬节点生金）。两者均跨道、不绑定单一六道。

### 6.1 盘缠（打怪额外掉金，服务 战 / 夺）
- 共鸣（`SET_RESONANCE.盘缠`）：tier2 `goldPct 0.15` + `shopDiscount 0.10`；tier3 `goldPct 0.30` + `shopDiscount 0.20` + `hpPct 0.10`。
- 槽位：武器 / 甲 / 宝（法宝）三槽 × 初 / 中 / 高。**法宝槽不计入共鸣**（共鸣只数 武器/甲/头/靴），故盘缠上限 tier2。
- 章节：ch1-8，其中 **ch5-8 为 V9.26 回填**（梵音 / 罗刹 / 狮驼 / 灵霄商路）。
- 获取：坊市购（`cost` 字段，按章解锁）。

### 6.2 巡游（爬节点额外生金，服务 渡 / 缘 / 逆 / 隐）
- 共鸣（`SET_RESONANCE.巡游`）：tier2 `nodeGold 18`；tier3 `nodeGold 45` + `hpPct 0.06`。
- 槽位：武器 / 甲 / 头 三槽 × 初 / 中 / 高（达 tier3 需 武器+甲+头 三件）。
- 章节：ch1-8（行脚 / 驿路 / 商队 / 使节 / 浮屠 / 流沙 / 魔域 / 天阙）。
- 获取：坊市购（`cost`）。
- **发放**：进入任意节点时，`enterNode` 读 `NDX.equipEconFlags(s).nodeGold` 累加入 `s.gold`（日志「巡游·爬节点生金」）。

### 6.3 注册
- `NDX.SET_SYS`：盘缠 / 巡游 均 `'ti'`（默认物理体系）。
- `NDX.SET_DAO`：盘缠 / 巡游 均 `null`（经济套跨道，不绑定单一六道）。

## 8. 待拍板 / 未决

1. **单节点 15 天 / 每章 20 节点**：用户提议「每章 30→20 节点、单节点 12→15 天」。实机 `ACT_RANGES.layers = 10/5/7/6/5/5/10/8/6`（共 62，非 20）；且 `RIDE_DAYS 12→15` 会破坏 `_verify_life_days.js` 门禁——B7（73 节点 = 3.6~4.2 年）会因 73×~27 天 ≈ 5.5 年超界，B7b（单节点 18~22 天）会因 elite = 15+8 = 23 > 22 失败。**已用「降战斗比 + 六道偏置」实现「少战斗」体验，未改字面数值**；若要正式改 15 天，须协同调 B7 / B7b 门禁区间（或先缩节点数，但 act1 受 `MAP_PLAN_CH1` 长度绑定，须一并改 `FIXED_EVENT_LAYERS` / `FIXED_EVENT_TRIALS`）。
2. **隐躲避补偿覆盖范围**：目前仅在车迟国「隐」分支落地；`zhuanjie.js` 等其他躲避 / 规避钩子待接同逻辑。
3. **盘缠上限 tier2**：因法宝槽不计入共鸣，盘缠共鸣封顶 tier2；若希望盘缠也到 tier3，须改槽位方案（如宝→头），待拍板。
