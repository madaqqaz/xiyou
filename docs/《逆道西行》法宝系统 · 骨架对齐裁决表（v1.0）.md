## 一、骨架真源：法宝是什么

骨架对法宝的定义**只有三句话**，全部落在 §〇 与逐难正文里，没有任何独立机制章节：

| 骨架出处 | 原文 | 语义 |
|---|---|---|
| §〇 规则 3 | **夺 → 物（法宝、剥材）** | 法宝是**【夺】道的专属产出签名**，与「战→料（装备）」并列且互斥 |
| 附录 A4 | **特殊装备线（独立于四件套与本命 6，并行不冲突）** | 法宝分两级：**普通法宝**（夺道掉落）／**独立特殊法宝**（三生红绳葫芦；飞龙宝杖等独立特殊装备） |
| v1.19 修订 ⑤ | **避火珠 / 定魂珠＝配件 ＋ 法宝双用**（可单独祭出，**拥有即计入升级、不消耗、不消失**） | **法宝不消耗**；法宝与配件**同物双用** |

**据此可推出的骨架法宝四要素**（全部有据，非推断）：

1. **获取**：只从【夺】选项产出（少数例外：A4 特殊装备、宝库 / 市场 / 集市兜底补齐、合成）。
2. **效果形态**：**主动改战斗规则**——「使敌怀胎 3 回合·攻击 −50%」「困敌全体·无法行动 3 回合」「致盲全体 3 回合」「一扇熄火·二扇生风·三扇下雨」。**不是**普攻概率触发。
3. **不消耗**：无充能、无次数、无「用一次少一次」。
4. **钩子属性**：特定法宝**克制特定 Boss**（定风珠破黄风怪吹沙、芭蕉扇克金刚琢），且**法宝钩子≠法宝本体**（钩子是跨难匹配关系，不是另一件道具）。

## 八、`treasure:` 字段归一方案（结构建议）

**问题**：`trials_chX.js` 的 `treasure:` 字段混装法宝／配件／装备三类物。

**建议改法（不删数据，只加归类字段）**：

```js
// 现状
effect: { alignGood: 8, treasure: 'tre_canghailongwen' }
// 建议：按骨架语义分字段
effect: { alignGood: 8, drop: { kind: 'accessory', id: 'acc_canghailongwen' } }  // 僧冠②
```

| 字段 | 收什么 | 消费端 |
|---|---|---|
| `drop.kind = 'treasure'` | 普通法宝（骨架 2.1 名录） | 法宝字典 `NDX.TREASURES` |
| `drop.kind = 'special'` | 独立特殊法宝 / 特殊装备（A4） | 特殊装备链 |
| `drop.kind = 'accessory'` | 唐僧四件套配件（六珠/六赐/六纤/六舍利） | 配件系统 |
| `drop.kind = 'equip'` | 普通装备（战→料） | 装备池 |

> **`treasure:` 旧字段保留一个过渡期**（读取端兼容），确认无遗漏后再下线。
