# 《逆道西行》Boss动画设计总纲

## 一、统一规范

| 项目 | 规范 |
|------|------|
| 分辨率 | **1024×1024**（手机横屏游戏，兼顾清晰度与体积） |
| 背景 | 纯透明（PNG格式，方便游戏引擎叠加） |
| 朝向 | **全部面朝右**（我方在左、敌在右；朝左用代码水平翻转，零美术成本） |
| 画风 | **水墨暗黑国风**（焦墨厚涂写意），低饱和黑白灰主色调 + 角色专属点缀色（鎏金/朱砂/暗紫） |
| 风格参考 | 刘洪、银角将军、黄风怪（金色盔甲版）已确立的统一画风 |
| 输出格式 | 透明PNG序列帧 + GIF预览 |

## 二、标准动作集（每形态25帧）

| 动作 | 帧数 | 播放速度 | 循环 | 说明 |
|------|------|----------|------|------|
| 待机 | 4帧 | 300ms/帧 | 循环 | 呼吸微动，战袍/毛发轻微飘动 |
| 攻击 | 6帧 | 150ms/帧 | 播完回待机 | 蓄力→前冲/挥砍→命中→收势 |
| 施法 | 6帧 | 200ms/帧 | 播完回待机 | 按Boss特性设计专属施法动作 |
| 受击 | 3帧 | 150ms/帧 | 播完回待机 | 后仰→颤抖→恢复（代码加闪白） |
| 死亡 | 6帧 | 400ms/帧 | 停在最后一帧 | 虚弱→跪倒→倒地→静止 |

**合计：25帧/形态**

## 三、形态分类与美术消耗

| 形态类型 | 帧数 | 说明 | 代表Boss |
|----------|------|------|----------|
| 单形态（纯妖） | 25帧 | 只有妖怪本体 | 青牛精、大鹏、黄眉 |
| 双形态（人+妖） | 50帧 | 人形态25帧 + 妖形态25帧 | 黄袍怪、牛魔王、铁扇公主、白鼠精、玉兔精、**金角银角** |
| 三阶段（人→妖→终极） | 50帧+粒子层 | 一、二阶段各25帧，三阶段叠加粒子 | 黄风怪、红孩儿、牛魔王 |
| 白骨精特殊 | 75帧+粒子 | 少女25+老妪25+老翁25+白骨夫人额外施法 | 白骨精 |
| **双Boss同屏** | **共享框架** | **金角银角造型一致，仅颜色/法宝不同，动作框架共享** | **金角银角** |

## 四、三段变身优化策略（核心省量方案）

### 原则
**一、二阶段重做形象与动作，三阶段不重做人物动作，只叠加粒子特效层。**

```
一阶段（人/基础妖形态）→ 完整25帧动作
二阶段（妖/强化形态）  → 完整25帧动作（形象变化大，必须重做）
三阶段（终极形态）     → 二阶段动作帧 + 粒子特效层叠加（5-8帧循环粒子）
                       + 代码实现全身泛光/变色/体型增大（零美术成本）
```

### 各Boss三阶段粒子设计

| Boss | 三阶段名称 | 粒子效果 | 代码层效果 |
|------|-----------|----------|-----------|
| 黄风怪 | 黄沙护身 | 黄色沙尘漩涡环绕全身 | 全身泛金光、移动带沙尘拖尾 |
| 红孩儿 | 三昧真火护体 | 火焰粒子环绕+头发火焰化 | 全身泛红、攻击带火焰特效 |
| 牛魔王 | 牛魔暴走 | 黑气环绕+眼睛红光 | 体型增大15%（代码缩放）、攻击带黑气 |
| 白骨夫人 | 幽蓝鬼火 | 蓝白色鬼火粒子环绕 | 骨骼泛幽蓝光、移动带鬼火拖尾 |

### 优势
- 三阶段节省约**70%**美术工作量
- 粒子层为独立透明PNG序列帧，可叠加到任意动作帧上
- 粒子层可跨Boss复用（如黑气、火焰等通用粒子）

## 五、施法动作分类设计

按Boss的技能特性分为7类施法动作，每类有固定的6帧流程：

| 施法类型 | 6帧流程 | 代表Boss |
|----------|---------|----------|
| **风系** | 深吸气→鼓腮→吹出狂风→风势最盛→风渐弱→收势 | 黄风怪、铁扇公主、大鹏 |
| **火系** | 双手聚火→火焰成型→向前推出→火焰爆炸→火渐弱→收势 | 红孩儿、牛魔王 |
| **水系** | 双手控水→水龙成型→向前放出→水花四溅→水渐弱→收势 | 灵感大王、九头虫 |
| **雷系** | 举天引雷→雷电汇聚→向下劈出→雷光炸裂→光渐弱→收势 | 虎力大仙、大鹏 |
| **毒系** | 口吐毒雾→毒雾扩散→毒雾笼罩→毒最盛→雾渐散→收势 | 蜘蛛精、蝎子精、百眼魔君 |
| **法宝系** | 祭出法宝→法宝升空→法宝发光→法宝攻击→法宝回收→收势 | 金角银角、青牛精、黄眉 |
| **法术系** | 双手合十→念经→法术成型→向前放出→光渐弱→收势 | 黄袍怪、黄眉老佛、九灵元圣 |

## 七、省量优化方案

1. **人形态动作共享**：同Boss多个人形态（如白骨精少女/老妪/老翁）的待机、受击、死亡可共享动作框架，只重做攻击+施法
2. **粒子层独立化**：所有三阶段粒子做成独立透明PNG序列，可复用到多个Boss
3. **代码层效果**：三阶段的泛光、变色、体型增大全部代码实现，不占美术资源
4. **死亡帧复用**：同形态不同阶段的死亡帧可共用（三阶段死亡=二阶段死亡+粒子消散）
5. **批量缩放**：已有2048帧批量缩放到1024，不影响画质，体积降为1/4

## 九、金角银角专门设计规范

### 9.1 核心省量原则
**金角银角造型完全一致，仅颜色（金/银）和法宝不同，动作框架100%共享。**

| 项目 | 金角 | 银角 | 共享方式 |
|------|------|------|----------|
| 人形态 | 金色道童 | 银色道童 | 造型共享，改色 |
| 妖形态 | 金色狐头妖王 | 银色狐头妖王 | 造型共享，改色 |
| 待机/受击/死亡 | 金色版 | 银色版 | 动作框架共享，改色 |
| 攻击 | 七星剑（金色剑光） | 七星剑（银色剑光） | 动作共享，剑光颜色代码实现 |
| 施法 | 紫金红葫芦 | 羊脂玉净瓶 | 动作框架共享，法宝外观不同 |

### 9.2 人形态（炼丹童子）
- **身份**：太上老君看守金炉/银炉的童子
- **造型**：少年道童，道髻+道袍+云履，胸前挂八卦护符
- **金角**：金色道袍+金色发簪+额间金色火焰印记+紫金红葫芦
- **银角**：银色道袍+银色发簪+额间银色月轮印记+羊脂玉净瓶

### 9.3 妖形态（狐头妖王）
- **血统**：九尾狐血统（原著中九尾狐狸是干娘）
- **造型**：狐头人身+金属盔甲+九条尾巴+兽爪手脚
- **金角**：金色盔甲+金色眼睛+金色烟雾+紫金红葫芦
- **银角**：银色盔甲+银色眼睛+银色烟雾+羊脂玉净瓶

### 9.4 法宝系施法6帧流程
```
祭出法宝 → 法宝升空 → 法宝发光 → 喊名收人 → 法宝回收 → 收势
```
- **金角**：紫金红葫芦，暗红色葫芦身+金色符文，金色吸力
- **银角**：羊脂玉净瓶，白色玉瓶+银色符文，银色寒气
- **喊名字幕**：代码实现，"我叫你一声你敢答应吗"

### 9.5 第三形态（代码实现，不额外出图）
- **名称**：九尾全开
- **触发**：血量低于30%时自动触发
- **表现**：九条尾巴全部展开+全身泛光（代码colorMatrix）+攻击速度+30%
- **不额外出图**：复用妖形态动作帧，代码叠加特效

## 十、双Boss同屏布局规范

### 10.1 布局
```
          玩家（左侧）
              |
    ┌─────────┴─────────┐
    |                   |
  银角（左）         金角（右）
```

### 10.2 动作协调
- **待机**：两人动作帧错开，避免同步僵硬
- **攻击**：轮流攻击，一人攻击时另一人待机
- **施法**：可同时施法（双法宝齐出），也可轮流
- **受击**：各自独立受击
- **死亡**：一人先死，另一人进入狂暴状态

### 10.3 狂暴状态（代码实现）
- 一人死亡后，另一人进入狂暴
- 表现：全身泛红光+攻击速度+50%+施法速度+30%
- 不额外出图，复用现有动作帧
