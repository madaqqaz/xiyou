## 〇、为什么作废「炼化」（旧 v1.0 的病灶）

| 项 | 旧 v1.0 | 判定 |
|---|---|---|
| 用词 | 「炼化」「饲料」「吞并」 | ❌ 炼丹 / 炼器口吻，**不是西游语汇**。西游里妖怪被收服叫**点化 / 收服 / 皈依 / 度脱** |
| 机制 | 同阶 2 名 → 主体升阶，饲料消散（**纯材料堆叠**） | ❌ 与《冒险日记》的合成精神相反 —— 冒险日记强调「**合成需特定条件**（神殿 / 强化大师 / 善恶值门槛 / 特定地点）」，不是无脑堆数量 |
| 玩法导向 | 鼓励「多收」，玩家凑数量 | ❌ 无配装目标，与「路线 = 装备 + 劫印 + 经文」的核心模型脱节 |
| 数值 | ×1.0 / ×1.8 / ×2.5 | ✅ **保留**（平衡已验证，本版不动） |

## 一、新体系：点化三阶

### 1.1 三阶（命名回归西游）

| 阶 | 名 | 助战倍率 | 语义 |
|---|---|---|---|
| 一 | **本相** | ×1.0 | 谈判收服时的妖形 |
| 二 | **显形** | ×1.8 | 受点化而脱尽妖气，显化人形 |
| 三 | **证道** | ×2.5 | 立誓皈依、愿力凝身（并开羁绊技） |

> 内部 key 沿用 `fan / ling / zhen`（存档兼容，不改字段名，避免存量存档迁移）。

### 1.2 两条晋升路径（对标《冒险日记》合成的四条特征）

| 《冒险日记》特征 | 本作落地 |
|---|---|
| **合成需特定条件**（神殿挑战 / 遇强化大师） | **机缘**：满足该妖王专属条件才升阶 |
| **合成需善恶门槛**（圣光之龙需 80 善） | 机缘条件含 `good` / `evil` 门槛 |
| **多件组合**（孤狼＋多蓝剑 = 持剑苍狼） | 机缘条件含 `with`（羁绊同行） |
| **合成区＝背包区，可互相吞并** | **渡引**：献上一名同阶随从为引（保底出口） |

| 路径 | 消耗 | 适用 |
|---|---|---|
| **机缘**（主） | **不消耗任何随从**，原地升阶 | 条件达成时（首选） |
| **渡引**（兜底） | 献上 1 名同阶随从 | 条件未达成时的收敛出口 |

**关键差别**：升阶靠「**你做了什么、带了什么**」，而不是「**你收了多少**」。
⇒ 收服行为第一次有了目标；配装、善恶取舍、羁绊搭配第一次与随从系统挂钩。

## 二、机缘条件（数据真源 `NDX.FOLLOWER_RITUALS`）

### 2.1 条件类型（全部确定性可判定，无随机）

| type | 判定 | 读哪 |
|---|---|---|
| `item` | 持有 / 装配该法宝（id 或 name） | `s.equips` |
| `seal` | 拥有该劫印 | `s.seals` |
| `good` | 本局累计善 ≥ n | `s.good` |
| `evil` | 本局累计恶 ≥ n | `s.evil` |
| `with` | 指定随从在册（羁绊） | `s.followers` |
| `act` | 当前地区 `s.act` ≥ min | `s.act` |

- 单个 step 内 `conds` 为**多取一**：任一条达成 ⇒ 该步可走。
- 走机缘时**附带的条件不用管**，只看当前阶对应的那一步（本相查 `toLing`，显形查 `toZhen`）。

## 五、证道阶羁绊技（A2-2 · 用户拍板「其他同意」）

> 三阶到此为止只是「助战 ×2.5 的倍率」——倍率再高也只是放大同一个自己。
> 证道阶再给**一件「技」**：只在**上阵**时生效，本相/显形不给（那是量变，不是质变）。

**真源 `NDX.FOLLOWER_BONDS`（12 名妖王一一对应，无遗漏）**

| 随从 | 羁绊技 | 效果 | 随从 | 羁绊技 | 效果 |
|---|---|---|---|---|---|
| 黄风大圣 | 三昧神风 | atk+18 dr+0.03 | 牛魔王 | 大力撼山 | atk+28 hp+180 |
| 白骨夫人 | 白骨归寂 | matk+22 mdef+0.04 | 九头虫 | 九头噬敌 | matk+26 dr+0.02 |
| 红孩儿 | 三昧真火 | atk+20 dr+0.02 | 大鹏金翅雕 | 云程万里 | atk+26 hp+120 |
| 灵感大王 | 鱼篮普渡 | hp+160 dr+0.03 | 玉兔精 | 月华捣药 | matk+28 mdef+0.04 |
| 蝎子精 | 倒马毒桩 | atk+24 hp+60 | 青牛精 | 金刚琢护主 | dr+0.06 hp+140 |
| 六耳猕猴 | 混世听心 | atk+16 mdef+0.04 | 黄袍怪 | 奎木狼星力 | atk+22 matk+14 |

- **接线纪律**：字段口径与 `NDX.FOLLOWERS` 助战平铺完全一致（atk/matk/hp/dr/mdef），
  走**既有 `computeStats` 通道**，**不新开战斗接线**（避免第二真源）。消费口 `combat_part1.js` 的 `bonus.followerBonds`。
- **零副作用**：无证道随从 ⇒ `followerBondMods()` 全 0；待命随从不产技（`activeFollowerBonds` 读上阵口径 `companionFollowerIds`）。
- 数值取助战基线的 1.2~1.6 倍 —— 证道本已 ×2.5，羁绊技补的是「质变」，不是第三次放大。

## 六、宠物格改流派驱动（A2-3 · 用户拍板「其他同意」）

`NDX.petSlotCapOf(s)` 开头加**流派口**：

```
当前路线 = summon（召唤流） ⇒ 直接给满 6 格（PET_SLOT_SUMMONER）
```

- 与英雄底色模型统一：**路线 = 玩家的选择**，配出召唤流就配得起召唤流，不再看隐藏职。
- 副作用可控：非召唤流**零变化**（仍走 `petSlotCapFor` 原判定）；召唤流本就该有 6 格
  （此前只有转职成隐藏职才给，等于「流派对但不给格」）。
