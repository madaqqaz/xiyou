# 《逆道西行》技能精研系统设计（阶段③ · v0.9 草案）

> 2026-09-26。上游：审计报告 §八（用户裁决 B＝按新设计重建技能构筑轴）。
> 方法论：game-numeric-design（五特性模型 + 幂函数成长曲线）。
> **本稿只定设计与数值，代码未动。** 拍板后进实装队列。

## 〇 · 一句话定位

**技能精研＝第 5 条技能成长轴：玩家对自己最顺手的 2 个技能做纵向深化（Lv0→Lv5），消耗通用材料，Lv5 时该技能主数值 +40%。**

与既有四轴的错位（不重复、不越位）：

| 轴 | 改变什么 | 精研不碰 |
|---|---|---|
| 六道 | 路线选择（横向） | 不改路线收益 |
| 经文 | BD 绑定（流派面） | 不给新流派 |
| 转职 | 形态变化（链上叠加） | 不动职阶 |
| 宠物 | 场域改写（Field） | 不进场域层 |
| **精研（本系统）** | **单个技能的纵向数值 + 轻度分化** | 不改技能机制本体 |

## 一 · 五特性

| 特性 | 设计 |
|---|---|
| 生成 | 通关劫难掉「香火/妖丹」（既有 COMMON_MATS，全章节通用，零新增货币）；技能面板新增「精研」入口 |
| 成长 | Lv0→Lv5 幂函数消耗、线性收益；**每英雄限 2 个技能可精研**（资源聚焦＝构筑决策） |
| 消亡 | 跨周目**不继承**（每周目重练，与转职 JOB_LEGACY 的长线区分开） |
| 变化 | Lv3 二选一分岔：「稳」消耗降档 /「险」收益升档（轻量承载旧 skill_build 的流派分化意图） |
| 联系 | 加成在 `resolveSkillAct` 入口对 act 主数值乘算；战力总评纳入；默认 Lv0 ⇒ 分支不可达 ⇒ **构造性零回归** |

## 二 · 数值表 v1（AI 主导参数，用户终审）

### 2.1 消耗曲线（幂函数 i=1.5 / i=1.3，先易后难）

| 升到 | 香火 `ceil(30×n^1.5)` | 妖丹 `ceil(2×n^1.3)` |
|---|---|---|
| Lv1 | 30 | 2 |
| Lv2 | 85 | 5 |
| Lv3 | 156 | 9 |
| Lv4 | 240 | 12 |
| Lv5 | 336 | 17 |
| **单技能满研合计** | **847** | **45** |

两技能全满 ≈ 1700 香火 / 90 妖丹（每周目目标）。

### 2.2 收益曲线

| 等级 | 技能主数值加成（加算叠乘） | 战力换算 `lv×150` |
|---|---|---|
| Lv0 | +0%（基线） | 0 |
| Lv1 | +8% | 150 |
| Lv2 | +16% | 300 |
| Lv3 | +24% | 450 |
| Lv4 | +32% | 600 |
| Lv5 | +40% | 750 |

- 加成对象＝act 主数值（伤害类 `dmg`、治疗类 `heal`、护盾类 `shield`），**不加成 hits**（多段技能已被 `act.dmg 总量按 hits 分摊` 语义约束，动 hits 会净增强/削弱翻转）。
- 战力量级对齐：eva×800 / blk×1200 / counter×900 ⇒ 精研 750/技能、两技能 1500，处于同量级但不碾压。

### 2.3 Lv3 分岔（二选一，不可回退）

| 分岔 | 效果 | 定位 |
|---|---|---|
| 甲·稳 | Lv4/Lv5 消耗各 -20%（272→？见下） | 资源紧张路线 |
| 乙·险 | Lv5 加成 40%→48%，但 Lv4/Lv5 消耗各 +15% | 极限 BD 路线 |

乙满研合计：847×1.15²≈1120 香火 / 59 妖丹，换 48%。

### 2.4 预算验证（待实测定档）

- 假设 ch1 小怪掉香火 1-2/场、劫难宝箱 2-4/个 ⇒ 单章净得 ≈ 120-180 香火 ⇒ 两技能满研需 **2.5-3 个周目章节奏**，与「周目内 2 技能满研」的目标差一档。**掉率标定在实装时用 `_dump_balance_db` 口径实测，超调先调掉率不动曲线。**
- DPS 验收线：满研后对 81 难同章标准怪的击杀回合数缩短 ≤ 20%（超调即削 8% 档距）。

## 三 · 实装要点（拍板后执行）

1. 数据：`NDX.SKILL_REFINE = { cap:5, cost(n), gain(lv), branchAt:3 }` 单源表；
2. 状态：`s.skillRefine = { skillId: {lv, branch} }`，存档字段走 `data_save` 白名单；
3. 结算：`resolveSkillAct` 入口一处乘算 `1 + gain(lv)`（含乙·险 48%）；
4. UI：技能面板精研行 + 战力面板并入；
5. 门禁：`_verify_skill_refine.js`（消耗曲线复算 / 加成只打主数值 / Lv0 零回归 / 分岔不可回退 / 战力换算）；
6. `?v=` 递增 + 全量回归。
