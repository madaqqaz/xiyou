# 逆道西行 · 系统简化与肉鸽核心回归设计文档

> 版本：V1.0
> 日期：2026-08-28
> 状态：设计方案

## 一、设计概述

### 1.1 核心设计理念

回归肉鸽本质，简化复杂系统，强化"运气+成长"的核心体验：
- **每一个隐藏都要有能通关的能力**，但前提是运气要好，都要与选定的路线相符
- **肉鸽的核心不是游戏问题，不是技术问题，纯粹是运气问题**
- **要有前期的艰难，才能有全拿到想要的爽感**
- **每次死亡都会给玩家些许增强**，这样才能有通关的快感

### 1.2 参考游戏分析

| 游戏 | 通关所需局数 | 死亡增强机制 | 核心体验 |
|------|-------------|-------------|---------|
| 杀戮尖塔 | 10-30局（新手） | 解锁新卡牌/遗物 | 每局Build不同，运气+策略 |
| 万世剑冢 | 15-40局（新手） | 传承装备/属性衰减 | 多周目成长，运气+积累 |
| 冒险日记 | 20-50局（新手） | 装备合成/图鉴解锁 | 装备收集，运气+合成 |
| 不一样西游 | 10-25局（新手） | 天赋解锁/属性成长 | 肉鸽+养成，运气+成长 |

**目标**：《逆道西行》新手通关所需局数控制在 **15-30局**，既有挑战感，又不会劝退。

## 二、经文系统简化方案

### 2.1 设计思路

参考《梦幻西游》的成品装备模式：
- **经文作为独立碎片形式**存在
- **收集碎片合成整本**后自动生效
- **不需要玩家手动装备**，减少学习成本
- **整本经文自动提供属性加成**，类似被动技能

### 2.2 经文获取方式

| 获取方式 | 碎片数量 | 说明 |
|---------|---------|------|
| 打怪掉落 | 1-2碎片/次 | 普通怪掉落1碎片，精英怪掉落2碎片 |
| 事件奖励 | 2-3碎片/次 | 渡道事件奖励2-3碎片 |
| 商店购买 | 1碎片/次 | 花费善缘购买 |
| Boss掉落 | 3-5碎片/次 | 地区Boss掉落3-5碎片 |

### 2.3 经文合成机制

- **每本经文需要10个碎片**合成
- **合成后自动生效**，不需要玩家手动装备
- **同名经文碎片可以叠加**，最多合成3本（每本效果叠加）
- **合成整本后，碎片清零**，开始收集下一本

### 2.4 经文效果示例

| 经文名称 | 道途 | 整本效果 | 第二本叠加 | 第三本叠加 |
|---------|------|---------|-----------|-----------|
| 心经 | 渡 | 法伤+8%，每回合回蓝2% | 法伤+5%，回蓝+1% | 法伤+3%，回蓝+0.5% |
| 法华经 | 渡 | 气血+10%，减伤+3% | 气血+5%，减伤+2% | 气血+3%，减伤+1% |
| 金刚经 | 战 | 物攻+8%，暴击+2% | 物攻+5%，暴击+1% | 物攻+3%，暴击+0.5% |
| 楞严经 | 战 | 物攻+5%，吸血+3% | 物攻+3%，吸血+2% | 物攻+2%，吸血+1% |
| 无量寿经 | 缘 | 气血+15%，每回合回血1% | 气血+8%，回血+0.5% | 气血+5%，回血+0.3% |
| 地藏经 | 夺 | 气血+10%，吸血+5% | 气血+5%，吸血+3% | 气血+3%，吸血+2% |
| 六祖坛经 | 隐 | 闪避+5%，暴击+3% | 闪避+3%，暴击+2% | 闪避+2%，暴击+1% |
| 涅槃经 | 逆 | 物攻+5%，法伤+5%，暴击+2% | 物攻+3%，法伤+3%，暴击+1% | 物攻+2%，法伤+2%，暴击+0.5% |

### 2.5 经文与装备的协同

- **英雄专属装备**：嵌入同道经文，属性加成+50%
- **通用装备**：嵌入任意经文，属性加成+20%
- **混搭装备**：嵌入经文，属性加成+10%

**注意**：简化后经文自动生效，不需要"嵌入"操作，这里的"嵌入"是指逻辑上的协同加成，玩家不需要手动操作。

### 2.6 经文系统简化的优势

1. **减少学习成本**：玩家不需要理解复杂的经文装备系统，只需要收集碎片合成整本
2. **自动生效**：合成整本后自动生效，不需要玩家手动装备
3. **收集感强**：独立碎片形式，有明确的成长目标
4. **类似梦幻西游**：玩家熟悉的模式，容易理解
5. **减少操作负担**：玩家不需要管理经文装备，专注于战斗和路线选择

### 2.7 经文系统简化的劣势

1. **失去策略性**：玩家不能选择装备哪本经文，失去了Build多样性
2. **失去灵活性**：不能根据战斗情况切换经文
3. **可能过于简单**：如果所有经文都是自动生效，可能失去深度
4. **需要平衡**：需要仔细平衡每本经文的效果，避免某些经文过强

## 三、劫印系统简化方案

### 3.1 设计思路

极度简化劫印系统：
- **取消劫印独立装备**，改为纯加成到英雄属性上
- **取消劫印品质**（白/蓝/金/红），所有劫印效果相同
- **玩家只需要看到选了几个渡、几个贪、几个战**
- **激活阈值效果**：激活3个贪，吸血加5%；激活6个战，攻击加10%

### 3.2 劫印获取方式

| 获取方式 | 劫印数量 | 说明 |
|---------|---------|------|
| 劫难抉择 | 1劫印/次 | 每次劫难抉择后获得1个对应道途的劫印 |
| 事件奖励 | 1-2劫印/次 | 特定事件奖励1-2个劫印 |
| Boss掉落 | 2-3劫印/次 | 地区Boss掉落2-3个劫印 |

### 3.3 劫印道途与效果

| 道途 | 激活3个效果 | 激活6个效果 | 激活9个效果 | 激活12个效果 |

### 3.5 劫印系统简化的优势

1. **极度简化**：玩家只需要看到选了几个渡、几个贪、几个战
2. **直观易懂**：激活3个贪，吸血加5%，激活6个战，攻击加10%
3. **减少学习成本**：不需要理解劫印品质、生效格等复杂概念
4. **纯属性加成**：直接加到英雄属性上，不需要管理装备
5. **阈值激励**：3/6/9/12的阈值设计，给玩家明确的成长目标
6. **道途差异化**：每个道途有独特的效果，鼓励玩家专注于1-2个道途

1. **失去策略性**：玩家不能选择生效哪些劫印，失去了Build多样性
2. **失去深度**：取消品质后，劫印的成长感降低
3. **可能过于简单**：如果所有劫印都是纯属性加成，可能失去深度
4. **需要平衡**：需要仔细平衡每个道途的阈值效果，避免某些道途过强

## 四、肉鸽核心机制

### 4.1 运气核心设计

**肉鸽的核心是运气**，但不是纯运气，而是"运气+策略+积累"的平衡：

| 维度 | 占比 | 说明 |
|------|------|------|
| 运气 | 40% | 掉落、事件、地图生成等随机因素 |
| 策略 | 35% | 路线选择、Build搭配、战斗操作等 |
| 积累 | 25% | 死亡增强、解锁内容、经文拓印等 |

### 4.2 每局体验差异化

确保每局游戏都有不同体验：
- **地图生成**：节点位置、类型、连接随机
- **掉落随机**：装备、经文碎片、劫印掉落随机
- **事件随机**：事件池随机抽取
- **敌人随机**：敌人组合、技能随机
- **Boss随机**：Boss技能、阶段随机

### 4.3 隐藏Build通关能力

**每一个隐藏都要有能通关的能力**，但前提是：
1. **运气要好**：拿到合适的装备、经文、劫印
2. **与选定的路线相符**：Build与道途、转职匹配
3. **玩家操作到位**：战斗操作、路线选择合理

**设计原则**：
- 没有绝对废的Build，只有不适合的玩法
- 每个Build都有通关的可能性，但难度不同
- 运气好时，弱势Build也能通关；运气差时，强势Build也可能翻车

## 五、死亡增强系统

### 5.1 设计思路

每次死亡都会给玩家些许增强，让玩家有进步感，但不会破坏肉鸽平衡：
- **增强幅度小**：每次死亡增强5-10%，不会让下一局直接通关
- **累积生效**：多次死亡后，增强效果叠加，逐渐降低通关难度
- **有上限**：增强效果有上限，避免无限成长破坏平衡
- **可重置**：玩家可以选择重置增强，挑战纯肉鸽模式

### 5.2 死亡增强内容

| 增强类型 | 首次死亡 | 累积上限 | 说明 |
|---------|---------|---------|------|
| 初始气血 | +5% | +30% | 6次死亡达到上限 |
| 初始物攻 | +3% | +15% | 5次死亡达到上限 |
| 初始法伤 | +3% | +15% | 5次死亡达到上限 |
| 经文碎片掉落 | +10% | +50% | 5次死亡达到上限 |
| 劫印获取 | +10% | +50% | 5次死亡达到上限 |
| 商店折扣 | +5% | +25% | 5次死亡达到上限 |
| 初始装备 | 解锁1件 | 解锁3件 | 3次死亡达到上限 |

### 5.4 死亡增强的优势

1. **进步感**：每次死亡都有增强，让玩家感觉在进步
2. **降低劝退**：新手不会因为一直通不了关而放弃
3. **保留挑战**：增强幅度小，不会破坏肉鸽平衡
4. **可重置**：高手可以选择重置，挑战纯肉鸽模式
5. **参考成功游戏**：杀戮尖塔、万世剑冢等都有类似机制

### 5.5 死亡增强的劣势

1. **可能破坏平衡**：如果增强幅度过大，会破坏肉鸽平衡
2. **可能降低挑战**：累积增强后，通关难度降低，失去挑战性
3. **需要仔细平衡**：需要仔细平衡增强幅度和上限

## 六、通关体验设计

### 6.1 新手通关曲线

```
通关概率
  ↑
  │                        ╭───── 熟练玩家（30+局）
  │                       ╱
  │                      ╱
  │                     ╱
  │                    ╱
  │         ╭─────────╯  ← 普通玩家（15-30局）
  │        ╱
  │       ╱
  │      ╱  ← 新手（5-15局）
  │     ╱
  │    ╱
  │   ╱
  │  ╱
  │ ╱
  │╱
  └──────────────────────→ 游戏局数
    5    10    15    20    25    30
```

- **新手（5-15局）**：通关概率10-30%，主要学习游戏机制
- **普通玩家（15-30局）**：通关概率30-60%，开始理解Build搭配
- **熟练玩家（30+局）**：通关概率60-90%，可以挑战高难度

### 6.2 通关爽感设计

**前期艰难，后期爽感**：
- **前期（第1-3章）**：资源少，Build未成形，战斗艰难
- **中期（第4-6章）**：资源逐渐积累，Build开始成形，战斗变得顺利
- **后期（第7-9章）**：Build完全成形，拿到想要的装备/经文/劫印，战斗爽快
- **Boss战**：最终Boss战有史诗感，通关后有强烈的成就感

### 6.3 通关奖励

| 奖励类型 | 说明 |
|---------|------|
| 称号 | 根据通关表现获得不同称号（夏僧/商僧/周僧...） |
| 排行榜 | 通关时间、最高难度、最高分数进入排行榜 |
| 解锁内容 | 解锁新英雄、新装备、新经文、新事件 |
| 经文拓印 | 集齐一道所有经文，永久拓印，跨周目生效 |
| 成就 | 解锁各种成就（首次通关、无伤通关、极速通关等） |

### 6.4 多周目设计

- **一周目**：新手体验，学习游戏机制，通关难度较低
- **二周目**：难度提升，敌人属性增强，掉落更好
- **三周目+**：难度继续提升，解锁隐藏内容，挑战极限
- **无限周目**：难度无限提升，排行榜竞争

## 七、优劣分析总结

### 7.1 整体优势

1. **回归肉鸽本质**：运气+策略+积累，符合肉鸽核心体验
2. **系统简化**：经文和劫印系统大幅简化，减少学习成本
3. **通关体验好**：前期艰难，后期爽感，死亡增强降低劝退
4. **Build多样性**：每个道途、每个转职、每个Build都有通关可能性
5. **参考成功游戏**：杀戮尖塔、万世剑冢、冒险日记等验证过的模式
6. **长期可玩性**：多周目、排行榜、成就、解锁内容，长期可玩性强

### 7.2 整体劣势

1. **失去策略深度**：经文和劫印简化后，策略深度降低
2. **需要大量内容**：需要足够多的装备、经文、事件、敌人，保证每局体验不同
3. **平衡难度大**：需要仔细平衡每个Build的强度，避免某些Build过强或过弱
4. **可能过于简单**：系统简化后，可能失去深度，对硬核玩家吸引力不足
5. **死亡增强平衡**：需要仔细平衡死亡增强的幅度和上限，避免破坏肉鸽平衡

### 7.3 风险与应对

| 风险 | 应对措施 |
|------|---------|
| 系统过于简单，失去深度 | 保留装备系统的深度，经文和劫印简化但保留阈值效果 |
| 死亡增强破坏平衡 | 增强幅度小（5-10%），有上限，可重置 |
| Build不平衡 | 每个Build都要有通关可能性，定期调整平衡 |
| 内容不足 | 优先保证核心内容，逐步扩充内容池 |
| 新手劝退 | 死亡增强+教学引导，降低新手门槛 |

## 八、实施建议

### 8.1 实施优先级

| 优先级 | 内容 | 说明 |
|--------|------|------|
| P0 | 劫印系统简化 | 取消独立装备和品质，改为纯属性阈值加成 |
| P0 | 经文系统简化 | 改为碎片合成整本，自动生效 |
| P1 | 死亡增强系统 | 每次死亡给些许增强，累积生效 |
| P1 | 通关曲线调整 | 新手通关所需局数控制在15-30局 |
| P2 | Build平衡调整 | 确保每个Build都有通关可能性 |
| P2 | 多周目系统 | 难度递增，解锁隐藏内容 |
| P3 | 排行榜/成就 | 长期可玩性内容 |

### 8.2 实施步骤

1. **第一阶段**：简化劫印系统和经文系统，测试基础体验
2. **第二阶段**：添加死亡增强系统，调整通关曲线
3. **第三阶段**：平衡Build强度，确保每个Build都有通关可能性
4. **第四阶段**：添加多周目、排行榜、成就等长期内容

### 8.3 注意事项

1. **保留装备系统深度**：经文和劫印简化后，装备系统应该保留足够的深度
2. **不要过度简化**：简化是为了减少学习成本，不是为了失去深度
3. **定期测试平衡**：每次调整后都要测试Build平衡
4. **收集玩家反馈**：根据玩家反馈调整难度和平衡
5. **保留核心体验**：无论如何调整，都要保留肉鸽的核心体验（运气+策略+积累）

## 九、结语

这个设计方案的核心是**回归肉鸽本质，简化复杂系统，强化运气与成长的平衡**。通过简化经文和劫印系统，减少学习成本；通过死亡增强系统，降低劝退率；通过Build多样性，保证每局体验不同。

**核心价值**：没有绝对最强的路线，只有最适合玩家风格的路线。每一个隐藏都要有能通关的能力，但前提是运气要好，都要与选定的路线相符。

**最终目标**：让玩家在经历了前期的艰难后，能够体验到全拿到想要的Build的爽感，并有强烈的通关成就感。
