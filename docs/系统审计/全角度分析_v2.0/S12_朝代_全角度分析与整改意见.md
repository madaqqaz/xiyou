## 1 · 现状事实（代码实证 · V9.69c 基线）

### 1.1 核心循环与玩家动线

「开局读朝 → 局内吃 feature → 死亡递进 → 通关归夏」，跨周目持久化于**单个 number**（`ndx_dynasty_idx`）：

1. **入口·读朝**：`getDynastyIdx()`（`data_dynasty.js:55`）→ `SaveSystem.loadNumber`（`:58`）→ clamp `[0, LAST_IDX=9]`（`:59`）→ 一次性脏档校准（`:60-67`）。
2. **局内·吃 feature**：三入口 `dynastyHas:132` / `dynastyValue:141` / `dynastyAdjust:158`，首行各判 `hasClearedAny()`（`:134/:143/:160`）⇒ **首周目 0/23 feature 生效**。
3. **死亡·递进**：`bumpDynasty:78`；调用点 战斗死亡 `game_combat_2.js:117-118`（紧跟 `:122 _syncAch()` 失败落簿）、寿尽 `game_meta.js:185-186`。唐（idx 9）死亡原地复位（`:81-84`）。
4. **通关·归夏**：`resetDynasty:92` 写 0；唯一链路 `startReturn`（`game_event_1.js:248-257`）→ `settleReturn`（`game_meta.js:193`）→ `:269-270` 复位。⚠ 早于 `:305/:307` 判定（§1.7-1）。
5. **轮回重开**：`reincarnateReset:113`（归夏 + `resetCycle` + 清 INHERIT/MONUMENT_GEAR/MONUMENT `:118-120`）；入口 `main.js:556`（带 `window.confirm` 二次确认 `:552-555`）。
6. **可感知层**：年表浮层 `ui_changan.js:171-197`；结算/总览朝代名 `ui_misc_1.js:395`、`ui_misc_2.js:643`；排行榜朝代名 `game_meta.js:227-235`。
7. **前 30 分钟首次体验**：开局读夏 → 全局死亡推进照跑 → feature 全关（门禁）→ 首次通关 → 归夏 + `xia_seng` 成就 → 二周目起才逐朝点亮。**玩家的前 10 世是纯叙事壳**。

### 1.5 边界与异常

- **clamp**：`data_dynasty.js:59` 双向钳位（`isNaN→0` + `Math.max(0,Math.min(9,v))`）⇒ 手改 localStorage 不崩 UI。
- **门禁三重 + 短路安全**：三入口各判 `hasClearedAny()`（`:134/:143/:160`），`!NDX.hasClearedAny ||` 前置 ⇒ owner 加载顺序颠倒或 `data_heroes_data.js` 缺失时安全退化为"feature 全不生效"（fail-safe 方向正确：宁可不加成，不可错误加成）。
- **幂等/兜底**：三入口全 try/catch，`dynastyAdjust` 异常回原值（`:228-230`）、`dynastyHas` 异常回 false（`:137`）⇒ 朝代永不成为崩点。
- **🔴 本轮新证（死锁反证的关键）**：`SaveSystem.saveNumber`（`save_system.js:257-266`）**内部 try/catch、失败仅 `console.warn` 并返回 false、不抛** ⇒ `resetDynasty`（`data_dynasty.js:94`）**不可能在写 0 之前抛异常** ⇒ 旧审计"idx 停在 9 且 resetDynasty 抛异常被 `game_meta.js:273` 吞掉时才可能触发"这条保留通道**被证伪、关闭**。
- **历史脏档自愈**：`data_dynasty.js:60-67` 一次性校准（`clears<=0 && cycle>1 && v<cycle-1` → 追平回写），条件不幂等复发；但注意**该校准在 win 结算路径上永远不触发**（通关必有 `clearedHeroes>0`）⇒ 不构成对 §1.7-1 的绕过。
- **rng**：朝代层不产随机数；消费侧 4 处裸 `Math.random`（§1.7-5）；概率型判定阈值 `_dropMul-1`（`game_combat_2.js:216`）在 `dynastyAdjust` 异常回原值（=1）时自然退化为 0% 概率——兜底方向安全。
