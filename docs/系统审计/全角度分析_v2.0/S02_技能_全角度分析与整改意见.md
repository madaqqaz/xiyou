### 1.5 边界与异常

- **逐层幂等**：`resolveSkillAct` 用 `act._skillDone[layer]` 登记，同层同 act 不跑两次（V9.54 回归防线）。探针实测 atk 键 `done_layers = [hero,dao,job,sutra,variant,jing,treasure]`（7 层；`ult` 因 `kinds` 不含 atk 正确跳过），`a1.dmg === a2.dmg`、`a1.note === a2.note` 逐字节相等。
- **单层异常隔离 + 静默吞异常**：`try { layer.run(act, c1); } catch (e) {}`（`data_skill_index.js:407`），`applyActVariant` 另有一层 `try/catch`（`data_skill_variant.js:74`）。⚠ **全程零 console / 零埋点**，线上无法区分"该层无操作"与"该层抛异常"。

- **未知 op 静默跳过**：`default: break`（`data_skill_variant.js:71`）+ 外层 try/catch。
- **跨周目与存档迁移**：技能层**不写 `s.*`**（§1.2），故无存档字段、无迁移成本、无白名单改动；R1 的容器失配是**纯读态**问题，不影响存档兼容性。
