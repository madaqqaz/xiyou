## 1 · 现状事实（代码实证 · V9.69c 基线）

### 1.1 核心循环与玩家动线

「对局行为 → `checkAch(s)` 纯函数全量重算 → `_syncAch` 历史并集比对 → 新点亮落 `saveAch`（跨周目持久，只增不回退）→ 平台上报（fire-and-forget）→ 播报 → 下一局开局经 `globalAchBonus`/`achvSlotBonus` 注入永久属性」。

| 环节 | 实现 | `file:line` |
|---|---|---|
| 重算 | `NDX.checkAch(s)` 纯函数，吃 state 返 `Set`，不写库 | `achievements.js:129-262` |
| 落簿 | `hist.push(id)` + `NDX.saveAch(hist)`；并集语义＝历史不回退 | `game_event_3.js:433-453` |
| 播报 | `【难簿·新功名】${a.icon} ${a.name}` + 首次解锁教学 toast（受 `if (a)` 门控，见 §1.7） | `game_event_3.js:439-449` |
| 平台上报 | `NDX.Platform.achievements.reportUnlocked(hist.slice(), newlyUnlocked)` | `game_event_3.js:458-465` |
| 反馈落地 | `globalAchBonus()` 开局注入 `s.bonusTi/bonusYuan`；槽位 +1 | `achievements.js:398-416`、`equipment_part3.js:173-178` |

**`_syncAch` 调用点（grep 实测 13 处，含定义行 ⇒ 12 个真调用点）**：`game_event_3.js:428`（每次抉择 `_autoGE` 尾）、`game_event_2.js:433/490`、`game_combat_2.js:122`（败局结算）、`game_equip.js:245`（套装合成）、`game_sutra.js:70`、`game_vault.js:73`、`game_region.js:122`（**佛经圆满 win 分支，不 reset 朝代**）、`game_meta.js:305`（通关收束）、`game_rest.js:234`、`game_core_2.js:253/379`（跨卷边界）。

**前 30 分钟首次体验路径**：首次战斗结束 → `game_combat_2.js:122` 首次 `_syncAch` → `fall_death`/`awaken`（若首战有恶业）大概率点亮 → 首次点亮触发 `game_event_3.js:445-448` 的**教学 toast**（`s.flags._achTaught` 一次性，**且只对 `ACH_BY_ID` 命中的 id 触发**——若首次点亮的是难簿功名，则玩家在整局中都收不到这条教学提示）。

**试玩截断**：`_demoEnd`（`game_region.js:148-168`）置 `s.over.win=true` 但不调 `_syncAch` ⇒ 试玩口径（前 3 章）下所有 win 类成就不落簿（`game_region.js:169` 的 `DEMO_MAX_ACT` 早退）。
