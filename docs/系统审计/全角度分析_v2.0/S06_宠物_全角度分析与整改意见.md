**本视角结论**

1. **本作把复杂度放在"同一实体的多条轴"上，竞品把复杂度放在"编队组合"上**，二者不可互替：本作 8 轴 × 3 阶 = 24 只已足够"看不完"，但缺**跨轴组合的活路**（`CROSS_SYNERGY` 整簇零消费）⇒ 玩家既拿不到多轴深度、也拿不到组合广度。**｜证据**：实测 + `equipment_part3.js:979-1085`｜**定级 P1**
2. **可达性差距是最大的一档**：Pokémon 进化链与 Hades 神犬都是"路径短且必达"，本作却是"本相 8/8 · 显形 8/8 · **证道 1/8**"⇒ 高级内容在竞品对标里属**事故级缺失**，不是难度设计。**｜证据**：§1.7-B｜**定级 P0**
3. **手感反馈对齐**：本作"掉落即得 + `desc` 文本直给（【轴·阶】数值 — 机制）"，接近 Hades"礼物→永久被动"的短反馈；但"13/19 配方点了没反应"是**唯一硬伤**，与竞品的"反馈确定"直接冲突。**｜证据**：`equipment_part1.js:941-951` + §1.7-C｜**定级 P0**
4. **"主动撤销星阶数值轴"是被迫的正确**：竞品单轴故不易爆炸，本作三轴叠乘若不撤会到 ×4.66（护栏 3.60）⇒ 减法方向对，但**减法之后没有补上替代收益**（养成轴零入口），玩家体感是"宠物变简单了"。**｜证据**：`data_pet.js:240-245` + §1.7-A｜**定级 P1**

> **反例构造（证伪"8 轴机制差异足够"）**：取证道阶（3 档）两只兽印对比——
> - `combo` 轴：`petCombo = min(0.30, 0.06×3) = 0.18`，`combat_part1.js:917-919` ⇒ 命中则追加 `deal×0.50` ⇒ 期望 `×(1+0.18×0.50) = ×1.090`
> - `crit` 轴：`cri += min(0.25, 0.05×3) = 0.15`，`criMult` 默认 1.6（`combat_part1.js:93/:839`）⇒ 暴击段额外 `0.6×phys` ⇒ 期望 `×(1+0.15×0.60) = ×1.090`
> **二者在小数点后三位完全相等**。玩家在 2 槽位下把"裂"换成"暴"，除白值 atk `46×1.5=69`→`50×1.5=75`（+6）、hp `120×1.5=180`→`105×1.5=158`（−22）外，**增伤期望逐字节相同**。而 `ward`（dr +2%/档 ⇒ t3 共 +6%）与 `evade`（开场免控 N 回合）在"无 debuff 的普通杂兵场景"下亦高度接近。⇒ **8 轴的可感知差异实际收敛到约 4–5 档**。
> **反证尝试（验证"恒等"结论）**：把 `crit` 的 `criMult` 拉到 2.0 时 crit 为 ×1.150 > combo ×1.090；把 combo 的 `cap` 从 0.30 降到 0.18 时两者在 t3 处**同时撞顶**成为硬等价。二者在**当前默认参数**下等价，不排除调参后拉开——但这恰恰说明它们目前**没有独立的数值身份**。
