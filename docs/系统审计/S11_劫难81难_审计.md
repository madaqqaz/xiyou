### 1.1 核心循环

```
建图期：ACT_RANGES 定章 → _assignTrialDiffs 把本章难号「固定绑定」到每层唯一劫难位
        （compact 游标跳过融合弧难号与已转缘难号）→ _ensureHiddenTrials 保隐藏职必经难必现
        → _capTrialNodes 按 actTrials-1-弧内非Boss难数 收敛多余劫难点
进入期：case 'trial' → fixedTrial 优先 → trialByLayer(diff,hero) → HERO_TRIALS 覆盖合并
        → normalizeTrial → s.pending{kind:'trial'} → 玩家择一选项
结算期：applyTrialOpt → _gainFate(六道) / gainMoral(善恶) / gainXinmo(心魔) / 劫印 or 善印
        → 战斗选项进战斗（bossDiff/战功）→ trialsPassed 记账 → 难簿分卷 → 隐藏职资格判定
复合期：case 'compound' → _compoundNext 逐子难结算 → 融合劫印（按子难数定档）
        → 车迟三战合体终局 / 通天河全渡·全逆终局矩阵
章末期：末层唯一关隘 Boss（难号 = actEnd(act)）→ 81 难历尽 → 第 81 难终局
```
