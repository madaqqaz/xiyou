## ① 当前游戏内容（代码事实）

### 1.1 核心循环
- **选角 → 养成 → 战斗**：`NDX.HEROES[id]` 提供基础属性与被动 → `playerBaseAt(diff)` 随难度缩放 → `computeStats` 结算底座（[耦合矩阵§二](02_耦合矩阵与数值口径登记表.md)）→ 三键 `ULTIMATES`/`CHANTS` 出手。定义 `../../js/data_heroes_data.js:10-95`；成长 `../../js/data_heroes.js:13-34`。
- **英雄专属剧情线**：每英雄在 ch1-9 有专属 `HERO_TRIALS`（选项带 `fate`/`effect.good/evil` + `dark` 叙事），驱动隐藏职与命数。`../../js/hero_trials_ch1.js:5-30`（wukong），全 5 英雄 × 9 章均有块（实测 45 处 `NDX.HERO_TRIALS.<hero>`）。
- **流派显影**：`NDX.currentStyle` 按「英雄底色 + 劫印 + 经文 + 隐藏职」加权 argmax，达信号下限才产出路线，否则 null（零操作）。`../../js/data_jobspec.js:520-535`。

### 1.5 边界与异常
- **裸号后期不再崩**：`matk` 现随 diff 成长（修前 15 难后愿流派打不过小兵），且 d28+ 斜率收敛，避免 d81 曾达 d1 的 ×23.7 爆炸。`../../js/data_heroes.js:9-23`。
- **难度即时反馈 clamp**：`scaleRunMods` 把渡/逆差距从 ±60% 收为 ±28%（`Math.max(0.72, Math.min(1.28, mult))`），多阶段 Boss `stages[]` 同步缩放防阶段条脱节。`../../js/data_heroes.js:44,49`。
- **2 阶大招解锁修正**：`ultimateTier` 原 `fate≥12` 即 2 阶，V8.58 改为 ≥18（对齐"一转"文案），防提前解锁膨胀。`../../js/data_ultimates.js:41-43`。
- **零操作兜底**：`currentStyle` 无任何非底色信号 → 返回 null，存量玩家行为逐字节不变；被动经软饱和恒 < 底色 1.0（只微调）。`../../js/data_jobspec.js:526-534,462-467`。
- **英雄解锁三通道**：通关全解锁 / 劫灰「金蝉余韵+逆心初萌」横向逐解（≤4）/ 死亡 1-2-4-8 递进。`../../js/data_reincarnation.js:56-58,66-67,86-92`（属 S04 跨周目，但直接决定英雄可达性）。

### 1.6 跨系统接口
- **对外提供**：`HEROES`（基础/被动/mainKey）→ 全战斗与 UI；`ULTIMATES`/`CHANTS` → S02 三键；`currentStyle` → 宠物槽扩容（`summon`）与大招变体（`ULT_STYLE_MOD`）。
- **依赖**：难度 `diff`（S18）、装备 `s.equips`（S03，经 `styleWeightVector2` L1）、劫印 `s.seals`（S06，`SEAL_STYLE_MAP`）、经文 `s.chantSutra`（S09，`SUTRA_KIND_STYLE`）、隐藏职 `JOB_STYLE`（S04）。
- **链回 [耦合矩阵 §1.6](02_耦合矩阵与数值口径登记表.md)**：难度定标 `playerBaseAt`（`t=(diff-1)/19`）+ `scaleRunMods` clamp 全在此登记，S18/S01 引用不重写。
- **链回 [耦合矩阵 §1.7](02_耦合矩阵与数值口径登记表.md)**：`HERO_STYLE_BASE`/`STYLE_W`/`currentStyle` 与 `currentStyle==='summon'→PET_SUMMONER_JOBS 灵宠槽` / `JOB_STYLE→ULT_STYLE_MOD` 的完整消费链以 §1.7 为准。

### 1.7 已知债务与死区
- **第五英雄命名口径**：代码英雄 id 为 `xiaobailong`（form「西海龙子」、portrait `longma.webp`），而设计文档以「白龙马」为第五英雄定稿；`ashUnlockHeroCount`/`DEATH_UNLOCKS.heroes` 亦用 `xiaobailong`。三命名同指一英雄，**未复现第五个独立 id**，文档口径与代码 id 需统一（非缺陷，登记）。`../../js/data_heroes_data.js:62-63`；`../白龙马英雄完整设定_第五英雄_最终定稿_2026-09-18.md`。
- **EQUIP 权重最高却空转**：`STYLE_W.EQUIP=2.4` 为流派最高权重，但依赖装备 `it.style` 字段（现网无 ⇒ 恒 0），英雄流派实际由劫印/经文/底色决定，装备"核心数值源"未反哺构筑。`../../js/data_jobspec.js:374,483-491`（同 S04 §1.7，防漂移仅登记一次，另处链接）。
- **`ULTIMATES` 与英雄 baseMatk 分库**：大招 `mult` 在 `data_ultimates.js`、绝招系数消费在 `combat_active.js`，无单一"英雄→大招倍率"表；跨文件人工对齐。`../../js/data_ultimates.js:9-35`。
- **`HERO_TRIALS` 无数值门禁校验 kind 合法性**：`options[].fate` 与 `effect` 键靠运行时消费，未见对 5×9 完整性的静态断言（仅 `_audit_herotrial_align.js`/`_verify_hero_trials_align.js` 存在，覆盖度待核）。
