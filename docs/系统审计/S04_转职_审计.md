## ① 当前游戏内容（代码事实）

> 硬规则：每条数值/机制必须带 `file:line` 或 BalanceDB 键；无证据者移入 §⑥。

### 1.1 核心循环
- **六道专职（明线）**：命运抉择累计某道命数 → `Z.evaluate` 逐道判定「恰好下一阶」是否达标 → `Z.nextEvent` 每节点只弹一个转职事件（latch）→ `Z.setTier` 升阶并 `sfx('levelup')` → `Z.tierBonus` 聚合为战斗可消费加成。入口 `../../js/zhuanjie.js:253-280`；升阶反馈 `../../js/zhuanjie.js:109-118`。
- **隐藏转职（暗线）**：难号结算校验 `HIDDEN_JOBS[].cond` → 记录已确认职为有序列表 `s.flags.jobs`（`NDX.activeJobs`）→ `NDX.mergeJobBonus/mergeJobPassive` 链上叠加合并 → `recordAwakened` 落 localStorage 跨周目保留。数据 `../../js/data_trials.js:10-46`；合并器 `../../js/data_trials.js:462-492,718-760`。
- **跨周目继承**：通关/死亡结算铸「劫灰」买永久线（`ASH_SHOP` 5 线）+ 死亡递进解锁英雄（`DEATH_UNLOCKS`）+ 隐藏职「觉醒印记」放大数值（`JOB_LEGACY_PCT`）。`../../js/data_reincarnation.js:56-102`；`../../js/data_trials.js:704-731`。

### 1.5 边界与异常
- **逐阶强制**：`nextEvent` 只取「恰好下一阶」（`Z.gateOf(dao, cur)`），进阶必须 0→1→2；同节点 `nodePopped` latch 一次，`enterNode` 重置。`../../js/zhuanjie.js:258,269-286`。
- **阶数 clamp**：`setTier` 用 `Math.max(0, Math.min(3, t|0))`，仅真升阶才 `sfx`（同阶回写不发声）。`../../js/zhuanjie.js:114-117`。
- **章节标尺修正**：`chapterOf` 经 `regionToActChapter` 把 17 地区号映射为 9 章制，修复二/三阶提前解锁。`../../js/zhuanjie.js:172-190`。
- **概率可注入 / rng**：缘劫反噬、深度复利均为纯函数确定性；`karmaBacklashChance` 有底有顶 clamp。`../../js/zhuanjie.js:423-432`。
- **全表回落查找**：`hiddenJobEntry(null, name)` 修正旧版 `HIDDEN_JOBS[null]` 恒 null 缺陷（2026-09-26）。`../../js/data_trials.js:448-459`。
- **零迁移兼容**：旧存档无 `s.flags.jobs` ⇒ 回退 `jobConfirm` 单值；`currentStyle` 无配装信号返回 null（存量玩家行为逐字节不变）。`../../js/data_trials.js:499`；`../../js/data_jobspec.js:526-534`。
- **存档幂等**：`giveRelic`/`consumeRelicById` 用 `s.materials[id]` 计数 + `first` 标记，杜绝无限锻造同名 L5。`../../js/zhuanjie.js:348-372`。

### 1.6 跨系统接口
- **对外提供**：`Z.tierBonus`（六道属性聚合）→ `computeStats`（结算底座，见 [耦合矩阵§二](02_耦合矩阵与数值口径登记表.md)）；`NDX.activeJobs`/`mergeJobBonus` → `attr_calc`/`combat_part1`。
- **依赖**：命运 `s.fate[dao]`（S01/S10 抉择产出）、章节 `NDX.chapterOf`、遗物材料库 `s.materials`（S03）。
- **链回耦合矩阵 §1.7**：`currentStyle==='summon'` → 灵宠槽扩容（`../../js/data_pet.js:27` `PET_SUMMONER_JOBS`、`equipment_part3.js:526`）；`JOB_STYLE` → `ULT_STYLE_MOD`（S05 大招）；`JOB_STYLE_VARIANT` → 三键变种表现层（S02）。**隐藏职 → 流派 → 大招/宠物槽/技能变种的完整链见** [02_耦合矩阵与数值口径登记表 §1.7](02_耦合矩阵与数值口径登记表.md)。
- **链回耦合矩阵 §1.4**：`JOB_PET_SLOT`/`JOB_TREASURE_SYNERGY`（`../../js/data_trials.js:495-496`）为「逆兽师」等职提供的宠物/法宝特例，已从 `equipment_part3.js` 收归本表单一真源。

### 1.7 已知债务与死区
- **行为累计口径失真**：`Z.behavior` 实际由「每道抉择次数」驱动（`_gainFate → _maybePromote` 传 choice 数），**非** `behType/behUnit` 声称的「击杀/精英/渡化」实战分型；`behType` 仅作门槛文案。代码注释已自认为债务。`../../js/zhuanjie.js:120-129`。
- **装备路线标签空转**：`styleWeightVector2` 的 `EQUIP:2.4`（权重最高）依赖 `it.style` 字段，但现网 300+ 装备**尚无该字段 ⇒ 本项恒为 0**，流派实际由劫印/经文/底色驱动。`../../js/data_jobspec.js:374,483-491`。
- **burn 流派薄**：2026-09-26 才把「罗刹·铁扇」由 purify 改归 burn 使 burn 由 2→3 成环，此前为唯一 <3 职的薄流派。`../../js/data_skill_index.js:206-209`。
- **无独立转职面板 owner 文件**：`lazy_load.js` 已退役（`index.html:256`），转职/觉醒 UI 散落于 `ui_misc_2.js`（链尾 nextJob 前置展示 `:719-733`），未见幻影文件；`js/skill_build.js` 属幻影清单禁引（[规范§三](01_审计方法与证据规范.md)）。
