## 一、目标框定（Goal Framing）

**目的**：让《逆道西行》的英雄/职业体系**符合玩家对"常规回合制 RPG"的既有认知**，把学习成本从"记 45 个剧情职名"降到"认 5 个定位"。

**成功标准**：
1. 新手在 30 秒内看懂「我这个英雄是干嘛的、该堆什么」
2. 玩家看到职业名就能推断出打法，不需要查表
3. 职业切换有**玩家可感知的玩法变化**，而不只是数值变化
4. 构筑深度不减（仍是路线 BD 游戏）

**约束**：
- 战斗是「一次性预结算 + 逐拍回放」（`calcCombat` 只调一次），**不能改成真回合制输入**
- 保留 45 个隐藏职的剧情价值（81 难叙事资产，不能删）
- 单源纪律：职业语义只住在 `data_trials.js` / `data_skill_variant.js`

**参照系**（三款作品拆出的共性，即"玩家已学会的东西"）：

| 作品 | 玩家已学会的模型 |
|---|---|
| 《万世剑冢》 | 三键（普攻 / 技能 / 大招）+ **怒气条**涨满放大招 + 透明立绘脚底血条 |
| 《不一样西游》 | 角色有**明确定位标签**（输出/坦克/辅助）+ 阵容站位 + 怒气大招 |
| 《冒险日记》 | 低操作高构筑：**阵容羁绊 + 词条搭配**才是深度来源，不是操作 |

**三者的交集 = 三键 + 怒气条 + 定位标签 + 阵容/构筑**。
《逆道西行》现状：**三键 ✅ 已有，怒气条 ❌ 无，定位标签 ❌ 无，阵容/构筑 ⚠️ 有但不可见**。

## 三、与常规回合制 RPG 的落差（Gap Analysis）

| 常规 RPG 认知 | 逆道西行现状 | 落差等级 |
|---|---|---|
| 职业 = 定位（战/法/牧/坦） | 职业 = **45 个剧情化职名**（弃经金蝉、鹏翼之悟） | 🔴 阻断 |
| 职业名能推断打法 | 流派标签（summon/ward/crit）**是内部字段，UI 不显示** | 🔴 阻断 |
| 开局选职业，全程稳定 | 难号节点 `cond` **自动触发**，玩家不可选、不可规划 | 🟡 设计风险 |
| 技能消耗资源（MP/怒气） | **只有 CD，无资源条**，玩家看不到"攒"的过程 | 🟡 设计风险 |
| 大招 = 怒气满才放 | 绝招按 CD，无"攒满"的正反馈 | 🟡 设计风险 |
| 速度决定行动顺序/次数 | 速度只定先手，不定次数 | 🟢 可记录 |
| 阵容/站位 | 有随行位（徒弟+妖怪共用 4 格）、宠物 2→4→6 格，但**战斗内不可见** | 🟡 设计风险 |

## 四、学习成本根因（4 条，按杠杆排序）

**L1 · 45 个无定位标签的职名**——玩家记住"弃经金蝉"不能推断出它是治疗流。这是最大的一笔成本。
**L2 · 流派语义对玩家不可见**——`JOB_STYLE` 是引擎字段，UI 只显示职名 + 数值 bonus。玩家看到的是"+30 matk"，不是"你变成了治疗"。
**L3 · 转职是被动事件而非玩家决策**——玩家没有"我要走哪条路"的规划感，只有"突然弹了个职"。
**L4 · 战斗缺可感知的资源循环**——没有怒气条，三键退化成"哪个亮了点哪个"，职业差异被稀释。

## 五、英雄层：定位校准

### 5.1 定位缺位诊断

按常规 RPG 五定位（输出 / 坦克 / 治疗 / 辅助 / 敏捷）对照：

| 定位 | 现有承担者 | 判定 |
|---|---|---|
| 物理输出 | 孙悟空（破甲）、小白龙（暴击） | ✅ 充足 |
| 坦克 | 猪八戒（护盾反伤）、沙僧（法坦反震） | ✅ 充足 |
| **治疗/辅助** | 取经人（**唯一**，且被动是输出向 `mercy 0.10` 加法伤） | 🔴 **缺位** |
| 敏捷 | 小白龙（闪避+暴击） | ✅ 单体强 |
| 召唤 | 无英雄本命（驯兽师是隐藏职） | 🟡 后置 |

**核心矛盾**：`purify` 流派有 **8 个职**（全流派最多），说明系统想让取经人当奶；但取经人的 `baseMatk 200` 是**全队最高**，被动 `慈悲愿力` 也是**加法伤**——**叙事想让他当奶，数值把他造成法师**。玩家会困惑。

> ✅ **已实证**：这条路走得通。`SUTRA_VARIANT_TMPL` 的 chant 列里，渡系 `zen-heal` 带 `healPct 0.18`（·甘露）、缘系 `bond-mantra` 带 `healPct 0.18`（·唤伴），而战系 `war-buff` 带 `crit + dmgMul 1.12`（·战意）。
> **即：持诵渡经 = 治疗，持诵战经 = 输出，数据基础已经具备，只需接线验证，不需改数值。**

### 5.2 建议：给取经人「双形态」而非二选一

不改数值，改**呈现与诵经语义**：

- 取经人诵经键 = **队伍技能**：持诵「渡系经」→ 治疗/净化；持诵「战系/贪系经」→ 法术输出
- 这样他既是奶又是法师，**由经文决定**，符合已拍板的「诵经 = 持诵经 chantSkill」设计
- 需要补：**渡系经的 chant 变体必须有 heal/cleanse**（已在 `SUTRA_VARIANT_TMPL` 补了 chant 列，需核对渡系是否带治疗）

### 5.3 沙僧定位冷门的处理

「反震法坦」不是常规 RPG 认知。建议**保留机制，改描述**：
`愿·法防·反震` → 玩家语言改为 **「御」（挨打变强）**，并在 UI 给一句话规则："你打我，你自己掉血"。

## 六、职业层：双层结构（核心方案）

### 6.1 方案：5 定位收纳 10 流派

**在 `JOB_STYLE`（流派）之上加一层 `定位 ROLE`**，玩家只认 5 个定位：

| 定位 | 图标语义 | 收纳流派 | 职数 | 一句话规则 | 常规 RPG 对应 |
|---|---|---|---|---|---|
| **战** | ⚔ 攻 | combo / crit / burn / reverse | 14 | "打得更多、更狠" | DPS |
| **御** | 🛡 守 | ward / reflect | 9 | "挨得住，还能弹回去" | Tank |
| **禅** | ☸ 渡 | purify | 8 | "回血、解状态" | Healer |
| **猎** | 🌀 疾 | evade / drain | 11 | "躲得掉、吸得回" | Rogue / 敏捷 |
| **御兽** | 🐾 召 | summon | 3 | "多打你几个" | Summoner |

**玩家心智成本：45 个职名 → 5 个定位 × 5 英雄 = 25 个组合**，且定位是通用认知。

### 6.2 职名保留策略

45 个剧情职名**全部保留**作为 L2 皮肤，UI 呈现改为：

```
【禅 · 弃经金蝉】          ← 定位标签在前，职名在后
  回血 + 净化，法伤 +30
```

一处改动，学习成本骤降，叙事资产零损失。

### 6.3 流派标签要进 UI 的三个落点

1. **转职弹窗**：`【你觉醒了 · 禅 · 弃经金蝉】`
2. **英雄面板职业栏**：显示当前定位图标 + 定位名
3. **战斗 HUD**：绝招按钮下方显示定位色（战=赤 / 御=黄 / 禅=青 / 猎=绿 / 御兽=紫）

## 七、转职层：从被动触发到玩家抉择

### 7.1 现状问题

`HIDDEN_JOBS` 的 `cond` 在难号节点**自动判定**，玩家：
- 不知道什么时候会转职
- 转了之后不知道自己变了什么
- 无法为"我要走治疗流"做规划

### 7.2 建议（不改引擎，改呈现 + 加一层选择）

**方案 A（推荐，改动最小）· 预告 + 确认**
- 达成条件前一难：UI 提示「前方有缘法：{定位名} · {职名}（条件：{cond}）」
- 达成时弹窗让玩家**确认接受 / 拒绝保留**（拒绝则留待下一节链）
- 玩家获得"我在规划"的感觉，代码只加一层 UI

**方案 B（深度）· 分叉选择**
- 同链节点给 2 个候选职（同一英雄不同流派），玩家二选一
- 需要 `HIDDEN_JOBS` 增加 `altJob` 字段 + 转职弹窗改造，工作量中等

## 八、战斗层：补「怒气条」

### 8.1 为什么必须补

常规 RPG 的核心循环是「攒 → 放 → 攒」。《万世剑冢》《不一样西游》都有怒气条，玩家**已经学会看这条**。现在《逆道西行》只有 CD，循环不可见，导致：
- 绝招不像"大招"，像第三个普攻
- 职业差异（绝招变体）被稀释

### 8.2 建议设计（不破坏预结算架构）

| 键 | 消耗 | 产出 | 说明 |
|---|---|---|---|
| 普攻 | 无 | **+10 怒气** | 常规：普攻攒怒 |
| 诵经 | **-30 怒气** | 效果按持诵经 | 有消耗才有取舍 |
| 绝招 | **满 100 怒气** | 流派变体大招 | 攒满放大招，正反馈闭环 |

**关键约束**：战斗是预结算回放，怒气条**不能影响结算结果**（否则要改 `calcCombat`）。
→ 做法：怒气条作为**纯 UI 表现层**，按回放逐拍推进，视觉上"攒满→释放"，数值上仍走已算好的回合表。
→ 这是**零结算风险**的改法，玩家感知到的循环完全成立。

| 英雄 | 裸 EHP | 主输出 | 判定 |
|---|---|---|---|
| 猪八戒 | **1804** | 150 物 | 坦度第一，输出末位 ✅ 符合定位 |
| 取经人 | 1793 | 200 法 | 法系输出 ✅ |

| 孙悟空 | **1103** | 180 物 + 破甲 | ⚠️ 坦度垫底（比八戒低 39%），靠破甲补偿够不够？ |

**待深算项**：
- **N-A**：小白龙 `eva 0.28` 折算成 EHP ×1.39，是否应按"闪避回合零输出"打折？（代码注释已承认有 28% 稀释，但未量化）
- **N-B**：孙悟空 EHP 1103 vs 八戒 1804，破甲 10% 的收益能否填平 700 点 EHP 差？
- **N-C（已实证为真实缺陷）**：善念加成**不对称钳制**——
  - `combat_part1.js:376`：`pTi.maxHp = Math.min(cap, ...)` ← 气血**有 cap**

  - `zhuanjie.js:431` 用 `good / 50` 暗示善念量级可达 ~50 → 体攻 **+350%**、法伤 **+500%**
  - 🔴 **结论**：善念系被动在后期必然失控，且五英雄里 4 个带善念系数（悟空/八戒/沙僧 mercyAtk·mercyHp、取经人 mercy）。**建议先给 atk/matk 的善念加成加同一个 cap**，再谈职业平衡。
