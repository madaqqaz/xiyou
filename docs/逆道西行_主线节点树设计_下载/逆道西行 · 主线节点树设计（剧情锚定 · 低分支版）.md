# 逆道西行 · 主线节点树设计（剧情锚定 · 低分支版）

> 核心原则：**81 难为固定收束锚点，劫难之间按剧情主线线性推进，仅保留少量关键分支。**
> 摒弃"每难多路线并行"的高分支思路，改为**主线单线 + 偶发二选一 + 节拍强制**，
> 让"向西而行"的史诗感不被选择疲劳稀释，同时保留 roguelike 的构筑深度。

---

## 第一部分：全局架构

### 一、设计目标

| 维度 | 目标值 | 说明 |
|------|--------|------|
| 单章节（区域）时长 | **12-18 分钟** | 含 1-2 劫难 + 强制节拍 + 可选事件 |
| 完整一周目时长 | **约 20-26 小时** | 81 难 ÷ 每区域 4-6 难 ≈ 17 区域 |
| 多周目增量 | 每世 +30%-40% | 解锁新 Fate 路线 / 隐藏劫难 |
| 强制战斗占比 | **约 55%** | 保证肉鸽战斗爽感 |
| 事件占比 | **约 35%** | 承载叙事与六道抉择 |
| 休息/商店占比 | **约 10%** | 节奏喘息 |

### 二、三类节点定义

#### 1. 锚点节点（固定 · 不可跳过）
- **劫难（Trial）**：81 难的核心 Boss/叙事节点，固定收束每个区域
- 含多阶段战斗 + 剧情演出 + 六道选择后果
- 数值已对齐 `enemies.js`（参考《数值对齐版》文档）

#### 2. 节拍节点（强制 · 不可跳过）
每个劫难前**必须经历**的过渡节点，保证"西行"的推进感：

| 节拍 | 类型 | 是否必打 | 说明 |
|------|------|---------|------|
| **启程** | 剧情叙事 | ✅ | 进入区域的剧情入口，无战斗 |
| **拦路** | 普通战斗 | ✅ | 1 场小怪，引入区域敌人 |
| **抉择** | 事件（二选一） | ✅ | 六道倾向分支，**仅 2 选项，降低分支爆炸** |
| **守关** | 精英战斗 | 奇数难必打 | 区域精英/Boss 前哨 |
| **歇脚** | 休息/商店 | ⭕ 可选 | 回血、购遗物、跳过 |

#### 3. 血肉节点（随机 · 可选）
- 从 `eventPool[region]` 按权重抽取，丰富重玩性
- 每个区域预留 **1-3 个**可选位置，玩家可绕行

### 三、强制节拍模板（核心创新）

> **不再"每难全强制"，而是"按难序号交替"，兼顾节奏与新鲜感。**

```
【区域入口：启程(剧情)】
        ↓
【拦路：普通战斗 ×1】(必打)
        ↓
   ┌────────────┐
   │ 抉择：事件二选一 │  ← 仅 2 选项，锁定六道分支
   └────────────┘
        ↓
   (奇数难额外)【守关：精英战斗 ×1】(必打)
        ↓
【劫难收束：Trial Boss】(固定锚点)
        ↓
【歇脚：休息/商店】(可选，进入下一区域)
```

**交替规则：**
- **奇数难（1,3,5…）**：启程 → 拦路 → 抉择 → **守关(精英)** → 劫难
- **偶数难（2,4,6…）**：启程 → 拦路 → 抉择 → 劫难（无守关，节奏稍缓）
- **逢十难（10,20…）**：启程 → 拦路 → 抉择 → 守关 → **双阶段劫难** → 歇脚
- **第 81 难**：全节拍 + 五圣证道多阶段

这样既保证"战斗与事件交替的呼吸感"，又避免 81 次重复强制的疲劳。

### 四、分支策略（低分支）

1. **主线线性**：劫难顺序严格按原著 81 难，**不可跳过、不可乱序**
2. **单点二选一**：仅在"抉择"节拍给 2 选项（如战/渡、夺/缘），**不选路线，只选倾向**
3. **区域基调锁定**：每个区域主推 2 个 Fate（如大唐=渡/缘、黄风岭=战/隐），抉择池定向投放
4. **隐藏分支唯一**：仅 5 个 HID 事件需主动探索，其余都是单线

| 玩家类型 | 区域均长 | 81 难总计 | 含多周目 |

### 三、防疲劳设计

1. **交替强制**：奇数难有守关、偶数难无，避免连续高强度
2. **歇脚密度**：每 2-3 难一个可选休息，回满+商店
3. **血肉可选**：可选节点可跳过，赶时间的玩家能压缩时长
4. **逢十奖励**：大劫难后给予专属遗物，补偿节奏紧张

## 第八部分：重玩性与多周目设计

### 一、单周目 vs 多周目差异

| 维度 | 第一周目 | 第二周目 | 第三周目+ |
|------|---------|---------|----------|
| 劫难顺序 | 固定 81 难 | 固定（不可跳） | 固定 |
| 抉择倾向 | 自由探索 | 定向（如专走逆道） | 补全隐藏 |
| 神仙链 | 逐步解锁 | 继承进度 | 全满 |
| 隐藏劫难 | 不可见 | 部分解锁 | 全开放 |
| 数值 | 基础 | 继承衰减 20% | 衰减累积 |

### 二、多周目"继承衰减"规则

```
每多一世，继承属性 ×0.8（第 5 世破损）
例：一世攻击+100 → 二世+80 → 三世+64 → ...
```

### 三、HID 隐藏劫难的触发（多周目核心动力）

5 个 HID 事件分布：
- **第 3 难**：龙太子归（四海链满）
- **第 7 难**：卷帘复权（隐≥25）
- **第 32 难**：狮驼三魔·逆（逆道线专属分支）
- **第 63 难**：逆道之种（玉兔，逆≥30）
- **第 72 难**：谤佛金蝉（接引，善<0）

> 第一周目仅能触发 1-2 个，需多周目才能集齐全部隐藏结局。

## 第九部分：实现对照清单

### 一、与现有代码对接点

| 系统 | 对接方式 |
|------|---------|
| `trials81.js` | 81 难劫难锚点 → 本节点树的【劫】节点 |
| `events.js` | 100 事件 → 分配到【抉】与【血肉】节点 |
| `combat.js` | 节拍战斗配置 → 普通/精英/Boss JSON |
| `enemies.js` | 怪物数值 → 直接引用，无需重新定义 |
| `zhuanjie.js` | 六道转职 → 【抉】选项的 Fate 后果 |
| `game.js` | 区域流转 → 【歇】节点的存档/继承 |

### 二、节点树数据结构建议

```javascript
// 单个节点
{
  id: "trial_01",           // 难号
  name: "长安出发",
  region: 1,                 // 区域
  type: "trial",            // trial/normal/elite/event/rest
  beats: [                  // 节拍序列
    { type: "story", text: "..." },
    { type: "combat", enemy: {...}, reward: {...} },
    { type: "choice", opts: [
      { fate: "渡", effect: {...} },
      { fate: "战", effect: {...} }
    ]},
    { type: "boss", enemy: {...} }
  ],
  isDecade: false,          // 是否逢十
  hidFlag: null             // 隐藏劫难标记
}
```

### 三、地图生成流程

```
1. 加载 trials81.js 的 81 难固定序列
2. 按区域分组，每组注入节拍模板（奇数难加守关）
3. 逢十难插入守关×2 + 双阶段 Boss
4. 【抉】节点从 events.js 按 region + Fate 定向抽取
5. 【血肉】节点随机插入（每区域 1-3 个）
6. 神仙链事件覆盖对应【抉】节点
7. HID 事件按条件注入特定劫难
```

> **最终结论**：本节点树以"81 难固定锚点 + 奇数难守关 + 二选一抉择 + 可选血肉"为核心，
> 将分支降到最低（主线单线），同时保留 roguelike 构筑深度与多周目重玩性。
> 单周目约 20 小时（对标《万世剑冢》21.5h），因固定锚点节奏更可控、更有"向西而行"的史诗感。
> 三大高潮（红孩儿/狮驼三魔/五圣证道）形成情感峰值，五条隐藏结局驱动多周目探索。
