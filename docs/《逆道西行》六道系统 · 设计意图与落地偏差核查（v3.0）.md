### 关于「概率偏置」——这条设计比表面看起来聪明

`dao_system.js:301-310` 注释原文：

> 六道（`s.fate`）已从「**属性给予者 + 硬门槛**」**降级为「投放池的概率偏置向量」**……
> 权重 `w[dao] = 1 + FATE_W_MAX * fate / (fate + FATE_W_HALF)` —— **软饱和曲线**，
> `fate→∞` 时趋近 `1+FATE_W_MAX`（**不封死其它道**，避免某道 100% 垄断）

这正是你说的「装备太多，为了让玩家尽可能选到同一路线」——**用概率偏置收敛，而不是用硬门槛封路**。
「不封死其它道」保住了你后面那句「也可以走其他路线」。**这一层做得对，不用改。**

## 二、缺口 G1：善恶有两层口径，后加的覆盖了你原来的

### 2.1 你的设计（数据层，已落地）

难 1「金蝉遭贬」选项原文：

```js
{ key: '渡', label: '双手捧钵，承佛之命',
  effect: { alignGood: 10, favor: '观音', material: '紫金钵盂·虚' } },
{ key: '缘', label: '指尖触钵，惜众生缘',
  effect: { alignGood: 8, material: '紫金钵盂·虚' } },
```

**善恶挂在「选项」上，不挂在「道」上** —— 这就是你说的
「不同选择 → 不同结果 → 结果被定义为一种道」，
也是「**可能逆是极恶，也可能缘才是极善**」的落实方式。
全量 **404 处**（ch1:102 / ch2:26 / ch3:35 / ch4:33 / ch5:23 / ch6:21 / ch7:58 / ch8:41 / ch9:35）。

### 2.2 后加的简化层（冲突源）

`dao_system.js:220-231`：

```js
function isEvilDao(dao) { return ['战','夺','逆'].includes(dao); }  // 固定！
function isGoodDao(dao) { return ['渡','隐','缘'].includes(dao); }  // 固定！
```

消费点两处：
1. **`dao_system.js:292`** → `sixDaoCards()` 输出 `align: isEvilDao(dao) ? '恶' : '善'`
   → **难 1 战后六道总览弹窗，直接展示给玩家**
2. **`data_daoxin.js:50-51`** → `sealDaoMod()`，道心档位调制劫印倍率
   （abyss：恶印 ×1.15 / 善印 ×0.90）

### 2.3 为什么这是真问题

**对玩家**：他在难 1 选了「渡」，刚做的是一个**具体情境下的道德选择**（善 +10）；
紧接着弹窗告诉他「渡 = 善道，战/夺/逆 = 恶道」——**具体选择被抽象标签覆盖**。
而到后面某一难，若「缘」道选了恶选项（有 `alignEvil` 记录），
与他刚看到的「缘 = 善道」标签**直接矛盾**。这正是你说的「缘才是极善」被钉死成了「缘永远是善」。

**对机制**：`sealDaoMod` 用「道的本质善恶」调倍率，
而真实的善恶是「玩家这一局具体选了什么」——**因果装反了**。

## 三、缺口 G2：两套「英雄道归属」真源打架

| 英雄 | `HERO_MAIN_DAOTU`（`jieseals.js:198`） | `HERO_HOME_DAO`（`data_config.js:90`） | 一致？ |
|---|---|---|---|
| 孙悟空 | **战** | **夺** | ❌ |
| 取经人 | 渡 | 渡 | ✅ |
| 沙僧 | **缘** | **战** | ❌ |
| 猪八戒 | **夺** | **缘** | ❌ |
| 小白龙 | 隐 | 隐 | ✅ |

**3/5 冲突。** 且两套各有消费方，同时在生效：

| 真源 | 消费点 | 实际作用 |
|---|---|---|
| `HERO_MAIN_DAOTU` | `dao_system.js:104`（主道回落）、`jieseals.js:321/343`（**劫印池 offerSeals**） | 决定系统**优先发哪一道的劫印** |
| `HERO_HOME_DAO` | `combat_part1.js:153`（劫印 ×1.25）、`zhuanjie.js:235`（转职 ×1.25）、`data_heroes.js:112`（死亡复盘提示） | 决定**哪一道有 ×1.25 加成** |

**以悟空为例的实际后果**：
系统按 `HERO_MAIN_DAOTU` 优先发 **战** 道劫印，
但 ×1.25 加成按 `HERO_HOME_DAO` 只给 **夺** 道劫印。
→ **发给玩家的印吃不到加成，能吃加成的印系统不优先发。**

> 💡 这很可能就是你说「其实并没有什么英雄本命道」的实感来源 ——
> 连代码自己都有两套互相矛盾的定义，这个"本命道"从未真正成立过。

`data_config.js` 自己的注释说「V9.29 修正：悟空与沙僧本命道写反」，
但那次修正**只改了 `HERO_HOME_DAO`，`jieseals.js` 的 `HERO_MAIN_DAOTU` 没跟着改** ——
所以修完之后，两套从"都对"变成了"打架"。

## 四、方案

### 4.1 G1 正解：善恶单一真源 = 逐选项；「道」不再是善恶的容器

**核心原则：道不携带善恶，"道 × 劫难"才产生善恶。**

| 动作 | 落点 | 说明 |
|---|---|---|
| ① 停用 `sixDaoCards.align` 的固定善恶 | `dao_system.js:292` | 改为输出**本局累计**：`渡道 · 本局善 +18 / 恶 +0` |
| ② `sealDaoMod` 改用「印自身来源的善恶」 | `data_daoxin.js:50` + `jieseals.js` | 劫印写入时带 `align`（来源选项的善恶），调制看印不看道 |
| ③ `isEvilDao/isGoodDao` 降级为**仅内部统计口径** | `dao_system.js:220` | 保留函数但不再对外表达"道=善恶"，加注释禁用于展示 |

**收益**：
- 「缘也可能极恶」成立 —— 缘道印若来自恶选项，就计入恶
- 玩家看到的从「渡=善道」（标签）变成「你本局在渡道累计善 +18」（**自己的行为记录**）
- **学习成本下降**：玩家不需要记"哪道是善哪道是恶"（这本来就不该记），只需知道自己每次选择的影响

### 4.2 G2 正解：先问你 —— 英雄该不该有道归属

按你的模型「六道是玩家的选择」，**英雄本就不该有道归属**。四个选项：

| 选项 | 做法 | 代价 |
|---|---|---|
| **A. 彻底取消**（最贴你的模型） | 删两套真源；×1.25 改为「跟随玩家当前主道」或直接取消 | 失去"英雄身份辨识 ×1.25" |
| **B. 降级为"推荐"**（推荐） | 保留 `HERO_HOME_DAO` 一套，**只用于难1弹窗高亮推荐 + 死亡复盘提示**；**不参与发印、不参与加成** | 需改 `jieseals.js:321/343` 与 `combat_part1.js:153` |
| **C. 统一为 `HERO_HOME_DAO`** | 改 `jieseals.js:198` 对齐（悟空夺/沙僧战/八戒缘） | 最小改动，但"英雄绑定道"仍在 |
| **D. 统一为 `HERO_MAIN_DAOTU`** | 回退 `data_config.js` 到 V9.6 口径 | 与 V9.29 修正冲突，不推荐 |

> B 的好处：既消掉冲突，又让"英雄"只是**开局建议**而不是**命运绑定** ——
> 玩家仍可自由走别的道，符合「六道是选择」的核心定义。

## 五、学习成本的真正根因（三版结论汇总）

| 版本 | 诊断 | 对错 |
|---|---|---|
| v1.0 | 缺战法牧定位 | ❌ 引入外部范式，加成本 |
| v2.0 | 本命道没暴露给玩家 | ❌ 前提错（本命道本就不该是核心） |
| **v3.0** | **① 善恶被固定标签覆盖了具体选择；② 两套英雄道归属打架，玩家看到的与实际生效的不一致** | ✅ 实证到位 |

**v3.0 的推论**：玩家真正需要理解的是**一件事**——
「我在这一难的选择，会把我的道和善恶推到哪去」。
而不是「六道各是什么」「英雄该走哪道」「哪道是善哪道是恶」。

**所以降学习成本不是加标签、加面板，而是：让玩家看清"选择 → 结果"这一条因果链。**

**第 3 项的实际口径（与 §4.1 ② 的差异，已知并接受）**：
劫印的 `align` 不取「来源**选项**的善恶」，而取**来源阵营** —— 战斗破劫得恶印 / 非战斗（兵不血刃）得善印
（真源 `NDX.SEAL_SOURCE_ALIGN = { evil: ['战','夺','逆'], good: ['渡','隐','缘'] }`）。
原因：劫印由**节点类型**（战斗 / 非战斗）发放，不由某个具体选项发放，故「来源」在代码里的现实粒度就是节点阵营。
玩家可感的因果链仍然成立：**力战破劫 → 恶印 → 道心愈恶则印愈强；兵不血刃 → 善印 → 道心愈善则印愈强**。
