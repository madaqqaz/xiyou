## 二、战斗精灵实现方式分析

### 2.1 技术方案

当前战斗精灵采用**CSS background-image + background-position**的方式播放序列帧动画：

```css
.fb-avatar.sprite .fb-idle {
  width: 100%;
  height: 100%;
  background-size: 600% 100%;  /* 6帧横条 */
  background-position: 0% 0%;
  display: block;
}
```

**优点**：
- 实现简单，兼容性好
- 性能优秀，GPU加速
- 无需JavaScript驱动播放循环

**缺点**：
- 只能播放固定帧率的循环动画
- 无法精确控制每帧时长
- 不支持单次播放后自动停止（需要JavaScript配合）

### 2.2 动画状态切换

当前使用CSS类名切换动画状态：

```css
.fb-avatar.sprite.is-attacking .fb-idle { display: none; }
.fb-avatar.sprite.is-attacking .fb-atk  { display: block; }
.fb-avatar.sprite.is-hit .fb-idle { display: none; }
.fb-avatar.sprite.is-hit .fb-hit  { display: block; }
```

**状态机**：
- `idle`（待机）：默认状态，循环播放
- `is-attacking`（攻击中）：攻击时切换，播放完成后回到idle
- `is-hit`（受击）：受击时切换，播放完成后回到idle
- `death`（死亡）：死亡时切换，停在最后一帧

### 2.3 攻击动画实现

攻击动画采用**时间驱动 + translateX扑击**的方式：

```javascript
// 在_fxStrike方法中实现
const step = (t) => {
  // ... 计算位移曲线
  el.classList.add('is-attacking');  // 切 atk 帧
  el.style.setProperty('transform', 'translateX(' + (dir * DIST * k) + 'px)', 'important');
  requestAnimationFrame(step);
};
```

**效果**：
- 攻击时切换到atk帧序列
- 同时立绘向对手方向扑出
- 命中后回位
- 播放完成后回到idle帧

### 2.4 通用怪物模块化系统

对于没有专属战斗精灵的普通小怪，使用**通用怪物模块化系统**：

```javascript
NDX.GENERIC_MOB = {
  models: {
    humanoid: { idle: '...', atk: '...' },
    beast: { idle: '...', atk: '...' },
    ghost: { idle: '...', atk: '...' },
    aquatic: { idle: '...', atk: '...' }
  },
  colors: { yao: 'hue-rotate(...)', gui: '...', ... },
  weapons: { blade: '...', spear: '...', ... },
  elite: { armor: '...', cloak: '...', aura: '...' }
};
```

**特点**：
- 4种基础模型（humanoid/beast/ghost/aquatic）
- 9种颜色滤镜（妖/鬼/水/火/木/虫/人/佛门/魔）
- 8种武器图层（blade/spear/staff/claw/hammer/bow/fan/treasure）
- 3种精英图层（armor/cloak/aura）
- 通过图层叠加生成多样化的怪物外观

- 管理多个精灵的渲染循环
- 使用requestAnimationFrame驱动
- 支持添加/移除精灵
