# 《逆道西行》美术内容补全表 + 新手执行手册（照抄版）

> 适用对象：完全不懂美术/AI 绘图的人。本文档的目标是：你**只管复制提示词、按步骤点鼠标、按模板存文件**，就能稳定产出可上架的游戏素材。
> 配套文档：《动画实现规范 + 精灵表打包规格》（讲"图怎么动起来、怎么进引擎"）。
> 融合来源：《美术生产规范文档》（生图提示词）、Boss 动画设计总纲（帧数/形态/施法/粒子）。

## 0. 你每天要做什么（一句话版）

**拿一个怪 → 先出"基准立绘" → PS 修干净 → 上传它当参考图 → 逐个出 6 个动作 → 每个动作 PS 修一遍 → 按命名存好 4 类证据 → 丢进引擎。** 一遍学会，81 个怪全是这套重复动作。

准备的工具（全部免费或已付费）：
- **无限画**（优先，带电子商用授权）/ **即梦 AI**（备选）
- **Photopea**（免费网页版，网址 photopea.com，功能和 PS 一样，不用安装）或 本地 PS
- **一个云盘**（阿里云盘 / 百度网盘），用来双备份
- **一个本地文件夹** `D:\逆道西行_美术版权存档`（按第 6 节建好）

## 1. 合规红线（必读，违反 = 上架被拒 + 版权投诉）

| 性质 | 红线 | 说明 |
|------|------|------|
| **法律边界** | 不复制"具体改编作品"的角色造型 | 版权只保护**独创性表达**。86 版、某影视/动漫/游戏里某个角色的**具体长相/造型**，若被你"实质性相似"地复刻才侵权。让生成的图和任一现有改编作品某角色"长得像"= 危险。 |
| **法律边界** | 公共领域元素可自由用 | 西游记原著（明清小说）已进入公共领域：唐僧、悟空、金箍棒、紧箍、取经框架等元素与名字任何人可用，**沾这些元素 ≠ 侵权**。 |
| **过审策略（推荐）** | 优先自创妖怪命名 | 平台（TapTap/微信）审核口径常比法律严，可能以"蹭 IP/误导"下架。为稳妥，优先用自创妖怪名（如"灰骨夜行"），只借"暗黑西游"题材氛围。 |
| **必需** | AI 图必须人工二次修图 | 直接拿 AI 原图进游戏 = 高风险；必须进 Photopea/PS 改过并存 PSD，才算"二次创作"。 |
| **必需** | 付费授权必须留证 | 无限画每批次下载商用授权书 PDF，归档。 |

> **关于你举的"唐僧"例子**：唐僧是西游记原著里**公共领域的角色**，名字和原型本身可用；但不能生成"和某部影视/动漫/游戏里的唐僧长得一模一样"的造型（那属于复制具体改编作品的表达）。下面用**自创妖怪「灰骨夜行」**做演示，但你完全可以用原著妖怪名（如白骨精、牛魔王）走同样流程——只要配明显自创的暗黑造型即可。

> **一句话自检**：设计完角色，问自己——"这个造型是否明显区别于任何单一现有改编作品、带我自己的独创视觉表达？" 是 → 安全（哪怕他拿金箍棒）；否（和某款游戏/影视某角色几乎一样）→ 危险。

## 3. 实战演练：原创妖怪「灰骨夜行」走完全程（照抄）

下面每一步都写清楚：**你点什么 / 复制什么 / 屏幕上看到什么 / 存什么**。

### 3.1 先定"外貌设定"（这一栏你自己填，其余全抄）

```
怪物名：灰骨夜行
外貌设定：瘦高人形枯骨妖，灰青干裂皮肤，头顶三根弯曲黑角，

右手持锈蚀月牙短杖，腰悬枯骨片，7 头身，暗黑国风。
```

> 之后所有动作的提示词里，`【外貌设定】` 这段原样粘贴，保证角色长相一致。

### 3.2 步骤 1 — 生成基准立绘

1. 打开无限画 → 新建画作。
2. **画布设置**：尺寸 `1024×1024`，背景 **透明**（开透明通道），采样/画风 **水墨暗黑国风（厚涂写意）**。
3. **正向提示词**（整段复制）：
```
横版2D游戏美术，原创暗黑国风妖怪，游戏精灵基准立绘，横版侧视全身站姿，静止中立，面向右方，
双脚平稳着地，完整全身，角色外观锁定：瘦高人形枯骨妖，灰青干裂皮肤，
头顶三根弯曲黑角，眼窝暗红光点，破旧灰褐色粗布僧袍，衣摆多处破洞，右手持锈蚀月牙短杖，
腰悬枯骨片，7头身，服饰、武器、肤色、五官、配饰完全固定，无动态动作，无特效，清晰轮廓，
暗黑水墨国风，黑神话质感，枯笔飞白与墨雾弥漫，低饱和暗紫调，鎏金与朱砂高光点缀，全身立绘，纯白背景，无装饰元素，原创角色，不复制任何具体改编作品角色造型。
```
4. **负向提示词**（整段复制，每次必贴）：
```
水印，文字，签名，logo，多余角色，多个人物，残缺肢体，畸形手脚，扭曲五官，模糊，低画质，
3D渲染，卡通Q版，86西游记，影视角色，动漫角色，现有游戏角色，知名IP形象，抄袭，复刻，
参考真人，照片，背景杂物，阴影杂边，画布外多余物体，变形武器，变色服装
```
5. 点生成，**只生成 1 张**。
6. **你看到**：一个透明底的站姿妖怪。
7. **立刻存档**（见第 6 节）：页面截图 + 原图 PNG + 提示词 txt，文件夹 `01_文字设定 / 灰骨夜行 / 基准立绘`。

### 3.3 步骤 2 — 修图定稿（基准立绘，最关键的一步）

> **不会 PS 也没事**：用 **Photopea**（photopea.com，免费网页版，不用安装、不用注册，功能和 PS 一样）。下面分「必做」和「选做」——**只做必做 3 步就满足合规的人工二次创作要求**，选做是让图更精致，不做也行。

**【必做 · 合规最低要求，5 分钟内搞定】**
1. 打开 Photopea → 左上「文件」→「打开」，选刚生成的 AI 图（透明 PNG）。
2. **清边**：左侧工具栏点「橡皮擦」（橡皮图标），右上把"大小"调到 20~30，在角色周围的白边/黑边/杂色上擦几下，让透明背景纯净。
3. **调明暗（这是"人工改动"的核心证据）**：上方菜单「图像」→「调整」→「色阶」或「曲线」，把中间滑块轻轻拖一点（让明暗有变化），点确定。
4. **存证据**：「文件」→「另存为 PSD」（一定选 PSD，别选 PNG，图层不合并）→ 再「文件」→「导出为」→「PNG」存一张干净图。
5. 写一行记录 txt：`灰骨夜行_基准立绘_20260920_v1：清边+调明暗。`

**【选做 · 想精修再做，不会可跳过】**
- 放大看手脚/五官，用「仿制图章」或「液化」修正明显扭曲。
- 用「曲线/色阶」把整体光影调得更统一。

> 这张**修好的 PNG 就是以后所有动作的"参考图"**，PSD 存到 `03_人工修图工程文件 / 灰骨夜行 / 基准立绘.psd`。

### 3.5 步骤 6 — 合规存档（确保不侵权，每次生图都做）

1. **页面截图**：含账号名、时间、完整正负提示词、参考缩略图、成图。
2. **原图 PNG**：平台原始输出，不压缩。
3. **授权证书 PDF**：无限画下载的本批次商用授权书。
4. **提示词 txt**：本次提示词，命名 `灰骨夜行_攻击_20260920_v1.txt`。

**文件夹示例**：`01_文字设定/灰骨夜行/攻击/（截图+原图+授权+txt）` + `03_人工修图工程文件/灰骨夜行/攻击.psd`。

## 5. Boss 逐个体要求模板（融入总纲，逐个写出）

> 总纲核心参数先记牢，下面每个 Boss 都套用：
> - **分辨率** 1024×1024 透明；**朝向** 全部面朝右（我方在左、敌在右；朝左用代码水平翻转，零成本）；**画风** **水墨暗黑国风**（焦墨厚涂写意），低饱和黑白灰主调 + 角色专属点缀色（鎏金/朱砂/暗紫）——2026-09-21/22 全项目锁定。
> - **每形态标准 25 帧**：待机 4 帧(300ms/帧,循环) / 攻击 6 帧(150ms/帧,播完回待机) / 施法 6 帧(200ms/帧) / 受击 3 帧(150ms/帧,代码加闪白) / 死亡 6 帧(400ms/帧,停最后一帧)。
> - **三段变身优化**：三阶段不重做人物动作，只叠加 5~8 帧循环粒子层 + 代码泛光/变色/体型增大。
> - **异常状态**（中毒/燃烧/冰冻/麻痹/眩晕）全部代码层 colorMatrix 实现，不额外出图。

## 6. 存档记录 SOP（确保不侵权——每次生图必做）

### 6.1 文件夹结构（本地 + 云盘双份）

```
逆道西行_美术版权存档/
├─ 01_文字设定文档/（本手册 docx+PDF + 各怪外貌设定）
├─ 02_AI生成记录/
│   └─ 怪物名/
│       ├─ 基准立绘/（AI原图PNG + 页面截图 + 授权证书PDF）
│       ├─ 待机/ 行走/ 攻击/ 受击/ 死亡/ 技能/（同上4类）
├─ 03_人工修图工程文件/（每个动作一个 PSD 源文件，不是只存PNG！）
└─ 04_最终游戏导出素材/（切片后的精灵表PNG）
```

### 6.2 每次 AI 生图必须保存的 4 类痕迹

1. **页面截图**：账号名 + 生成时间 + 完整正负提示词 + 参考缩略图 + 成图。
2. **原图 PNG**：平台原始输出，不压缩。
3. **授权凭证**：无限画本批次商用授权书 PDF。
4. **文字记录**：本次提示词存 txt，命名 `怪物名_动作_日期_v1.txt`。

### 6.3 人工修图留存（关键，降侵权风险）

- **所有 AI 原图必须进 Photopea/PS 做至少一次人工改动**（哪怕只是清个边、调一下明暗），这是证明"不是直接搬运 AI 原图"的核心证据。完全不会 PS 的人看第 3.3 节「必做」5 步即可。
- 存 **PSD 分层源文件**（证明二次创作的核心证据，不能只存 PNG）。
- 写修改记录 txt，如：`灰骨夜行_行走_20260920_v1：清边+调明暗。`

### 6.4 命名 + 备份

- 命名规范：`怪物名_动作_日期_版本号`（例：`灰骨夜行_攻击帧_20260920_v1.png`）。
- 备份：本地硬盘一份 + 云盘一份，平台账号丢了记录也会没。

### 6.5 上架前自查清单（逐项核对）

- [ ] 全部 AI 素材来自付费商用授权，授权文件已存
- [ ] 所有角色未实质性相似于任何影视/动漫/游戏的具体角色造型（可用西游公共领域原型，但须原创诠释、明显区别于任一现有改编作品）
- [ ] 全部图片经人工二次修图，存在分层 PSD 工程
- [ ] 全套生成截图 + 提示词记录 + 授权证书 双备份
- [ ] 画面无血腥暴力，妖怪不恐怖过激（TapTap 内容规范）
- [ ] 精灵帧尺寸统一、透明通道正常、无水印文字
- [ ] 微信小游戏另需：类目资质 + 平台版权自查（与 TapTap 分开过审）

## 8. UI / HUD 美术清单（照抄执行）

> UI 和角色不同：**UI 是静态图，不进精灵表、不需要 25 帧动画**。它走"AI 出图 → Photopea 修 → 直接当 PNG 用"的简化流程。统一风格：**黑白灰主色 + 项目点缀色（暗金/暗红）**，国风描边，无写实血腥。
> **手机横版设计分辨率锁定 1920×1080（16:9）**：全游戏场景 / UI 统一以此为画布，引擎按比例缩放适配各机型；角色精灵为独立贴图，叠在画布上。

### 8.1 静态图通用生成流程（比角色少两步）

1. 无限画新建 → 尺寸按下表 → 背景**透明**（图标/框类）或**纯色底**（背景类）。
2. 正向提示词模板（复制改词）：
```
暗黑西游国风 UI 元素，______（具体物件，如"宝剑技能图标"），
扁平厚涂，黑白灰主色 + 暗金描边，清晰轮廓，无文字无水印，透明背景，游戏 HUD 风格。
```
3. 负向提示词（贴总文档负面词，加：复杂纹理，写实，3D，花哨）。
4. Photopea 修图（**必做**：清边 + 调明暗 + 存 PSD，同 §3.3）。
5. 导出 PNG + 存 4 类痕迹（截图/原图/授权/提示词 txt，同 §6.2）。

### 8.2 UI 元素清单（逐项打勾产出）

| 编号 | 元素 | 尺寸（基准 @1x，按设备补 @2x） | 透明 | 数量 |
|------|------|------|------|------|
| U1 | 游戏 Logo / 应用图标 | 512×512 | ✅ | 1 |
| U2 | 标题画面 / 主菜单背景 | 1920×1080（横）或 1334×750（H5） | ❌ 纯色底 | 1 |
| U3 | 主菜单按钮（开始/继续/设置/图鉴） | 单按钮 320×96，9-slice | ✅ | 4 + 悬停态 |
| U4 | Boss 顶部血条框 | 顶栏 900×60 | ✅ | 1（底板+填充分层） |
| U5 | 脚底血条 / 能量条底板 | 120×16 | ✅ | 1~2 |
| U6 | 技能 / 法宝图标 | 128×128 | ✅ | 约 12~20 |
| U7 | 货币 / 资源图标（经文碎片、金币等） | 64×64 | ✅ | 约 4~6 |
| U8 | 状态图标（中毒/燃烧/冰冻/麻痹/眩晕） | 64×64 | ✅ | 5（角色身上是代码层 colorMatrix，HUD 上要小图标） |
| U9 | 章节选择 / 地图节点 | 背景 1334×750 + 节点 96×96 | 背景❌/节点✅ | 1+81 节点 |
| U10 | 加载页 | 1334×750（H5） | ❌ | 1 |
| U11 | 结算界面（胜利/失败框） | 800×500 | ✅ | 2 |

> 尺寸是**基准**，实际导出按三端设备倍率补 `@2x`（微信小游戏/手机多为 2x）。代码层用 9-slice（九宫格）拉伸按钮/血条框，省图又适配。
> 伤害飘字、连击数等**用代码字体渲染，不产图**。

### 8.3 UI 命名 + 存档

- 命名：`UI_元素名_日期_v1.png`（例：`UI_技能图标_火咒_20260921_v1.png`）。
- 存档：归入 `02_AI生成记录/UI/` 各子文件夹 + PSD 工程入 `03_人工修图工程文件/UI/`，双备份（同 §6.4）。
