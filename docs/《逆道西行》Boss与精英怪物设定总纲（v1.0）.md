## 二、存在形态 · 逆道多形态（规则 2）

每个怪物存在**三层形态**，决定它在战斗与逆道收服时的表现：

| 层 | 名称 | 说明 | 出现场景 |
|---|---|---|---|
| L1 | **真源层（本相）** | 怪物的真实物种形（妖 / 鬼 / 精本相） | 章末 Boss 最终形态、战后显形 |
| L2 | **拟态层（人形态）** | 怪物幻化 / 伪装的人形，多数 Boss 以此欺世；**在场时唐僧飘出斥语（「悟空／八戒／沙僧，不可伤人」）→ 玩方对其伤害 −80%**（骨架 v1.19 §〇 规则 5） | 章节 Boss 第一形态、逆道收服态「·人形态」 |

### 2.1 逆道多形态规则

1. **收为逆随从后可双形态部署**：同一逆随从同时拥有 L1 本相形态（高攻 / 暴露破绽）与 L2 人形态（伪装 / **承伤 −80%** 但隐蔽），玩家可切换上场。
2. **人形态减伤 80%** 是通用规则（**统一口径＝在场人形态 → 唐僧斥语 → 玩方对其伤害 −80%**；见骨架 v1.19 §〇 规则 5、法宝钩子文档 §三 照妖镜），故「人形态」既是拟态也是战术形态——无照妖镜时人形态极难破。**注**：v1.11 起统一旧稿「出手伤害降低 80%」与「对其减伤 80%」两种互斥表述为同一回事。
3. **形态约定**：逆道收服统一呈「**·人形态**」；缘道收服多为「**·妖形态**」（兽形 / 宠物位）。**白马系例外**——白龙马 / 龙三太子标「**龙族形态**」（v1.9；见骨架 A6.5-a）。
4. **多形态连锁**：章节 Boss 的多形态（§4）与逆道多形态相互独立——Boss 战中是 Boss 的变身层数；收服后该随从按 §2.1 双形态。

## 三、怪物结局 · 由路线（六道）裁定（规则 3）

> **核心裁定法则（2026-09-20 二次修正·食人红线重定）**：**怪物若在原著中「食人」（食百姓、童男童女等，非仅觊觎唐僧肉）→ ① 禁止进入【逆】道（不配为逆随从，逆道名录剔除）；② 结局只能「死」（不可度化 / 菩萨收回 / 收编）。** 仅觊觎唐僧肉者（白骨夫人、红孩儿、沙僧等）不受此限，可走任意六道。六道路线裁定（v1.1）仍适用于非食人怪物。寅将军魔改例外（随从未死则活）保留。

### 3.1 六道路线裁决表

| 所选路线（道） | 怪物结局 | 说明 |
|---|---|---|
| **渡** | 菩萨 / 神仙收回（收徒 · 坐骑 · 星官属下） | 与原著收回者一致（观音 / 如来 / 文殊 / 普贤 / 寿星 / 太乙等） |
| **战 / 夺** | **死**（被主角团斩杀） | 金鱼精、大鹏等：不走渡而用战 / 夺 → 结局即死 |
| **逆** | 收为逆随从 | 须满足「有人性一面、值得折服」前提（见 §3.3）；**★食人怪物此路线锁定不可用** |
| **隐 / 缘** | 放归 / 结成善缘 | 不强制死，可逍遥（如黄袍怪放回天庭、部分怪结善缘） |

### 3.2 食人红线（二次修正重点）

- **食人怪物的硬判定**：大鹏（狮驼岭食一国之人）、金鱼精（食童男童女）、白鹿精（食比丘国小儿心肝）等原著明确「食人」者 → **【逆】路线锁定不可用**（不出现收随从 / 收编选项），且【缘】收编（点化 / 宠物）同样禁用；但**【渡】仍可行**（观音 / 如来 / 寿星等原主收回），【战 / 夺】＝死（不走渡则死），【隐】可绕路避免——即结局为「死 或 原主收回」二选一，与 v1.9 原则一致。
- **仅觊觎唐僧肉 ≠ 食人，不计入红线**。白骨夫人（欲食唐僧）、红孩儿（蒸食唐僧）、沙僧（前世食九世取经人）——三者只按 §3.1 路线裁决，可走渡 / 战 / 夺 / 逆 / 隐 / 缘任意路线。
- **寅将军（双叉岭）魔改例外**：剧情已对双叉岭进行魔改——**若所带随从（详见骨架 v1.17 附录 A7「随从不死·五人齐」/ A9 英雄选择）未死，寅将军亦能活**（不被斩、不被太白驱散）。保留「随从不死」是其他四英雄专属剧本的底层机制。

### 3.3 设计约束

- 走【渡】收回者**必须与原著收回者一致**（合规条款），不得自创。
- 走【逆】收为随从者，须满足「有人性一面、值得折服」前提；明显无可救药者不入逆道名录。
- 结局须与劫难所选路线**自洽**：同一难不同路线可得不同结局（死 / 收回 / 逆收 / 放归），正文按此回写。

### 3.4 逆道「杀 / 收」二选一 · 精魄（v1.6 新增 · 用户拍板）

走【逆】、以纯实力折服怪物后，**末段二选一**：

| 选项 | 怪物结局 | 玩家产出 | 代价 |
|---|---|---|---|
| **收** | 收为逆随从 | 逆随从（计入逆兽 / 逆经，可转职） | 无 |
| **杀** | 死 | **精魄**（新资源）＋ 自身属性成长 | **＋心魔**；断该兽的逆兽 / 转职计数 |

- **精魄**＝逆道专属资源：击杀折服之妖所得之「精魂」，用于自身属性强化（逆道成长线）。
- **【战】道斩杀不加心魔**——战为「怪该死」的正义斩杀，无额外心魔；**唯【逆】捕而杀**（本可折服却为精魄反手屠之）方＋心魔。
- **形态约定**：逆道所收＝**人形态**（统一）；缘道所收＝多为**妖形态**（兽形 / 宠物位）。详见骨架 A6.5。
- 食人红线不受影响：食人怪【逆】本已禁用（见 §3.2）。
- **悟空特例（v1.8）**：悟空走【逆】**默认全杀**（捕则不收）——其逆道＝以杀止杀；转职改由「**杀心魔**」触发（心魔满值章末具现「心魔 · 悟空」镜像战，**照妖镜无效**，斩一次转一阶；见骨架 A6.8）。

## 四、怪物形态 · 变身层数（规则 4）

### 4.1 总则

- **基础标准＝妖 / 人双形态**。所有章节 Boss 的基础结构为「人形态（伪装 / 混入）→ 妖形态（现本相）」两形态；这是美术与战斗的底层骨架，多数 Boss 仅需两套独立美术资产。
- **第三态＝粒子增强，不做第三套美术**。需要「三段层次」的 Boss，其三形态**不在妖形态之外另绘新美术**，而是在「妖形态（二段）」基础上叠加特殊粒子 / 特效层实现（如黄风怪三阶段的「黄沙护体」即画沙粒子护盾）。美术成本 = 2 套资产 + 1 层粒子，而非 3 套资产。
- **多怪物章节：降为双形态（人 → 妖）即可**。一章内多个独立 Boss（车迟国三仙、狮驼岭三魔、三只犀牛）每个只做两变，避免时长爆炸与数值堆叠。
- **人身妖怪**：多数 Boss 本是「人身妖怪」，第一形态即人形态，变身即「褪去人皮现本相」，天然契合双形态；其「三戏 / 三变」由**同人形 base 的年龄 / 配色变体**或**妖形上的粒子层**低成本实现，而非重绘。

### 4.3 美术成本原则（双形态 + 粒子增强）· 标准范例

> **原则**：章节 Boss 的美术资产上限＝**两套**（人形态 / 妖形态）。所谓「第三形态」一律通过**在妖形态上叠加粒子 / 特效层**实现，不新增独立立绘。这同时满足「三段变身」的战斗层次感与可控的美术成本。

**范例一 · 黄风怪（双形态 + 黄沙护体粒子层）**——形态与机制详见 §4.2 / §5.3：

| 阶段 | 形态 | 美术资产 | 机制 |
|---|---|---|---|
| 1 | 人形态（黄风岭妖伪装） | 人形 | 普攻；打败后进入 2 形态 |
| 2 | 妖形态 | 妖形 | 技能「吹沙」→ 给玩家上 MISS debuff；玩家用**定风珠**清除异常＋得「定风」增益 buff；此后怪物再放吹沙无效、头顶冒「？」、该回合结束 |
| 3 | 妖形态·黄沙护体 | 妖形 ＋ **画沙粒子护盾层** | 剧情后进入；开局「黄沙护体」减伤（护盾）；吹沙照常可用、**不影响定风珠**效果；吹沙被定风珠 counter 时**仍冒「？」回合结束（与形态2一致）**——逆道需无宝通关、定风珠为降难核心；护盾打破则视觉回落为 2 形态（妖形无粒子），但仍是 3 阶段血量与机制 |

- 资产合计：人形 1 ＋ 妖形 1 ＋ 粒子层 1 ＝ 2 套立绘，符合成本上限。
- 定风珠在第 2 阶段是「counter 吹沙」的核心钩子；第 3 阶段护盾独立于风系，定风珠仍清 debuff 但不破盾，**破盾靠玩家爆发伤害**。

**范例二 · 白骨夫人（同 base 变体 + 现成妖形）**：

- 人形态三变体＝**少女 / 老妪 / 老翁**，全部复用同一「人形 base」做年龄 / 配色 swap，零新增立绘成本，且正好对应「三戏白骨精」剧情。
- 妖形态＝**白骨夫人**（现成 sprite ＋ 一段额外施法动作），无需重绘第四套。
- 资产合计：人形 base 1 ＋ 妖形（白骨夫人）1 ＝ 2 套，三戏与真身均由变体 / 动作层表达。

> **其余章节 Boss 同模型**：红孩儿（火甲粒子）/ 青牛精（金刚琢无敌粒子）/ 六耳（镜像粒子）/ 牛魔王（芭蕉扇风暴粒子）/ 九灵（断岳法相粒子）等，均为「人形 → 妖形（本相）＋ 妖形上的粒子 / 特效层」，具体粒子层在各章正文落地（参见 §4.2 变身规划表「双形态＋粒子增强（三态）」标注）。

## 五、特有技能与法宝破除钩子（规则 5）

### 5.1 技能设定原则

1. **符合原著**：每个 Boss 的技能必须源自原著描写（黄风怪之风、红孩儿之三昧真火、牛魔王之芭蕉扇、六耳之听音辨形、九灵之「一声断岳」等），不得凭空捏造。
2. **特殊法宝设定**：Boss 的本命法宝须与原著一致（金刚琢、芭蕉扇、金铙、阴阳二气瓶、倒马毒桩等），详见《法宝钩子系统 v1.2》§二~§三。
3. **技能随形态解锁**：变身层数即技能层数——人形态用伪装 / 小技能，本相 / 魔相解锁终极技能（如九灵第三形态才放「一声断岳」）。

### 5.2 法宝破除钩子范式

参照三种经典钩子范式，每个章节 Boss **必须绑定至少一个破除法宝钩子**：

| 范式 | 原型 | 机制 | 适用 Boss |
|---|---|---|---|
| **定风珠型** | 定风珠破黄风怪三昧神风 | 「环境系 / 全屏 AOE」类技能，无对应珠则伤害无解，持珠即破 | 黄风怪（风）、牛魔王（芭蕉扇风火）、铁扇公主 |
| **照妖镜型** | 照妖镜破白骨夫人幻化 | 「变化 / **人形态**」类技能——**人形态在场即唐僧斥语 → 玩方伤害 −80%**；无镜则人形态（白骨夫人另有假死无限复活），持镜即破 | 白骨夫人、青狮（乌鸡国）、黄袍怪 |
| **避水珠型** | 避水珠破金鱼精水遁 | 「水盾 / 潜水 / 水系」类技能，持珠破除减伤 / 追入水域 | 金鱼精、鼍龙、三只犀牛、九头虫 |

## 附录 D · Boss 专属技能系统（v1.0 · 2026-09-21 实现）

### D.1 系统概述

Boss专属技能系统为《逆道西行》所有Boss和精英怪物提供独特的战斗技能，使每个Boss都有鲜明的战斗特色和策略深度。系统包含：

- **25个章节Boss**：每个Boss拥有2-5个专属技能
- **11个精英怪物**：每个精英拥有1-3个专属技能
- **9个区域属性传染**：每个章节的小怪和精英附带该章节章末Boss的低配版属性
- **18种技能类型**：DOT/护盾/缴械/眩晕/致盲/吸血/遁形/魅惑/召唤/终极/多段/重击/防御/回血/增益/被动/阶段

### D.2 技能触发机制

- **基础触发概率**：30%（每回合检查一次）
- **低血增强**：血量≤50%时触发概率提高到40%，≤30%时提高到50%
- **阶段限制**：stage=2技能仅血量≤50%可触发，stage=3仅≤30%可触发
- **教学战例外**：tutorial标记的怪物不触发专属技能（保持教学节奏）

| 控制类型 | 效果 | 代表技能 |
|----------|------|----------|
| **眩晕（stun）** | 玩家跳过回合，无法攻击或使用法宝 | 青牛精·独角冲撞 |
| **缴械（disarm）** | 玩家无法物理攻击，但法宝仍可使用 | 青牛精·金刚琢 |
| **魅惑（charm）** | 玩家下回合攻击自己 | 蝎子精·琵琶曲 |

### D.8 设计原则

1. **原著还原**：技能设计源自《西游记》原著，如红孩儿的三昧真火、青牛精的金刚琢
2. **策略深度**：每个Boss有独特的技能组合，玩家需要针对性地选择法宝和策略
3. **区域一致性**：小怪和精英附带区域Boss的低配版属性，保持章节战斗风格统一
4. **渐进难度**：低血时触发概率提高，阶段技能限制，使Boss战有紧张感和节奏感
5. **克制关系**：部分技能可被特定法宝克制（如定风珠克制飞沙走石）

### D.9 后续优化方向

1. **技能图标**：为每个Boss专属技能设计独特的图标
2. **技能特效**：为Boss专属技能添加独特的视觉特效
3. **数值调优**：根据实机测试结果调整技能触发概率和效果强度
4. **技能配音**：为Boss专属技能添加语音配音
5. **成就系统**：添加与Boss专属技能相关的成就（如"识破三昧真火"）
