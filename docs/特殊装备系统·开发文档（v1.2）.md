# 《逆道西行》特殊装备系统 · 开发文档
> ⚠ **难号与落点真源 = 《逆道西行》81难骨架·攻略总表（v1.6）**；本文件与之冲突时，以骨架总表为准。

> 本文档为《逆道西行》游戏的特殊装备系统完整设计，包含所有特殊装备的名称、来源、升级路径、属性效果、获取劫难等。
> 核心设计：特殊装备通过击杀特定妖怪获取材料升级，每件装备有独立的升级路径，升级材料均来自原著劫难。

---

## §〇 · 路线归属：黑暗隐藏路线（2026-09-25 用户拍板）

> 用户原话：**「虎皮裙，包括黑熊精袈裟，原来设计就是英雄走黑暗隐藏路线设计的。」**

| 线 | 英雄 | 链首 | 路线 | 黑暗属性 |
|---|---|---|---|---|
| **虎皮裙** Lv.1→Lv.4 | 悟空 | 难 6 双叉岭「扒皮做裙」 | 【**夺**】 | 链首恶 +10；走的是**剥皮做衣**的暗线 |
| **黑熊精袈裟** | 唐僧 | 难 6 黑风山（代码 `tre_nishang` 锦襕袈裟·夺） | 【**夺**】 | 从黑熊精怀里抽走它唯一的体面；恶 +12 |

⇒ 两条线的**共同设计语言**（＝「黑暗隐藏路线」的定义）：

1. **只走【夺】可得** —— 不夺就没有，与六道的正线（渡／缘）互斥；
2. **恶业入账** —— 每次获取都加恶值，「黑暗」是量化在 `alignEvil` 上的；
3. **链式门控**（骨架 v1.16 §〇 规则 4）—— 首环未取 ⇒ 后续 Lv.2/3/4 **永久关闭**，是隐藏路线的单向门。

⚠ 由此**修正审计报告 P4 的判定**：「虎皮裙系列完全未落地」**不是遗漏** —— 它属**黑暗隐藏路线的设计内容**，与常规装备线（兵刃／甲胄／头冠／战靴）不属同一批；落地优先级由内容排期决定，**不计入常规装备缺口**。

## 一、虎皮裙系列（孙悟空专属）🐯

孙悟空的标志性装备，通过击杀虎豹类妖怪获取皮毛升级。共4个等级，升级材料均来自原著劫难。

### Lv.1 虎皮裙

| 属性 | 内容 |
|------|------|
| **获取劫难** | **第5-7难·双叉岭（寅将军）· 夺路线「扒皮做裙」**（**唯一链首入口**；**不产自第13难**——第13难只作升级） |
| **获取方式** | **夺路线**：难6 战胜寅将军后「**扒皮做裙**」（恶+10）剥取虎皮。**链首物**——未取则整条升级链（Lv.2 / Lv.3 / Lv.4）**永久关闭**（链式门控 · 骨架 v1.16 §〇 规则 4） |
| **装备效果** | 物理防御+10%，暴击率+5% |
| **原著依据** | 原著中孙悟空在双叉岭打死老虎，用虎皮做了裙子 |
| **描述** | 用猛虎之皮制成的战裙，虽简陋但透着野性。 |

### Lv.2 虎先锋皮裙

| 属性 | 内容 |
|------|------|
| **升级材料** | 虎先锋皮（**第13难**·黄风岭虎先锋 · **夺路线**） |
| **获取方式** | 第13难 **夺路线**「夺取虎皮」（恶+10）后剥取虎皮，与 Lv.1 虎皮裙合并升级（**前置**：已持虎皮裙 Lv.1；未持则本项**永不再现**） |
| **装备效果** | 物理防御+20%，暴击率+10%，速度+5% |
| **原著依据** | 虎先锋是黄风怪麾下第一先锋官，虎皮更坚韧 |
| **描述** | 加入虎先锋之皮的战裙，防御力大增，虎虎生风。 |

### Lv.3 豹纹虎皮裙

|------|------|

| **获取方式** | **战路线**击杀南山大王后剥取豹皮，与 Lv.2 虎先锋皮裙合并升级（**前置**：已持 Lv.2；链式门控） |

### Lv.4 百兽战裙（终极形态）

## 七、设计说明 📝

### 设计亮点

1. **原著依据**：所有升级材料均来自原著劫难中的妖怪，不凭空捏造
2. **升级路径清晰**：每件装备有明确的升级路径和材料来源
3. **跨章节联动**：虎皮裙的终极升级需要狮驼岭材料，形成跨章节收集目标
4. **专属装备**：悟空、八戒、沙僧、唐僧各有专属装备，角色差异化
5. **终极形态有特殊被动**：每件装备的终极形态都有独特的被动技能

### 虎皮裙升级说明

- **Lv.1**：双叉岭寅将军（**第5-7难 · 难6 · 夺路线「扒皮做裙」**）剥取虎皮 —— **链首物，唯一入口**（**第13难不产 Lv.1**）
- **Lv.1→Lv.2**：黄风岭虎先锋（**第13难 · 夺路线**）剥取虎皮
- **Lv.2→Lv.3**：隐雾山南山大王（**第71难 · 战路线**）获取豹皮
- **Lv.3→Lv.4**：狮驼岭三魔（**第61-64难 · 战路线**）集齐狮鬃、象皮、鹏羽合成百兽战裙

**注意 ①**：狮驼岭（第61-64难）在隐雾山（第71难）之前，所以玩家在到达隐雾山时已经可以获取狮驼岭材料，但需要先到达隐雾山升级到 Lv.3 后才能合成 Lv.4。这形成了"先收集材料，后合成终极"的收集乐趣。
**注意 ②（链式门控）**：**放弃链的第一次选择 = 放弃整条链**——若第 5-7 难未走「夺 · 扒皮做裙」取得 **虎皮裙 Lv.1**，则第 13 难「虎先锋皮裙 Lv.2」**不再出现**，第 71 / 61-64 难升级一并**永久关闭**（骨架 v1.16 §〇 规则 4）。

### 设计原则

1. 特殊装备升级材料必须来自原著劫难
2. 每件装备最多升级3次（4个形态），避免过度膨胀
3. 终极形态必须有独特的被动技能
4. 升级材料可以跨章节获取，形成收集目标
5. 专属装备与角色特点匹配（悟空=虎皮裙暴击、八戒=九齿钉耙破甲、沙僧=降妖宝杖水系、唐僧=锦襕袈裟防御回复）
