# 《逆道西行》八十一难 · 骨架总表 / 攻略索引（v1.19）

> **这是什么**：全 81 难的**结构骨架 + 玩家攻略**二合一。每一难只记「怎么选 → 走向哪 → 得什么 → 判归哪道」，不写叙事文本、不写战斗数值。
> **这不是什么**：**不是叙事文本载体**。台词、战斗细节、设计说明仍写在各章正文里；但**结构 / 选项 / 流向 / 产出 / 六道判定 / 劫印档位以本表为最终真源**，正文按本表调整。
> **为什么要它**：① 玩家查攻略——想走某条道，看该在哪一难怎么选、拿什么；② 设计调整——**改结构只动本文件，改文本才进正文**，避免在万字长文里反复翻找。
> **维护约定（2026-09-18 用户拍板 · 真源反转）**：**本表 = 最终真源**。任何一难的结构、选项、流向、产出、六道、劫印档位变动，一律以本表为准；**九章正文与一切旧稿（各章整理版 / 旧系统文档 / 旧分析报告）须据此回写**。旧稿与新稿冲突，以新为准。

   - **事件链**：多阶段事件链的**第一次选择**若未触发，则**后续事件整体关闭**（如 15-16 难「夺 · 见宝起意」未选 → 「后续哪吒隐藏事件关闭」；黄风岭「灵吉记恨」→ 47-49 难灵吉闭门不助）。

5. **人形态减伤 · 唐僧斥语（v1.19 新增 · 用户拍板）**：**所有人形态怪物**（拟态层 L2：妖 / 精 / 鬼幻化人形、神佛参与者）在场时，**唐僧会飘出一句斥语**——点名当前出手的徒弟（**「悟空，不可伤人」／「八戒，不可伤人」／「沙僧，不可伤人」**，视出战者而定；主角即唐僧时改为自语同句）——**玩方随即获得 debuff「不可伤人」：对该目标造成伤害 −80%**（等价表述：该人形态单位**减伤 80%**）。
   - **破法二选一**：① **照妖镜**（照破本相 → 转 L1 本相 · 伤害恢复；**破幻后该难【逆】关闭**）② **唤土地山神作证**（渡线 · 每次**耗寿 10 天**）。

   - **逆随从的「·人形态」属同一层**：作**战术姿态**可切 L1 本相上场（A6.5）。
   - 本规则**统一**旧稿两种互斥表述（「出手伤害降低 80%」＝「对其减伤 80%」）——**一律指玩方对该人形态目标的伤害 −80%**。

## A7. 随从不死 · 五人齐机制 / 八戒情缘路线特殊结局（v1.9 新增，2026-09-20）

> 上位：本表 §〇、A5 双轨转职、A6 五类怪物分类。本附录定义「取经人初始构成」与「八戒专属情缘结局」，是正文与《Boss 与精英怪物设定总纲 v1.2》§3 的底层剧情锚。

### A7.1 初始五人 · 随从不死机制

- **取经人初始构成**：除唐僧外，**其他四位初始英雄（悟空 / 八戒 / 沙僧 / 白马）亦从长安出发，且各自带一名随从**（长安随行）。
- **随从不死（魔改原则）**：剧情保留「**随从不会死**」的设定——这是为四位英雄专属剧本（独立剧情线）预留的底层机制。随从一旦在途中阵亡，则该英雄专属剧本断裂。
- **两界山 · 残魂交流**：若某英雄的随从**未死**抵达**两界山（五行山）**，该随从会与山中**残魂**（取经人前世 / 悟空被压残魂，视剧本而定）交流，**回复唐僧身份 / 补全取经人阵容**。
- **五人齐**：理论上，只要随从全数存活，取经团在途中即可凑齐**五人**（唐僧 + 四英雄），形成「五人齐」的完整阵容状态，后续章节按此展开。
- **例外印证**：双叉岭寅将军（5-7）即依此魔改——随从未死则寅将军亦活（详见《Boss 与精英怪物设定总纲 v1.2》§3.2）。

### A7.2 八戒专属 · 情缘路线特殊结局

> 八戒转职路线（缘）的终局设计：放所有人去其「情缘」，自身独行取经，终以「撒魂残驱＋随从」成特殊结局链。

- **情缘散场（途中触发）**：
  - 悟空 → **与白晶晶同回花果山**（难 20【缘】线触发，见第二章第 20 难；白骨夫人平时「人形态」，归山现「**妖形态**」，返队时即为妖形态）
  - 八戒 → 留**高老庄**；离去时**分出一魂一魄随嫦娥而去**（缘线结局 · 情根未断）
  - 唐僧 → 留**女儿国**
  - 沙僧 → 回**流沙河**了结执念：取下颈上九个骷髅，一一沉入河中——那九次西行都断在这条河上，他守的从来不是河，是「替第九个人走完第十次」的执念；今执念既了，河自平（沙僧本相＝流沙河主 · **鬼怪**）
  - 白马 → 归**西海**：化龙身入海，却**不受那副鞍**——这一回是他自己走回去的，不是被谁牵回去的（白马本相＝西海孽龙 · **精怪**；呼应逆兽「玉龙 · 未受鞍 · 不回龙宫 · 不受那副鞍」）
- **逆线对照（不冲突）**：若此行以【逆】为主，则至 **78 天竺国 · 嫦娥亲自现身揭穿**——「嫦娥」原本只是**王母设下的一个套**；八戒闻言**大彻大悟**，情关自破，反走出去走自己的逆道。与缘线「一魂一魄随嫦娥去」各自成立、互不排斥。
- **独行取经**：情缘散尽后，**八戒成为唯一继续西行取经者**。
- **凌云渡 · 撒魂**：至**凌云渡**，八戒**撒去自身魂魄**，只余**残驱**随一名随从渡过，面见如来。
- **真经带回**：取得真经后，**由随从（来福）将经卷带回长安**，形成「八戒撒魂、随从传经」的特殊故事链结局。
- **叙事意义**：此结局解释「为何保留唐僧」——唐僧留女儿国，取经使命由八戒一脉以「残驱＋随从」方式完成，呼应「五人齐」中唐僧身份在两界山被随从补全的设定。

### A7.3 设计约束

- 随从不死是**全局底层机制**，影响四英雄专属剧本；任一随从死亡须有独立剧情补偿（不强行续写专属线）。
- 八戒情缘路线属**逆 / 缘 双轨可触发的特殊结局**，不与常规通关结局冲突，作为「故事链特殊结局」单列。
- 沙僧 / 白马两端情缘**已于 A7.2 补完**（沙僧＝流沙河执念了结、白马＝西海归位不受鞍）——四方情缘散场**五端齐全**，八戒情缘路线**无占位遗留**。
