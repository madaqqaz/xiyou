2. **去水印工具（优先级）**：

   - ② 本地 `python3`（已装 3.13.12）+ `pillow`（**当前未装**，`pip install pillow` 即可）→ 区域 inpaint/贴补。
   - ③ ⚠ 本机 `which convert` 命中的是 `C:\Windows\System32\convert`（**磁盘格式转换**，**不是 ImageMagick**）—— **不可当图像工具用**。
3. **去水印后重编码为 `.webp`**，保持文件名与路径不变（避免动数据映射）；`bg.webp` 等大图注意保清晰度。
4. **三端发布前必须全清**（team-lead 判定为上架阻断项）；`img/bg.webp` 与 `boss_liuhong` 优先（曝光最高）。

### 1.5 全量复核脚本（发布前跑一次）

```python
# python3 scripts/_wm_scan.py   （需 pip install pillow；有 tesseract 时自动 OCR）
import glob, os, shutil
from PIL import Image
try:
    import pytesseract; HAS_OCR = True
except Exception:
    HAS_OCR = False
HITS = []
OUT = 'docs/_wm_review'; os.makedirs(OUT, exist_ok=True)
for p in glob.glob('img/**/*.webp', recursive=True):
    im = Image.open(p).convert('RGB'); w, h = im.size
    crop = im.crop((int(w*0.70), int(h*0.86), w, h))   # 右下角水印常驻区
    hit = False
    if HAS_OCR:
        txt = pytesseract.image_to_string(crop, lang='chi_sim+eng')
        hit = any(k in txt for k in ('AI生成', 'AI', '即梦', '生成式'))
    if hit:
        HITS.append(p)
    # 无 OCR 时：导出裁片供人工速览（每 60 张拼一张 contact sheet）
    crop.save(os.path.join(OUT, os.path.basename(p).replace('/', '_') + '.png'))
print('OCR 命中', len(HITS)); [print(' -', x) for x in HITS]
```
