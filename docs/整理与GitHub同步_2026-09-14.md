## 四、⚠️ 发现并修复：标题页 / 长安场景全程无 BGM

### 根因
`js/sound.js` 的 BGM `onerror` 回退链**只有一步**：
```
bgm_X_seed.wav  →  bgm_X_ai.ogg
```
而 **`title` / `home` 两场景连 `_ai.ogg` 都不存在**（磁盘只有 8 个 `_ai.ogg`：
map/fight/boss/event/shop/rest/ending/hidden）。触发点都是真实可达的：
- `js/ui/ui_core.js:167` → `music('title')`（主界面）
- `js/ui/ui_core.js:217` → `music('home')`（长安主城）

### 同时纠正我上一提交的误判
`41d7b83` 把 `bgm_{title,home,map,fight,boss}.ogg` 一并归档，理由写作「已被 `_ai.ogg` 取代」。
复核后：该理由对 map/fight/boss 成立，**对 title/home 不成立** —— 那两条 ogg 是全项目
**仅有的**标题/主页配乐（五者 md5 互不相同，非占位音频）。已复原回 `demo/assets/sound/`。

### 改法（兼容「Seed Audio 1.0」计划，不构成补丁式开发）
回退链改为**候选链依次尝试**，并加防自环保护：
```
_seed.wav → _ai.ogg → 旧版裸名.ogg → 旧版裸名.mp3
```
一旦后续 `bgm_X_seed.wav` 到位即优先播放，**与既有计划不冲突**。

### 验证（三端一致）
| 环境 | 请求序列 | 运行时 | 异常 |
|---|---|---|---|
| 本地 HTTP | 404 seed.wav → 404 _ai.ogg → **200 `.ogg`** | `audio.src = bgm_title.ogg` | 0 |
| **线上 Pages（关缓存 CDP）** | 404 seed.wav → 404 _ai.ogg → **206 `.ogg`** | `audio.src = bgm_title.ogg` | 0 |

（206 = 真的在流式播放。）门禁 `31/31 全绿`；`index.html` 中 `sound.js ?v=380 → 381`。
