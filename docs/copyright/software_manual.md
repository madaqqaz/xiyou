## 一、软件概述

《逆道西行》是一款以《西游记》为蓝本进行黑暗化重构的**单局 Roguelike（肉鸽）构筑类单机游戏**。玩家扮演踏上"逆道"的取经人，在八十一难的十字路口之间辗转抉择，通过地图探索、回合与即时混合战斗、装备/劫印/经文构筑与六道转职，逐步走向 10 种截然不同的结局之一。

软件采用纯前端架构，核心玩法代码（`js/`）、样式（`css/`）与入口（`index.html`）在浏览器 H5、微信小游戏、TapTap 买断版三端共享，通过 `platform/` 适配层隔离存档、支付、分享等平台差异。游戏不依赖任何后端服务器，全部进度存储于本地。

## 二、运行环境与安装

### 2.1 硬件环境
- 桌面端：x86 / x64 个人计算机，建议 4GB 以上内存。
- 移动端：iOS / Android 智能手机或平板。

### 2.2 软件环境
- **浏览器端**：Chrome / Edge / Firefox 等现代 Chromium 内核浏览器，直接双击 `index.html` 即可运行（推荐通过本地 HTTP 服务器访问，以获得最佳缓存与性能表现）。
- **微信小游戏**：在微信客户端内通过小游戏入口运行，使用 web-view 承载 H5 核心，并经微信 JS-SDK 对接平台能力。
- **TapTap 买断版**：在 TapTap 客户端内运行，启动时验证买断状态，支持完全离线游玩。

### 2.3 安装
- 浏览器端：无需安装，打开网页或加载本地文件即可游玩。
- 微信小游戏 / TapTap：通过对应应用商店搜索"逆道西行"下载安装。

## 三、功能介绍

### 3.1 主界面与开始游戏
启动后进入开始界面，提供"开始新游戏 / 继续游戏 / 规则说明"等入口。首次进入可选择开局种子，跨周目进度自动通过本地存档恢复。

### 3.2 英雄选择系统（5 位可操英雄）
开局可从 5 位英雄中择一，每位英雄拥有独立立绘、初始属性、专属剧情与专属结局：
1. **孙悟空**
2. **取经人（唐僧）**
3. **猪八戒**
4. **小白龙**
5. **沙僧**

### 3.3 六道转职系统
游戏进程中，英雄可在"六道"方向之间抉择转职，解锁截然不同的战斗流派、天赋与技能路线；部分转职为隐藏路线，需满足特定条件触发。

### 3.4 地图探索（9 章 17 地区）
单局以"章—地区"为单位推进，共 **9 章、17 个地区**。地图为节点网状结构，玩家在岔路口选择前进方向，不同地区遭遇战斗、事件、商店、休整、宝库等不同类型节点。

### 3.5 战斗系统（回合策略 + 即时操作混合）
- 采用回合策略与即时操作混合的战斗表现。
- 包含**气势爆发**、**QTE 抉择**、**随从钦点**等交互机制。
- 怪物具备行为模式循环、技能池加权释放、低血量阶段切换、技能预告等 AI 行为。
- 战斗数值、技能、buff 由核心数据层统一驱动。

### 3.6 八十一难事件系统（网状叙事 · 10 结局）
- 共 **81 难**事件节点，采用网状叙事，支持复合选项与多分支。
- 玩家的善/恶（good/evil）倾向、阵营（camp）、命运（fate）、抉择标记（choiceFlags）持续累积。
- 最终依据上述状态动态判定结局，共 **10 种结局**（如：灵山逆座、六耳同修、长安还俗、万宝归一、万法皆空、战佛临世、缘定三生、金蝉正果、一魄转世、逆道西行）。

### 3.7 构筑系统（装备 / 劫印 / 经文）
- **装备**：通过战斗与事件获取装备，词条可叠加形成流派。
- **劫印**：获取劫印词条，强化特定战斗机制。
- **经文**：收集并排列经文，构筑成阵，形成体系化加成。
- 三者相生相克，构成每局差异化的 Build 核心。

### 3.8 存档与跨周目系统
- 单局进度自动保存至本地（浏览器 `localStorage` / 微信存储 API / TapTap 本地存储，经 `NDX.Platform` 适配层统一读写）。
- 支持跨周目论道、轮回强化与成就解锁，多周目间保留永久性成长。

## 四、操作说明

| 操作 | 鼠标（桌面端） | 触屏（移动端） |
|---|---|---|
| 选择节点 / 选项 | 单击 | 点按 |
| 确认 / 开始战斗 | 单击按钮 | 点按按钮 |
| QTE 抉择 | 限时内单击对应按钮 | 限时内点按对应按钮 |
| 查看背包 / 角色 | 单击对应图标 | 点按对应图标 |
| 横屏适配 | 自动 | 自动旋转 / 强制横屏布局 |

- 全游戏以"点按 / 单击"为主，无复杂键盘操作。
- 移动端默认强制横屏显示，保证战斗与地图布局完整。
- 游戏内可随时通过界面按钮查看规则说明。

## 六、技术特点

- **零依赖**：纯原生 HTML + CSS + JavaScript，无任何第三方运行时框架或引擎。
- **三端共享**：核心代码库三端一致，平台差异经 `platform/` 适配层隔离。
- **单机离线**：无后端、无网络数据收集，数据仅存本地。
- **可复现**：版本号缓存机制保证发布一致性。
