# 《逆道西行》隐私政策

> 适用版本：V8.5x 及后续版本
> 更新日期：2026-09-01
> 运营主体：【待填：公司/个人主体名称与联系方式】

## 一、总则

《逆道西行》（以下简称"本游戏"）是一款单局 Roguelike 肉鸽构筑类游戏，目前以纯前端 H5（浏览器）、微信小游戏、TapTap 买断版三种形态提供。本游戏尊重并保护用户（以下简称"您"）的隐私，依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》及相关法律法规制定本政策，向您说明本游戏对个人信息的处理方式。

## 二、我们收集的信息

本游戏为**单机离线游戏**，无账号体系、无后端服务器、无网络排行榜（TapTap 排行榜除外）。

1. **本地存档与设置**：游戏进度、成就、设置（音效/战斗速度等）仅保存在您的设备本地（浏览器 `localStorage` / 微信小游戏存储 / TapTap 本地存储）。**不会**上传至任何服务器。
2. **设备标识**：为区分本地存档与功能需要，本游戏可能在本机生成并使用本地随机标识。该标识仅存于本机，不对外传输。
3. **平台 SDK**：当您通过微信小游戏或 TapTap 游玩时，对应平台（腾讯微信、TapTap）的 SDK 可能按其自身规则处理与平台账号、实名认证、支付相关的信息。此部分由**平台方**的隐私政策管辖，请您查阅对应平台的隐私政策。
4. **崩溃与日志**：本游戏不主动收集崩溃日志。

## 三、我们如何使用信息

- 仅用于在您的设备本地实现存档读写、成就解锁、设置保存等游戏功能。
- 不用于广告定向、用户画像、跨应用追踪。

## 四、信息的存储与保护

- 所有本地数据存储在您的设备上，由您设备自身的安全机制保护。
- 本游戏不建立任何个人信息数据库，因此不存在个人信息泄露至第三方的风险源。

## 五、您的权利

- 您可以随时在游戏内【设置 → 重置全部存档】清除全部本地数据。
- 您也可以手动删除浏览器站点数据 / 微信缓存 / TapTap 本地数据以清除存档。

## 六、未成年人保护

本游戏包含黑暗、暴力及宗教思辨类剧情，**建议年满 16 周岁**游玩。根据国家相关规定，微信小游戏平台将接入防沉迷与实名认证体系；未满 18 周岁的用户应遵守平台的防沉迷规则，并建议在监护人指导下使用。

## 七、政策更新

本政策如有更新，将在游戏内【关于】面板展示最新版本。重大变更将显著提示。
