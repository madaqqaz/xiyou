> 设计版本：v1.0
> 最后更新：2026-09-20
> 对应章节：第三章 · 平顶山莲花洞

---

## 一、角色背景与定位

### 1.1 原著身份
- **金角大王**：太上老君看守金炉的童子，下凡为妖
- **银角大王**：太上老君看守银炉的童子，下凡为妖
- **据点**：平顶山莲花洞
- **法宝**：紫金红葫芦（金角）、羊脂玉净瓶（银角）、芭蕉扇、七星剑、幌金绳

### 1.2 游戏定位
- **章节**：第三章Boss（双Boss战，可单独出现也可同时出现）
- **难度**：中高，考验玩家对法宝的应对
- **特色**：法宝系施法，喊名收人机制
- **美术策略**：金角银角造型完全一致，仅颜色（金/银）和法宝不同，节省50%美术资源

## 二、形态设计

### 2.1 形态分类决策

| 方案 | 形态数 | 帧数 | 优点 | 缺点 |
|------|--------|------|------|------|
| **方案A：单形态（纯妖）** | 1 | 25帧×2=50帧 | 最省资源，符合总纲原设定 | 缺少身份反差，童子身份不体现 |
| **方案B：双形态（人+妖）** ⭐ | 2 | 50帧×2=100帧 | 有身份反差，符合原著童子下凡设定 | 美术量翻倍 |
| **方案C：双形态+省量优化** ⭐⭐ | 2 | 人形态共享框架+妖形态完整 | 兼顾反差与省量 | 人形态动作略简 |

**推荐方案C**：人形态动作框架共享（待机/受击/死亡共用，只重做攻击+施法），妖形态完整25帧。

### 2.2 人形态（炼丹童子）

#### 金角童子
| 项目 | 设计 |
|------|------|
| **整体** | 少年道童，约15-16岁，面容清秀但带邪气 |
| **头部** | 黑发束成道髻，金色发簪，额间有金色火焰印记 |
| **服装** | 金色道袍，内衬白色中衣，腰系金色丝绦，足蹬云履 |
| **配饰** | 胸前挂金色八卦护符，袖口有金色火焰纹 |
| **法宝** | 紫金红葫芦（暗红色葫芦，金色符文，挂在腰间） |
| **气质** | 高傲、自信，带着仙童的优越感 |
| **点缀色** | 金色（#FFD700）+ 暗红（#8B0000） |

#### 银角童子
| 项目 | 设计 |
|------|------|
| **整体** | 少年道童，约15-16岁，面容清秀但带阴郁 |
| **头部** | 黑发束成道髻，银色发簪，额间有银色月轮印记 |
| **服装** | 银色道袍，内衬白色中衣，腰系银色丝绦，足蹬云履 |
| **配饰** | 胸前挂银色八卦护符，袖口有银色水波纹 |
| **法宝** | 羊脂玉净瓶（白色玉瓶，银色符文，挂在腰间） |
| **气质** | 沉稳、阴鸷，比金角更有心计 |
| **点缀色** | 银色（#C0C0C0）+ 月白（#F0F8FF） |

#### 人形态动作设计（框架共享）
| 动作 | 帧数 | 金角/银角差异 |
|------|------|---------------|
| 待机 | 4帧 | 共享框架，仅颜色/法宝不同 |
| 攻击 | 6帧 | 各自独立（金角用七星剑，银角用手掌法术） |
| 施法 | 6帧 | 各自独立（金角用葫芦，银角用净瓶） |
| 受击 | 3帧 | 共享框架 |
| 死亡 | 6帧 | 共享框架（死亡时现出妖气，道袍碎裂） |

**人形态合计**：共享13帧 + 独立12帧 = 25帧/人（实际新增约15帧/人）

| **盔甲** | 金属盔甲，肩甲、胸甲、臂甲、腿甲齐全，盔甲上有狐纹装饰 |

| **手脚** | 兽爪手脚，指甲锋利，足蹬战靴 |
| **烟雾** | 金色/银色烟雾缭绕全身 |

### 2.4 第三形态决策

| 方案 | 说明 | 推荐 |
|------|------|------|
| **无第三形态** | 人→妖两阶段，符合原著 | ⭐ 推荐 |
| **第三形态：九尾妖狐真身** | 妖形态+九尾全开粒子层 | 可选，省量方案 |

**决策：不设独立第三形态**。理由：
1. 金角银角在原著中没有明确的三段变身
2. 双形态（童子→妖王）已经有足够的身份反差
3. 节省美术资源，优先保证质量
4. 如后续需要强化，可用代码实现"九尾全开"特效（尾巴全部展开+全身泛光），不额外出图

## 四、施法动作详细设计（法宝系）

### 4.1 法宝系施法6帧通用流程

```
祭出法宝 → 法宝升空 → 法宝发光 → 法宝攻击 → 法宝回收 → 收势
```

### 4.2 金角施法（紫金红葫芦）

| 帧 | 动作 | 细节 |
|----|------|------|
| 1 | 祭出法宝 | 左手将紫金红葫芦从腰间解下，举到胸前，右手掐诀指向葫芦 |
| 2 | 法宝升空 | 葫芦从左手升起，悬浮在头顶上方，暗红色葫芦身开始发光 |
| 3 | 法宝发光 | 葫芦全身发出暗金色光芒，金色符文在葫芦身上流转，葫芦口打开 |
| 4 | 法宝攻击 | 葫芦口对准目标，喊出"我叫你一声你敢答应吗"，金色吸力从葫芦口喷出，目标被吸向葫芦 |
| 5 | 法宝回收 | 吸力停止，葫芦口关闭，葫芦缓缓落回左手，光芒减弱 |
| 6 | 收势 | 葫芦挂回腰间，双手自然下垂，恢复待机姿态 |

### 4.3 银角施法（羊脂玉净瓶）

| 帧 | 动作 | 细节 |
|----|------|------|
| 1 | 祭出法宝 | 左手将羊脂玉净瓶从腰间解下，举到胸前，右手掐诀指向净瓶 |
| 2 | 法宝升空 | 净瓶从左手升起，悬浮在头顶上方，白色玉瓶开始发光 |
| 3 | 法宝发光 | 净瓶全身发出月白色光芒，银色符文在瓶身上流转，瓶口打开 |
| 4 | 法宝攻击 | 瓶口对准目标，喊出"我叫你一声你敢答应吗"，银色寒气从瓶口喷出，目标被冻住并吸向净瓶 |
| 5 | 法宝回收 | 寒气停止，瓶口关闭，净瓶缓缓落回左手，光芒减弱 |
| 6 | 收势 | 净瓶挂回腰间，双手自然下垂，恢复待机姿态 |

### 4.4 施法特效设计（代码层实现，不额外出图）

| 特效 | 金角 | 银角 |
|------|------|------|
| 法宝光芒 | 暗金色光晕 | 月白色光晕 |
| 吸力效果 | 金色漩涡粒子 | 银色漩涡粒子 |
| 喊名字幕 | 金色文字弹出 | 银色文字弹出 |
| 被吸状态 | 目标身体拉长+金色拖尾 | 目标身体冻结+银色拖尾 |

## 六、双Boss同屏布局设计

### 6.1 同时出现时的布局

```
          玩家（左侧）
              |
    ┌─────────┴─────────┐
    |                   |
  银角（左）         金角（右）
  银色盔甲           金色盔甲
  羊脂玉净瓶         紫金红葫芦
```

### 6.2 同屏时的动作协调
- **待机**：两人各自独立待机，动作帧错开（避免同步僵硬）
- **攻击**：轮流攻击，一人攻击时另一人待机或施法准备
- **施法**：可同时施法（双法宝齐出），也可轮流施法
- **受击**：各自独立受击
- **死亡**：一人先死，另一人进入"狂暴"状态（攻击+施法加速，代码实现）

### 6.3 狂暴状态（代码实现，不额外出图）
- 当金角或银角其中一人死亡时，另一人进入狂暴
- 表现：全身泛红光（代码colorMatrix），攻击速度+50%，施法速度+30%
- 不额外出图，复用现有动作帧

## 七、省量优化方案

### 7.1 金角银角共享策略

| 优化项 | 说明 | 节省量 |
|--------|------|--------|
| **造型共享** | 金角银角造型完全一致，仅颜色和法宝不同 | 50% |
| **动作框架共享** | 待机/受击/死亡动作框架完全共享，只改颜色 | 30% |
| **攻击动作共享** | 妖形态攻击动作完全共享，只改剑光颜色 | 20% |
| **施法动作共享** | 施法动作框架共享，只改法宝外观和特效颜色 | 20% |

**实际美术量**：
- 银角完整一套：人形态25帧 + 妖形态25帧 = 50帧
- 金角：基于银角改色+换法宝，约新增10帧（主要是施法的法宝部分）
- **合计约60帧**（原计划100帧，节省40%）

### 7.2 人形态省量
- 待机/受击/死亡：金角银角完全共享框架，只改颜色
- 攻击/施法：各自独立（因为法宝和武器不同）

### 7.3 妖形态省量
- 所有动作框架完全共享，只改颜色（金/银）和法宝外观
- 攻击时的剑光颜色用代码实现，不额外出图
- 施法时的法宝特效用代码粒子实现，不额外出图
