## 一、项目概览

### 1.1 产品定位

**《逆道西行》**——黑暗西游·单局Roguelike肉鸽构筑游戏。

- **题材**：黑暗西游，颠覆传统取经叙事
- **玩法**：单局肉鸽构筑，每局随机地图、随机事件、随机掉落
- **核心循环**：选英雄→走地图→战斗/事件→获取装备/劫印/经文→打Boss→死亡/通关→跨周目继承
- **参考标杆**：《杀戮尖塔》（路径模式）、《冒险日记》（成长曲线）、《万世剑冢》（配额制+战斗节奏）

### 1.2 技术栈

- **前端**：纯原生 H5（HTML + CSS + 原生 JavaScript ES6+）
- **零依赖**：无第三方运行时库，无构建步骤，无 npm 依赖
- **运行方式**：浏览器双击 `demo/index.html` 即玩
- **存档**：`localStorage`（浏览器）/ 微信存储API（微信小游戏）/ 本地存储（TapTap）
- **三端同步**：浏览器 H5 主线 + 微信小游戏 + TapTap 买断版

### 1.3 全局常量

| 常量 | 值 | 说明 |
|------|-----|------|
| `TOTAL_ACTS` | 9 | 九章制（非四章） |
| `TOTAL_REGIONS` | 17 | 十七地区 |

### 2.3 战斗系统 ✅ 完成

**Owner**：`combat.js`（129KB）、`game_combat_1-3.js`

**核心机制**：
- **AI自动对轰**：英雄AI自动普攻，玩家手动操作法宝/技能
- **手动攻击强制**：长安及两界山区域强制手动攻击（新手教学）
- **战斗速度**：第五章后开放2倍速，第十章后开放3倍速，第十五章后开放跳过
- **气势系统（Momentum）**：攻击/受击积累气势，满后爆发
- **识破系统（ShiPo）**：perfect/ok/miss三档判定
  - perfect（≤0.5秒）：免伤+1.2×双攻反击+3气势
  - ok（0.5-1.5秒）：免伤+0.8×双攻反击+2气势
  - miss（>1.5秒）：无效果，正常受击
- **怪物行为引擎**：pattern循环/技能池加权/低血阶段切换/guard·buff/意图预告
- **战斗特效**：攻击前冲/击退/受击位移/伤害飘字/震屏/刀光/命中停顿/暴击台词
- **战斗高潮层**：识破/破韧/爆发/终结/Boss大招触发慢镜+全屏闪光+大粒子+震屏+大字台词
- **五行属性**：区域怪物和英雄配五行，法宝特殊无五行属性（如避水珠改水）

**战斗时长**：普通战3-5回合，精英战5-8回合，Boss战8-15回合

### 5.1 平台适配层 ✅ 完成

- **taptap.js**：TapTap买断版适配（买断验证/成就/排行榜/离线游玩）

### 5.2 统一接口

`NDX.Platform` 对象提供统一的平台能力接口：
- 存档读写
- 支付
- 分享
- 成就/排行榜
- 广告

### 5.3 微信小游戏特殊规则

- 首包大小控制：不超过4MB，超出部分用分包加载
- 资源加载：大图片/音频用CDN或微信云存储
- 性能优化：图片压缩/代码精简/减少DOM操作
- 审核合规：符合微信平台审核规则

### 5.4 TapTap买断版特殊规则

- 买断验证：启动时验证买断状态
- 无广告：不得包含任何广告
- 无内购：除买断本身外，所有内容必须在买断后可玩
- 离线游玩：必须支持完全离线游玩
- 成就/排行榜：接入TapTap SDK
