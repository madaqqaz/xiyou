# 逆道西行 · 系统简化与肉鸽核心回归 · V2 修订意见

> 版本：V2（修订自 V1 设计方案 V1.0，2026-08-28）
> 地位：意见书，非替代方案；与 V1 并列，标注逐条取舍供决策

## 〇、一句话修改主张

V1 的立场是**「简化 = 减少决策」**，这个立场打错了靶。肉鸽的护城河恰恰是**一次性的高利害决策密度**；真正的认知负担不是"可以选的路线多"，而是"**要就地管理的东西多**"（品质、生效格、嵌入、手动换装）。

因此 V2 把修改主轴改为：

> **简化维修的是认知成本，不是决策权。砍掉一切就地管理，保留并强化每一个"选哪条路"的决策。**

## 一、V1 中值得直接保留的交集

以下内容认同 V1，可原样落地，不做修改：

- **新手通关局数目标 15–30 局**（既压挑战又不劝退）。
- **前期艰难、后期爽感** 的通关曲线（前 1–3 章资源少 Build 未成形，后段 Build 成形爽快）。
- **劫印道途计数 + 3/6/9/12 阈值**（「激活 3 个贪吸血+5%、6 个战攻击+10%」这一表述本身直观且方向正确）。
- **死亡增强 + 可重置开关**（思路成立，机制需改，见 §三.3）。
- **通关奖励 / 多周目 / 经文拓印 / 成就** 等长线内容骨架。

## 二、修改总原则（抉择铁律）

对每个系统，套用同一条判定公式：

> **决策必须一次性、操作成本低、但后果有份量**
> （`cheap to make, expensive to ignore` —— 上手轻，但每个选择都值钱）

据此把改动分成三类：

| 类别 | 定义 | 处置 |
|---|---|---|
| **该砍（就地管理）** | 跨局/跨节点要反复操作的元负担：品质、生效格、嵌入、换装 | 砍掉，用计数/自动承接 |
| **该留（决策权）** | 每个采集/奖励点的"选哪条路"动作：三选一、养什么 build | 必须保留，这是肉鸽命根 |
| **该补（核心技术）** | 运气与难度如何被钳制在"运气差不会必死、运气好能起飞" | V1 空缺，必须新增（见 §五） |

**判断口诀**：`砍之前先问——砍的是'管理'还是'决策'？砍决策 = 自杀；砍管理 = 正解。`

## 三、逐系统修订对照

### 3.1 劫印 —— 保留"选择"，砍掉"管理"

| 维度 | V1 做法 | V2 修订 |
|---|---|---|
| 品质 | 取消白/蓝/金/红 | **保留"脸好拿金印"的正反馈**：极品劫印仍以低概率出现，作为「运气 40% 支柱」的峰谷爽点；砍掉的是它的**就地管理**（品质数值堆叠表），只保留等级台阶 |
| 装备/生效格 | 取消独立装备 | 同意取消生效格与换装；劫印不入装备格 |
| 核心动作 | 纯自动加属性 | **保留"劫难抉择后三选一道途劫印"这一个动作**——这是肉鸽的手感，缺失则变成被动转盘 |
| 阈值 | 3/6/9/12 | 保留 3/6/9/12 档位与效果表（沿用 V1 §3.3） |
| 引导（新增） | — | **轻度道途倾向**：已投入的道途使同类抉择更易刷出对应劫印（非锁死，留变数），让"专心养一途"有明确达成路径 |

**判定**：V1 砍掉了"选择"（致命）；V2 砍掉"管理"、留下"选择"（正解）。

### 3.2 经文 —— 收集可以自动，但养成手感要留

| 维度 | V1 做法 | V2 修订 |
|---|---|---|
| 碎片 | 打怪/事件/商店/Boss 掉落，自动收 | 保持自动碎片收集（认可，减负正确） |
| 合成 | 10 碎片合成整本，**自动生效不可选** | **合成后不在掉落瞬间无脑生效，而是在关键节点（每章收尾/露营）给一次"套用/转化"决策**：把已集经文投向一个道途槽位 |
| 效果 | 8 本平铺效果（§2.4） | 绑定**道途触发链**（渡经养渡、战经养战）；同一个经对当前主道途有加倍权重 |
| 培养手感 | 无（纯抽卡） | 因为有了"投向哪个道途槽"的动作，玩家能说清"这一把我养的是什么"，才支撑「全拿到想要的」的后期爽感 |
| 简化支线（可选） | — | 若坚持全自动：把"选择"换成"**自动路由**"——经文自动并入**当前主道途**生效（同一经对主道途加倍），保住养成导向又不加操作 |

**判定**：V1「自动生效且不可选」取消了选择权与养成手感；V2 用一次关键节点的"投向"保留决策，同时保持碎片收集的全自动。

### 3.3 死亡增强 —— 从纵向涨数值，改为横向解锁

| 维度 | V1 做法 | V2 修订 |
|---|---|---|
| 内容 | +% 数值：初始血/攻/经/印/折扣 | **全部改为横侧解锁**：新英雄、新经文、新事件、新转职——只拓宽玩法，不涨数值曲线 |
| 平滑曲线 | 6 次死亡叠到上限 | 依据：**纵向 +% 鼓励"靠躺刷次数"，会直接拆掉你要的"一命见真章"爽感**；且与「经文拓印永久生效」叠加必爆 |
| 兜底 | 无 | 若强烈保留一条 +%：仅限**感受性保障**（如"保底不掉落、商店保底出现已集残片"），不做乘法攻血 |
| 开关 | 可重置纯肉鸽 | 保留「重置传承，挑战纯肉鸽」，逼格与甜头兼得 |

**判定**：V1 的 +30% 血 / 传承+拓印双永久 = 靠躺通关且数值必炸；V2 全换横侧解锁，传承=拓宽玩法而非躺赢。

### 3.4 运气（V1 技术空缺，必补）—— 见 §五

## 四、V1 没想到、V2 必须补齐的三件事

1. **Build 成形的可验收定义**（否则"每个 build 都能通关"是空话）：
   `主道途层数 ≥ N + 关键经/印到位 ≥ M + 至少 1 条 synergy 闭环`。
   用这一定义做数据验证，替代"手感调平衡"。

2. **Synergy-in-reach 检测**：生成时确保"潜在的 build synergy 在路线内可达、未被互斥事件锁死"，避免"看似能通、实则必死"的伪随机。

3. **运气峰谷正反馈保真**：金/红品质这类"脸好"爽点若被砍，必须用等价物补位（稀有经文三选一、传说事件、Boss 随机双词缀），否则 40% 的运气支柱会被削成反哺油的 empty 随机——运气是设计支柱，不是拿来削的。

## 五、核心技术空缺点（V1 最该补的一节）

V1 只写了原则（§4.1 运气 40%），没写**如何让"运气差也难过、运气好能起飞"落地**。这是肉鸽的技术核心，缺它则平衡全靠玄学。

修订做法：

- **Seed 播种**：每局用确定性 seed 生成整张路线/掉落/事件，可复盘、可回放、可测平衡。
- **Build 值匹配采样**：生成时按"玩家当前 build 强度"做钳制——不是"随机打不打得过"，而是"**随机出『有解但必须选对』**"。
  - 与本项目已验证思路同构：canvas 试炼里 `pickFight` 的"多难度采样：选能获胜且回合最长的势均战斗"——把随机难打变成随机有解法（需正确选路）。
- **方差钳制**：整局保证"真正的必死局占比 ≤ 约 1/3"，其余 2/3 在策略与运气共同作用下有胜机。没有这层，"运气好能通"和"运气差翻车"无法共存于同一套数值。

| 优先级 | 内容 | 相对 V1 的处置 |
|---|---|---|
| P0 | 劫印：保留"抉择三选一"，砍品质/生效格管理 | 承接 V1，方向改为留选择 |
| P0 | 经文：碎片自动收集 + 关键节点"投向道途"抉择 | 承接 V1，机制由"自动生效"改为"关键选择" |

## 七、风险与应对（V2 修订）

| 风险 | 应对 |
|---|---|
| 一刀切过简化、失去深度 | 用"决策密度铁律"把关：每砍一项先问"砍的是管理还是决策" |
| 横侧解锁仍显内容空 | 先保证核心闭环（识破/爆发/劫印三选一/synergy）落地，再扩充池子；少而准 > 多而散 |
| 道途绑定过度、锁死 build | 用"轻度倾向 + 全局阈值保底"（任何道途积累都给基础保障）对冲，避免被迫只用一条路 |
| +数值传承破坏肉鸽 | 彻底不涨曲线，只解锁工具；保留可重置开关 |

## 八、结语

V2 不改 V1 的两个正确目标——**对新手友好、回归肉鸽**；只改它的一个错误手段——**拿决策换简单**。

> V2 主张：你想要的上手门槛低，来自"决策好懂、不用管理"；而不是"没有决策"。
> 玩家的一局应该充满"这个三选一我怎么选"的爽感，而不是"我什么都不用碰"。

**最终可验收断言**：当一名新玩家能在 15–30 局内，因为"选对路、运气不错、养成了可感知的 build"而通关——且通关的那局**手感上是他自己搭出来而非抽奖品堆出来的**——本方案才算真正达成 V1 设定的目标。
