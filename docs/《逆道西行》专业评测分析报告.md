## 二、游戏定位与核心循环

**Fun Hypothesis（一句话好玩内核）**：「以黑暗西游为皮、六道命数为骨，在 81 难的随机险途中，用劫印/装备/经文/法宝的横向构筑，把一次次失败兑换成下一次更从容的西行。」——核心乐趣来自**构筑发现 × 道德抉择后果 × 轮回横向解锁**。

**三层核心循环：**

| 层级 | 周期 | 循环内容 |
|---|---|---|
| Moment-to-moment | 0–30s | 节点抉择（善/恶/渡/逆）→ 战斗一递一还 → 掉落三选一（劫印/装备/经文） |
| Session loop | 5–30min | 连续地图推进（17 地区）→ 关隘 Boss → 长安大本营整备（合成/转职/祭赛/轮回） |
| Long-term | 小时–周 | 死亡→轮回横向解锁（传承英雄/经文/事件）→ 二周目论道（部分） |

**设计支柱（从代码反推的不可妥协体验）：**
1. 黑暗西游叙事一致性（文言/白话混合，玄墨·佛光视觉）。
2. 劫印「获得即强化」的肉鸽直觉（V3 砍掉堆叠/合成操作）。
3. 战斗逻辑/演出分离，让绝招/法宝/连招有发挥窗口（GLOBAL_DMG_MUL=0.5 防秒杀）。
4. 失败正向化（轮回横向解锁，破「挫败-滚雪球」死循环）。

## 五、各系统详尽分析

### 5.1 命运六道与劫印（叙事 × 构筑主轴）
- 六道独立属性（战→atk / 渡→matk / 缘→dr+mdef / 夺→hp / 隐→eva / 逆→reflect），非旧版「三大归并」，已重写。
- 劫印砍掉堆叠/合成，回归「获得即强化」，符合肉鸽直觉；道途层数驱动属性与机制（`SEAL_WORDS.mech/mechTier`）。
- **耦合点**：劫印是单局机制唯一真源，`fateFlags → 回合内核` 单通道进入战斗，架构干净。

### 5.2 装备与合成（经济 source/sink）
- 套装共鸣系统解决「套装差距不大」的历史失衡（V47 重构）。
- **保底机制**：`EQUIP_PITY_THRESHOLD` soft-pity、装备掉落保底（宠物进化/缘/劫印善道档位），缓解长尾空虚。
- **风险**：标尺错位（§4.2#2）使掉落曲线前移，通胀压力在中局显现。

### 5.3 经文（渡/逆双体系）
- 渡经 16 部 133 片 + 逆经 9 部 58 片；V3 改为「合成入背包→自动路由主道途生效」，主道经 ×1.5 实时跟随。
- **设计取舍**：不新增手动决策点（自动路由），降低认知负荷，但牺牲了「手动投向」的构筑表达深度。

### 5.4 法宝克制（西游特色解厄）
- 垂直切片：黄风致盲→定风珠、白骨减攻→照妖镜、红孩灼烧→芭蕉扇；非战斗法宝 紫金钵（3 次回血）/ 救命毫毛（3 根复活）。
- **克制真源**：`PDEBUFF_DEFS` 玩家 debuff + `_bossDebuffSpec(name)` 按名子串匹配 + `cleanse` 事后修补。
- **缺口**：仅 3 对，其余 Boss 待按同范式批量补；临阵祭宝两路径须同步接 cleanse。

### 5.5 转职 / 宠物 / 隐藏职
- 转职路线各英雄补齐（§62）；隐藏职 6 个（战/渡/逆/隐/夺/缘）已落地并接入回归门禁。
- 宠物进化 + 助战并入 `computeStats`，渠道与观音助战/随从一致。

### 5.6 事件 / 随从谈判 / 罪业贸易
- 143 事件覆盖命运抉择、梵音、谈判等；谈判成功→妖王臣服（上限 3，满则替换最旧），助战平铺攻/血/减伤/法伤/法防。
- 罪业贸易 `SIN_ROUTES` 提供善恶兑换的「风险-收益调节器」。

### 5.7 轮回 / 死亡增强（留存引擎）
- 从「纵向数值滚雪球」改为「横向渐进解锁」：以累计死亡次数为轴，逐级解锁传承英雄/经文/事件。**失败一局＝一桩新内容**，是对肉鸽挫败感的关键对冲。

### 5.8 梵音 / 镜 / 舍利 / 道心 / 心魔（元系统）
- 均有数据注册（`data_daoxin`/`data_xinmo`/`data_mirror`/`data_vault` 等），构成长线 meta 层。深度与相互耦合强度需专项走查（建议后续补一份 meta 系统耦合矩阵）。

## 六、战斗系统深度分析（核心维度）

### 6.1 架构（优秀）
`combat.js` 为**纯逻辑分阶段状态机**：`INTRO → BATTLE_LOOP(TURN_START→PLAYER_PHASE→ENEMY_PHASE→TURN_RESOLVE→CHECK_END[→ENRAGE]) → VICTORY/DEFEAT`，产出 `roundsDetail` 供 UI 逐拍演出。**逻辑/演出分离**是工程亮点，使战斗可被无头门禁（regression 149 项）完整覆盖。

### 6.2 机制维度
- **速度先手**：spd 决定出手顺序，先手击杀则后手不出手。
- **怪物反击（反弹裂缝）**：counter 0.10（mob）→0.30（boss）。
- **DOT 持续伤害**：每回合结算，turns 递减。
- **狂暴**：残血 <30% 且未狂暴 → 攻击 ×1.5（ENRAGE_MULT），持续至结束。
- **气势（Momentum）/ 识破（ShiPo）/ 战斗标记（battleFlags）**：提供阶层化决策资源。
- **连招**：基础攻击链每 `COMBO_BASIC_EVERY=3` 次触发暴击 `×1.5`；手动风格 `combo→burst→pierce` 串联 `COMBO_CHAIN_MUL=1.25`（手操深度奖励）；自动战斗仅代点基础攻击，绝招/法宝/爆发强制手动（Boss 战禁自动）。
- **绝招**：15 个（5×3 阶），kind 覆盖 heal-dmg/shield-dmg/crit-dmg/aoe-dmg/drain-dmg/guard-dmg/multi-dmg/ignore-dmg/wish-blade，构筑表达充分。
- **全局削力** `GLOBAL_DMG_MUL=0.5`：让暴击/法宝/破韧/绝招有时间生效，是「战斗不秒杀、演出有空间」的关键旋钮。

### 6.3 技能设计评价
- 正向：绝招分阶 + 风格串联 + 法宝克制，构筑维度丰富；自动/手动职责边界清晰（保玩家关键决策权）。
- 待补：① 五行方向已放弃，构筑「属性克制」维度缺位；② 法宝克制仅 3 对，未铺满；③ 技能演出依赖 `roundsDetail` 回放，复杂连段（多段/multi）的视觉拆解是否清晰需实机确认。

### 6.4 战斗时长与分布（需实机采样校准）
- 模型推断：回合制一递一还，`GLOBAL_DMG_MUL=0.5` + 狂暴延长尾盘 → 典型 Boss 战预期 **8–18 回合**；墙钟约 `FIGHT_TICK=2000ms`（1x，倍速同比压缩），即普通 5–10 回合 / Boss 10–18 回合对应约 10–36s（1x）。
- **风险点**：装备标尺错位（§4.2#2）使玩家中期数值超模 → 战斗时长被压短、策略窗口收窄。**建议**：用现有 telemetry（CAP=200 环形缓冲）扩展采集「每场回合数/总时长/胜负/难度」，建立时长分布基线后再调 `GLOBAL_DMG_MUL`、狂暴阈值与怪物 HP 曲线。**［P0-3 已于 2026-09-06 落地］** telemetry 环形缓冲已由 CAP=200→**600**（单局双采样≈2 事件/场，可保约 3 整局基线）；新增 `fight_end` 事件（每场记录 胜负/类型/难度/回合/墙钟时长 ms）与 `econ_snapshot` 事件（post_fight / run_end 记录 金/装备/材料/劫印/法宝/碎片 存量）；配套 `scripts/_smoke_telemetry_pace.js`（36 项门禁）与 `scripts/_analyze_telemetry.js`（实机导出→时长分布/通胀曲线基线分析器），把「时长分布」「通胀曲线」从推测变可证伪。

### 6.5 打击感与表现（代码层推断）
- 已知技法：位移演出走 **JS 时间驱动 + `!important` 内联 transform**（规避 `@keyframes` 被 `.fb-arena` 重建打断）；`.hit-shake`/闪白做受击反馈；`COMBAT_SPRITES` 注册表驱动战斗精灵帧。
- 可加强：~~当前偏「抖动+闪白」，缺少 hit-stop/屏震/数字飘字分层/镜头微推~~ **审计翻案（2026-09-07 P2-9）**：hit-stop（四档 50–80ms steps 定格）、屏震（四档 `fx-shake-*`）、伤害数字分层（六类异色 + 双速度曲线 `dmgFly`/`dmgFlyCrit` + 色盲适配 + 同屏限额错位）**三项均已实现并接线**；唯一残留「镜头微推」已落地 `_fxCamPunch`（JS 时间驱动 + `!important` 内联 transform 挂 `.fightbox`，四档推近量，顿帧联动，fightSpeed 同比压缩）。门禁 `_smoke_cam_punch.js` 23/0。

## 八、音乐与音效分析

### 8.1 现状
- `sound.js` + `js/audio/ndx_audio_engine.js`：Web Audio 即时合成 + **5 条 BGM**（title/map/fight/boss/home）+ **3 条 SFX**（click 木鱼 / zhuanjie 转职觉醒 / worship 诵经梵呗），AI 生成 mp3（128kbps 单声道 44.1kHz），静音偏好落 localStorage，首次手势才建 AudioContext。

### 8.2 评价与缺口
- 正向：零外部依赖、零版权风险、文件缺失自动回退合成，符合「file:// 即玩」定位。
- 缺口复核（2026-09-07 实测，**原结论大面积过期**）：①「无地区 BGM 变体」**不成立**——自适应引擎 17 act→zone 音景（混响交叉淡入 + 风水洞环境层 + 区域基音/调式/动机变体）已实现并接线（`ndx_audio_bridge.js` 250ms 轮询真实战斗状态）；②「缺受击/暴击/法宝/绝招 SFX」**大部分不成立**——引擎合成注册 25 个 sfx 名（含 hit/crit/treasure/seal），MP3 仅 3 条但合成层全覆盖；③「无动态混音」**不成立**——CombatIntensity/ThreatLevel/PlayerHealth/RunDepth 四轴 RTPC 平滑混音已在跑。真实残留仅一项：绝招与普通技能共用 `skill` 音 → 已补独立 `ult` 音（引擎三重叠加 + legacy 合成回退，2026-09-07 落地）。
- **建议**：至少补「受击/暴击/法宝启动/绝招释放/劫印获得」5–6 条 SFX，并为战斗加一层 intensity 渐强 pad；BGM 按地区簇（前/中/后段）做 3 套变体即可显著降低单调感。

### 9.1 平衡旋钮（设计合理）
- `GLOBAL_DMG_MUL=0.5` 全局削力：防秒杀、保演出窗口。

- 狂暴 ×1.5 + <30% 触发：给尾盘紧张感。
- 经纬主道 ×1.5：强化「构筑方向感」。

### 9.2 通胀风险（需关注）
- **装备标尺错位（§4.2#2，阻断级）**：旧四章标尺残留使后期装备提前 ~47 难掉落 → 中局偏膨胀、战斗时长被压短、构筑选择被数值碾压。**必须整改**：定义 `regionToTier()`（17 地区→4 档）统一装备/红材/转职三处消费点。

### 9.3 经济 source/sink
- source：节点掉落（劫印/装备/经文/材料）、长安购买、罪业贸易、轮回解锁。
- sink：合成消耗、祭赛国、转职、劫灰坊、梵音。
- 当前 sink 覆盖尚可，但**无全局通胀监测**（telemetry 仅采运营事件，未采经济存量曲线）——建议加「单局资源存量随时间」采样。**［P0-3 已于 2026-09-06 落地］** 已加 `econ_snapshot` 事件（post_fight / run_end 采样点，记录 金/装备/材料/劫印/法宝/碎片 存量），配套 `_analyze_telemetry.js` 输出各章通胀曲线，可证伪监控。
