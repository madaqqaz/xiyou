# 六道奖励框架与二周目论道 · 设计文档

> 对应网页版规格：`liudao-reward-design.html`（本项目站外归档）。本文档为权威设计规格，第1·2难已按其实施，其余 3–81 难在设计/回填阶段。
>
> 主基调：**奖励绑定「道」，不绑定「善恶」——善恶只作精确分档，不作路线锁定。**

---

## 一、设计原则

1. **奖励绑定「六道」，不绑定「善恶」** —— 善恶仅作展示与分档积累，无阵营锁定，与「一周目全解锁、无强制路线」一致。所有选项一律可选。
2. **善恶走「精确分档」而非固定 ±1** —— 二级子选项带 `alignGood / alignEvil` 精确档位，取代旧引擎「按 fate 固定 ±1」，让六道心迹轻重可读、可设计、可配平。
3. **每难「共通保底」+「道专属见面礼」** —— 先拿共通保底，再按所选道发一份道专属奖励，既教学、又不让玩家空手。
4. **六道奖励品类天然错开** —— 战→劫印、渡→原著法宝/好感、缘→机制法宝、隐→闪避装、夺→掠夺装、逆→经文，避免「专精一路却反复只拿同一种东西」的单调与失衡。
5. **一通百通的教学章** —— 第1难即六道首次全亮相，奖励即「各道见面礼」，让玩家第一次选择就明白「选哪条道、会得到什么、进了哪个系统」。
6. **战 / 夺是"人造刷取之道"** —— 战以「凭空召唤 / 开启」非西游本劫的一场战斗来养更多劫印（原西游劫难战太少，否则劫印到不了最高）；夺以「强夺本无的装备」来喂隐藏线。二者<mark class="warn">不绑定"该难原著是否有战/宝"</mark>，是两条自成体系的库存来源；也因此"战"在难中常表现为一场硬造的战斗（如第3难：召唤前世金身与之一战）。
7. **战道的战斗形态随唐僧成长阶段实时推进** —— 战不从"凭空开战"起跳，而是把「以力刷劫印」的诉求，落进"剧情此刻本就该有的那场仗"：唐僧婴儿期力不能战，则**召唤前世金身代战**（难3）；少年出山则**猎户等助阵双人杀虎**（难5）；中段行者/随从/神相助战、借力破局（难7–30）；后段武德渐备、**亲自下场**（act3 起）；到 Act4 返程以主角自战为主，直面写经人。它以最小改造成就"战=劫印来源"，也让唐僧"越战越强"成为可见的成长弧光。

### 战道战斗形态 · 成长阶段映射表

| 阶段 | 大致难段 | 唐僧处态 | 战道战斗形态 |
|------|----------|----------|--------------|
| 婴儿出世 | 难 2–3 | 不足满月·无武力 | 婴儿不能战 → **召唤前世金身代战**（难3 金身·江流残识） |
| 少年出山 | 难 4–6 | 渐可走动 | 借外力 / 助阵：难4 少年提剑自战；难5 **猎户伯钦助阵·双人杀虎** |
| 随从相伴 | 难 7–30 | 行者 / 八戒 / 沙僧相随 | 借随从与神相助战、借力破局（降龙、收妖皆助战） |
| 武德渐备 | 难 31–50 | 出手渐有章法 | 开始**亲自下场**，助阵退为辅助 |
| 逆道返程 | 难 51–81 | 全盛·主角 | **主角自战为主**，直面写经人 |

> **为何善恶也要「精确」**：±1 让「渡」与「隐」这类品性差异极大的选择在善恶账上毫无分别，玩家感受不到「这一念」的分量。精确分档使劫难内的抉择轻重、两难取舍、论道时算账依据都更清晰；同时只为带精确档的二级选项启用，普通旧选项仍走 ±1。

## 三、四个收紧点

### 3.1 缘 vs 隐：隐装是缘装的「子集」

同一难里六道本就互斥（一次只选一条），「不同时出现」自动成立。真正要区分的是**品类 / 掉落池**：

- **缘** → 机制向（重掷、复制掉落、路线增益），「顺势借势」
- **隐** → 生存向（闪避、降低被命中、减伤），「避世无痕」

### 3.2 渡 vs 缘：都落在「法宝」，也要拆

- **渡** → 原著情怀法宝（避水珠、锦襕袈裟、紫金钵盂等名著名物）+ 可加「神仙好感」
- **缘** → 随机 / 机制型法宝

### 3.3 「神仙好感」是全新子系统，不是改奖励表

已落地轻量 flag 列表 `s.favors = { gods: [...] }`，在第4难等后续难接「若有某神好感 → 额外选项 / 助战」，可复用既有 `hidden: { cond: ... }` 门槛机制。它是**新增系统**，而非改奖励表字段。

### 3.4 夺 / 战必须绑定题词条

- **战** → 战道劫印（走既有 `jieseals.js` 劫印体系）
- **夺** → 掠夺题装备（击破额外掉落 / 劫灰 / 偷敌方属性）

两者一个走劫印、一个走装备，系统天然分开。

## 四、第1难定案 · 两级洋葱（已落地）

为免六道首难全铺开导致选型庞大，第1难采用**对称 2/2/2 折叠骨架**：一级只问「以何种姿态应对」（3 入口、不标善恶），二级才定「道 + 善恶动作」，六道经二级子选项完整亮相。二级以**二级弹窗**承接（引擎新增 `sub-choices` 状态 / `sub-trial-opt` 动作）。

### 4.1 关键结构原则

- **一级不标善恶** —— 它是「姿态」不是「阵营」；善恶与道全部沉到二级子选项逐项标注。
- **同一姿态可落多个道，同一道可在不同姿态出现** —— 解耦善恶与道，想走纯善的玩家仍可借顺命等姿态触及进取道途。
- **二级子选项仅本分支出现、不重复获得** —— 主轴道具（如钵盂虚影）只发一次，功能随所选道分化，奖励绑「道」不绑「善恶」。
- **共通保底** —— 无论选哪条道，先得金蝉舍利（`treasure:{id:'jinchan'}`，序章续命法宝）。

### 4.2 一级×二级映射 · 最终落地值

| 一级·姿态 | 二级·道 / 善恶 | 二级·选项动作 | 二级·奖励与后续分化 |
|-----------|----------------|----------------|----------------------|
| 顺命 | **渡 · 善 +10** | 双手捧钵，承佛之命 | `favor:'观音'` 好感种下 + `紫金钵盂·虚`；→ 第4难「长安送行」凝实【紫金钵组件】；特效偏防御渡化 |
| 顺命 | **缘 · 善 +8** | 指尖触钵，惜众生缘 | 同一钵盂虚影，功能偏机缘增益（触发暴击） |
| 争胜 | **战 · 恶 +8** | 夺鞭立威，驱而不伤 | ⚔ 触发轻战（起手 +1 动量）→ 开启战系劫印线路 |
| 争胜 | **夺 · 恶 +10** | 抽走鞭梢，掠走物证 | ⚔ 触发常规战 → 得「青驴鞭影」（对神系妖首回合扣 5–10% 最大血，本局一次性；弃「打神鞭」名避封神 IP） |
| 避世 | **隐 · 善 +6** | 任碎石盖身，避世无痕 | 学会生存；本战首回合被动闪避加成（闪避 +8） |
| 避世 | **逆 · 恶 +6** | 直问「账簿上，我值几文」（一周目可启） | 无战斗，仅得【逆道经文感悟 · 直问天条】存命数面板 `s.niInsights`；一周目不给数值，二周目论道后兑现 |

**最终档位对齐（自旧版修正）**：渡 +10 · 缘 +8 · 战 +8 · 夺 +10 · 隐 +6 · 逆 +6。其中 **缘 +8（非 +5）、隐 +6（非 +5）、逆 +6（非 +8）、夺 +10（非 +8）** 为最终值；「逆 +6」有意压低——逆道同属避世姿态，倾向"以问代动"，不正面作恶，故恶念较轻。

### 4.3 二级弹窗机制（引擎新增）

一级姿态含 `subOptions` → `applyTrialOpt` 不结算、切到 `sub-choices` 二级面板（`ui.js` 复用 `sceneModal`，动作 `sub-trial-opt`），选完二级才结算并回退 `choices`。数据经 `normalizeTrial` 透传 `subTitle / subText / subOptions`。善恶精确档由 `applyEffectCore` 消费 `alignGood / alignEvil`，并**抑制旧 `_autoGE` 的固定 ±1 叠染**（避免 10+1=11 的错账）。

## 五、第2难定案 · 三途首战

第2难「出胎几杀」是地区1（大唐境内）首场战斗，承接第1难「度谁」余题。此难**排序为 战/渡/隐**，故「隐」以 `noDao: true` 显式解除引擎「三选项第三位=声道路线锁定」的自动约定，让三途皆可直选。

| 选项 | 道 / 善恶 | 动作文 | 奖励 |
|------|-----------|--------|------|
| 战 | **恶 +8** | 护母突围，夺路而走 | ⚔ 开战（起手 +1 动量，`reward` atk+12）；善恶开打前即入账 |
| 渡 | **善 +10** | 随江流漂走，顺命入劫 | 气血 +40（渡·续航） |
| 隐 | **善 +6** | 藏入棺椁，权且避世 | 得「状元印」 |

**三途承接 / 暗线**：

- **战斗补挂**：战斗型抉择原本在 `applyTrialOpt` 的 `isFightOpt` 分支提前返回、跳过善恶结算 → 新增开打前补挂 `alignGood / alignEvil`（仅对带该字段的选项生效，其余战斗选项行为不变）。
- **暗线**：刘洪腰牌上的灵山莲花纹，是**证物**，供二周目「论道」回扣（`echo` 已标注）。
- **袈裟线**：此难必掉 `ts_robe_base` 袈裟胚——唐僧单一袈裟线基座，与暗文"母亲压进襁褓的袈裟边角"呼应。

## 六、二周目「论道」 · 定稿

「论道」是第1难那句**未答之问**的终极了结——"若经书本身便是枷锁，度的是谁？"。当二周目完成足够逆道经文感悟（`s.niInsights`）后，于灵山直面如来，翻出第一世那本旧账簿。

### 6.1 结构 · 序章 · 三问 · 选择

- **开启条件**：二周目 + `s.niInsights` 集满 **3 条**（不足则论道不现）。
- **序章**：重提旧账簿，条目第一行：「*金蝉子 · 轻慢 · 十世轮回*」。
- **三问**：三条已录经文逐条摊开，化作三个要不要答的问题：
  1. 问「度谁」：经书若只渡得了合它尺寸的人，余下的呢？
  2. 问「账簿」：条目是写你的「罪」，还是编写经人「需要你个罪」？
  3. 问「自写契约」：这一次，纸条上你亲笔写下的，是承诺还是抵触？

  *（三问逐一以「道」作答，账簿条目随之改写；作答方式不入善恶账，只影响收束口吻。）*

- **选择**：三问之后，最终在「旧账簿如何了断」上由你落笔，三择其一。

### 6.2 三选 · 结局分支（定稿）

**结论先行**：「**焚 · 天条逆命**」是本作**主结局**；「重续 · 引渡者」保留为顺途出口；「存留 · 隐藏结局」为多周目彩蛋。三选不按善恶分档判定（避免"善恶=阵营"卷土重来），而按**对旧账簿的了断姿态**三择其一；善恶账只调各结局的收束口吻，不改变走向。

| 选择 | 结局 key | 落笔动作 | 结局线 | 状态 / 附加 |
|------|----------|----------|--------|--------------|
| 焚 | `ending_fire` | 当庭焚簿，逆天消账 | 「天条逆命」 | **★ 主结局**；把已兑经文再剥一层——不留账、不灭道，只还这天一个清楚 |
| 重续 | `ending_guide` | 奉还账簿，续引渡旧路 | 「引渡者」 | 保留结局；倾向善的玩家多数自然落此线（不锁），作"度一人度一世"的顺途出口 |
| 存留 | `ending_keep` | 收簿入怀，带下灵山 | 隐藏结局 | 多周目彩蛋；需前置（暂拟：本轮回从未焚烧过任何经文 + 持特定道具） |

**存留线为何是彩蛋**：焚是"了断"，重续是"归修"，存留则是对两途的**拒绝**——既不言弃、也不续修，把账留着写给"下一个自己"。这最反直觉，故需前置门槛（暗示玩家"这一轮回还差一段因缘"），达成后获得 meta 道具**《旧账》**可带进下周目，呼应"此世攒的，下世接着带"。

**兑现机制**：一周目「逆」只录 `s.niInsights` 不赋数值；论道开启（二周目 + 3 条经文）三问既答后，所录经文中一次性兑现为命数面板可读的数值/被动，随即进入最终三选，依「焚 → 天条逆命」判定为主结局，按其落笔写就收束段；其余两线按上文条件触发。
