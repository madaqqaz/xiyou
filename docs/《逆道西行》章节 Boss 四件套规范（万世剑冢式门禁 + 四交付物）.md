# 《逆道西行》章节 Boss 四件套规范（万世剑冢式门禁 + 四交付物）

> 缘起：单机实测反馈——前两章「刷吐了、无成就感」，Boss「没感觉到难度」。
> 用户设计意图（已确认）：每个章结尾是一个**有名字的标志性 Boss**，玩家在前面刷（尤其战道能无限刷）攒条件，攒够门禁才刷出 Boss；该 Boss 必须交付 **辨识度 / 战斗难度 / 战力阶梯度 / 成就感** 四件套。参照《万世剑冢》的「门禁刷出最终 Boss」结构。
> 结论先讲：**底座已经很强**（17 地区末 Boss 全有立绘+多段形态+行为脚本+难度阶梯），真正要补的是 ①白骨未接进章节链 ②战力阶梯度无硬规则 ③门禁是量化可被战道刷穿。本规范锁定 黄风=Ch1、白骨=Ch2，定义四件套标准，重做门禁，并给出全 9 章 Boss 映射提案。
> 状态：纸面规范，未落地任何代码。待用户签批后执行。

## 一、Design Pillar（章节 Boss 的唯一功能）

**章节 = 积累（刷怪攒门禁）→ 高潮（标志性 Boss）→ 释放（四件套交付）。**

每个玩家可见章必须交付四件套，缺一就不算「章 Boss」：

1. **辨识度**：独立立绘 + ≥2 段变身形态 + 专属行为脚本 + 名字揭晓演出。
2. **战斗难度**：难度阶梯逐章递增 + 残血狂暴 + **对玩家实力的动态校准**（防刷穿）。
3. **战力阶梯度**：章末必掉 1 件「本章阶梯核心成长物」（装备/劫印/法宝），让战力可感知地台阶式上扬。
4. **成就感**：章通关成就 + 过场/演出 + 转职解锁提示，让「阶段性成就感」落地。

## 四、四件套规范（每个章末 Boss 的强制标准）

### 4.1 辨识度（现状：达标 80%）
- **标准**：① 独立 Boss 立绘（`data_heroes_data.js` boss_xxx）；② ≥2 段变身形态（`BOSS_FORMS` 登记 phases）；③ 专属行为脚本（pattern/guardPct/buffAtkPct）；④ 章末「名字揭晓」演出（UI 显示 Boss 真名 + 道相）。
- **现状**：黄风/白骨/红孩儿/车迟/六耳/牛魔王/大鹏/老鼋 均已达标；刘洪/白龙/沙僧/黄袍/黄狮为单段（教学/收服类，可接受但 Ch 末 Boss 不允许单段）。
- **要求**：**章末 Boss 一律 ≥2 段形态**，单段仅限教学/收服类非章末节点。

### 4.2 战斗难度（现状：有阶梯，但可被刷穿）
- **标准**：① `diff` 逐章递增（见 §二阶梯 4→81，基本成立，仅黄风9<白龙12 需微调）；② 残血 enrage（现有 enrage:0.3/enrageMul:1.5 已普及）；③ **动态校准**（新增，见 §五）。
- **致命缺口**：当前门禁量化（`game_core_2.js:506`「历经足够劫难 + 仅缘分管禁」），战道玩家农场到阈值后 Boss 形同虚设。必须加动态校准，否则「战斗难度」与「成就感」同时归零。

### 4.3 战力阶梯度（现状：散，无硬规则）★新立规
- **标准（硬规则）**：**每章末 Boss 死 → 必掉 1 件「本章阶梯核心成长物」**，按章号阶梯缩放：
  - Ch1–3：基础套装件 / 一阶劫印（如 启程套·甲乙丙）
  - Ch4–6：英雄专属套件 / 二阶劫印 / 关键法宝（如 芭蕉扇·残、定风珠·真）
  - Ch7–9：红劫印材料 / 三阶劫印 / 隐藏职线索
- **现状**：掉落散在 `BOSS_TABLE.drop` / `equipment.js(chapter:)` 标签，无「每章必给核心物」强制。需立规并审计每件掉落是否落在正确章阶。
- **数值 rationale**：核心物战力增量 ≈ 章末前后小怪战力的 15%~25%（保证「刚够打下一章」，不溢出也不卡死），具体值标 `[PLACEHOLDER·待 playtest]`。

### 4.4 成就感（现状：缺）
- **标准（硬规则）**：章末通关触发三件事——① 章通关成就（`achievements.js` 新增 `ch_clear_1…9`）；② 过场/演出（Boss 倒下特写 + 名字铭刻）；③ **转职解锁提示**（若本章末落在某英雄 actGate 节点，弹「可转职」）。
- **现状**：仅 `十七路皆通`（全 17 地区）总成就，无逐章通关反馈。需新增 9 个章通关成就 + 通关演出钩子。

## 五、门禁重做（质化 AND + 动态难度校准）★核心修复

### 5.1 门禁：量化 → 质化多条件 AND
- **现状**：`game_core_2.js:506`「Boss 门禁改『历经足够劫难』：仅缘分管禁」——本质量化，战道可刷穿。
- **改为多条件 AND**（任一单轴刷满开不了）：
  ```
  gateOpen(章N) =
      历经劫难 ≥ X_N                    // 基础进度（防跳章）
    ∧ 走过 ≥3 种不同六道抉择            // 质化：逼玩家体验多道，非单刷战
    ∧ 持有本章关键法宝/线索（如 定风珠/三戏线索）
    ∧ (缘分管禁：仅「渡/缘」向章节需缘≥阈值)
  ```
- 这样战道玩家无法靠单轴农场开门禁，必须横向体验。

### 5.2 Boss 动态难度校准（防刷穿）
- **机制**：Boss 开战前按 `s` 当前战力（体攻/愿伤/血量/劫印档）做**二次难度校准**：
  - `effectiveDiff = clamp(baseDiff × playerPowerRatio, floorDiff_N, ceilDiff_N)`
  - `floorDiff_N`：本章最低难度地板（保证「难但公平」，刷穿也有下限）；
  - `ceilDiff_N`：本章上限天花板（保证「不溢出」，过度刷也不至于 impossible）。
- **现状**：无校准，固定 `diff`。需新增 `NDX.calibrateBossDiff(baseDiff, s, chapter)`。
- rationale：玩家战力比基准高 30% → Boss diff 封顶在 ceil，不让其变纸糊；低 30% → 地板保底，不让其变劝退。
