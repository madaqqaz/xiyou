## 二、学习成本的真正根因（v1.0 找错了方向）

不是"缺战法牧定位"，而是：**本命道这个概念全程不对玩家暴露**。

### 2.1 证据

**英雄卡面**（`data_heroes_data.js`）写的是机制描述，不写本命道：

```
取经人 · 愿·法伤·善念      ← 玩家看到这个
（本命道「渡」在哪？没有）
```

**唯一的本命道提示在死亡复盘里**（`data_heroes.js:112`）：

```js
flaws.push(`主走「${_domDao}」道非 ${_hn} 的本命道「${_homeDao}」
            ——同路线本命道收益 ×${NDX.HOME_DAO_MULT} 未吃满`);
```

🔴 **即：玩家死了才知道自己走错道。本命道是「事后批评」，不是「事前引导」。**

这就是学习成本的全部来源——**不是要加新分类，是要把已有的本命道从结算页搬到开局页**。

### 2.2 v1.0 的错 vs v2.0 的正

| | v1.0（错） | v2.0（正） |
|---|---|---|
| 加什么 | 新增 5 个战法牧定位（战/御/禅/猎/御兽） | **不加新分类，暴露已有的「本命道」** |
| 玩家心智 | 45 职名 → 25 组合（仍是新概念） | 45 职名 → **5 条官方路线**（概念已存在） |
| 改动量 | 中（新映射层） | **小（只是把已有信息挪到 UI）** |
| 与你的模型 | 冲突（替换） | 一致（暴露） |

## 三、三个真缺口

### 🔴 G1 · "放弃本职"没有落地

**你的原话**：「通过隐藏转职业，**放弃本职**，增加其他属性」

**代码现实**：`HIDDEN_JOBS[].effect` 全部是 `{ bonus: {...}, passive: {...} }`，
grep `penalty|代价|放弃|削弱|cost:` 在 `data_trials.js` **零命中**。

**后果**：转职 = **纯加法**。玩家走野路子时：
- 没有付出代价 → 官方路线的 ×1.25 优势被"白送属性"稀释
- 没有换来对应属性 → 野路子只是"官方路线 + 一堆数值"，**不是变种**

**修法**：给隐藏职加 `swap` 字段（只加野路子职，官方路线职不加）：

```js
// 野路子职：弃渡 → 换战
{ trial: 39, cond: '...', job: '弃经者',
  effect: { bonus: { yuan: { matk: 30 } }, passive: { mercy: 0.05 } },
  swap: { from: '渡', to: '战',
          cost: { hp: -0.10, dr: -0.05 },     // 放弃渡的气血/减伤
          gain: { atk: +0.15, cri: +0.06 },   // 换战的攻/暴
          desc: '弃渡从战：气血减伤折半，换来攻伐之锐' } }
```

玩家看到的是一句人话：**「弃渡从战：血薄了，但打得动了」**——这就是变种。

### 🟡 G2 · 变种清单不可查

你列举的变种：护盾反伤 / 护盾攻击 / 防御反击 / 反击吸血 / 暴击吸血。
代码里**都有**（`reflect` / `ward` / `drain` / `crit` 流派 + 法宝/命痕词条），
但**玩家没有一个地方能看到"我这套配置能凑出什么变种"**。

**修法**：不需要新系统，在英雄面板加一格「**变种图鉴**」：
列出当前装备 + 转职 + 经文能激活的组合，例如

```
护盾反伤  ✓ 已激活（八戒·护禅 + 缘道护盾劫 + ward-mantra 经）
反击吸血  ✗ 缺「夺」道吸血劫（可在第 X 难后获取）
```

### 🔴 G3 · 驯兽师死锁 + 随从无合成

**死锁**：`驯兽师·百兽归心`@64 门槛是「**出阵灵兽 ≥ 3**」，但宠物初始只有 **2 格**（`petSlotCapFor` base 2）。
→ 玩家**必须先解锁到 4 格**才能觉醒召唤师，而扩容途径之一是成就/逆道——**循环依赖**。

**无合成**：`FOLLOWERS` 12 条（黄风/白骨/红孩儿/灵感/蝎子/六耳/牛魔/九头…），
grep `合成|融合|merge|fuse` 在 `data_negotiate.js` **零命中**。你说"逆收的随从太多了"——**收了就只能堆着，没有消耗出口**。

## 四、驯兽师 + 随从合成设计（G3 落地方案）

### 4.1 随从合成：三阶炼化

参考《冒险日记》的"合成/升星"，解决"收太多没处用"：

| 阶 | 来源 | 效果 |
|---|---|---|
| **凡** | 谈判收服直接得 | 基础属性（现 `FOLLOWERS` 数值） |
| **灵** | **2 个同名凡** 或 **3 个异名凡** 合成 | 属性 ×1.8 + **解锁第 2 被动** |
| **真** | **2 个灵** 合成 | 属性 ×2.5 + **解锁羁绊技**（与英雄本命道共鸣 +20%） |

**关键收益**：12 个随从位不再线性堆叠 → 玩家主动"收一堆凡 → 炼一个真"，**收服行为有了目标**。

### 4.2 驯兽师：三档能力（解决死锁 + 给它真正的玩法）

| 档 | 门槛（建议改） | 能力 |
|---|---|---|
| **御兽者** | 累计收服随从 ≥3（**改：不再是"出阵"，解死锁**） | 宠物格 2→4 |
| **驯兽师·百兽归心** | 难64 + 夺 + **合成过 1 次「灵」阶随从** | 宠物格 4→**6** + 随从合成**保底成功** |
| **兽王** | 合成出 1 个「真」阶 + 6 格全满 | **随从可参与连携**：每只随从给英雄 +3% 全属性（6 只 = +18%） |

**驯兽师与六道的关系**（你说它是"不同于六道的变种"）：
驯兽师**不吃本命道 ×1.25**（它不走六道），改为吃**随从数量与阶数**——
即它是一条**平行成长线**：别人堆道命，它堆随从。这才是真正的"第六种玩法"。

### 4.3 需要你拍板的两个数

- 合成消耗比例：2 同名凡 → 1 灵（推荐）/ 3 异名凡 → 1 灵
- 驯兽师是否**完全不吃本命道加成**（推荐：不吃，走平行线）/ 仍吃夺道 ×1.25
