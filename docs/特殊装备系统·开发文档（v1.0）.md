## 一、虎皮裙系列（孙悟空专属）🐯

孙悟空的标志性装备，通过击杀虎豹类妖怪获取皮毛升级。共4个等级，升级材料均来自原著劫难。

### Lv.1 虎皮裙

| 属性 | 内容 |
|------|------|
| **获取劫难** | 第1难·双叉岭（寅将军）或第10难·黄风岭（虎先锋） |
| **获取方式** | 战路线击杀寅将军/虎先锋后剥取虎皮 |
| **装备效果** | 物理防御+10%，暴击率+5% |
| **原著依据** | 原著中孙悟空在双叉岭打死老虎，用虎皮做了裙子 |
| **描述** | 用猛虎之皮制成的战裙，虽简陋但透着野性。 |

### Lv.2 虎先锋皮裙

| 属性 | 内容 |
|------|------|
| **升级材料** | 虎先锋皮（第10难·黄风岭虎先锋） |
| **获取方式** | 战路线击杀虎先锋后剥取虎皮，与Lv.1虎皮裙合并升级 |
| **装备效果** | 物理防御+20%，暴击率+10%，速度+5% |
| **原著依据** | 虎先锋是黄风怪麾下第一先锋官，虎皮更坚韧 |
| **描述** | 加入虎先锋之皮的战裙，防御力大增，虎虎生风。 |

### Lv.3 豹纹虎皮裙

| 属性 | 内容 |
|------|------|
| **升级材料** | 艾叶花豹皮（第71难·隐雾山南山大王） |
| **获取方式** | 战路线击杀南山大王后剥取豹皮，与Lv.2虎先锋皮裙合并升级 |
| **装备效果** | 物理防御+30%，暴击率+15%，速度+10%，闪避+5% |
| **原著依据** | 南山大王是艾叶花皮豹子精，豹皮有花纹且更轻盈 |
| **描述** | 虎皮为底、豹皮为纹的战裙，攻守兼备，疾如闪电。 |

### Lv.4 百兽战裙（终极形态）

| 属性 | 内容 |
|------|------|
| **升级材料** | 青狮鬃毛+白象皮+大鹏金羽（第62-64难·狮驼岭三魔） |
| **获取方式** | 战路线连续击败青毛狮子怪、黄牙老象、大鹏金翅雕后，集齐三种材料与Lv.3豹纹虎皮裙合成终极战裙 |
| **装备效果** | 物理防御+50%，暴击率+20%，速度+15%，闪避+10%，全属性抗性+10% |
| **原著依据** | 狮驼岭三魔是兽类终极Boss，狮鬃、象皮、鹏羽集齐可成百兽之王战裙 |
| **描述** | 集狮之威、象之韧、鹏之速于一身的终极战裙，百兽辟易。 |
| **特殊被动** | 【百兽之王】：对所有兽类妖怪伤害+30% |

## 七、设计说明 📝

### 设计亮点

1. **原著依据**：所有升级材料均来自原著劫难中的妖怪，不凭空捏造
2. **升级路径清晰**：每件装备有明确的升级路径和材料来源
3. **跨章节联动**：虎皮裙的终极升级需要狮驼岭材料，形成跨章节收集目标
4. **专属装备**：悟空、八戒、沙僧、唐僧各有专属装备，角色差异化
5. **终极形态有特殊被动**：每件装备的终极形态都有独特的被动技能

### 虎皮裙升级说明

- **Lv.1→Lv.2**：双叉岭寅将军（第1难）或黄风岭虎先锋（第10难）获取虎皮
- **Lv.2→Lv.3**：隐雾山南山大王（第71难）获取豹皮
- **Lv.3→Lv.4**：狮驼岭三魔（第62-64难）集齐狮鬃、象皮、鹏羽合成百兽战裙

**注意**：狮驼岭（第62-64难）在隐雾山（第71难）之前，所以玩家在到达隐雾山时已经可以获取狮驼岭材料，但需要先到达隐雾山升级到Lv.3后才能合成Lv.4。这形成了"先收集材料，后合成终极"的收集乐趣。

### 设计原则

1. 特殊装备升级材料必须来自原著劫难
2. 每件装备最多升级3次（4个形态），避免过度膨胀
3. 终极形态必须有独特的被动技能
4. 升级材料可以跨章节获取，形成收集目标
5. 专属装备与角色特点匹配（悟空=虎皮裙暴击、八戒=九齿钉耙破甲、沙僧=降妖宝杖水系、唐僧=锦襕袈裟防御回复）
