## 一、音效系统现状

### 1.1 音效系统架构

游戏音效系统采用三层架构：

1. **基础音效层**（sound.js）
   - Web Audio API 即时合成
   - 音频文件播放（MP3/OGG/WAV）
   - 文件格式自动回退（wav→mp3→ogg）
   - 程序化合成兜底（文件缺失时自动使用合成音效）

2. **自适应音频层**（ndx_audio_engine.js + ndx_audio_config.js + ndx_audio_bridge.js）
   - 区域音景自适应（17个区域）
   - 战斗强度动态调节
   - 六道试炼音景映射
   - Boss战强制音景

3. **Boss技能音效层**（boss_skill_audio.js）
   - Boss专属技能音效
   - 技能配音
   - 战斗音效增强

### 1.3 音效系统特性

1. **文件格式自动回退**
   - 优先使用WAV格式
   - WAV缺失时回退到MP3
   - MP3缺失时回退到OGG
   - 全部缺失时使用Web Audio程序化合成

2. **独立音量控制**
   - BGM音量（默认0.7）
   - 音效音量（默认0.8）
   - 环境音音量（默认0.5）
   - 主音量（默认0.5）

3. **静音记忆**
   - 静音偏好保存到localStorage
   - 跨周目记忆
   - 恢复静音时自动重启当前场景BGM

4. **浏览器策略兼容**
   - 首次用户手势才创建AudioContext
   - 自动播放失败时静默处理
   - 支持现代浏览器自动播放策略

## 三、音效系统使用说明

### 3.1 基础音效播放

```javascript
// 播放音效
NDX.sound.play('click');      // UI点击
NDX.sound.play('attack');     // 攻击
NDX.sound.play('hit');        // 受击
NDX.sound.play('crit');       // 暴击
NDX.sound.play('victory');    // 胜利
NDX.sound.play('defeat');     // 失败
```

### 3.2 BGM播放

```javascript
// 播放BGM
NDX.sound.music('title');     // 主界面
NDX.sound.music('map');       // 地图
NDX.sound.music('fight');     // 战斗
NDX.sound.music('boss');      // Boss战
NDX.sound.music('home');      // 长安
NDX.sound.music('none');      // 停止BGM
```

### 3.3 环境音播放

```javascript
// 播放环境音
NDX.sound.ambient('wind');    // 风声
NDX.sound.ambient('rain');    // 雨声
NDX.sound.ambient('bell');    // 钟声
NDX.sound.ambient('fire');    // 火焰
NDX.sound.ambient('water');   // 水流
NDX.sound.ambient('bird');    // 鸟鸣
NDX.sound.ambient('none');    // 停止环境音
```

### 3.4 音量控制

```javascript
// 设置音量
NDX.sound.setBgmVolume(0.7);      // 设置BGM音量
NDX.sound.setSfxVolume(0.8);      // 设置音效音量
NDX.sound.setAmbientVolume(0.5);  // 设置环境音音量

// 获取音量
const bgmVol = NDX.sound.getBgmVolume();
const sfxVol = NDX.sound.getSfxVolume();
const ambientVol = NDX.sound.getAmbientVolume();

// 静音切换
NDX.sound.toggle();  // 切换静音状态
```

### 3.5 初始化

```javascript
// 首次用户手势后初始化
document.addEventListener('click', function initAudio() {
  NDX.sound.init();
  document.removeEventListener('click', initAudio);
}, { once: true });
```
