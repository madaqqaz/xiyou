# 《逆道西行》短局模式设计方案

> 成文：2026-09-09｜基线：V8.58，`TOTAL_TRIALS = 81`，17 地区（实测）
> 配套：《逆道西行_数值模型与调参手册_2026-09-09.md》《逆道西行_全景综合分析与开发规划_2026-09-09.md》

---

## 0. 问题：这是一条战略级错配，不是「偏长」

| | 本作 | 2026 微信小游戏赛道主流 | 倍数 |
|---|---|---|---|
| 单局时长 | **8–12 小时**（81 难 × 5–8 分钟） | **3–5 分钟** | **约 100×** |

**这不是「偏长」，是跨数量级。** 参考《无限轮回》——3 天冲进畅销榜 Top10 并稳居 Top8，其单局被严格压缩在 3–5 分钟。

后果（按严重度排序）：

1. **小游戏端留存塌方**：小游戏是「碎片时间 + 广告变现」模型，8 小时单局意味着玩家 3 天内几乎不可能获得一次完整「通关反馈」，而**完整反馈正是肉鸽的核心多巴胺**。
2. **首日流失**：新手看到进度条 1/81，认知负荷直接劝退。
3. **广告点位失效**：激励视频依赖「单局结束」节点，8 小时一局 = 广告点位近乎不存在。
4. **传播链断裂**：小游戏靠分享拉新，没人会分享一个「我玩了 6 小时还没打完」的游戏。

**但——长局本身不是原罪。** TapTap 买断端玩家恰恰期待「史诗长跑」。
**正解不是砍短，是分端。**

---

## 1. 核心策略：三端分策，而非一刀切

| 端 | 单局目标 | 策略 | 内容完整性 |
|---|---|---|---|
| **微信小游戏** | **4–6 分钟** | 短局模式（本方案主体） | 单地区切片，进度跨局共享 |
| **浏览器 H5** | 15–25 分钟 | 中段模式（3 地区一章） | 章节制 |
| **TapTap 买断** | **8–12 小时**（保持） | 完整模式 | 81 难全量，不变 |

**关键洞察**：三端共用**同一套内容**，差异只在**切片粒度与进度共享规则**。
这意味着短局模式**不是做减法，而是换一种游标方式遍历同一份内容** —— 成本远低于「另做一套小游戏」。

## 2. 短局模式规格

### 2.1 切片规则（核心）

```
地区数 = 17，总难 = 81，平均每地区 4.76 难

短局单元 = 1 个地区切片（约 4–6 难）
  ├─ 固定骨架：3 战斗 + 1 事件 + 1 精英/Boss（尾难必为 Boss）
  ├─ 目标时长：4–6 分钟
  └─ 结算：完成即触发「地区结算屏」（成就 / 进度 / 排行）
```

**切片选取算法**：

```js
// 伪码：短局 = 从当前「章节游标」取一个地区
function buildShortRun(progress) {
  const act = progress.currentAct;            // 1..17
  const scale = NDX.DIFFICULTY[progress.difficulty];
  const nodes = [];
  nodes.push({ kind: 'fight',  tier: 'mob'   });
  nodes.push({ kind: 'trial',  pool: eventsForAct(act) });   // 161 事件中按 region 抽
  nodes.push({ kind: 'fight',  tier: 'mob'   });
  nodes.push({ kind: 'rest'  });              // 或 shop（提升商店占比，见 §4）
  nodes.push({ kind: 'boss',  act });         // 尾难 = 该地区 Boss（M13 有专属动机）
  return nodes;
}
```

**为什么尾难必为 Boss**：
- 提供**明确的短局高潮与结束信号**（4–6 分钟一次完整情绪弧线）；
- 复用已落地的 **M13 17 关隘 Boss 动机变体**，每个地区音乐可辨 —— 短局玩家能在 5 分钟内听到一个完整「专属 Boss 动机」，这正是长局做不到的密度优势；
- 天然广告点位。

### 2.2 进度共享（跨局元进度）

这是短局模式的**灵魂**——没有它，短局只是「把长局切成垃圾碎片」。

```
局内（run-scoped，每局重置）
  ├─ HP / 当前构筑 / 临时 buff / 金币
  └─ 本地区内节点选择

局外（meta-scoped，跨局累积）★ 新增
  ├─ 已通关地区集合  → 解锁下一地区
  ├─ 已收集经文 / 残片 → 图鉴进度
  ├─ 劫印层阶        → 永久属性
  ├─ 元货币（骨灰）  → 解锁初始构筑 / 起始难度
  └─ 地区最佳成绩    → 排行榜
```

**每局结束必须产生至少 1 个 meta 收益**，哪怕失败：
- 胜利：解锁下一地区 + 元货币 + 图鉴条目
- 失败：元货币（按推进难数折算）+ 图鉴条目

> 设计铁律：**失败也必须有收益。** 这是《杀戮尖塔》《吸血鬼幸存者》验证过的留存引擎。

### 2.3 断点续玩

现状实测：`NDX.SaveSystem` 已提供原子存取（`load/save/loadString/saveString/loadNumber/saveNumber/loadBoolean`），但**未见全局 `autosave`/`saveGame` 入口**。

**最小改造（P0）**：

```js
// 建议挂载点：每个节点结算后
NDX.SaveSystem.save(NDX.SaveSystem.SAVE_KEYS.RUN, JSON.stringify({
  act, nodeIndex, hp, build, gold, ts: Date.now()
}));

// 启动检测
if (NDX.SaveSystem.exists(NDX.SaveSystem.SAVE_KEYS.RUN)) {
  showContinueDialog();   // 「继续上次（第 N 难）」/「重新开始」
}
```

**小游戏端额外要求**：微信可随时被切走（来电、微信消息），**必须**在每个节点结束时落盘，不能依赖「玩家点保存」。

## 3. 三端差异化落地

### 3.1 微信小游戏端（P0，最高优先级）

| 项 | 规格 |
|---|---|
| 单局 | 4–6 分钟（1 地区 5 节点） |
| 会话 | 支持随时切走，回来从当前节点续玩 |
| 新手 | 前 3 局强制低难度（`pressureFactor` 0.42），保证首胜 |
| 广告 | 地区结算屏后激励视频（复活 / 双倍元货币） |
| 分享 | 地区结算生成战绩卡片（第 N 地区 / 用时 / 评级） |

### 3.2 浏览器 H5 端（P1）

15–25 分钟 = 3 地区一章，共约 6 章。保留完整构筑成长弧线。

### 3.3 TapTap 买断端（P2，保持现状）

8–12 小时完整 81 难。**不要动** —— 买断玩家买的就是这个。
短局模式的进度共享层可**可选开启**（作为「休闲档」），但默认关闭。

## 4. 与既有问题的协同（一次改造解多个根因）

短局模式不是孤立功能，它天然修复主报告里的几处根因：

| 根因 | 短局模式如何修复 |
|---|---|
| **B. 单向经济无回收**（商店节点仅 0.2%） | 短局骨架固定含 1 个 `rest/shop` 节点 → 商店占比从 0.2% 跃升至 **20%** |
| **C. 感知层缺失**（成长看不见） | 每局结算屏强制展示「本局 vs 上局」属性对比 → 成长刻度面板的最小可用版 |
| **D. 孤儿系统**（`Exploration` / `LoopEnhance` 外部引用 0） | `LoopEnhance`（多层循环强化）正是**为跨局元进度而生** → 直接成为短局的 meta 层宿主，一个改动既接活孤儿系统又补上 meta 层 |
| 单局时长错配 | 直接解决 |

> **强烈建议**：短局模式的 meta 层**直接建在 `LoopEnhance` 之上**，而不是新造一套。
> 这是本方案最高性价比的一笔——原本要「决定孤儿系统是删是留」，现在答案明确：**接入，且它是短局模式的地基**。

## 5. 音频侧的短局适配（本 Expert 视角）

短局化对音频提出**全新且有利**的要求：

1. **音乐必须在 4–6 分钟内完成一次完整弧线**
   - 现有 M15 长曲式为 8 小节 A→B→A'→C ≈ 20 秒一轮，短局内可跑 12–18 轮，**密度刚好**；
   - 建议短局端把 `_formSection` 加速（BPM 96 → 108），让一次短局听到更完整的曲式发展。

2. **Boss 动机变体（M13）价值被放大**
   - 长局里 17 个 Boss 动机分散在 8 小时内，玩家记不住；
   - 短局里每 5 分钟一个专属动机 → **每个地区的听觉身份真正成立**。

3. **结算音必须有仪式感**
   - 短局每 5 分钟一次结算，结算音会高频出现；
   - 现有 `victory/defeat` 合成音效偏单薄，建议加一层「渡/逆分支结算动机」（渡=上行明亮，逆=下行沉重），让每次结算都在强化六道叙事。

4. **切走/回来恢复**
   - `visibilitychange` 已处理，但短局端需在恢复时**淡入**而非硬切（避免微信切回时爆音）。

## 6. 实施计划

### 阶段 S1（1–2 周）· 短局骨架 — **P0 — ✅ 已落地（2026-09-09）**

> **落地说明（含一处设计修正）**：原计划写「新增 `NDX.SHORT_RUN` 配置 + 实现 `buildShortRun(progress)` 复用节点生成器」。
> 实际取证后发现**不必新建生成器**——本作地图本就是**地区段结构**（`_buildRegionSegment(act, off)`，
> 每段 `1..actLayers(act)` 层，**末层天然就是地区关隘 Boss**）。因此短局 = 「只跑一段」，
> 直接复用既有段落生成，无需 `buildShortRun`，也无需额外强制尾难 Boss（地区末难本就是 Boss）。
> 这是「前提三查」省下的一次重复实现。

**已交付：**

- [x] 新增 `js/data_runmode.js` — `NDX.RunMode` 模块（取代原计划的 `NDX.SHORT_RUN`）
      - 模式表 `full` / `short`；短局规格 `SHORT_SPEC`（地区数 / 起始地区 / 加速 / 不进榜）
      - `startAct()` 支持 `'random'`（重玩性：随机从 17 地区之一开局）或指定地区
      - `endAct()` / `shouldFinish(s)` 终局判定；`applyToState(s)` 新局应用
      - `fightGate()` 短局下**全部即时解锁**自动战斗 / 2x / 3x / 跳过
      - `recordClear()` meta 进度，并同步落一份到 `NDX.Exploration`（孤儿系统复用）
      - 存储走 `NDX.SaveSystem` → `localStorage` → 内存三级兜底，`file://` 安全
- [x] `js/game/game_region.js` — `chooseBossReward()` 终局判定前插入短局分支（**本次唯一一处既有代码改动**）
- [x] `index.html` — 挂载 `js/data_runmode.js`（`data_region_config.js` 之后、`game_region.js` 之前）
- [x] `scripts/validate_runmode.js` — 门禁 **35 通过 / 0 失败**

**核心设计决策：短局不复用完整局终局流程**

完整局终局要走「返程三步 → 排行榜 → 二周目论道 → 引渡匣承继 → 朝代重置」，
那套流程的前提是走完八十一难；短局只有 4~5 难，套上去只会算出荒谬的余寿与名次。
故短局走轻量结算：

```js
s.over = {
  win: true,
  reason: `短局功成 · ${地区名}关隘已破（第 ${actEnd(act)} 难）`,
  shortRun: true,
  ending: { title: '功成身退', text: `此局西行止于${地区名}——关隘已破，因果暂了，来日再启长途。` },
};
s.pending = { kind: 'gameover' };
```

**未做（属 S2/S3）**：地区结算屏分享卡片、节点级 autosave、UI 模式选择入口。
当前可用控制台切换：`NDX.RunMode.set('short', { startAct: 'random' })`，
`NDX.RunMode.diagnostics()` 查看当前配置。

- **验收**：（门禁已覆盖判定逻辑与零影响）单局时长与续玩仍需实机测量

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 短局让「史诗感」流失 | 买断端玩家不满 | **TapTap 端保持 `full` 默认**，短局仅小游戏/H5 |
| meta 层与现有 `DEATH_UNLOCKS`/`ASH_SHOP` 冲突 | 经济重复 | meta 货币统一走骨灰（`ASH_SHOP` 已存在），不新增币种 |
| 切片后事件池不足（161 事件 / 17 地区 ≈ 9.5 条/地区） | 重复感 | 优先补**通用事件**（当前通用占比已高，可直接跨地区复用） |
| 排行榜作弊 | 公平性 | 小游戏端走微信开放数据域，服务端校验关键字段 |
| 进度共享削弱「一命通关」的紧张感 | 核心体验稀释 | 短局端明确标注「休闲档」，完整档（一命 81 难）作为独立模式保留并主推 |

## 9. 一句话结论

**内容不用砍，换一种游标遍历它。**
短局模式 = 把 81 难切成 17 个 5 分钟地区切片 + 跨局 meta 进度（`LoopEnhance` 承接），
一次改造同时解决**时长错配 / 孤儿系统 / 经济无回收 / 成长不可见**四个根因，
且让已投入的 **M13 十七 Boss 动机** 与 **M15 长曲式** 在短局里获得远高于长局的感知密度。
