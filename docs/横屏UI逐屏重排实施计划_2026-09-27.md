# 横屏 UI 逐屏重排 · 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以 CDP 真渲染取证驱动，在 `.ndx-short-landscape` 类门控体系内对 26 屏逐屏重排横屏 UI（字号/间距/堆叠/热区），达成真实横屏态 P1=0、P2=0、全部可点元素 ≥36px。

**Architecture:** 保持 `index.html` 内联门控为唯一门槛真源、`css/mobile-landscape.css` 为横屏微调唯一 owner；审计工具扩展真实横屏视口与新场景跳屏（`enterNode` 状态驱动，零游戏代码改动）；热区门禁脚本化为 `_verify_landscape_hotzone.js` 并入跑批总入口。

**Tech Stack:** 原生 CSS + Node（CommonJS、零依赖）+ Edge headless CDP（内置 WebSocket）。

**Spec:** `docs/横屏UI逐屏重排设计与验收方案_V1.0.md`（缺陷分级、重排红线、视口矩阵、边界文件均以该 spec 为准；本计划逐 Task 引用其章节）

## Global Constraints

- 零第三方依赖、无构建步骤；不引入框架/TS/引擎（AGENTS §一）。
- 禁止触碰 `js/**`、`platform/**`、`capacitor.config.json`（spec §六）；取证发现必须改 JS 才能闭合的缺陷 → 停止并报告用户。
- `css/mobile-landscape.css` 全部规则以 `html.ndx-short-landscape`（或文件尾 `body.ndx-rotated` / 大屏块 `html.ndx-wide-landscape`）起头；不给该文件加 media 属性门槛（既有文件头注释纪律）。
- 热区红线：可点元素实测 `getBoundingClientRect()` 宽高均 ≥36px；战斗主操作 ≥44px（spec §四.2）。
- 字号阶梯：窄横屏仅允许 11/13/16/18px 四档显示字号 + 12px HUD 特例；同屏出现第 6 种杂散字号即为缺陷（spec §四.1，实测基线在 Task 3 定档）。
- 旋转伪横屏态禁止新增 vh/vw 依赖（spec §四.4）。
- 每改 `css/*.css` 或 `js/*.js` 必须递增 `index.html` 对应 `?v=`（当前基线：`style.css?v=161`、`mobile-landscape.css?v=172`）。
- 生成物不提交：`scripts/_audit_shots/**`（已入 `.gitignore`）、`.tmp/**`。
- git 提交按项目「手动确认规范」：每个 Task 的 commit 步骤在会话检查点获得用户确认后才执行；禁止 `git add .`，只 stage 本 Task 文件。
- P1 阻断当批收掉，不得降级；无关优化不入本轮（spec §七）。

- [ ] **Step 3: main() 场景循环改造（cleanExpr 之后按 prep/query 分支 + 每屏采集热区）**

场景表达式由现有 flag 二分支改为三分支（flag / prep / query 场景则在视口循环开始时用 `ROOT_URL + sc.query` 重新 navigate 一次并复用 init 流程）；每次渲染后、截图前插入热区采集：

```js
const HOTZONE_EXPR = `(function(){var min=36;var sel='a,button,[data-action],.opt-btn,.node,.cell,.bag-cell,.dock-chip,.jing-pick,.rub-sutra,.shop-reroll,.treasure-btn,.skill-btn,.fab-btn';var out=[];
  document.querySelectorAll(sel).forEach(function(el){var st=getComputedStyle(el);
    if(st.display==='none'||st.visibility==='hidden'||parseFloat(st.opacity)<0.05)return;
    var r=el.getBoundingClientRect();if(r.width<=0||r.height<=0)return;
    if(r.bottom<0||r.top>innerHeight||r.right<0||r.left>innerWidth)return;
    if(r.height<min||r.width<min)out.push({t:el.tagName,c:String(el.className).slice(0,60),a:el.getAttribute('data-action')||'',w:Math.round(r.width),h:Math.round(r.height)});});
  return JSON.stringify(out);})()`;
// 场景循环内：
const hz = await cdp.send('Runtime.evaluate', { expression: HOTZONE_EXPR, returnByValue: true });
const viol = hz && hz.result && hz.result.value ? JSON.parse(hz.result.value) : [];
(summary[vp.name] = summary[vp.name] || {})[sc.screen] = viol;
if (viol.length) console.log('  [热区] ' + sc.screen + ': ' + viol.length + ' 处 <36px');
```

### Task 2: 热区门禁脚本 `_verify_landscape_hotzone.js`（先红后绿）

**Files:**
- Create: `scripts/_verify_landscape_hotzone.js`
- Test: 自身即门禁；由 `scripts/_run_all_gates.js` 自动发现（命名匹配 `_verify_*`）

**Interfaces:**
- Consumes: Task 1 的 `--hotzone-only` CLI 与 `hotzone_summary.json`
- Produces: 退出码 0=全达标 / 1=违规；stdout 末行 `HOTZONE PASS (violations=0)` 或 `HOTZONE FAIL (violations=N) · worst: <tag.class WxH>`

- [ ] **Step 1: 写门禁脚本（全文如下）**

```js
#!/usr/bin/env node
'use strict';
/* _verify_landscape_hotzone.js — 真实横屏(844×390)可点元素热区门禁
 * 依据: docs/横屏UI逐屏重排设计与验收方案_V1.0.md §四.2（热区红线 ≥36px）
 * 依赖本机 Edge（同 _tool_landscape_cdp.js）；无法启动浏览器时跳过并退出 0（打印 SKIP）。 */
const { spawnSync } = require('child_process');
const fs = require('fs');
const path = require('path');
const tool = path.join(__dirname, '_tool_landscape_cdp.js');
const summaryFile = path.join(__dirname, '_audit_shots', 'hotzone_summary.json');
try { fs.unlinkSync(summaryFile); } catch (e) {}
const r = spawnSync(process.execPath, [tool, 'file', '--hotzone-only'], { encoding: 'utf8', timeout: 420000 });
if (!fs.existsSync(summaryFile)) { console.log('HOTZONE SKIP (browser unavailable): ' + (r.stderr || '').slice(0, 200)); process.exit(0); }
const summary = JSON.parse(fs.readFileSync(summaryFile, 'utf8'));
let total = 0, worst = null;
for (const vp of Object.keys(summary)) for (const sc of Object.keys(summary[vp])) {
  for (const v of summary[vp][sc]) { total++; if (!worst || v.w * v.h < worst.w * worst.h) worst = Object.assign({ screen: sc }, v); }
}
if (total === 0) { console.log('HOTZONE PASS (violations=0)'); process.exit(0); }
console.log('HOTZONE FAIL (violations=' + total + ') · worst: ' + worst.t + '.' + worst.c + ' ' + worst.w + 'x' + worst.h + ' @' + worst.screen);
process.exit(1);
```

Run: `node scripts/_verify_landscape_hotzone.js`
Expected: `HOTZONE FAIL (violations=N)`，N≥1 且含 `.jing-pick`/`.rub-sutra` 条目（与 Task 1 Step 4 计数一致）。若 SKIP（Edge 路径变化），先修 Task 1 的 `EDGE` 常量再回来。
