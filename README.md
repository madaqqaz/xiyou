# 逆道西行

> 黑暗西游 · 单局 Roguelike 肉鸽构筑

## 游戏简介

《逆道西行》是一款黑暗西游题材的单局Roguelike肉鸽构筑游戏。玩家扮演金蝉子，在八十一难中逆道而行，通过六道抉择、劫印构筑、装备收集、法宝搭配，打造独一无二的Build，挑战灵山真相。

### 核心特色

- **六道抉择系统**：渡/战/缘/夺/隐/逆，每一次选择都影响Build方向
- **劫印构筑**：同道途劫印叠加，形成流派（诵经流/爆发流/闪避流等）
- **地区配额制**：借鉴万世剑冢，必须满足配额才能挑战地区Boss
- **朝代轮回**：十世金蝉子，每一代遗产保留，唐朝为终点
- **隐藏转职**：6+隐藏职业，需特定条件触发，运气与策略并重
- **八十一难**：完整还原西游劫难，每难有独特剧情和抉择

## 技术栈

- **纯前端H5**：HTML + CSS + 原生JavaScript
- **零依赖**：无第三方运行时依赖，无构建步骤
- **PWA支持**：可添加到主屏幕，离线可用，自动更新
- **三端同步**：浏览器H5 + 微信小游戏 + TapTap买断版

## 快速开始

### 本地运行

```bash
# 方法1：Python
python -m http.server 8080
# 访问 http://localhost:8080

# 方法2：Node.js
npx http-server -p 8080
# 访问 http://localhost:8080

# 方法3：直接双击
# 浏览器直接打开 index.html（部分功能可能受限）
```

### PWA部署

1. 将本仓库部署到支持HTTPS的静态托管（GitHub Pages / Vercel / Netlify）
2. 手机浏览器打开游戏网址
3. 菜单 → "添加到主屏幕"
4. 点击桌面图标，全屏玩游戏

详细部署步骤见 [PWA_DEPLOY_GUIDE.md](PWA_DEPLOY_GUIDE.md)

## 游戏系统

### 英雄（5位）
- **唐僧**：均衡型，诵经法伤
- **悟空**：爆发型，高攻击高暴击
- **八戒**：坦克型，高气血反伤
- **沙僧**：防御型，护盾格挡
- **小白龙**：敏捷型，闪避连击

### 六道
- **渡**：慈悲顺命，法伤+诵经
- **战**：以力破局，物攻+爆发
- **缘**：结缘众生，辅助+治疗
- **夺**：贪婪掠夺，吸血+资源
- **隐**：避世隐匿，闪避+暴击
- **逆**：叛道逆天，心魔+强力

### 地区（17个）
长安 → 两界山 → 黄风岭 → 流沙河 → 五庄观 → 火云洞 → 车迟国 → 通天河 → 女儿国 → 真假美猴王 → 火焰山 → 祭赛国 → 比丘国 → 天竺玉兔 → 灵山 → 凌云渡 → 西天
